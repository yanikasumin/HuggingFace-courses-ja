## ローカル及びリモートのデータセットを扱う[[working-with-local-and-remote-datasets]]

Datasets には、ローカル及びリモートのデータセットを読み込む為のローディングスクリプトが用意されています。対応する主なデータ形式は、次の通りです。

|    データ形式     | ローディングスクリプト |                         例                         |
| :----------------: | :------------: | :-----------------------------------------------------: |
|     CSV & TSV      |     `csv`      |     `load_dataset("csv", data_files="my_file.csv")`     |
|     テキストファイル     |     `text`     |    `load_dataset("text", data_files="my_file.txt")`     |
| JSON & JSON Lines  |     `json`     |   `load_dataset("json", data_files="my_file.jsonl")`    |
| Pickle 化された DataFrame |    `pandas`    | `load_dataset("pandas", data_files="my_dataframe.pkl")` |

表の通り、どの形式でも指定方法は同じです。`load_dataset()` に、形式に対応するローディングスクリプトの名前と、1つ以上のファイルのパスを示す `data_files` 引数を渡します。まず、ローカルファイルからの読み込みを説明します。リモートファイルからの読み込みは、その後で説明します。

## ローカルデータセットの読み込み[[loading-a-local-dataset]]

この例では、イタリア語の質問応答用の大規模データセットである [SQuAD-it データセット](https://github.com/crux82/squad-it/) を使います。

訓練用とテスト用の分割（split）は GitHub 上に置かれています。次の `wget` コマンドでダウンロード出来ます。

```python
!wget https://github.com/crux82/squad-it/raw/master/SQuAD_it-train.json.gz
!wget https://github.com/crux82/squad-it/raw/master/SQuAD_it-test.json.gz
```

このコマンドで、*SQuAD_it-train.json.gz* と *SQuAD_it-test.json.gz* の2つの圧縮ファイルがダウンロードされます。次に、Linux の `gzip` コマンドで解凍します。

```python
!gzip -dkv SQuAD_it-*.json.gz
```

```bash
SQuAD_it-test.json.gz:	   87.4% -- replaced with SQuAD_it-test.json
SQuAD_it-train.json.gz:	   82.2% -- replaced with SQuAD_it-train.json
```

圧縮ファイルは _SQuAD_it-train.json_ と _SQuAD_it-test.json_ に解凍されます。データの保存形式は JSON です。

> [!TIP]
> シェルコマンドの先頭にある `!` は、Jupyter ノートブックの中で実行する為の記号です。ターミナルでダウンロードと解凍を行う場合は、この記号を付けずに実行してください。

JSON ファイルを `load_dataset()` で読み込む際は、形式の区別が重要です。通常の JSON（ネストした辞書のような形式）か、JSON Lines（行ごとに区切られた JSON）かで、指定方法が変わります。SQuAD-it は、多くの質問応答データセットと同じネスト形式です。全てのテキストは `data` フィールドに格納されています。その為、次のように `field` 引数を指定します。

```py
from datasets import load_dataset

squad_it_dataset = load_dataset("json", data_files="SQuAD_it-train.json", field="data")
```

ローカルファイルを読み込むと、既定では `train` 分割だけを持つ `DatasetDict` オブジェクトが作られます。作られた `squad_it_dataset` オブジェクトは、次の通りです。

```py
squad_it_dataset
```

```python out
DatasetDict({
    train: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 442
    })
})
```

表示されるのは、訓練セットの行数と列名です。例を1つ見るには、次のように `train` 分割の先頭の要素にアクセスします。

```py
squad_it_dataset["train"][0]
```

```python out
{
    "title": "Terremoto del Sichuan del 2008",
    "paragraphs": [
        {
            "context": "Il terremoto del Sichuan del 2008 o il terremoto...",
            "qas": [
                {
                    "answers": [{"answer_start": 29, "text": "2008"}],
                    "id": "56cdca7862d2951400fa6826",
                    "question": "In quale anno si è verificato il terremoto nel Sichuan?",
                },
                ...
            ],
        },
        ...
    ],
}
```

（サンプル文の訳：タイトルは「2008年の四川大地震」です。質問は「四川で地震が発生したのは何年ですか？」です。文脈は「2008年の四川大地震、又は地震…」という途中までが示されています）

これで、ローカルデータセットを読み込めました！但し、読み込めたのは訓練セットだけです。次は、`train` と `test` の両方を1つの `DatasetDict` オブジェクトに入れます。両方を入れておけば、`Dataset.map()` を両方の分割にまとめて適用出来ます。その為には、`data_files` 引数に、分割名とファイル名を対応付けた辞書を渡します。

```py
data_files = {"train": "SQuAD_it-train.json", "test": "SQuAD_it-test.json"}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
squad_it_dataset
```

```python out
DatasetDict({
    train: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 442
    })
    test: Dataset({
        features: ['title', 'paragraphs'],
        num_rows: 48
    })
})
```

求めていた形になりました。これで、データのクリーニングやレビューのトークナイズなど、様々な前処理を適用出来ます。

> [!TIP]
> `load_dataset()` 関数の `data_files` 引数には、柔軟な指定方法があります。単一のファイルパス、ファイルパスのリスト、分割名とファイルパスを対応づける辞書のいずれかを渡せます。Unix シェルの規則に従ったワイルドカードパターンで、条件に一致する複数のファイルを指定することも出来ます。例えば、`data_files="*.json"` と指定すると、ディレクトリ内の全ての JSON ファイルを1つの分割として読み込みます。詳細は Datasets の[ドキュメント](https://huggingface.co/docs/datasets/loading#local-and-remote-files)を参照してください。

ローディングスクリプトには、入力ファイルを自動で解凍する機能もあります。`data_files` 引数に圧縮ファイルを直接指定すれば、`gzip` による解凍は不要でした。

```py
data_files = {"train": "SQuAD_it-train.json.gz", "test": "SQuAD_it-test.json.gz"}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
```

GZIP ファイルが多数ある場合に、手作業で解凍する必要がなくなります。自動解凍は ZIP や TAR など他の一般的な形式にも対応します。どの形式でも、`data_files` に圧縮ファイルを指定するだけで済みます！

ローカルファイルの読み込みは以上です。次に、リモートファイルの読み込みを説明します。

## リモートデータセットの読み込み[[loading-a-remote-dataset]]

会社で働いている場合、分析対象のデータセットがリモートサーバーに保存されていることは珍しくありません。リモートファイルの読み込み手順は、ローカルファイルの場合とほぼ同じです。違いは、`load_dataset()` の `data_files` 引数に、ローカルファイルのパスではなく、リモートファイルの URL を1つ以上指定する点です。例えば、GitHub 上の SQuAD-it データセットでは、次のように `data_files` に _SQuAD_it-*.json.gz_ の URL を指定します。

```py
url = "https://github.com/crux82/squad-it/raw/master/"
data_files = {
    "train": url + "SQuAD_it-train.json.gz",
    "test": url + "SQuAD_it-test.json.gz",
}
squad_it_dataset = load_dataset("json", data_files=data_files, field="data")
```

返ってくるのは、上で得たものと同じ `DatasetDict` オブジェクトです。但し、_SQuAD_it-*.json.gz_ ファイルを手作業でダウンロードして解凍する手間は省けます。以上が、Hugging Face Hub に置かれていないデータセットの読み込み方法です。次は、読み込んだデータセットを使って、様々なデータ加工の方法を試します。

> [!TIP]
> **やってみよう！** GitHub や [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/index.php) で公開されているデータセットの中から別のものを選び、ここで紹介した方法で、ローカルとリモートの両方から読み込んでみてください。追加の課題として、CSV 形式やテキスト形式で保存されたデータセットの読み込みにも挑戦してみてください（各形式の詳細は[ドキュメント](https://huggingface.co/docs/datasets/loading#local-and-remote-files)を参照してください）。
