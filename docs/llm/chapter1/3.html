Transformer は何が出来るのか？

このセクションでは、Transformer モデルに何が出来るのかを見ていきます。併せて、🤗 Transformers ライブラリの最初のツールである pipeline() 関数を使います。

Transformer はあらゆる所に

Transformer モデルは、自然言語処理（NLP）、コンピュータビジョン、音声処理など、様々なモダリティにわたるあらゆる種類のタスクを解く為に使われています。Hugging Face と Transformer モデルを使っている企業や組織の中には、自社のモデルを共有してコミュニティに貢献している所もあります。例えば、次の企業・組織です。

🤗 Transformers ライブラリは、そうした共有モデルを作成し、利用する為の機能を提供します。Model Hubには、誰でもダウンロードして使える事前学習済みモデルが数百万も集まっています。自分のモデルを Hub にアップロードすることも出来ます。

💡 ヒント

⚠️ Hugging Face Hub は Transformer モデルだけに限られません。誰でも、好きな種類のモデルやデータセットを共有出来ます。全ての機能を使うには、huggingface.co アカウントを作成しましょう。

Transformer モデルの内部の仕組みに入る前に、興味深い NLP の問題を解く為にどう使えるのか、いくつか例を見てみましょう。

パイプラインを使う

🤗 Transformers ライブラリで最も基本的なオブジェクトが、pipeline() 関数です。モデルに必要な前処理と後処理のステップをモデルとつなぐ役割を持ち、任意のテキストを直接入力して、分かり易い答えを得られます。

from transformers import pipeline

classifier = pipeline("sentiment-analysis")
classifier("I've been waiting for a HuggingFace course my whole life.")

（入力文の訳：ずっと Hugging Face のコースを待ち望んでいました）

```python out [{'label': 'POSITIVE', 'score': 0.9598047137260437}]

複数の文を渡すことも出来ます。

```python
classifier(
    ["I've been waiting for a HuggingFace course my whole life.", "I hate this so much!"]
)

（追加された文の訳：これは本当に大嫌いです！）

```python out [{'label': 'POSITIVE', 'score': 0.9598047137260437}, {'label': 'NEGATIVE', 'score': 0.9994558095932007}]

既定では、このパイプラインは英語の感情分析向けにファインチューニングされた特定の事前学習済みモデルを選びます。モデルは、`classifier` オブジェクトを作成した時にダウンロードされ、キャッシュされます。コマンドを再実行した場合は、キャッシュされたモデルが使われる為、改めてダウンロードする必要はありません。

テキストをパイプラインに渡すと、主に次の3つのステップが行われます。

1. テキストが、モデルが理解出来る形式に前処理されます。
2. 前処理された入力が、モデルに渡されます。
3. モデルの予測が後処理され、人間が意味を読み取れる形になります。

`pipeline()` 関数は複数のモダリティに対応しており、テキスト、画像、音声、更にはマルチモーダルなタスクにも使えます。このコースではテキストのタスクに焦点を当てますが、Transformer アーキテクチャの可能性を理解する助けになる為、ここで概要を簡単に紹介します。

利用出来るものの一覧は次の通りです。

### テキストパイプライン

- `text-generation`：プロンプトからテキストを生成する
- `text-classification`：テキストを予め定義したカテゴリに分類する
- `summarization`：重要な情報を保ちながら、テキストをより短い文にまとめる
- `translation`：テキストを或る言語から別の言語に翻訳する
- `zero-shot-classification`：特定のラベルで事前に学習することなく、テキストを分類する
- `feature-extraction`：テキストのベクトル表現を抽出する

### 画像パイプライン

- `image-to-text`：画像のテキストによる説明を生成する
- `image-classification`：画像の中の物体を識別する
- `object-detection`：画像の中の物体の位置を特定し、識別する

### 音声パイプライン

- `automatic-speech-recognition`：音声をテキストに変換する
- `audio-classification`：音声をカテゴリに分類する
- `text-to-speech`：テキストを音声に変換する

### マルチモーダルパイプライン

- `image-text-to-text`：テキストプロンプトに基づいて画像に応答する

これらのパイプラインのいくつかを、もう少し詳しく見ていきましょう。

## ゼロショット分類

まずは、ラベルが付いていないテキストを分類するという、少し難しいタスクから始めます。テキストへの注釈付けは時間が掛かり、専門知識も必要になる為、実際のプロジェクトではよく有る場面です。この用途には `zero-shot-classification` パイプラインが非常に強力です。分類に使うラベルを自分で指定出来るので、事前学習済みモデルのラベルに頼る必要がありません。先程は、モデルが文を positive と negative の2つのラベルで分類するのを見ました。同じ仕組みで、好きなラベルの集合を使った分類も出来ます。

```python
from transformers import pipeline

classifier = pipeline("zero-shot-classification")
classifier(
    "This is a course about the Transformers library",
    candidate_labels=["education", "politics", "business"],
)

（入力文の訳：これは Transformers ライブラリについてのコースです。候補ラベルは「教育」「政治」「ビジネス」です）

```python out {'sequence': 'This is a course about the Transformers library', 'labels': ['education', 'business', 'politics'], 'scores': [0.8445963859558105, 0.111976258456707, 0.043427448719739914]}

このパイプラインが _ゼロショット_ と呼ばれるのは、自分のデータでモデルをファインチューニングしなくても使えるからです。指定したラベルのリストについて、確率スコアを直接返します。

## テキスト生成

次に、パイプラインでテキストを生成する方法を見てみます。基本的な考え方は、プロンプトを与えると、モデルがその続きのテキストを生成して自動で補完するというものです。多くのスマートフォンに有る予測変換の機能に似ています。テキスト生成にはランダム性が含まれる為、下に示す結果と全く同じ結果が得られなくても、普通のことです。

```python
from transformers import pipeline

generator = pipeline("text-generation")
generator("In this course, we will teach you how to")

（プロンプトの訳：「このコースでは、〜の方法を教えます」という文の途中までです）

```python out [{'generated_text': 'In this course, we will teach you how to understand and use ' 'data flow and data interchange when handling user data. We ' 'will be working with one or more of the most commonly used ' 'data flows — data flows of various types, as seen by the ' 'HTTP'}]

（出力の訳：このコースでは、ユーザーデータを扱う時のデータフローとデータ交換を理解し、使う方法を教えます。最もよく使われるデータフローの1つ以上を扱います。HTTP から見た、様々な種類のデータフローです）

生成されるシーケンスの数は `num_return_sequences` 引数で、出力テキストの全体の長さは `max_length` 引数で制御出来ます。

## マスク補完

次に試すパイプラインは `fill-mask` です。このタスクは、与えられたテキストの空白を埋めるものです。

```python
from transformers import pipeline

unmasker = pipeline("fill-mask")
unmasker("This course will teach you all about <mask> models.", top_k=2)

（入力文の訳：このコースでは モデルについて全てを学べます）

```python out [{'sequence': 'This course will teach you all about mathematical models.', 'score': 0.19619831442832947, 'token': 30412, 'token_str': ' mathematical'}, {'sequence': 'This course will teach you all about computational models.', 'score': 0.04052725434303284, 'token': 38163, 'token_str': ' computational'}]

（出力の訳：補完された文は「このコースでは数学的モデルについて全てを学べます」と「このコースでは計算的モデルについて全てを学べます」です）

`top_k` 引数は、表示する候補の数を制御します。ここでモデルが埋めているのは特殊な単語 `<mask>` で、これは *マスクトークン* と呼ばれることがよくあります。マスク補完のモデルによってマスクトークンが異なる場合が有る為、別のモデルを使う時は、正しいマスク単語を常に確認するのがよい方法です。確認方法の1つは、ウィジェットで使われているマスク単語を見ることです。

## 固有表現認識

固有表現認識（NER）は、入力テキストのどの部分が人物、場所、組織といったエンティティに対応するかを、モデルが見つけ出すタスクです。例を見てみましょう。

```python
from transformers import pipeline

ner = pipeline("ner", aggregation_strategy="simple")
ner("My name is Sylvain and I work at Hugging Face in Brooklyn.")

（入力文の訳：私の名前は Sylvain で、ブルックリンの Hugging Face で働いています）

```python out [{'entity_group': 'PER', 'score': 0.99816, 'word': 'Sylvain', 'start': 11, 'end': 18}, {'entity_group': 'ORG', 'score': 0.97960, 'word': 'Hugging Face', 'start': 33, 'end': 45}, {'entity_group': 'LOC', 'score': 0.99321, 'word': 'Brooklyn', 'start': 49, 'end': 57} ]

ここでは、Sylvain が人物（PER）、Hugging Face が組織（ORG）、Brooklyn が場所（LOC）であることを、モデルが正しく識別しました。

パイプラインの作成関数に `aggregation_strategy="simple"` オプションを渡すと、文の中で同じエンティティに対応する部分をまとめ直すよう、パイプラインに指示出来ます。ここでは、名前が複数の単語から構成されているにもかかわらず、モデルは "Hugging" と "Face" を1つの組織として正しくまとめました。実際、次の章で見るように、前処理では単語が更に小さい部分に分割されることさえあります。例えば `Sylvain` は、`S`、`##yl`、`##va`、`##in` の4つのピースに分割されます。後処理のステップで、パイプラインはこれらのピースを正しくまとめ直しました。

## 要約

要約とは、テキストに含まれる重要な側面を全て（又は殆ど）保ちながら、テキストを短くするタスクです。例を示します。

```python
from transformers import pipeline

summarizer = pipeline("summarization")
summarizer(
    """
    America has changed dramatically during recent years. Not only has the number of 
    graduates in traditional engineering disciplines such as mechanical, civil, 
    electrical, chemical, and aeronautical engineering declined, but in most of 
    the premier American universities engineering curricula now concentrate on 
    and encourage largely the study of engineering science. As a result, there 
    are declining offerings in engineering subjects dealing with infrastructure,

## 翻訳

翻訳では、タスク名に言語ペアを指定すれば（`"translation_en_to_fr"` のように）既定モデルを使うことも出来ますが、最も簡単な方法は、[Model Hub](https://huggingface.co/models)で使いたいモデルを選ぶことです。ここでは、フランス語から英語への翻訳を試してみます。

```python
from transformers import pipeline

translator = pipeline("translation", model="Helsinki-NLP/opus-mt-fr-en")
translator("Ce cours est produit par Hugging Face.")

```python out [{'translation_text': 'This course is produced by Hugging Face.'}]

（入力文はフランス語で「このコースは Hugging Face が制作しています」という意味で、出力はその英語訳です）

テキスト生成や要約と同様に、結果に対して `max_length` や `min_length` を指定出来ます。

## 画像と音声のパイプライン

テキスト以外にも、Transformer モデルは画像や音声を扱えます。いくつか例を示します。

### 画像分類

```python
from transformers import pipeline

image_classifier = pipeline(
    task="image-classification", model="google/vit-base-patch16-224"
)
result = image_classifier(
    "https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/pipeline-cat-chonk.jpeg"
)
print(result)

```python out [{'label': 'lynx, catamount', 'score': 0.43350091576576233}, {'label': 'cougar, puma, catamount, mountain lion, painter, panther, Felis concolor', 'score': 0.034796204417943954}, {'label': 'snow leopard, ounce, Panthera uncia', 'score': 0.03240183740854263}, {'label': 'Egyptian cat', 'score': 0.02394474856555462}, {'label': 'tiger cat', 'score': 0.02288915030658245}]

### 自動音声認識

```python
from transformers import pipeline

transcriber = pipeline(
    task="automatic-speech-recognition", model="openai/whisper-large-v3"

複数のソースからデータを組み合わせる

Transformer モデルの強力な応用の1つは、複数のソースからデータを組み合わせて処理出来ることです。これは特に、次のような場合に役立ちます。

  1. 複数のデータベースやリポジトリを横断して検索する
  2. 異なる形式（テキスト、画像、音声）の情報を統合する
  3. 関連情報の統一的なビューを作成する

例えば、次のようなシステムを構築出来ます。

  • テキストや画像といった複数のモダリティにわたって、データベース内の情報を検索する。
  • 異なるソースから得た結果を組み合わせ、1つの首尾一貫した回答にまとめる。例えば、音声ファイルとテキストによる説明から回答を作る。
  • ドキュメントとメタデータのデータベースの中から、最も関連性の高い情報を提示する。
