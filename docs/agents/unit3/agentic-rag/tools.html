エージェントのためのツールの構築と統合

このセクションでは、AlfredにWebへのアクセスを許可し、最新のニュースや世界の動向を見つけられるようにします。 さらに、天気データやHugging Face Hubのモデルのダウンロード統計にもアクセスできるようにし、新鮮な話題で適切な会話ができるようにします。

エージェントにWebへのアクセスを与える

Alfredには、世界の深い知識を持つ、真のルネサンス的ホストとしての存在感を確立してほしいのでしたね。

そのためには、Alfredが世界に関する最新のニュースや情報にアクセスできるようにする必要があります。

まずはAlfredのためのWeb検索ツールを作成しましょう！

smolagents

from smolagents import DuckDuckGoSearchTool

# DuckDuckGo検索ツールを初期化する
search_tool = DuckDuckGoSearchTool()

# 使用例
results = search_tool("Who's the current President of France?")
print(results)
期待される出力： 
The current President of France in Emmanuel Macron.

llama-index

from llama_index.tools.duckduckgo import DuckDuckGoSearchToolSpec
from llama_index.core.tools import FunctionTool

# DuckDuckGo検索ツールを初期化する
tool_spec = DuckDuckGoSearchToolSpec()

search_tool = FunctionTool.from_defaults(tool_spec.duckduckgo_full_search)
# 使用例
response = search_tool("Who's the current President of France?")
print(response.raw_output[-1]['body'])
期待される出力： 
The President of the French Republic is the head of state of France. The current President is Emmanuel Macron since 14 May 2017 defeating Marine Le Pen in the second round of the presidential election on 7 May 2017. List of French presidents (Fifth Republic) N° Portrait Name ...

花火のスケジュールを決めるための天気情報カスタムツールの作成

完璧なガラには、澄み渡った空に花火が上がります。悪天候で花火が中止にならないようにしなければなりません。

外部の天気APIを呼び出して、指定した場所の天気情報を取得するカスタムツールを作成しましょう。

💡 ヒント

簡単のため、この例ではダミーの天気APIを使います。本物の天気APIを使いたい場合は、ユニット1のように、OpenWeatherMap APIを使う天気ツールを実装できます。

smolagents

from smolagents import Tool
import random

class WeatherInfoTool(Tool):
    name = "weather_info"
    description = "Fetches dummy weather information for a given location."
    inputs = {
        "location": {
            "type": "string",
            "description": "The location to get weather information for."
        }
    }
    output_type = "string"

    def forward(self, location: str):
        # ダミーの天気データ
        weather_conditions = [
            {"condition": "Rainy", "temp_c": 15},
            {"condition": "Clear", "temp_c": 25},
            {"condition": "Windy", "temp_c": 20}
        ]
        # 天気の状態をランダムに選ぶ
        data = random.choice(weather_conditions)
        return f"Weather in {location}: {data['condition']}, {data['temp_c']}°C"

# ツールを初期化する
weather_info_tool = WeatherInfoTool()

影響力のあるAIビルダーのためのHub統計ツールの作成

ガラには、AIビルダーの著名人たちが集まります。Alfredは、彼らの最も人気のあるモデルやデータセット、Spaceについて話して、感心させたいと考えています。ユーザー名に基づいてHugging Face Hubからモデルの統計を取得するツールを作成しましょう。

smolagents

from smolagents import Tool
from huggingface_hub import list_models

class HubStatsTool(Tool):
    name = "hub_stats"
    description = "Fetches the most downloaded model from a specific author on the Hugging Face Hub."
    inputs = {
        "author": {
            "type": "string",
            "description": "The username of the model author/organization to find models from."
        }
    }
    output_type = "string"

    def forward(self, author: str):
        try:
            # 指定した作者のモデルを、ダウンロード数の降順で取得する
            models = list(list_models(author=author, sort="downloads", direction=-1, limit=1))

            if models:
                model = models[0]
                return f"The most downloaded model by {author} is {model.id} with {model.downloads:,} downloads."
            else:
                return f"No models found for author {author}."
        except Exception as e:
            return f"Error fetching models for {author}: {str(e)}"

# ツールを初期化する
hub_stats_tool = HubStatsTool()

# 使用例
print(hub_stats_tool("facebook")) # 例: Facebookの最もダウンロードされたモデルを取得する
期待される出力： 
The most downloaded model by facebook is facebook/esmfold_v1 with 12,544,550 downloads.

ツールとAlfredの統合

すべてのツールがそろったので、Alfredのエージェントに統合しましょう。

smolagents

from smolagents import CodeAgent, InferenceClientModel

# Hugging Faceモデルを初期化する
model = InferenceClientModel()

# すべてのツールを持ったAlfredを作成する
alfred = CodeAgent(
    tools=[search_tool, weather_info_tool, hub_stats_tool],
    model=model
)

# ガラの最中にAlfredが受け取りそうなクエリの例
response = alfred.run("What is Facebook and what's their most popular model?")

print("🎩 Alfredの応答：")
print(response)
期待される出力： 
🎩 Alfredの応答：
Facebook is a social networking website where users can connect, share information, and interact with others. The most downloaded model by Facebook on the Hugging Face Hub is ESMFold_v1.

llama-index

from llama_index.core.agent.workflow import AgentWorkflow
from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI

# Hugging Faceモデルを初期化する
llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")
# すべてのツールを持ったAlfredを作成する
alfred = AgentWorkflow.from_tools_or_functions(
    [search_tool, weather_info_tool, hub_stats_tool],
    llm=llm
)

# ガラの最中にAlfredが受け取りそうなクエリの例
response = await alfred.run("What is Facebook and what's their most popular model?")

print("🎩 Alfredの応答：")
print(response)
期待される出力： 
🎩 Alfredの応答：
Facebook is a social networking service and technology company based in Menlo Park, California. It was founded by Mark Zuckerberg and allows people to create profiles, connect with friends and family, share photos and videos, and join groups based on shared interests. The most popular model by Facebook on the Hugging Face Hub is `facebook/esmfold_v1` with 13,109,861 downloads.

langgraph

from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

# ツールを含むチャットインターフェースを生成する
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

# AgentStateとエージェントのグラフを生成する
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## グラフ
builder = StateGraph(AgentState)

# ノードを定義する: 実際の処理を行う
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# エッジを定義する: 制御フローの動きを決める
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # 最新のメッセージがツールを必要とする場合は、ツールへルーティングする
    # それ以外の場合は、直接応答する
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

messages = [HumanMessage(content="Who is Facebook and what's their most popular model?")]
response = alfred.invoke({"messages": messages})

print("🎩 Alfredの応答：")
print(response['messages'][-1].content)
期待される出力： 
🎩 Alfredの応答：
Facebook is a social media company known for its social networking site, Facebook, as well as other services like Instagram and WhatsApp. The most downloaded model by Facebook on the Hugging Face Hub is facebook/esmfold_v1 with 13,202,321 downloads.

まとめ

これらのツールを統合することで、AlfredはWeb検索から天気の更新、モデルの統計まで、さまざまなタスクを処理できるようになりました。これにより、ガラで最も情報通で魅力的なホストであり続けられます。
