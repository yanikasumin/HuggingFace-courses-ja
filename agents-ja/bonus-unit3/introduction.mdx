# はじめに

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/bonus-unit3/pokemon_thumbnail.png" alt="ボーナスユニット 3：ゲームにおける AI"/>

誰にも負けない存在になりたい……

**AI エージェントとゲーム**が交わる、わくわくする世界を探る**ボーナスユニット**へようこそ！

ノンプレイヤーキャラクター（NPC）が、決められたセリフを話すだけでなく、状況に応じて会話し、プレイヤーの戦略に合わせて行動を変え、物語の進行と共に変化するゲームを想像してみて下さい。**LLM と、自分で考えて行動するエージェントの仕組みをゲームに組み合わせる**と、こうしたことが可能になります。**プレイヤーとのやり取りから新しい物語やゲームの展開が自然に生まれる**ようになるのです。

このボーナスユニットでは、次のことを学びます。

- **ポケモン風のターン制バトル**に参加出来る AI エージェントの作り方を学ぶ  
- そのエージェントと対戦したり、オンラインで他のエージェントに挑戦したりする

AI コミュニティでは、LLM を使って Pokémon をプレイする事例が既にいくつか登場しています。例えば、[Claude の事例](https://www.anthropic.com/research/visible-extended-thinking)や[Gemini の事例](https://www.twitch.tv/gemini_plays_pokemon)があります。このユニットでは、コースで学んだことを生かして、自分のエージェントで同じようなことを実現する方法を学びます。

## 更に先へ進みたい方へ

- **ゲームにおける LLM を極める**：専門コース [Machine Learning for Games Course](https://hf.co/learn/ml-games-course) で、ゲーム開発を更に深掘り出来ます。

- **AI プレイブックを手に入れる**：[AI Playbook for Game Developers](https://thomassimonini.substack.com/) では、AI を活用したゲーム設計の未来を取り上げ、有益な知見やアイデア、実践的なヒントを紹介しています。

では、エージェントを作り始める前に、LLM が実際のゲームでどのように使われているのか、**4 つの興味深い事例**を見ていきましょう。
