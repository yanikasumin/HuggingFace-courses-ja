Contrastive Language-Image Pre-training（CLIP）

はじめに

CLIP は、自然言語による教師を通じて視覚概念を把握することに長けたニューラルネットワークです。テキストエンコーダと画像エンコーダを同時に学習し、キャプションと対応する画像を照合する事前学習タスクに焦点を当てることで動作します。このアーキテクチャにより、CLIP はさまざまな視覚分類ベンチマークへシームレスに適応できます。認識すべき視覚カテゴリの名前を与えるだけでそれが可能であり、GPT-2 や GPT-3 のモデルで見られたものと同様の「ゼロショット」学習能力を示しています。

対照事前学習

画像・テキストのペアのバッチが与えられると、CLIP はそのバッチ内のすべての（画像、テキスト）候補の組み合わせについて、密なコサイン類似度行列を計算します。核心のアイデアは、正しいペア（下図で青で示されたもの）の類似度を最大化し、間違ったペア（図で灰色で示されたもの）の類似度を最小化することです。そのために、これらの類似度スコアに対する対称クロスエントロピー損失を最適化します。

OpenAI から引用した画像

簡単に説明すると、画像とそれに対応するキャプションの類似度をできるだけ高くし、画像と他のキャプションの類似度は小さくしたい、ということです。この論理をキャプション側にも適用し、キャプションとそれに対応する画像の類似度を最大化し、他のすべての画像との類似度を最小化したいと考えます。

テキストエンコーダと画像エンコーダ

CLIP の設計は、画像とテキストに独立したエンコーダを備えており、その選択に柔軟性があります。標準の画像エンコーダである Vision Transformer を ResNet のような代替手段に入れ替えたり、別のテキストエンコーダを選んだりでき、適応性と実験の幅が広がります。もちろん、エンコーダのどちらかを切り替えると、埋め込みの分布が変わるため、モデルを再学習する必要があります。

ユースケース

CLIP はさまざまな応用に活用できます。代表的なユースケースを挙げます:

  • ゼロショット画像分類;
  • 類似度検索;
  • 拡散モデルの条件付け。

使い方

実際の応用では、通常、画像とあらかじめ定義されたクラスを入力として使います。次の Python の例は、CLIP の実行に transformers ライブラリを使う方法を示しています。この例では、下の画像を dog と cat のどちらかにゼロショット分類したいとします。

from PIL import Image
import requests

from transformers import CLIPProcessor, CLIPModel

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

inputs = processor(
    text=["a photo of a cat", "a photo of a dog"],
    images=image,
    return_tensors="pt",
    padding=True,
)

outputs = model(**inputs)
logits_per_image = outputs.logits_per_image
probs = logits_per_image.softmax(dim=1)

このコードを実行した結果、得られた確率は次のとおりです: - "a photo of a cat": 99.49% - "a photo of a dog": 0.51%

限界

CLIP はゼロショット分類に長けていますが、専門にファインチューニングされたモデルを上回る可能性は低いでしょう。さらに、その汎化能力はやや限定的で、特に学習中に遭遇しなかったデータや例を含むシナリオではそうです。 論文ではまた、Fairface データセットを使ったテストで示されたように、CLIP の有効性とバイアスはカテゴリの選択に影響されることも示されています。性別と人種の分類で顕著な差が見られ、性別の精度は 96% 超、人種の精度は 93% 程度でした。

まとめ

まとめると、OpenAI の CLIP モデルはマルチモーダル分野に革命をもたらしました。CLIP を際立たせているのは、ゼロショット学習への習熟度であり、明示的に学習していないカテゴリへ画像を分類できます。この驚くべき汎化能力は、画像とテキストキャプションを照合することで学習するという革新的な学習方法から来ています。
