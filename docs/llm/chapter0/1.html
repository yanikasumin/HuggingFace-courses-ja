はじめに

Hugging Face コースへようこそ！このページでは、作業環境のセットアップ方法を案内します。コースを始めたばかりの方は、まず 第1章 に目を通してから、ここに戻って環境をセットアップし、実際にコードを試してみるのがおすすめです。

このコースで使うライブラリはすべて Python パッケージとして提供されているので、ここでは Python 環境のセットアップと、必要なライブラリのインストール方法を紹介します。

作業環境のセットアップには、Colab ノートブックを使う方法と、Python の仮想環境を使う方法があります。ここでは、この2つの方法を紹介します。自分に合った方を選んでください。初心者の方は、まず Colab ノートブックから始めるのがおすすめです。

なお、このコースでは Windows での環境構築は扱いません。Windows を使っている方は、Colab ノートブックで進めるのがおすすめです。Linux か macOS であれば、このページで紹介するどちらの方法でも進められます。

コースの大部分では Hugging Face アカウントが必要になります。まだの方は、今のうちにアカウントを作成しておきましょう。

Google Colab ノートブックを使う

Colab ノートブックを使うのが、作業環境を整える最も手軽な方法です。ブラウザでノートブックを開けば、すぐにコーディングを始められます！

Colab に慣れていない方は、まず入門ノートブックで基本的な操作を学ぶのがおすすめです。Colab では GPU や TPU といったアクセラレータを使えますし、小規模なワークロードなら無料で利用できます。

Colab の操作に慣れてきたら、新しいノートブックを作成して、セットアップを始めましょう。

次に、このコースで使うライブラリをインストールします。インストールには、Python のパッケージマネージャーである pip を使います。ノートブックでは、コマンドの前に ! を付けるとシステムコマンドを実行できるので、🤗 Transformers ライブラリは次のようにインストールできます。

!pip install transformers

パッケージが正しくインストールされたかどうかは、Python からインポートしてみれば確認できます。

import transformers

これでインストールされるのは、とても軽量なバージョンの 🤗 Transformers です。PyTorch や TensorFlow のような機械学習フレームワークは含まれません。このコースでは 🤗 Transformers のさまざまな機能を使うため、ほぼあらゆる用途に必要な依存パッケージがそろう開発版をインストールすることをおすすめします。

!pip install transformers[sentencepiece]

少し時間がかかりますが、これで残りのコースを進める準備が整います！

Python の仮想環境を使う

Python の仮想環境を使いたい場合は、まずシステムに Python をインストールします。手始めにこのガイドに沿って進めるのがおすすめです。

Python をインストールしたら、ターミナルで Python のコマンドを実行できるようになっているはずです。次に進む前に、python --version コマンドを実行して、Python が正しくインストールされているか確認しておきましょう。システムで使える Python のバージョンが表示されるはずです。

ターミナルで python --version のような Python コマンドを実行するとき、呼び出される Python は、システムの「メイン」の Python だと考えてください。このメインの Python にはパッケージを直接入れず、作業するアプリケーションごとに別々の環境を作るために使うのがおすすめです。そうすれば、アプリケーションごとに依存関係やパッケージを分離でき、ほかのアプリケーションとの互換性の問題を心配する必要がなくなります。

Python ではこれを仮想環境で実現します。仮想環境とは、特定のバージョンの Python 本体と、アプリケーションに必要なすべてのパッケージをまとめた、独立したディレクトリ構造です。仮想環境を作るツールはいくつかありますが、ここでは Python 公式のパッケージである venv を使います。

まず、アプリケーションを置くディレクトリを作成します。たとえば、ホームディレクトリ直下に transformers-course という新しいディレクトリを作るといいでしょう。

mkdir ~/transformers-course
cd ~/transformers-course

このディレクトリの中で、Python の venv モジュールを使って仮想環境を作成します。

python -m venv .env

これで、空だったフォルダの中に .env というディレクトリができているはずです。

ls -a

.      ..    .env

仮想環境の有効化と無効化は、activate スクリプトと deactivate スクリプトで行います。

# 仮想環境を有効化する
source .env/bin/activate

# 仮想環境を無効化する
deactivate

環境が有効化されているかどうかは、which python コマンドで確認できます。表示されたパスが仮想環境の中を指していれば、有効化できています！

which python

/home/<user>/transformers-course/.env/bin/python

依存関係のインストール

前のセクション（Google Colab）と同様に、ここでもコースの続きを進めるために必要なパッケージをインストールします。🤗 Transformers の開発版は、パッケージ管理ツールの pip を使ってインストールできます。

pip install "transformers[sentencepiece]"

これでセットアップは完了です。さっそく始めましょう！
