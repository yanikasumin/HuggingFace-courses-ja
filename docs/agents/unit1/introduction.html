エージェント入門

最初のユニットへようこそ。ここでは AI エージェントの基礎をしっかり身につけます。扱う内容は次のとおりです。

  • エージェントを理解する
  • エージェントとは何か、どのように動作するのか

  • エージェントは推論と計画をどう使って意思決定するのか

  • エージェントにおける LLM（大規模言語モデル）の役割

  • LLM がエージェントの「頭脳」としてどう働くか

  • LLM が Messages の仕組みを通じて会話をどう構成するか

  • ツールとアクション

  • エージェントが外部ツールを使って環境とやり取りする方法

  • エージェント用のツールを構築し、統合する方法

  • エージェントのワークフロー

  • 思考（Think） → 行動（Act） → 観察（Observe）

これらを学んだあとは、smolagents を使って 初めてのエージェントを構築します。

Alfred という名前のエージェントに簡単なタスクを処理させ、ここで学んだ概念を実際にどう応用するかを確認します。

さらに、エージェントを Hugging Face Spaces に公開する方法 も学ぶので、友人や同僚と共有できるようになります。

最後に、このユニットの締めくくりとしてクイズに挑戦します。合格すると、コース最初の認定証 である 🎓 Certificate of Fundamentals of Agents（エージェント基礎認定証）を取得できます。

このユニットは 欠かせない出発点 であり、より高度なトピックへ進む前にエージェントを理解するための土台を築きます。

ボリュームのあるユニットなので、時間をかけて 取り組み、ときどき各セクションに戻って確認してください。

準備はできましたか？さあ、始めましょう！ 🚀
