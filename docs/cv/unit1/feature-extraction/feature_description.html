﻿# 特徴記述（Feature Description）

特徴は、モデルがインスタンスから学習した属性であり、後で新しいインスタンスを認識するために使われます。

データ構造で特徴をどう表現するか？

データにおける特徴の表現は、データを効果的に整理し操作するために重要です。特徴、つまり属性や変数は、数値やカテゴリから、画像やテキストのようなより複雑な構造まで、多様でありえます。コンピュータビジョンタスクで特徴を表現する方法には、次のようなものがあります。

  • 数値特徴

  • 配列/リスト: 数値を格納する最も単純な形式。配列の各要素が特徴に対応します。

  • テンソル: 多次元配列。機械学習フレームワークで大量の数値データを効率的に処理するためによく使われます。

  • カテゴリ特徴

  • 辞書/リスト: カテゴリを数値ラベルに割り当てたり、カテゴリ値を直接格納したりします。

  • ワンホットエンコーディング: カテゴリ変数を、各ビットがカテゴリを表すバイナリベクトルに変換します。

  • 画像特徴

  • ピクセル値: ピクセル値の行列、または多次元配列。

  • 畳み込みニューラルネットワーク特徴（CNN）: 事前学習済み CNN モデルを使って特徴を抽出します。

良い記述子とは

画像処理やコンピュータビジョンにおける良い記述子とは、画像内の物体やシーンについての重要な情報を効果的に表す、一連の特性や特徴のことです。良い記述子の条件には、次のような側面があります。

  • 変換に対する不変性: 記述子は理想的には、回転、平行移動、スケーリング、照明の変化といった変動に対してロバストであるべきです。つまり、物体がどう配置されても、画像がどう変更されても、記述子は比較的変わらず、元のものと同じ記述を含むべきです。
  • 識別性: 良い記述子は、物体についての固有の情報を捉えます。異なる物体や画像の部分を識別でき、似た要素と区別できるだけの識別性を持つべきです。
  • 次元数: 良い記述子は扱いやすいサイズであることが多く、過度に大きくなることなく十分な情報を伝えます。次元数のバランスは、処理と保存の効率に不可欠です。
  • 局所性: 記述子はしばしば画像内の局所的な特徴を特定します。局所記述子は特定の領域やキーポイントに焦点を当て、その領域の特性を記述することで、異なる画像間で類似した領域のマッチングと認識を可能にします。
  • 再現性: 記述子は、ノイズや小さな変動がある場合でも、同じ物体やシーンの複数のインスタンスにわたって一貫し、再現可能であるべきです。
  • マッチングアルゴリズムとの互換性: 記述子は、異なる画像間の対応を見つけるためにマッチングアルゴリズムと併用されることがよくあります。良い記述子は、距離指標、機械学習モデル、その他のテクニックに基づくか否かを問わず、使用するマッチングアルゴリズムに適しているべきです。
  • 計算効率: 効率は記述子にとって本当に重要な要素であり、特にリアルタイムアプリケーションにおいてそうです。記述子は、ロボティクスや自動運転車のように速度が重要なシナリオでは特に、素早い処理のために計算上実現可能であるべきです。
  • 適応性: 処理しているデータから適応したり学習したりできる記述子は、特に物体やシーンの特性が時間とともに変化しうる状況で、非常に効果的です。これにより、記述子の使いやすさが高まります。
  • ノイズへのロバスト性: 記述子は、根底にある特徴を正確に表す能力を大きく損なうことなく、画像データのノイズを扱えるべきです。

特徴記述子で使われるテクニックの例

SIFT

Scale Invariant Feature Transform の略です。画像内の局所的な特徴を検出・記述するために、コンピュータビジョンと画像処理で広く使われているアルゴリズムです。

SIFT の動作は以下のとおりです。

  • スケールスペースの極値検出: 複数のスケールにわたって画像内の潜在的な注目点を検出することから始めます。ガウス関数の差が空間とスケールに対して最大または最小に達する画像内の位置を探します。これらのキーポイントの位置は、さまざまなスケール変化の下で安定しているとみなされます。
  • キーポイントの局所化: 潜在的なキーポイントが特定されると、SIFT はその位置をサブピクセル精度に改良し、低コントラストのキーポイントとエッジ上のキーポイントを除外して、正確な局所化を保証します。
  • 方向の割り当て: SIFT は、局所的な画像の勾配方向に基づいて、各キーポイントの支配的な方向を計算します。このステップにより、記述子は画像の回転に対して不変になります。
  • 記述子の生成: 各キーポイント領域に対して記述子が計算され、キーポイント付近の局所的な画像勾配についての情報を捉えます。この記述子は、キーポイントを囲む画像パッチの主要な特性を凝縮したコンパクトな表現です。
  • 記述子のマッチング: 最後に、これらの記述子は異なる画像間のキーポイントのマッチングに使われます。ある画像の記述子を別の画像のものと比較して、対応を見つけます。

SIFT は、さまざまな画像変換に対するロバスト性と、画像内の識別的な特徴を見つける能力により、物体認識、画像スティッチング、3D 再構成などの応用で価値があります。

SURF

Speeded Up Robust Features の略です。コンピュータビジョンと画像処理におけるもう1つの人気アルゴリズムです。局所的な画像特徴を検出・記述する際の速度とロバスト性で特に知られています。

SURF の基本的なワークフローは以下のとおりです。

  • 積分画像: SURF は、元の画像の事前計算された表現である積分画像を利用します。これにより画像内の矩形領域の合計を高速に計算でき、より速い特徴計算が可能になります。

  • ブロブ検出: 他の特徴検出アルゴリズムと同様に、SURF は画像内の潜在的な注目点やキーポイントを特定することから始めます。ヘッセ行列を使って、複数の方向とスケールで強度に大きな変動を示すブロブや領域を検出します。これらの領域が潜在的なキーポイントです。

  • スケール選択: スケールスペースで大きな変化のある領域を特定することで、キーポイントのスケールを決定します。異なるスケールにわたるヘッセ行列の行列式を分析し、複数のスケールでロバストなキーポイントを見つけます。

  • 方向の割り当て: 検出された各キーポイントについて、SURF は支配的な方向を割り当てます。これは、キーポイントの近傍の周りで異なる方向の Haar ウェーブレット応答を計算することで行います。SIFT とは異なり、SURF はキーポイントの近傍のサブ領域に適用される矩形フィルター（Haar ウェーブレット）の集合を使います。これらのフィルターの応答を使って、キーポイントを表す特徴ベクトルを作成します。

  • 記述子のマッチング: 生成された記述子は、異なる画像間のキーポイントのマッチングに使われます。マッチングでは、ある画像のキーポイントの特徴ベクトルを別の画像のものと比較して、対応を見つけます。

SURF の主要な強みは、積分画像と Haar ウェーブレット近似の使用で達成される計算効率にあり、スケール、回転、照明の変化に対するロバスト性を維持します。これにより SURF は、物体検出、追跡、画像スティッチングなど、速度が重要な役割を果たすリアルタイムアプリケーションに適しています。
