[第2章](/course/chapter2) では、トークナイザと事前学習済みモデルを使って予測する方法を見てきました。では、事前学習済みモデルを特定のタスク向けにファインチューニングするには、どうすればよいのでしょうか。この章では、その方法を学びます。主な内容は次のとおりです。

* 🤗 Datasets の最新機能を使って、Hub から大規模なデータセットを用意する方法
* 高レベルの `Trainer` API を使い、現在推奨されている手法に沿ってモデルをファインチューニングする方法
* 最適化手法を取り入れたカスタム学習ループの実装方法
* 🤗 Accelerate ライブラリを使って、あらゆる環境で分散学習を簡単に実行する方法
* モデルの性能を最大限に引き出すために、現在推奨されているファインチューニング手法を活用する方法

> [!TIP]
> 📚 **おすすめ資料**: この章を始める前に、[🤗 Datasets のドキュメント](https://huggingface.co/docs/datasets/) でデータ処理について復習しておくとよいでしょう。

この章では、🤗 Transformers 以外の Hugging Face ライブラリにも入門します。🤗 Datasets、🤗 Tokenizers、🤗 Accelerate、🤗 Evaluate が、モデルをより効率よく、効果的に学習させるためにどう役立つのかを見ていきます。

この章の主なセクションでは、次の内容を扱います。
- **セクション2**: 現在使われているデータ前処理の手法と、データセットを効率よく扱う方法
- **セクション3**: 強力な `Trainer` API を使いこなし、最新機能を活用する方法
- **セクション4**: 学習ループを一から実装する方法と、Accelerate を使った分散学習の仕組み

この章を終えるころには、高レベル API を使う方法とカスタム学習ループを使う方法のどちらでも、自分のデータセットでモデルをファインチューニングできるようになります。また、この分野で現在推奨されている手法も実践できるようになります。

> [!TIP]
> 🎯 **この章で作るもの**: この章を終えるころには、BERT モデルをテキスト分類向けにファインチューニングし、その手法を自分のデータセットやタスクに応用する方法を理解しているはずです。

この章では **PyTorch** のみに焦点を当てます。PyTorch が深層学習の研究や本番環境での運用において、標準的なフレームワークになっているためです。また、Hugging Face エコシステムの最新の API と、現在推奨されている手法を使用します。

学習したモデルを Hugging Face Hub にアップロードするには、Hugging Face のアカウントが必要です。[アカウントを作成](https://huggingface.co/join)
