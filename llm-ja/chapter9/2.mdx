まずは Gradio をインストールしましょう！Python パッケージなので、次を実行するだけです:

`$ pip install gradio `

Gradio はどこでも実行できます。お気に入りの Python IDE でも、Jupyter ノートブックでも、Google Colab でも 🤯！
Python が動く場所ならどこでも、Gradio をインストールして使えます。

Gradio の構文に慣れるために、シンプルな「Hello World」の例から始めましょう:

```py
import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()
```

上のコードを順に見ていきましょう:

- まず、`greet()` という関数を定義します。ここでは名前の前に "Hello" を付けるだけのシンプルな関数ですが、一般的には *どんな* Python 関数でも構いません。たとえば機械学習の応用では、入力に対して *モデルを呼び出して予測を行い*、出力を返す関数になるでしょう。
- 次に、`fn`、`inputs`、`outputs` の3つの引数で Gradio の `Interface` を作成します。これらの引数で、予測関数と、使いたい入出力コンポーネントの _種類_ を定義します。今回の例では、どちらのコンポーネントもシンプルなテキストボックスです。
- 最後に、作成した `Interface` に対して `launch()` メソッドを呼びます。

このコードを実行すると、Jupyter/Colab のノートブックでは下のようなインターフェースが自動的に表示され、スクリプトから実行した場合はブラウザで **[http://localhost:7860](http://localhost:7860/)** が開きます。

下の例を見てみましょう:

```py
import gradio as gr

    return "Hello " + name


# Textbox クラスをインスタンス化します

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()
```

## 🤖 モデルの予測を取り入れる[[including-model-predictions]]

ここでは、GPT-2 のような **テキスト生成** モデルのデモができる、シンプルなインターフェースを作ります。

モデルは 🤗 Transformers の `pipeline()` 関数を使って読み込みます。
手早く復習したい場合は、[Chapter 1 の該当セクション](/course/chapter1/3#text-generation) に戻ってください。

まず、テキストプロンプトを受け取り、補完されたテキストを返す予測関数を定義します:

```py
from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion
```

この関数は、与えたプロンプトを補完します。自分の入力プロンプトで実行して、動作を確認してみてください。例はこちらです（補完結果は異なる場合があります）:

```
predict("My favorite programming language is")
```

```
>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.
```

予測を生成する関数ができたら、先ほどと同じ方法で `Interface` を作成して起動できます:

```py
import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()
```


これだけです！下のように、このインターフェースを使って GPT-2 モデルでテキストを生成できます 🤯。
