Interface の高度な機能

基本的なインターフェースの作成と共有が出来るようになりました。この節では、状態（state）や解釈（interpretation）など、より高度な機能を扱います。

状態を使ってデータを保持する

Gradio は セッション状態 をサポートします。セッション状態とは、ページを読み込んだ後の複数回の送信にわたってデータを保持する仕組みです。例えばチャットボットのデモでは、ユーザーがモデルとやり取りする間、データを保持する用途に使います。

セッション状態のデータは、モデルのユーザー同士では共有されません。

セッション状態にデータを保存するには、次の3つを行います：

  1. インターフェースの状態を表す 追加のパラメータ を、関数に渡します。
  2. 関数の最後で、更新した状態の値を 追加の戻り値 として返します。
  3. Interface を作成する際に、'state' 入力コンポーネントと 'state' 出力コンポーネントを追加します。

下記にチャットボットの例を示します：

import random

import gradio as gr


def chat(message, history):
    history = history or []
    if message.startswith("How many"):
        response = random.randint(1, 10)
    elif message.startswith("How"):
        response = random.choice(["Great", "Good", "Okay", "Bad"])
    elif message.startswith("Where"):
        response = random.choice(["Here", "There", "Somewhere"])
    else:
        response = "I don't know"
    history.append((message, response))
    return history, history


iface = gr.Interface(
    chat,
    ["text", "state"],
    ["chatbot", "state"],
    allow_screenshot=False,
    allow_flagging="never",
)
iface.launch()

出力コンポーネントの状態は、送信を繰り返しても保持されます。状態パラメータには既定値を渡せます。既定値は、状態の初期値として使われます。

解釈を使って予測を理解する

機械学習モデルの多くはブラックボックスです。関数の内部の処理は、エンドユーザーからは見えません。Gradio では、透明性を確保する為に、解釈機能を簡単に追加出来ます。Interface クラスの interpretation 引数に "default" を指定するだけです。解釈機能を使うと、入力のどの部分が出力に影響したかをユーザーが確認出来ます。下記は、解釈機能を含めた単純な画像分類器のインターフェースです：

import requests
import tensorflow as tf

import gradio as gr

inception_net = tf.keras.applications.MobileNetV2()  # モデルを読み込む

# 人間が読める ImageNet のラベルをダウンロードします。
response = requests.get("https://git.io/JJkYN")
labels = response.text.split("\n")


def classify_image(inp):
    inp = inp.reshape((-1, 224, 224, 3))
    inp = tf.keras.applications.mobilenet_v2.preprocess_input(inp)
    prediction = inception_net.predict(inp).flatten()
    return {labels[i]: float(prediction[i]) for i in range(1000)}


image = gr.Image(shape=(224, 224))
label = gr.Label(num_top_classes=3)

title = "Gradio Image Classifiction + Interpretation Example"
gr.Interface(
    fn=classify_image, inputs=image, outputs=label, interpretation="default", title=title
).launch()

解釈機能は、入力を送信した後、出力コンポーネントの下の Interpret をクリックすると試せます。

既定の解釈方法以外では、interpretation パラメータに shap を指定する方法も使えます。この場合は num_shap パラメータも設定します。これは Shapley 値に基づく解釈で、詳しくはこちらで読めます。

独自の解釈関数を interpretation パラメータに渡すことも出来ます。例は、Gradio の getting started ページのこちらにあります。

以上で、Gradio の Interface クラスの詳しい説明は終わりです。このクラスを使うと、数行の Python コードで機械学習のデモを作成出来ます。一方で、レイアウトを変更したい場合や、複数の予測関数をつなげたい場合もあります。そのようなカスタマイズには、Interface を分割した「ブロック」が向いています。ブロックは、次の最終セクションで扱います。
