ここでは、Argilla にあるアノテーション済みデータをエクスポートして使う方法を学びます。 

## データセットを読み込む

まず、これまでのステップと同様に Argilla インスタンスに接続していることを確認します。

```python
import argilla as rg

HF_TOKEN = "..."  # プライベートな Space の場合のみ

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # プライベートな Space の場合のみ
)
```

次に、作業対象のデータセットを読み込みます。

```python
dataset = client.datasets(name="ag_news")
```

データセットを読み込み、`dataset.records` でレコードを取得すれば、そのデータを独自の処理やパイプラインで利用できます。ただしここでは、レコードのフィルタリングや、データセットの Hugging Face Hub へのエクスポートといった任意の操作もいくつか学びます。

## データセットをフィルタリングする

完了したレコードだけを使いたい場合もあります。そこでまず、ステータスに基づいてデータセット内のレコードをフィルタリングします。

```python
status_filter = rg.Query(filter=rg.Filter([("status", "==", "completed")]))

filtered_records = dataset.records(status_filter)
```

>[!TIP]
>⚠️ `completed` ステータスのレコード（タスクの割り当て設定で設定した送信済みレスポンスの最小数を満たしたレコード）は複数のレスポンスを持つことがあり、各レスポンスのステータスは `submitted`、`draft`、`discarded` のいずれかになり得る点に注意してください。

レコードのクエリとフィルタリングについて詳しくは、[Argilla のドキュメント](https://docs.argilla.io/latest/how_to_guides/query/) を参照してください。

## Hub にエクスポートする

アノテーションを Hugging Face Hub にエクスポートすれば、他の人と共有できます。そのためには、レコードを 🤗 Dataset に変換してから Hub にプッシュします。

```python
filtered_records.to_datasets().push_to_hub("argilla/ag_news_annotated")
```

あるいは、次のように Argilla データセット全体（保留中のレコードを含む）を直接エクスポートすることもできます。

```python
dataset.to_hub(repo_id="argilla/ag_news_annotated")
```

データセット全体をエクスポートしておくと、他の人も各自の Argilla インスタンスに取り込めます。設定が自動的に保存されるため、1行のコードでデータセット全体をインポートできます。

```python
dataset = rg.Dataset.from_hub(repo_id="argilla/ag_news_annotated")
```
