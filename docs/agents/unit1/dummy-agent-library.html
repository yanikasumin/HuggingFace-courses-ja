ダミーエージェントライブラリ

このコースはフレームワークに依存しません。AI エージェントの概念に集中し、特定のフレームワークの詳細に深入りしない ためです。

また、受講者がこのコースで学んだ概念を、好きなフレームワークを使って自分のプロジェクトで使えるようになってほしいと考えています。

そのため、このユニット1では、ダミーのエージェントライブラリと、LLM エンジンにアクセスするためのシンプルなサーバーレス API を使います。

本番環境でこれらを使うことはないでしょうが、エージェントの仕組みを理解するための良い出発点 になります。

このセクションのあとは、smolagents を使って シンプルなエージェントを作成する 準備が整います。

そして続くユニットでは、LangGraph や LlamaIndex のような他の AI エージェントライブラリも使います。

シンプルにするために、ツールとエージェントとしてシンプルな Python 関数を使います。

datetime や os のような Python の組み込みパッケージを使うので、どんな環境でも試すことができます。

このノートブック でプロセスを追い、自分でコードを実行 できます。

サーバーレス API

Hugging Face のエコシステムには、Serverless API と呼ばれる便利な機能があり、多くのモデルで簡単に推論を実行できます。インストールやデプロイは不要です。

import os
from huggingface_hub import InferenceClient

## トークンが https://hf.co/settings/tokens, から必要です。トークンの種類として 'read' を選択してください。
## Google Colab で実行する場合は、左サイドバーの「Secrets」タブ（鍵アイコン）に "HF_TOKEN" という名前で追加してください。
try:
    from google.colab import userdata
    HF_TOKEN = userdata.get("HF_TOKEN")
except ImportError:
    HF_TOKEN = os.environ.get("HF_TOKEN")

client = InferenceClient(model="moonshotai/Kimi-K2.5", token=HF_TOKEN)

チャットテンプレートを適用する便利で信頼できる方法なので、chat メソッドを使います。

output = client.chat.completions.create(
    messages=[
        {"role": "user", "content": "The capital of France is"},
    ],
    stream=False,
    max_tokens=1024,
    extra_body={'thinking': {'type': 'disabled'}},
)
print(output.choices[0].message.content)

出力:

Paris.

chat メソッドは、モデル間のスムーズな移行を保証するために推奨される（RECOMMENDED）方法です。

ダミーエージェント

前のセクションでは、エージェントライブラリの中核はシステムプロンプトに情報を追加することだと見ました。

このシステムプロンプトは、先ほど見たものより少し複雑ですが、すでに次を含んでいます。

  1. ツールについての情報
  2. サイクルの指示（思考 → アクション → 観察）
# このシステムプロンプトは少し複雑で、実際には関数の説明がすでに追加されています。
# ここでは、ツールのテキストによる説明がすでに追加されていると仮定します。

SYSTEM_PROMPT = """Answer the following questions as best you can. You have access to the following tools:

get_weather: Get the current weather in a given location

The way you use the tools is by specifying a json blob.
Specifically, this json should have an `action` key (with the name of the tool to use) and an `action_input` key (with the input to the tool going here).

The only values that should be in the "action" field are:
get_weather: Get the current weather in a given location, args: {"location": {"type": "string"}}
example use :

{{
  "action": "get_weather",
  "action_input": {"location": "New York"}
}}


ALWAYS use the following format:

Question: the input question you must answer
Thought: you should always think about one action to take. Only one action at a time in this format:
Action:

$JSON_BLOB (inside markdown cell)

Observation: the result of the action. This Observation is unique, complete, and the source of truth.
... (this Thought/Action/Observation can repeat N times, you should take several steps when needed. The $JSON_BLOB must be formatted as markdown and only use a SINGLE action at a time.)

You must always end your output with the following format:

Thought: I now know the final answer
Final Answer: the final answer to the original input question

Now begin! Reminder to ALWAYS use the exact characters `Final Answer:` when you provide a definitive answer. """

システムプロンプトのあとにユーザーの指示を追加する必要があります。これは chat メソッドの中で起こります。このプロセスは以下で確認できます。

messages = [
    {"role": "system", "content": SYSTEM_PROMPT},
    {"role": "user", "content": "What's the weather in London?"},
]

print(messages)

問題が見えますか？

この時点で、モデルはハルシネーションを起こしています。実際の関数やツール呼び出しの結果ではなく、自分で生成した捏造の「観察（Observation）」を作り出しているからです。 これを防ぐために、"Observation:" の直前で生成を停止します。 これにより、関数（例: get_weather）を手動で実行し、本物の出力を観察として挿入できます。

# 答えはモデルによってハルシネーションされました。実際に関数を実行するために停止する必要があります！
output = client.chat.completions.create(
    messages=messages,
    max_tokens=150,
    stop=["Observation:"], # 実際の関数が呼び出される前に停止しましょう
    extra_body={'thinking': {'type': 'disabled'}},
)

print(output.choices[0].message.content)

出力:

Thought: To answer the question, I need to get the current weather in London.
Action:
```
{
  "action": "get_weather",
  "action_input": {"location": "London"}
}

ずっと良くなりました！

では、ダミーの天気取得関数を作成 しましょう。実際の状況では API を呼び出すことができます。

# ダミー関数
def get_weather(location):
    return f"the weather in {location} is sunny with low temperatures. \n"

get_weather('London')

出力:

'the weather in London is sunny with low temperatures. \n'

システムプロンプト、基本プロンプト、関数の実行までの補完、そして関数の結果を観察として連結し、生成を再開しましょう。

messages=[
    {"role": "system", "content": SYSTEM_PROMPT},
    {"role": "user", "content": "What's the weather in London ?"},
    {"role": "assistant", "content": output.choices[0].message.content + "Observation:\n" + get_weather('London')},
]

output = client.chat.completions.create(
    messages=messages,
    stream=False,
    max_tokens=200,
    extra_body={'thinking': {'type': 'disabled'}},
)

print(output.choices[0].message.content)
