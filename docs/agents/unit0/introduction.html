🤗 AI Agents コースへようこそ

今、AI 分野で最も注目されているテーマ、Agents（エージェント）の世界へようこそ！

この無料コースでは、初歩から専門的な内容まで段階的に学びながら、AIエージェントの仕組みを理解し、活用し、自分で構築する方法を身に付けられます。

この最初のユニットは、コースを始めるための準備編です。

  • コースのシラバスを確認します。
  • 受講の進め方を選びます（聴講のみか、認定プロセスか）。
  • 認定プロセスについて詳しく知ることができます。
  • コースの運営チームを紹介します。
  • Hugging Face アカウントを作成します。
  • Discord サーバーに参加して、クラスメイトや運営チームと交流します。

さあ、始めましょう！

このコースで得られること

このコースでは、次のようなことに取り組みます。

  • 📖 AIエージェントを理論・設計・実践の面から学ぶ
  • 🧑‍💻 smolagents、LlamaIndex、LangGraph といった実績のあるAIエージェント用ライブラリの使い方を学ぶ
  • 💾 自分のエージェントを Hugging Face Hub で共有し、コミュニティが作ったエージェントを探索する
  • 🏆 自分のエージェントを他の受講生のエージェントと競わせるチャレンジに参加する
  • 🎓 課題をこなして修了証を取得する

ほかにも盛りだくさんです！

コースを終える頃には、エージェントの仕組みや、最新のライブラリ・ツールを使って独自のエージェントを構築する方法が分かるようになります。

忘れずにコースに登録してください！

（プライバシーは尊重します。メールアドレスは、各ユニットの公開時にリンクを送ったり、チャレンジや更新情報を案内したりするためにのみ収集します）

コースの構成

このコースは次の要素で構成されています。

  • 基礎ユニット: エージェントの基本概念や理論を学びます。
  • ハンズオン: 実績のあるAIエージェント用ライブラリを使い、それぞれに特色のある環境でエージェントを訓練する方法を学びます。実習には、あらかじめ環境が設定された Hugging Face Spaces を使用します。
  • ユースケース課題: 学んだ概念を応用して、自分で選んだ現実の問題を解きます。
  • チャレンジ: 自分のエージェントを他の受講生のエージェントと競わせます。エージェントの性能を比較できるリーダーボードも用意されています。

このコースは、受講生のフィードバックと貢献で進化し続ける生きたプロジェクトです！ GitHub で Issue や PR を開いたり、Discord サーバーで議論したりして、気軽に参加してください。

コースを終えた後は、👉 こちらのフォームからフィードバックも送れます。

シラバス

コース全体のシラバスは次のとおりです。各ユニットの公開に合わせて、より詳しいトピック一覧も公開します。

章 トピック 説明
0 オンボーディング 使用するツールやプラットフォームの準備をします。
1 エージェントの基礎 Tools、Thoughts、Actions、Observations とその形式を説明します。LLM、メッセージ、特殊トークン、チャットテンプレートも扱います。Python 関数をツールとして使うシンプルなユースケースも紹介します。
2 フレームワーク エージェントの基本概念が、人気ライブラリ（smolagents、LangGraph、LLamaIndex）でどのように実装されているかを学びます。
3 ユースケース 実生活の課題を題材に、いくつかのユースケースを実装します（経験豊富なエージェント開発者からの PR も歓迎です 🤗）
4 最終課題 選定されたベンチマークに対応するエージェントを構築し、受講生リーダーボードで学習成果を示します 🚀

本編のシラバスに加えて、ボーナスユニットが3つあります。 - ボーナスユニット 1: Function-calling のための LLM ファインチューニング - ボーナスユニット 2: エージェントの可観測性と評価 - ボーナスユニット 3: ポケモンで遊ぶエージェント

たとえばボーナスユニット 3 では、ポケモンバトルをプレイするエージェントの作り方を学びます 🥊。

前提知識

このコースについていくには、次の知識が必要です。

  • Python の基礎知識
  • LLM の基礎知識（ユニット 1 に復習用のセクションがあります）

必要なツール

必要なものは2つだけです。

  • インターネットに接続できるコンピュータ
  • Hugging Face アカウント: モデルやエージェントのアップロード・読み込みや、Spaces の作成に使います。アカウントがまだない場合は、こちらから無料で作成できます。

認定プロセス

このコースは聴講のみで受講することも、課題に取り組んで運営が発行する2種類の証明書のいずれかを取得することもできます。

聴講の場合でも、すべてのチャレンジに参加でき、希望すれば課題にも取り組めます。運営への連絡は不要です。

認定プロセスは完全無料です。

  • 基礎認定を取得するには: コースのユニット 1 を修了する必要があります。エージェントの最新トレンドを押さえたい受講生向けです。
  • 修了証を得るには: ユニット 1 の修了に加えて、コース内で提示されるユースケース課題のうち1つと、最終チャレンジを修了する必要があります。

認定プロセスに締め切りはありません。

推奨ペース

このコースの各章は、週あたりおよそ3〜4時間の学習で、1週間で修了できるように設計されています。

推奨ペースはこちらです。

コースを最大限に活用するには

コースを最大限に活用するためのアドバイスをいくつか紹介します。

  1. Discord で勉強会グループに参加する: 仲間と一緒に学ぶほうが、学習を進めやすくなります。参加するには、Discord サーバーに入り、Hugging Face アカウントを認証してください。
  2. クイズと課題に取り組む: 学ぶ最良の方法は、実践と自己評価です。
  3. 学習の進度を合わせるためにスケジュールを立てる: 下の推奨ペースを参考にするか、自分に合った学習計画を立ててください。
