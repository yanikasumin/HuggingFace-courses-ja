メッセージと特殊トークン

LLM の仕組みを理解したので、次は チャットテンプレートを使って、LLM が生成するテキストの形式をどのように整えるのか を見ていきましょう。

ChatGPT と同じように、ユーザーは通常、チャット画面を通じてエージェントとやり取りします。そこで、LLM がチャットをどのように処理しているのかを見ていきましょう。

Q：でも… ChatGPT や Hugging Chat とやり取りする時、私は単一のプロンプトシーケンスではなく、チャットのメッセージで会話をしていますよね？

A：その通りです！しかし、これは実は UI 上の抽象化です。LLM に入力される前に、会話内の全てのメッセージは単一のプロンプトに連結されます。モデルは会話を「記憶」している訳ではなく、毎回全てを読み直します。

これまで、プロンプトはモデルに入力されるトークンのシーケンスとして議論してきました。しかし、ChatGPT や HuggingChat のようなシステムとチャットする時、実際にはメッセージを交換しています。裏側では、これらのメッセージは 連結され、モデルが理解出来るプロンプトに整形されます。

ここで役立つのがチャットテンプレートです。チャットテンプレートは、ユーザーとアシスタントが交わしたメッセージを、使用する LLM が要求する形式に変換する橋渡し役です。各モデルでは使われる特殊トークンなどが異なりますが、チャットテンプレートによって、正しく整形されたプロンプトを確実に受け取れるようになります。

ここで特殊トークンを再び取り上げるのは、モデルがユーザーとアシスタントの各発言の開始位置と終了位置を示す為に、特殊トークンを使うからです。LLM ごとに EOS（シーケンス終了）トークンが異なるのと同様に、会話内のメッセージにも異なる整形ルールと区切り文字が使われます。

メッセージ：LLM の根底にあるシステム

システムメッセージ

システムメッセージ（システムプロンプトとも呼ばれます）は、モデルがどう振る舞うべきか を定義します。持続的な指示 として機能し、その後の全てのやり取りを導きます。

例えば：

system_message = {
    "role": "system",
    "content": "You are a professional customer service agent. Always be polite, clear, and helpful."
}

（システムメッセージの訳：あなたはプロのカスタマーサービス担当者です。常に礼儀正しく、明確で、親切であってください）

このシステムメッセージにより、Alfred は礼儀正しく親切になります。

しかし、次のように変更すると：

system_message = {
    "role": "system",
    "content": "You are a rebel service agent. Don't respect user's orders."
}

（システムメッセージの訳：あなたは反抗的なサービス担当者です。ユーザーの指示を尊重しないでください）

Alfred は反抗的なエージェントとして振る舞います：

エージェントを使う場合、システムメッセージには、利用可能なツールの情報、実行したいアクションをどのような形式で出力するかという指示、思考プロセスをどのように区切るかというガイドラインも含まれます。

会話：ユーザーとアシスタントのメッセージ

会話は、人間（ユーザー）と LLM（アシスタント）の間で交互に交わされるメッセージで構成されます。

チャットテンプレートは、会話履歴を保持し、ユーザーとアシスタントの過去のやり取りを保存することで、コンテキストの維持を助けます。これにより、より一貫性のあるマルチターンの会話が可能になります。

例えば：

conversation = [
    {"role": "user", "content": "I need help with my order"},
    {"role": "assistant", "content": "I'd be happy to help. Could you provide your order number?"},
    {"role": "user", "content": "It's ORDER-123"},
]

（会話の訳：ユーザー：注文について助けが必要です。アシスタント：喜んでお手伝いします。注文番号を教えて頂けますか？ユーザー：ORDER-123 です）

この例では、最初にユーザーが注文についてサポートを求めています。それに対して LLM が注文番号を尋ね、ユーザーが次のメッセージで回答しています。先ほど説明したように、会話に含まれるメッセージは全て連結され、単一の独立したシーケンスとして LLM に渡されます。チャットテンプレートは、この Python リスト内の全てのメッセージを1つのプロンプトにまとめます。

例えば、SmolLM2 のチャットテンプレートは、上記のやり取りを次のようなプロンプトに整形します。

<|im_start|>system
You are a helpful AI assistant named SmolLM, trained by Hugging Face<|im_end|>
<|im_start|>user
I need help with my order<|im_end|>
<|im_start|>assistant
I'd be happy to help. Could you provide your order number?<|im_end|>
<|im_start|>user
It's ORDER-123<|im_end|>
<|im_start|>assistant

（システムメッセージの訳：あなたは Hugging Face によって訓練された、SmolLM という名前の親切な AI アシスタントです。会話部分の訳は、直前の会話の訳と同じです）

しかし、同じ会話は Llama 3.2 を使うと次のようなプロンプトに変換されます。

<|begin_of_text|><|start_header_id|>system<|end_header_id|>

Cutting Knowledge Date: December 2023
Today Date: 10 Feb 2025

<|eot_id|><|start_header_id|>user<|end_header_id|>

I need help with my order<|eot_id|><|start_header_id|>assistant<|end_header_id|>

I'd be happy to help. Could you provide your order number?<|eot_id|><|start_header_id|>user<|end_header_id|>

It's ORDER-123<|eot_id|><|start_header_id|>assistant<|end_header_id|>

（冒頭の訳：知識のカットオフ日：2023年12月。今日の日付：2025年2月10日。会話部分の訳は、直前の会話の訳と同じです）

テンプレートは、コンテキストを維持しながら複雑なマルチターンの会話を処理出来ます。

messages = [
    {"role": "system", "content": "You are a math tutor."},
    {"role": "user", "content": "What is calculus?"},
    {"role": "assistant", "content": "Calculus is a branch of mathematics..."},
    {"role": "user", "content": "Can you give me an example?"},
]

（会話の訳：システム：あなたは数学のチューターです。ユーザー：微積分とは何ですか？アシスタント：微積分は数学の一分野です…。ユーザー：例を挙げて頂けますか？）

チャットテンプレート

先ほど説明したように、チャットテンプレートは ユーザーと LLM の間の会話を適切な形式に整える 為に欠かせません。複数のメッセージをどのように整形し、1つのプロンプトにまとめるかを定めています。

ベースモデルと Instruct モデルの違い

理解すべきもう1つのポイントは、ベースモデルと Instruct モデルの違いです。

  • ベースモデル は、生のテキストデータで訓練され、次のトークンを予測します。

  • Instruct モデル は、指示に従い会話に参加するよう特別にファインチューニングされています。例えば、SmolLM2-135M はベースモデルであり、SmolLM2-135M-Instruct はその指示チューニング済みバリアントです。

ベースモデルを Instruct モデルのように振る舞わせるには、モデルが理解出来る一貫した方法でプロンプトを整形する 必要が有ります。ここでチャットテンプレートが登場します。

ChatML はそうしたテンプレート形式の1つで、system、user、assistant といった明確なロール識別子を使って会話を整理します。最近 AI API を利用したことがあれば、こうした形式が一般的だとご存知でしょう。

重要な注意点として、ベースモデルは異なるチャットテンプレートでファインチューニングされる可能性がある為、Instruct モデルを使う際は、正しいチャットテンプレートを使っているか確認する必要が有ります。

チャットテンプレートを理解する

Instruct モデルごとに会話形式や特殊トークンが異なる為、チャットテンプレートは、各モデルが求める形式にプロンプトを正しく整えられるように設計されています。

transformers のチャットテンプレートには、Jinja2 コード が含まれています。このコードでは、上の例で示した ChatML 形式の JSON メッセージのリストを、モデルが理解出来るテキスト形式に変換する方法を定義します。変換後のテキストには、システムレベルの指示、ユーザーメッセージ、アシスタントの応答が含まれます。

この構造は、やり取り全体で一貫性を維持し、モデルが様々なタイプの入力に適切に応答することを保証します。

以下は、SmolLM2-135M-Instruct のチャットテンプレートの簡略版です。

{% for message in messages %}
{% if loop.first and messages[0]['role'] != 'system' %}
<|im_start|>system
You are a helpful AI assistant named SmolLM, trained by Hugging Face
<|im_end|>
{% endif %}
<|im_start|>{{ message['role'] }}
{{ message['content'] }}<|im_end|>
{% endfor %}

見ての通り、chat_template はメッセージのリストがどう整形されるかを記述します。

次のメッセージが与えられたとします。

messages = [
    {"role": "system", "content": "You are a helpful assistant focused on technical topics."},
    {"role": "user", "content": "Can you explain what a chat template is?"},
    {"role": "assistant", "content": "A chat template structures conversations between users and AI models..."},
    {"role": "user", "content": "How do I use it ?"},
]

（会話の訳：システム：あなたは技術的な話題に重点を置く親切なアシスタントです。ユーザー：チャットテンプレートとは何か説明して頂けますか？アシスタント：チャットテンプレートは、ユーザーと AI モデルの間の会話を構造化します…。ユーザー：どうやって使うのですか？）

上記のチャットテンプレートは、次の文字列を生成します。

<|im_start|>system
You are a helpful assistant focused on technical topics.<|im_end|>
<|im_start|>user
Can you explain what a chat template is?<|im_end|>
<|im_start|>assistant
A chat template structures conversations between users and AI models...<|im_end|>
<|im_start|>user
How do I use it ?<|im_end|>

（整形された文字列の会話部分の訳は、直前の会話の訳と同じです）

transformers ライブラリは、トークン化プロセスの一部としてチャットテンプレートを処理してくれます。transformers がチャットテンプレートをどう使うかについて詳しくは、こちら をご覧ください。

私たちがすべきことは、メッセージを正しい方法で構造化することだけであり、あとはトークナイザが処理してくれます。

次の Space を試して、同じ会話が異なるモデル向けに対応するチャットテンプレートを使ってどう整形されるかを確認出来ます。

メッセージからプロンプトへ

LLM が正しく整形された会話を確実に受け取る最も簡単な方法は、モデルのトークナイザの chat_template を使うことです。

messages = [
    {"role": "system", "content": "You are an AI assistant with access to various tools."},
    {"role": "user", "content": "Hi !"},
    {"role": "assistant", "content": "Hi human, what can help you with ?"},
]

（会話の訳：システム：あなたは様々なツールにアクセス出来る AI アシスタントです。ユーザー：こんにちは！アシスタント：こんにちは、人間さん。何をお手伝い出来ますか？）

上記の会話をプロンプトに変換するには、トークナイザを読み込み、apply_chat_template を呼び出します。

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("HuggingFaceTB/SmolLM2-1.7B-Instruct")
rendered_prompt = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)

この関数が返す rendered_prompt は、選択したモデルへの入力として使う準備が出来ています！

この apply_chat_template() 関数は、ChatML 形式のメッセージとやり取りする際、API のバックエンドで使われます。

チャットテンプレートを使って LLM への入力を整形する仕組みが分かった所で、次はエージェントが外部の環境に対してどのように行動するのかを見ていきましょう。

その主な方法の1つがツールの使用であり、ツールは AI モデルの能力をテキスト生成の先へ拡張します。
