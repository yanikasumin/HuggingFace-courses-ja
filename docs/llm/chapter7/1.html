はじめに

Chapter 3 では、モデルをテキスト分類向けにファインチューニングする方法を扱いました。この章では、代表的な言語タスクを取り上げます。いずれも、従来の NLP モデルでも最新の LLM でも欠かせない基本のタスクです。

  • トークン分類
  • マスク言語モデリング（BERT など）
  • 要約
  • 翻訳
  • 因果言語モデリングによる事前学習（GPT-2 など）
  • 質問応答

これらのタスクは、大規模言語モデル（LLM）の仕組みの土台です。最先端の言語モデルを扱うには、まずこの土台を理解する必要があります。
