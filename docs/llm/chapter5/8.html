この章ではたくさんの内容を扱いました！細部まで全部を把握できていなくても心配いりません。これからの章で、裏側の仕組みがどう動いているかが分かるようになります。

とはいえ、先に進む前に、この章で学んだことをテストしてみましょう。

1. 🤗 Datasets の load_dataset() 関数では、次のどこにあるデータセットを読み込めますか？

正解です！load_dataset() の data_files 引数にローカルファイルのパスを渡せば、ローカルデータセットを読み込めます。
正解です！データセット ID を指定すれば、Hub 上のデータセットを読み込めます。例: load_dataset('emotion')。
正解です！load_dataset() の data_files 引数に URL を渡せば、リモートファイルを読み込めます。

2. 次のように GLUE タスクの1つを読み込んだとします。

from datasets import load_dataset

dataset = load_dataset("glue", "mrpc", split="train")

次のうち、dataset からランダムに50件のサンプルを取り出すコマンドはどれですか？

これは不正解です。Dataset.sample() というメソッドは存在しません。
正解です！この章で見たとおり、まずデータセットをシャッフルしてから、そこからサンプルを選択します。
これは不正解です。コードは実行できますが、シャッフルされるのはデータセットの最初の50件だけです。

3. 家庭のペットに関する pets_dataset というデータセットがあり、各ペットの名前を示す name 列があるとします。次のうち、名前が「L」で始まるペットだけを抽出できる方法はどれですか？

正解です！このような手早いフィルタには Python のラムダ関数を使うのがおすすめです。ほかにどんな解法が考えられますか？
これは不正解です。ラムダ関数は lambda *arguments* : *expression* という一般形を取るため、この場合は引数を指定する必要があります。
正解です！Dataset.map() と同じように、明示的な関数を Dataset.filter() に渡せます。短いラムダ関数では収まらない複雑なロジックがある場合に便利です。他の選択肢では、どれがうまくいきますか？

4. メモリマッピングとは何ですか？

違います。もう一度考えてみましょう！
正解です！🤗 Datasets は各データセットをメモリマップドファイルとして扱います。これにより、データセット全体をメモリに読み込まなくても、その要素にアクセスして操作できます。
これは正しくありません。もう一度考えてみましょう！

5. メモリマッピングの主な利点は、次のうちどれですか？

正解です！おかげで 🤗 Datasets は非常に高速に動作します。ただし、利点はそれだけではありません。
正解です！おかげで、ノートパソコン上でも CPU を爆発させることなく、数ギガバイト規模のデータセットを読み込めます。メモリマッピングには他にどんな利点がありますか？

6. 次のコードが失敗するのはなぜですか？

from datasets import load_dataset

dataset = load_dataset("allocine", streaming=True, split="train")
dataset[0]
これは正しくありません。ストリーミングデータセットはその場で解凍されるため、ごくわずかな RAM でテラバイト級のデータセットも処理できます！
正解です！IterableDataset はコンテナではなくジェネレータなので、その要素には next(iter(dataset)) を使ってアクセスする必要があります。
これは不正解です。Hub の [allocine データセットカード](https://huggingface.co/datasets/allocine) で、どの分割が含まれているか確認してみてください。

7. データセットカードを作成する主な利点は、次のうちどれですか？

正解です！ドキュメントのないデータセットは、作成者の意図を反映しないモデルの訓練に使われるおそれがあります。また、プライバシーやライセンスの制限に反するデータでモデルを訓練すると、法的な扱いが不明確なモデルが生まれる可能性もあります。ただし、利点はそれだけではありません！
正解です！ほぼすべてのデータセットには何らかのバイアスがあり、下流で悪影響を及ぼす可能性があります。それを認識しておくことで、モデル開発者は内在するバイアスへの対処法を理解できます。データセットカードは他に何の役に立ちますか？
正解です！よく書かれたデータセットカードは、大切なデータセットの利用率を高める傾向があります。他にどんな利点がありますか？

8. セマンティック検索とは何ですか？

これは不正解です。この種の検索は *語彙検索（lexical search）* と呼ばれ、従来の検索エンジンで一般的に見られるものです。
正解です！セマンティック検索は埋め込みベクトルでクエリとドキュメントを表現し、類似度指標で両者の重なりの度合いを測ります。他にどう説明できますか？
正解です！セマンティック検索エンジンはキーワードマッチングよりもクエリの意図をよく捉えることができ、通常は、関連性の高いドキュメントをより高い精度で取得できます。ただし、正しい答えはそれだけではありません。セマンティック検索は他に何を提供しますか？
