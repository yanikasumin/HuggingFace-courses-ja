  1. まだなら Hugging Face アカウントを作成する
  2. Discord に登録して自己紹介する（遠慮なく 🤗）
  3. Hub で Hugging Face Agents コースをフォローする
  4. コースのことを周りに広める

（まだの場合）Hugging Face アカウントをこちらから作成してください。

ステップ 5: Ollama でモデルをローカル実行する（クレジット上限に達した場合）

  1. Ollama をインストールする

    公式の手順はこちら。

  2. モデルをローカルに取得する

    bash ollama pull qwen2:7b

    ここでは qwen2:7b モデルを取得しています。他のモデルは Ollama のサイトで確認してください。

  3. ターミナルを1つ開き、Ollama をバックグラウンドで起動する bash ollama serve

    "listen tcp 127.0.0.1:11434: bind: address already in use" というエラーが出た場合は、sudo lsof -i :11434 コマンドでそのポートを使用中のプロセス ID（PID）を特定できます。プロセスが ollama であれば、上記のインストールスクリプトが既に Ollama サービスを起動している可能性が高いため、このコマンドでの Ollama 起動はスキップできます。

  4. InferenceClientModel の代わりに LiteLLMModel を使う

smolagents の LiteLLMModel モジュールを使うには、pip コマンドでモジュールをインストールします。

    pip install 'smolagents[litellm]'

    from smolagents import LiteLLMModel

    model = LiteLLMModel(
        model_id="ollama_chat/qwen2:7b",  # 他の Ollama 対応モデルも試せます
        api_base="http://127.0.0.1:11434",  # Ollama のデフォルトのローカルサーバー
        num_ctx=8192,
    )
  1. なぜこれで動くのか - Ollama は http://localhost:11434 で OpenAI 互換 API を使ってモデルをローカルに提供します。 - LiteLLMModel は、OpenAI の chat/completion API 形式に対応するあらゆるモデルと通信できるよう作られています。 - つまり、InferenceClientModel を LiteLLMModel に置き換えるだけで、他のコードを変更する必要はありません。接続先のモデルを簡単に切り替えられます。
