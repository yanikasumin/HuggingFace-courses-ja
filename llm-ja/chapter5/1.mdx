[Chapter 3](/course/chapter3) では、🤗 Datasets ライブラリを初めて使いました。モデルのファインチューニングでは、主に次の3つの手順を行います。

1. Hugging Face Hub からデータセットを読み込む。
2. `Dataset.map()` でデータを前処理する。
3. 指標を読み込んで計算する。

しかし、これは Datasets で出来ることの、ほんの一部に過ぎません。この章では、このライブラリを詳しく解説します。解説の中で、次の疑問に答えます。

* データセットが Hub に無い場合はどうすればよいか？
* データセットをどうやって切り分けたり加工したり出来るか？（どうしても Pandas を使いたい場合は？）
* データセットが巨大で、ノートパソコンの RAM を使い切ってしまう場合はどうするか？
* 「メモリマッピング」や Apache Arrow とは、何か？
* 自分のデータセットを作って Hub にプッシュするにはどうすればよいか？

ここで学ぶ手法は、[Chapter 6](/course/chapter6) と [Chapter 7](/course/chapter7) で扱う高度なトークナイズとファインチューニングの準備になります。コーヒーを用意して、始めましょう！
