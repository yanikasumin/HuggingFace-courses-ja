セクション 5 では、🤗 Datasets の GitHub リポジトリに在る issue とコメントからデータセットを作成しました。このセクションでは、そのデータを使い、ライブラリについて特に気になることの答えを探せる検索エンジンを作ります！

埋め込みを用いたセマンティック検索

第1章 で見たように、Transformer ベースの言語モデルは、テキストの各トークンを 埋め込みベクトル で表します。個々の埋め込みベクトルをプーリング（集約）すると、文や段落、場合によってはドキュメント全体も1つのベクトルで表せます。検索したいテキストの埋め込みとコーパス内の各ドキュメントの埋め込みについて、内積による類似度（又は別の類似度指標）を計算し、類似度の高いドキュメントを返すことで、内容が似たドキュメントを探せます。

このセクションでは、埋め込みを使ってセマンティック検索エンジンを作ります。セマンティック検索には、クエリに含まれるキーワードとドキュメントを照合する従来の検索方法に比べ、いくつかの利点があります。

テキスト埋め込みの作成

第2章 で見たように、AutoModel クラスを使えばトークン埋め込みを取得出来ます。あとは、モデルの読み込みに使う適切なチェックポイントを選ぶだけです。

幸い、埋め込みの作成に特化した sentence-transformers というライブラリがあります。このライブラリのドキュメントによると、今回のように短いクエリの答えを issue のコメントなど比較的長いドキュメントから探す処理は、非対称セマンティック検索 に当たります。また、ドキュメント内のモデル概要表では、multi-qa-mpnet-base-dot-v1 チェックポイントがセマンティック検索で最も高い性能を示している為、これを使います。トークナイザも同じチェックポイントから読み込みます。

{#if fw === 'pt'}

from transformers import AutoTokenizer, AutoModel

model_ckpt = "sentence-transformers/multi-qa-mpnet-base-dot-v1"
tokenizer = AutoTokenizer.from_pretrained(model_ckpt)
model = AutoModel.from_pretrained(model_ckpt)

モデルと入力を GPU に置けば、埋め込みの計算を高速化出来ます。ここでその準備をしておきましょう。

import torch

device = torch.device("cuda")
model.to(device)

{:else}

from transformers import AutoTokenizer, TFAutoModel

from_pretrained() メソッドの引数として from_pt=True を設定していることに注目してください。これは、multi-qa-mpnet-base-dot-v1 チェックポイントには PyTorch の重みしか無い為で、from_pt=True を設定すれば自動的に TensorFlow 形式に変換してくれます。見ての通り、Transformers ではフレームワーク間の切り替えが非常に簡単です！

前に述べたように、GitHub の issue から作ったコーパスの各エントリを1つのベクトルで表したいので、トークン埋め込みを何らかの方法でプーリングする必要があります。平均化もその方法の1つです。よく使われる方法の1つに、モデルの出力に対する CLS プーリング があります。これは、特殊トークン [CLS] に対応する最終隠れ状態を取り出す方法です。次の関数で実装出来ます。

def cls_pooling(model_output):
    return model_output.last_hidden_state[:, 0]

次に、ドキュメントのリストをトークナイズし、テンソルを GPU に配置して、モデルに入力し、最後に出力に CLS プーリングを適用するヘルパー関数を作成します。

{#if fw === 'pt'}

def get_embeddings(text_list):
    encoded_input = tokenizer(
        text_list, padding=True, truncation=True, return_tensors="pt"
    )
    encoded_input = {k: v.to(device) for k, v in encoded_input.items()}
    model_output = model(**encoded_input)
    return cls_pooling(model_output)

FAISS による効率的な類似検索

埋め込みベクトルを格納したデータセットが出来たので、次はその中から似たベクトルを探す仕組みが必要です。ここでは、Datasets で利用出来る FAISS インデックス というデータ構造を使います。FAISS（Facebook AI Similarity Search の略）は、埋め込みベクトルを高速に検索・クラスタリングする為のアルゴリズムを提供するライブラリです。

FAISS の基本的な考え方は、インデックスと呼ばれる特殊なデータ構造を作成し、入力した埋め込みに類似する埋め込みを見つけられるようにすることです。Datasets で FAISS インデックスを作成するのは簡単です。Dataset.add_faiss_index() 関数を使い、データセットのどの列をインデックス化するかを指定します。

embeddings_dataset.add_faiss_index(column="embeddings")

これで、Dataset.get_nearest_examples() 関数を使って、インデックスから近いベクトルを探す最近傍検索が出来るようになりました。まず、質問文を埋め込みベクトルに変換して試してみましょう。
