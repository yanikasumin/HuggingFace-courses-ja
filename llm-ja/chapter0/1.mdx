# はじめに[[introduction]]

Hugging Face コースへようこそ！このページでは、作業環境のセットアップ方法を案内します。コースを始めたばかりの方は、まず [第1章](/course/chapter1) に目を通してから、ここに戻って環境をセットアップし、実際にコードを試してみるのがおすすめです。

このコースで使うライブラリはすべて Python パッケージとして提供されているので、ここでは Python 環境のセットアップと、必要なライブラリのインストール方法を紹介します。

作業環境を整える方法として、Colab ノートブックと Python の仮想環境を紹介します。自分に合った方を選んでください。初心者の方には、まず Colab ノートブックから始めることを特におすすめします。

なお、このコースでは Windows での環境構築は扱いません。Windows を使っている方は、Colab ノートブックで進めるのがおすすめです。Linux か macOS であれば、このページで紹介するどちらの方法でも進められます。

このコースの大部分を学習するには、Hugging Face アカウントが必要です。まだアカウントを持っていない方は、今のうちに[アカウントを作成](https://huggingface.co/join)しておきましょう。

## Google Colab ノートブックを使う[[using-a-google-colab-notebook]]

Colab ノートブックを使うのが、作業環境を整える最も手軽な方法です。ブラウザでノートブックを開けば、すぐにコーディングを始められます！

Colab に慣れていない方は、まず[入門ノートブック](https://colab.research.google.com/notebooks/intro.ipynb)で基本的な操作を学ぶのがおすすめです。Colab では、GPU や TPU など、処理を高速化するハードウェアを利用できます。小規模な処理なら無料で使えます。

Colab の操作に慣れてきたら、新しいノートブックを作成して、セットアップを始めましょう。

</div>

次に、このコースで使うライブラリをインストールします。インストールには、Python のパッケージ管理ツールである `pip` を使います。ノートブックでは、コマンドの先頭に `!` を付けるとシステムコマンドを実行できます。この仕組みを使って、🤗 Transformers ライブラリを次のようにインストールします。

```
!pip install transformers
```

パッケージが正しくインストールされたかどうかは、Python からインポートしてみれば確認できます。

```
import transformers
```

</div>

これでインストールされるのは、とても軽量なバージョンの 🤗 Transformers です。PyTorch や TensorFlow のような機械学習フレームワークは含まれません。開発版には、考えられるほぼすべての用途に必要な依存パッケージが含まれています。このコースでは 🤗 Transformers の様々な機能を使うので、この開発版をインストールすることをおすすめします。

```
!pip install transformers[sentencepiece]
```

少し時間がかかりますが、これで残りのコースを進める準備が整います！

## Python の仮想環境を使う[[using-a-python-virtual-environment]]

Python の仮想環境を使うには、まずシステムに Python をインストールする必要があります。インストールの手順は、[このガイド](https://realpython.com/installing-python/)を参考にしてください。

Python をインストールしたら、ターミナルで Python のコマンドを実行できるようになっているはずです。次に進む前に、`python --version` コマンドを実行して、Python が正しくインストールされているか確認しておきましょう。システムで使える Python のバージョンが表示されるはずです。

ターミナルで `python --version` のようなコマンドを実行したときに呼び出される Python を、システムの「メイン」の Python だと考えてください。メインの Python にはパッケージを直接インストールしないことをおすすめします。代わりに、メインの Python を使って、アプリケーションごとに別の環境を作成します。こうすれば、アプリケーションごとに必要なパッケージと依存関係を分けて管理でき、ほかのアプリケーションとの互換性を心配せずに済みます。

Python では、アプリケーションごとに環境を分けるために[仮想環境](https://docs.python.org/3/tutorial/venv.html)を使います。仮想環境は、特定のバージョンの Python 本体と、そのアプリケーションに必要なすべてのパッケージをまとめた独立したディレクトリ構造です。仮想環境を作るツールはいくつかありますが、ここでは Python 公式のパッケージである [`venv`](https://docs.python.org/3/library/venv.html#module-venv) を使います。

まず、アプリケーションを置くディレクトリを作成します。たとえば、ホームディレクトリ直下に *transformers-course* という新しいディレクトリを作るといいでしょう。

```
mkdir ~/transformers-course
cd ~/transformers-course
```

このディレクトリの中で、Python の `venv` モジュールを使って仮想環境を作成します。

```
python -m venv .env
```

これで、空だったフォルダの中に *.env* というディレクトリができているはずです。

```
ls -a
```

```out
.      ..    .env
```

仮想環境の有効化と無効化は、`activate` スクリプトと `deactivate` スクリプトで行います。

```
# 仮想環境を有効化する
source .env/bin/activate

# 仮想環境を無効化する
deactivate
```

環境が有効化されているかどうかは、`which python` コマンドで確認できます。表示されたパスが仮想環境の中を指していれば、有効化できています！

```
which python
```

```out
/home/<user>/transformers-course/.env/bin/python
```

### 依存関係のインストール[[installing-dependencies]]

Google Colab を使う場合と同じように、仮想環境にもコースの続きで必要になるパッケージをインストールします。🤗 Transformers の開発版は、パッケージ管理ツールの `pip` を使ってインストールできます。

```
pip install "transformers[sentencepiece]"
```

これでセットアップは完了です。さっそく始めましょう！
