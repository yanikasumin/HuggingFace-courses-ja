イントロダクション

最初のボーナスユニットへようこそ。ここでは、Function-calling（関数呼び出し）の為に大規模言語モデル（LLM）をファインチューニングする方法を学びます。

LLM を扱う上で、Function-calling は急速に知っておくべき技術になりつつあります。

考え方はこうです。ユニット 1 で行ったようなプロンプトベースの方法だけに頼るのではなく、Function-calling ではモデルが行動を起こし、その結果を解釈出来るよう、訓練の段階から学習させます。これにより、AI をより堅牢に出来ます。

このボーナスユニットはいつやるべきですか？

このセクションは任意で、ユニット 1 より高度な内容です。今すぐ取り組んでもよいし、このコースで知識が深まってから戻ってきても構いません。

但し心配はいりません。このボーナスユニットでは、必要な情報を一通り説明します。ファインチューニングの詳しい仕組みをまだ知らなくても、Function-calling の為のファインチューニングに必要な基本概念を一つずつ学べるように説明します。

このボーナスユニットをスムーズに進めるには、次の知識が有ると役立ちます。

  1. Transformers を使った LLM のファインチューニング方法を知っていること。分からない場合はこちらを確認してください。

  2. モデルのファインチューニングに SFTTrainer を使う方法を知っていること。詳しくはこちらのドキュメントを確認してください。

学ぶこと

  1. Function-calling
    現在の LLM が会話を適切に構成し、ツールを呼び出せるようにする仕組み。

  2. LoRA（Low-Rank Adaptation）
    計算とストレージのオーバーヘッドを抑える、軽量で効率的なファインチューニング手法。LoRA を使うと、大規模モデルをより速く、低コストで訓練出来、デプロイもしやすくなります。

  3. Function-calling モデルにおける Thought → Act → Observe サイクル
    モデルが関数を呼び出すタイミングと方法を判断し、中間ステップを追跡して、外部のツールや API から返された結果を解釈出来るようにする為の、シンプルで強力な方法。

  4. 新しい特殊トークン
    モデルが次のものを区別するのに役立つ特殊なマーカーを紹介します。 - 内部で行う「思考の連鎖（chain-of-thought）」による推論 - 外部への関数呼び出し - 外部ツールから返ってくる応答

このボーナスユニットを終える頃には、次のことが出来るようになります。

  • ツールを扱う API が内部でどのように動くのかを理解する。
  • LoRA の手法を使ってモデルをファインチューニングする。
  • Thought → Act → Observe サイクルを実装・変更して、堅牢で保守し易い Function-calling のワークフローを作る。
  • 特殊トークンを設計・活用して、モデルの内部推論と外部アクションをシームレスに分離する。

そして、自分のモデルを Function-calling に対応させる為のファインチューニングも完了しているはずです。

さあ、Function-calling を学んでいきましょう！
