ここでは、Argilla にあるアノテーション済みデータをエクスポートし、活用する方法を学びます。

## データセットを読み込む

まず、これまでと同様に Argilla インスタンスに接続していることを確認します。

```python
import argilla as rg

HF_TOKEN = "..."  # プライベートな Space の場合のみ

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # プライベートな Space の場合のみ
)
```

次に、作業対象のデータセットを読み込みます。

```python
dataset = client.datasets(name="ag_news")
```

データセットを読み込み、`dataset.records` でレコードを取得すれば、データセットとレコードを自分の用途やパイプラインでそのまま使えます。このセクションでは、それに加えて、レコードのフィルタリングや Hugging Face Hub へのエクスポートといった任意の操作も扱います。

## データセットをフィルタリングする

完了したレコードだけを使いたい場合もあります。まず、ステータスを基準にデータセット内のレコードを絞り込みます。

```python
status_filter = rg.Query(filter=rg.Filter([("status", "==", "completed")]))

filtered_records = dataset.records(status_filter)
```

>[!TIP]
>⚠️ `completed` ステータスのレコード（割り当て設定で定めた送信済みレスポンスの最小数を満たしたレコード）には、複数のレスポンスが含まれる場合があります。各レスポンスのステータスは `submitted`、`draft`、`discarded` のいずれかです。

レコードのクエリとフィルタリングについて詳しくは、[Argilla のドキュメント](https://docs.argilla.io/latest/how_to_guides/query/) を参照してください。

## Hub にエクスポートする

アノテーションは Hugging Face Hub にエクスポートして、他の人と共有出来ます。その為には、レコードを 🤗 Dataset に変換してから Hub にプッシュします。

```python
filtered_records.to_datasets().push_to_hub("argilla/ag_news_annotated")
```

あるいは、次のように Argilla データセット全体（保留中のレコードを含む）を直接エクスポートすることも出来ます。

```python
dataset.to_hub(repo_id="argilla/ag_news_annotated")
```

データセット全体をエクスポートしておくと、他の人が自分の Argilla インスタンスでそのまま開ける為、便利です。設定も自動的に保存されるので、データセット全体のインポートはコード1行で済みます。

```python
dataset = rg.Dataset.from_hub(repo_id="argilla/ag_news_annotated")
```
