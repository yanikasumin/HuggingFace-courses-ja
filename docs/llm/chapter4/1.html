Hugging Face Hub

Hugging Face Hub は Hugging Face のメインの Web サイトです。誰でも最先端のモデルやデータセットを見つけて利用したり、新しいモデルやデータセットを公開してコミュニティに貢献したり出来ます。10,000 を超える多種多様なモデルが公開されています。この章ではモデルを取り上げ、データセットについては Chapter 5 で説明します。

Hub で公開されているのは、🤗 Transformers のモデルや NLP 向けのモデルだけではありません。NLP 向けには Flair や AllenNLP、音声処理向けには Asteroid や pyannote、画像処理向けには timm など、様々なライブラリのモデルが公開されています。

これらのモデルはそれぞれ Git リポジトリとして公開されている為、バージョンを管理出来、結果の再現もし易くなっています。Hub でモデルを共有すると、コミュニティの誰もが簡単に利用出来るようになります。利用者は自分でモデルを学習させる必要がなくなり、モデルを共有したり利用したりする手間も減らせます。

更に、Hub でモデルを共有すると、そのモデルをサーバー上で実行出来る Inference API が自動的に用意されます。コミュニティの誰でも、モデルのページで好きな入力を指定し、用途に合ったウィジェットを使って直接試せます。

何より、Hub の公開モデルの共有も利用も完全に無料です。モデルを非公開で共有したい場合は 有料プラン もあります。

以下の動画では、Hub の使い方を紹介します。

このパートでは Hugging Face Hub 上にリポジトリを作成し、管理します。その為、huggingface.co のアカウントが必要です。未だ持っていない場合は、アカウントを作成 してください。
