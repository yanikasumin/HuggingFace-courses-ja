# 畳み込みニューラルネットワーク入門

前のユニットでは、視覚、画像、コンピュータビジョンの基礎を学びました。また、コンピュータで画像を解析する上で重要な要素である視覚的特徴についても見てきました。

これまで扱った手法は、現在では「古典的な」コンピュータビジョンと呼ばれることがよく有ります。小規模で制約の多いデータセットや環境ではうまく機能しますが、実世界の大きなデータセットを相手にすると限界が見えてきます。

このユニットでは、コンピュータビジョンの規模と性能を大きく前進させた畳み込みニューラルネットワーク（Convolutional Neural Networks）について学びます。

## 畳み込み：基本的な考え方

畳み込み（convolution）は、データから特徴を抽出する為に使われる演算です。データは1次元、2次元、3次元のいずれでも構いません。具体例で演算の仕組みを説明します。今の所は、数値を並べた行列をデータの上で少しずつずらし、重なった位置の数値同士を掛け合わせて、その結果を総て足し合わせる演算だと理解しておけば十分です。この行列はカーネル（kernel）又はフィルタ（filter）と呼ばれます。

「特徴抽出と何の関係があるのか、どうやって適用すればいいのか」と思うかもしれません。慌てなくて大丈夫です。これから説明します。

直感をつかむ為に、例を見てみましょう。1次元のデータが有り、それを可視化したものがこちらです。可視化すると、畳み込み演算の効果が分かり易くなります。

</div>

カーネルは [-1, 1] です。先ず一番左の要素にカーネルを置き、重なった数値同士を掛けて合計します。カーネルでは、その要素の1つを中心として扱います。ここでは右側の要素である 1 を中心とします。左側には想像上のゼロが有ると仮定します。これはパッド（pad）と呼ばれるもので、後ほど改めて出てきます。

カーネルの中心は全ての要素に触れなければいけないので、便宜上、要素の左側にゼロを置きます。パディングをしなければ、-1 は一番左の要素と掛けられますが、1 が一番左の要素に触れなくなってしまう為、パディングを適用するのです。どのような様子か見てみましょう。

一番左の要素（現在はパッドです）に -1 を掛け、最初の要素（ゼロ）に 1 を掛けて合計すると 0 になり、それを記録します。次に、カーネルを1つ分ずらして同じことを行い、再び記録します。この時、カーネルを一度にどれだけずらすかをストライドと呼びます。通常は1ピクセルずつ移動させます。より多くのピクセル分を動かすことも出来ます。現在の結果（畳み込まれたデータ）は [0, 0] という配列です。

## 畳み込みニューラルネットワーク

なるほど、ではこれは深層学習とどう関係するのでしょうか。特徴を抽出する為にフィルタを力任せに探す方法は、全ての画像に対してうまくいく訳ではありません。重要な情報を抽出したり、画像中の物体を検出したりする為の最適なフィルタを何らかの方法で見つけられたらどうでしょうか。そこで登場するのが畳み込みニューラルネットワークです。画像を様々なフィルタで畳み込み、特徴マップのピクセルがやがて最適化すべきパラメータとなり、最終的にその問題に最適なフィルタが見つかります。

考え方は、フィルタを使って情報を抽出するというものです。複数のフィルタをランダムに初期化し、特徴マップを作り、それを分類器に入力して、バックプロパゲーションを行います。その前に、「プーリング」と呼ばれるものを紹介します。

上の例で分かるように、特徴マップには変化を示すピクセルが数多く有ります。エッジが有ることを知るには、変化（エッジや角など何でも）が存在することだけが分かれば十分です。

<div class="flex justify-center">
    <img src="https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/CNNs/max_pooling.png" alt="プーリング">
</div>

上の例では、2つの内1つだけが得られれば十分でした。そうすれば、特徴を保ったまま保持するパラメータを減らせます。特徴マップの中で最も重要な要素を取り出すこの操作がプーリングです。プーリングを行うと、エッジがどこに在るかという正確なピクセルの位置は失われますが、保持するパラメータは少なくなります。またこの方法により、特徴抽出の仕組みが小さな変化に対して堅牢になります。例えば、画像に顔が有ることを知るには、2つの目、鼻、口が有ることが分かればよく、それらの要素間の距離や大きさは顔ごとに変わる傾向が有りますが、プーリングによってモデルはそうした変化に対して堅牢になります。

プーリングのもう1つの利点は、様々な入力サイズに対応し易くなることです。以下は最大プーリング（max pooling）の演算で、4ピクセルごとに最大のピクセルを取得します。プーリングには平均プーリング、重み付きプーリング、L2 プーリングなど、様々な種類が有ります。

簡単な CNN アーキテクチャを構築してみましょう。説明の為に Keras の例を使い、何が起きているかを順に追っていきます。以下がモデルです（繰り返しますが、慌てなくて大丈夫です。順に説明します）。

Keras の Sequential API が何をするか分からない場合の為に説明すると、レゴブロックのように層を積み重ねて接続します。各層にはそれぞれハイパーパラメータが有ります。Conv2D 層では畳み込みフィルタの数、カーネルサイズ、活性化関数を指定します。MaxPooling2D 層ではプーリングサイズを、Dense 層では出力ユニット数を指定します。今は、それぞれの層でこうした設定を行うのだと理解しておけば大丈夫です。

殆どの ConvNet の実装では、画像処理のようにカーネルを全てのピクセルに触れさせる為のパディングは行いません。ゼロでパディングをすると、境界にも特徴が有るかもしれないという前提が入り、計算の複雑さも増します。その為、最初の入力サイズが (26,26) になり、境界沿いの情報が失われます。

```python
model = keras.Sequential(
    [
        keras.Input(shape=input_shape),
        layers.Conv2D(32, kernel_size=(3, 3), activation="relu"),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Conv2D(64, kernel_size=(3, 3), activation="relu"),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Flatten(),
        layers.Dropout(0.5),
        layers.Dense(num_classes, activation="softmax"),
    ]
)
model.summary()
```

### 畳み込みニューラルネットワークにおけるバックプロパゲーションの理論

ここではバックプロパゲーションはどのように機能するのでしょうか。最適化したいのは最適なカーネルの値であり、それが重みとなります。最終的には、分類器がピクセル値、カーネル、クラスの間の関係を見つけ出すことが期待されます。つまり、ピクセル値に初期の重み（カーネルの要素）を使って畳み込みを行い、プーリングと活性化を経て得られた値を、長い1次元の配列に並べたものを使います。これらの重みを、「猫と犬の写真を区別する為に、どのカーネルを適用すべきか」という問いに答えられるよう更新します。CNN の訓練の要点は最適なカーネルを見つけることであり、それはバックプロパゲーションを使って見つけられます。

CNN 以前は、特徴を抽出する為に人々が自ら画像に沢山のフィルタを試していましたが、汎用的なフィルタ（上で見た Prewitt や Sobel など）は、画像が同じデータセット内でも大きく異なり得る為、全ての画像に必ずしも有効とは限りません。だからこそ CNN は従来の画像処理技術を上回る性能を発揮します。

畳み込みニューラルネットワークを使うと、ストレージの面でもいくつかの利点が有ります。

### パラメータ共有

畳み込みニューラルネットワークでは、全てのピクセル、全てのチャンネル、全ての画像に対して同じフィルタで畳み込みを行います。これによりパラメータの保持の面で利点があり、全結合ニューラルネットワークで画像を処理するよりもはるかに効率的です。これは「重みの共有（weight tying）」と呼ばれ、その重みは「tied weights」と呼ばれます。これはオートエンコーダでも見られる仕組みです。

### 疎な相互作用

全結合ニューラルネットワークでは、データ全体を一度に入力します。画像には数百から数千のピクセルが有る為、これは非常に負担が大きくなります。一方、ConvNet では、特徴を抽出する為に使うカーネルが小さいです。これは疎な相互作用（sparse interaction）と呼ばれ、使用するメモリを減らす助けになります。
