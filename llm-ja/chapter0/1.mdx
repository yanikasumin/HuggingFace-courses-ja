# はじめに[[introduction]]

Hugging Face コースへようこそ。このページでは、学習を始める前の作業環境の整え方を説明します。コースを始めたばかりの方は、まず[第1章](/course/chapter1)に目を通してください。その後、このページに戻って環境を整えると、自分でコードを動かしながら読み進められます。

このコースで使うライブラリは、全て Python パッケージとして提供されています。その為、ここでは Python の実行環境を用意し、必要なライブラリをインストールする手順を説明します。

環境の整え方には、Colab ノートブックを使う方法と、Python の仮想環境を使う方法の2つがあります。自分に合った方を選んでください。初心者には、Colab ノートブックから始める方法をお勧めします。

なお、Windows での環境構築は扱いません。Windows を使っている方は、Colab ノートブックで進めてください。Linux や macOS であれば、どちらの方法でも進められます。

このコースの大部分は、Hugging Face のアカウントがある前提で進みます。未だアカウントを持っていない方は、今の内に[アカウントを作成](https://huggingface.co/join)しておきましょう。

## Google Colab ノートブックを使う[[using-a-google-colab-notebook]]

Colab ノートブックを使う方法が、最も手軽です。ブラウザでノートブックを開くだけで、直ぐにコードを書き始められます。

Colab に慣れていない方は、まず[入門ノートブック](https://colab.research.google.com/notebooks/intro.ipynb)で基本的な操作を学んでください。Colab では、GPU や TPU のような高速化の為のハードウェアを使えます。小規模な処理であれば、無料で利用出来ます。

操作に慣れたら、新しいノートブックを作成し、次の手順でセットアップを進めます。

</div>

次に、このコースで使うライブラリをインストールします。インストールには、Python のパッケージ管理ツールである `pip` を使います。ノートブックでは、コマンドの先頭に `!` を付けるとシステムコマンドを実行出来ます。この仕組みを使って、🤗 Transformers ライブラリを次のようにインストールします。

```
!pip install transformers
```

インストールが正しく出来たかどうかは、Python の実行環境の中でインポートしてみると確認出来ます。

```
import transformers
```

</div>

これで入るのは、とても軽量な Transformers です。PyTorch や TensorFlow のような機械学習フレームワークは含まれていません。このコースではライブラリの様々な機能を使う為、ほぼ全ての用途に必要な依存パッケージが揃った開発版のインストールをお勧めします。

```
!pip install transformers[sentencepiece]
```

インストールには少し時間が掛かります。これが終われば、残りのコースを進める準備が整います。

## Python の仮想環境を使う[[using-a-python-virtual-environment]]

仮想環境を使う場合は、最初に Python をシステムへインストールします。手順は[このガイド](https://realpython.com/installing-python/)を参考にしてください。

インストールが終わると、ターミナルで Python のコマンドを実行出来るようになります。次の手順へ進む前に、`python --version` を実行して、正しくインストールされているか確認してください。システムで使える Python のバージョンが表示されるはずです。

ターミナルで `python --version` のようなコマンドを実行する時に呼び出される Python は、そのシステムの「メイン」の Python です。このメインの Python には、パッケージを直接入れない運用をお勧めします。代わりに、メインの Python を使って、アプリケーションごとに独立した環境を作ります。環境を分けておけば、アプリケーションごとに依存関係とパッケージを管理でき、他のアプリケーションとの互換性の問題を心配せずに済みます。

Python でこの役割を担うのが[仮想環境](https://docs.python.org/3/tutorial/venv.html)です。仮想環境とは、特定のバージョンの Python 本体と、そのアプリケーションに必要なパッケージ一式を収めた、独立したディレクトリ構造のことです。仮想環境を作るツールはいくつかありますが、ここでは Python 公式のパッケージである [`venv`](https://docs.python.org/3/library/venv.html#module-venv) を使います。

まず、アプリケーションを置くディレクトリを作成します。例えば、ホームディレクトリの直下に *transformers-course* という名前のディレクトリを作ります。

```
mkdir ~/transformers-course
cd ~/transformers-course
```

このディレクトリの中で、Python の `venv` モジュールを使って仮想環境を作成します。

```
python -m venv .env
```

空だったフォルダの中に、*.env* というディレクトリが出来ているはずです。

```
ls -a
```

```out
.      ..    .env
```

仮想環境への出入りには、`activate` スクリプトと `deactivate` スクリプトを使います。

```
# 仮想環境を有効化する
source .env/bin/activate

# 仮想環境を無効化する
deactivate
```

環境が有効になっているかどうかは、`which python` コマンドで確認出来ます。仮想環境の中を指していれば、有効化に成功しています。

```
which python
```

```out
/home/<user>/transformers-course/.env/bin/python
```

### 依存関係のインストール[[installing-dependencies]]

Colab の場合と同じく、コースの続きで必要になるパッケージをインストールします。ここでも `pip` を使い、🤗 Transformers の開発版をインストールします。

```
pip install "transformers[sentencepiece]"
```

これでセットアップは完了です。
