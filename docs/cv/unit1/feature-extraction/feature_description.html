特徴記述（Feature Description）

特徴は、モデルがインスタンスから学習した属性であり、後で新しいインスタンスを認識する為に使われます。

データ構造で特徴をどう表現するか？

データにおける特徴の表現は、データを効果的に整理し操作する為に重要です。特徴、つまり属性や変数は、数値やカテゴリから、画像やテキストのようなより複雑な構造まで、多様であり得ます。コンピュータビジョンタスクで特徴を表現する方法には、次のようなものがあります。

  • 数値特徴

  • 配列／リスト： 数値を格納する最も単純な形式。配列の各要素が特徴に対応します。

  • テンソル： 多次元配列。機械学習フレームワークで大量の数値データを効率的に処理する為によく使われます。

  • カテゴリ特徴

  • 辞書／リスト： カテゴリを数値ラベルに割り当てたり、カテゴリ値を直接格納したりします。

  • ワンホットエンコーディング： カテゴリ変数を、各ビットがカテゴリを表すバイナリベクトルに変換します。

  • 画像特徴

  • ピクセル値： ピクセル値の行列、又は多次元配列。

  • 畳み込みニューラルネットワーク特徴（CNN）： 事前学習済み CNN モデルを使って特徴を抽出します。

良い記述子とは

画像処理やコンピュータビジョンにおける良い記述子とは、画像内の物体やシーンについての重要な情報を効果的に表す、一連の特性や特徴のことです。良い記述子の条件には、次のような側面があります。

  • 変換に対する不変性： 記述子は理想的には、回転、平行移動、スケーリング、照明の変化といった変動に対してロバストであるべきです。つまり、物体がどう配置されても、画像がどう変更されても、記述子は比較的変わらず、元のものと同じ記述を含むべきです。
  • 識別性： 良い記述子は、物体についての固有の情報を捉えます。異なる物体や画像の部分を識別出来、似た要素と区別出来るだけの識別性を持つべきです。
  • 次元数： 良い記述子は扱い易いサイズであることが多く、過度に大きくなることなく十分な情報を伝えます。次元数のバランスは、処理と保存の効率に不可欠です。
  • 局所性： 記述子はしばしば画像内の局所的な特徴を特定します。局所記述子は特定の領域やキーポイントに焦点を当て、その領域の特性を記述することで、異なる画像間で類似した領域のマッチングと認識を可能にします。
  • 再現性： 記述子は、ノイズや小さな変動が有る場合でも、同じ物体やシーンの複数のインスタンスにわたって一貫し、再現可能であるべきです。
  • マッチングアルゴリズムとの互換性： 記述子は、異なる画像間の対応を見つける為にマッチングアルゴリズムと併用されることがよくあります。良い記述子は、距離指標、機械学習モデル、その他の手法のどれを使う場合でも、組み合わせるマッチングアルゴリズムに適している必要があります。
  • 計算効率： 記述子の計算効率は、リアルタイムアプリケーションでは特に重要です。ロボティクスや自動運転車のように処理速度が求められる用途では、記述子を短時間で計算出来る必要があります。
  • 適応性： 処理するデータに合わせて変化したり、そのデータから学習したり出来る記述子は、特に物体やシーンの特性が時間と共に変わる状況で効果を発揮します。これにより、記述子の使い易さが高まります。
  • ノイズへのロバスト性： 記述子は、根底にある特徴を正確に表す能力を大きく損なうことなく、画像データのノイズを扱えるべきです。

特徴記述子で使われるテクニックの例

SIFT

Scale Invariant Feature Transform の略です。画像内の局所的な特徴を検出・記述する為に、コンピュータビジョンと画像処理で広く使われているアルゴリズムです。

SIFT の動作は以下の通りです。

  • スケールスペースの極値検出： 複数のスケールにわたって画像内の潜在的な注目点を検出することから始めます。差分ガウシアン（DoG、ガウス関数の差）が、位置とスケールに関して極大又は極小となる点を画像内から探します。これらのキーポイントの位置は、様々なスケール変化の下で安定しているとみなされます。
  • キーポイントの局所化： 潜在的なキーポイントが特定されると、SIFT はその位置をサブピクセル精度まで絞り込み、低コントラストのキーポイントとエッジ上のキーポイントを除外して、正確な局所化を保証します。
  • 方向の割り当て： SIFT は、局所的な画像の勾配方向に基づいて、各キーポイントの支配的な方向を計算します。このステップにより、記述子は画像の回転に対して不変になります。
  • 記述子の生成： 各キーポイント領域に対して記述子が計算され、キーポイント付近の局所的な画像勾配についての情報を捉えます。この記述子は、キーポイントを囲む画像パッチの主要な特性を凝縮したコンパクトな表現です。
  • 記述子のマッチング： 最後に、これらの記述子は異なる画像間のキーポイントのマッチングに使われます。或る画像の記述子を別の画像のものと比較して、対応を見つけます。

SIFT は、様々な画像変換に対するロバスト性と、画像内の識別的な特徴を見つける能力により、物体認識、画像スティッチング、3D 再構成などの応用で価値があります。

SURF

Speeded Up Robust Features の略です。コンピュータビジョンや画像処理で広く使われている、もう1つのアルゴリズムです。局所的な画像特徴を検出・記述する際の速度とロバスト性で特に知られています。

SURF の基本的なワークフローは以下の通りです。

  • 積分画像： SURF は、元の画像の事前計算された表現である積分画像を利用します。これにより画像内の矩形領域の合計を高速に計算出来、より速い特徴計算が可能になります。

  • ブロブ検出： 他の特徴検出アルゴリズムと同様に、SURF は画像内の潜在的な注目点やキーポイントを特定することから始めます。ヘッセ行列を使って、複数の方向とスケールで強度に大きな変動を示すブロブや領域を検出します。これらの領域が潜在的なキーポイントです。

  • スケール選択： スケールスペースで大きな変化の有る領域を特定することで、キーポイントのスケールを決定します。異なるスケールにわたるヘッセ行列の行列式を分析し、複数のスケールでロバストなキーポイントを見つけます。

  • 方向の割り当て： 検出された各キーポイントについて、SURF は支配的な方向を割り当てます。その為に、キーポイントの周辺で様々な方向の Haar ウェーブレット応答を計算します。SIFT とは異なり、SURF はキーポイントの近傍のサブ領域に適用される矩形フィルター（Haar ウェーブレット）の集合を使います。これらのフィルターの応答を使って、キーポイントを表す特徴ベクトルを作成します。

  • 記述子のマッチング： 生成された記述子は、異なる画像間のキーポイントのマッチングに使われます。マッチングでは、或る画像のキーポイントの特徴ベクトルを別の画像のものと比較して、対応を見つけます。

SURF の主要な強みは、積分画像と Haar ウェーブレット近似の使用で達成される計算効率にあり、スケール、回転、照明の変化に対するロバスト性を維持します。これにより SURF は、物体検出、追跡、画像スティッチングなど、速度が重要な役割を果たすリアルタイムアプリケーションに適しています。
