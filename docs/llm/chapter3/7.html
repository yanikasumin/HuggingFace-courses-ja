章末の認定証

コースの修了、おめでとうございます！事前学習済みモデルをファインチューニングする方法、学習曲線の見方、そしてモデルをコミュニティと共有する方法を学びました。ここからはクイズに挑戦して、知識を確認し、認定証を取得しましょう。

クイズを受けるには、次の手順に従ってください。

  1. Hugging Face アカウントにサインインします。
  2. クイズの問題に回答します。
  3. 回答を送信します。
