Synthetic Data Generation with Diffusion Models

腫瘍のセグメンテーションのためにモデルを訓練しようとしていると想像してみてください。医療画像はデータを集めるのが難しいため、モデルを収束させるのは本当に困難でしょう。 理想的には、シンプルなベースラインを構築するのに十分なデータが少なくとも欲しいところですが、サンプルがほんの少ししかなかったらどうでしょうか？合成データの生成手法はこのジレンマを解決しようとするものであり、生成モデルのブームによって、現在では多くの選択肢があります！

前のセクションで見たように、DCGAN のような生成モデルを使って合成画像を生成することができます。このセクションでは、diffusers を使った拡散モデル（diffusion models）に焦点を当てます！

Recap of the Diffusion Models

拡散モデルは、高品質な画像を生成する能力のおかげで、近年大きな人気を集めている生成モデルです。現在では、画像、動画、テキストの合成に広く使われています。

拡散モデルは、ランダムなガウスノイズを段階的にノイズ除去（denoise）することを学習することで動作します。訓練プロセスでは、入力サンプルにガウスノイズを加え、モデルにノイズ除去を学習させることが必要です。

拡散モデルは一般に、データ分布とは別に、テキストプロンプト、画像、さらには音声といった何らかの入力で条件付けされます。さらに、無条件の生成器を構築することも可能です。

モデルの内部の仕組みの背後には多くの基礎概念がありますが、簡略化したバージョンは次のようなものです。

まず、モデルは入力にノイズを加えて処理します。

次に、モデルは与えられたデータ分布のノイズ除去方法を学習します。

理論に深く踏み込むことはしませんが、拡散モデルの仕組みを理解しておくと、ユースケースに合わせて合成データを生成する手法を選ぶ必要があるときに、とても役立ちます。

Text-To-Image Diffusion Model: Stable Diffusion

本質的に、Stable Diffusion（SD）の仕組みは上で述べたものと同じです。高品質な画像を生成するために、次の3つの主要コンポーネントを使います。

  1. 拡散プロセス（The diffusion process）: 入力は複数回処理され、画像に関する有用な情報を生成します。この「有用性」はモデルの訓練中に学習されます。

  2. 画像エンコーダ・デコーダモデル（Image encoder and decoder model）: モデルが画像をピクセル空間からより小さな次元空間へ圧縮できるようにし、意味のない情報を抽象化しながら性能を高めます。

  3. 任意の条件付けエンコーダ（Optional conditional encoder）: このコンポーネントは、生成プロセスを入力で条件付けるために使われます。この追加の入力は、テキストプロンプト、画像、音声、その他の表現でありえます。当初はテキストエンコーダでした。

全体のワークフローは次のようになります。

当初は、プロンプトでモデルを条件付けるためにテキストエンコーダを使っていました。

この短い概要は氷山の一角にすぎません！Stable Diffusion（あるいは拡散モデル）の背後にある理論を深く掘り下げたい場合は、参考資料のセクションをご覧ください！

diffusers は、さまざまなタスクにすぐ使える pipeline を提供しています。たとえば次のようなものです。

タスク 説明 Pipeline
Unconditional Image Generation ガウスノイズから画像を生成する unconditional_image_generation
Text-Guided Image Generation テキストプロンプトを与えて画像を生成する conditional_image_generation
Text-Guided Image-to-Image Translation テキストプロンプトに導かれて画像を変換する img2img
Text-Guided Image-Inpainting 画像、マスク、テキストプロンプトを与えて、画像のマスクされた部分を埋める inpaint
Text-Guided Depth-to-Image Translation 深度推定で構造を保持しながら、テキストプロンプトに導かれて画像の一部を変換する depth2img

サポートされているタスクの完全なリストは、Diffusers Summary の表からも確認できます。

つまり、合成データを生成するためのツールがたくさん手元にあるということです！

Approaches to Synthetic Data Generation

合成データが必要になるケースは、一般に3つあります。

既存のデータセットの拡張（Extending an existing dataset）:

  • サンプルが十分でない: 良い例は、DDSM（Digital Database for Screening Mammography、約2500サンプル）のような医療画像データセットです。サンプル量が少ないと、その後の分析のためのモデル構築が難しくなります。このような医療画像データセットを構築するのは、かなり費用もかかります。

データセットをゼロから作成する（Creating a Dataset from Scratch）:

  • サンプルがまったくない: CCTV の映像ストリームの上に武器検出システムを構築したいとしましょう。しかし、検出したい特定の武器のサンプルが存在しない場合、異なる環境での類似の観測を使ってスタイル変換を適用し、CCTV ストリームのように見せることができます！

プライバシーの保護（Preserving Privacy）:

  • 病院は患者に関する膨大な量のデータを収集し、監視カメラは個人の顔や活動に関する生の情報を捉えます。これらすべてが、プライバシー侵害の可能性をもたらします。拡散モデルを使えば、プライバシーを保護したデータセットを生成してソリューションを開発でき、誰のプライバシー権も放棄する必要がありません。

テキストから画像への拡散モデルを利用してカスタマイズした出力を生成する方法はいろいろあります。たとえば、事前に訓練された拡散モデル（Stable Diffusion XL など）を単に利用し、良いプロンプトを構成して画像を生成しようと試みることができます。しかし、生成画像の品質は一貫しないかもしれず、特定のユースケース向けにそのようなプロンプトを構成するのは本当に難しいかもしれません。

通常、望むパーソナライズされた出力を生成するには、モデルの一部を変更する必要があります。そのために使える手法をいくつか紹介します。

Textual Inversion で訓練する:

Textual Inversion は、モデルのアーキテクチャ内のテキスト埋め込みに干渉することで動作する手法です。語彙に新しいトークンを追加し、少数の例を使って埋め込みをファインチューニングできます。

新しいトークンに対応するサンプルを与えることで、物体の特徴を捉えるよう埋め込みを最適化しようとします。

LoRA（Low-Rank Adaptation） モデルを訓練する:

LoRA は、LLM のファインチューニングの問題に取り組んできました。重みの更新を、低ランク分解による2つの小さな更新行列で表現します。これにより、パラメータの量が大幅に少なくなります。そして、これらの行列を訓練して新しいデータに適応させることができます！

ベースモデルの重みはプロセス全体を通じて凍結されたままで、新しい更新行列だけを訓練します。最後に、適応した重みを元の重みと組み合わせます。

つまり、LoRA の訓練は本質的に、モデルの完全なファインチューニングよりもはるかに高速です！重要な注意点として、LoRA はモデル自体の上に付け加えることができるため、他の手法と組み合わせることも可能です。

DreamBooth で訓練する:

DreamBooth は、出力をパーソナライズするためにモデルをファインチューニングする手法です。対象の画像を数枚与えると、事前に訓練されたテキストから画像へのモデルをファインチューニングできます。主な考え方は、その特定の対象に一意な識別子を関連付けることです。

訓練では、語彙内のトークンを使い、できれば希少なトークンの識別子を使ってデータセットを構築します。ありふれた識別子を選ぶと、モデルは元の意味から切り離すことも学習しなければならなくなるからです。

元の論文では、著者らは語彙内の希少なトークンを見つけ、そこから識別子を選びます。これにより、識別子が強い事前分布を持つリスクが減ります。モデルのすべての層をファインチューニングすることで最良の結果が得られたとも述べられています。

Custom Diffusion で訓練する:

Custom Diffusion は、モデルをパーソナライズするための本当に強力な手法です。前述の方法と同様に必要なサンプルはごくわずかですが、その力は、複数の概念を同時に学習できることにあります！

上で述べた拡散プロセスの一部とテキストエンコーダだけを訓練することで動作し、最適化するパラメータが少なくなります。したがって、この方法でも高速なファインチューニングが可能です！
