データセットを Argilla に読み込む

取り組んでいる NLP タスクや具体的なユースケース・アプリケーションによって、データやアノテーションタスクの形は変わります。このセクションでは、ニュースを集めたデータセット を使って、2つのタスクを行います。各テキストのトピックを判定するテキスト分類と、言及されている固有表現を特定するトークン分類です。

Hub からデータセットをインポートすることは Argilla の UI からも直接出来ますが、ここでは SDK を使います。必要に応じてデータに更に手を加える方法も学べる為です。

データセットを設定する

最初のステップは、前のセクションで行ったように Argilla インスタンスに接続することです。

import argilla as rg

HF_TOKEN = "..."  # プライベートな Space の場合のみ

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # プライベートな Space の場合のみ
)

次に、Argilla におけるデータセットの設定を考えます。これは、データに対して行うアノテーションタスクを表すものです。まず Hub からデータセットを読み込み、列の構成やデータ型を表す features を確認して、データセットを正しく設定出来るようにします。

from datasets import load_dataset

data = load_dataset("SetFit/ag_news", split="train")
data.features

データセットの特徴は次の通りです。

```python out {'text': Value(dtype='string', id=None), 'label': Value(dtype='int64', id=None), 'label_text': Value(dtype='string', id=None)}

データセットには `text` と、テキスト分類用の初期ラベルが含まれています。これらを、固有表現の範囲を指定するスパンアノテーション用の質問と一緒にデータセットの設定に追加します。

```python
settings = rg.Settings(
    fields=[rg.TextField(name="text")],
    questions=[
        rg.LabelQuestion(
            name="label", title="Classify the text:", labels=data.unique("label_text")
        ),
        rg.SpanQuestion(
            name="entities",
            title="Highlight all the entities in the text:",
            labels=["PERSON", "ORG", "LOC", "EVENT"],
            field="text",
        ),
    ],
)

（質問文の訳：テキスト中の全ての固有表現をハイライトする：）

これらの設定が何を意味するのか、もう少し詳しく見ていきましょう。

まず fields（フィールド） を定義しました。これには、アノテーション対象の情報が含まれます。今回はフィールドが1つだけであり、それがテキストの形をしている為、TextField を選びました。

次に、データに対して行いたいタスクを表す questions（質問） を定義します。

  • テキスト分類タスクには LabelQuestion を選び、ラベルには label_text 列のユニークな値を使いました。質問で使用するラベルを、データセットに既に含まれているラベルと一致させる為です。
  • トークン分類タスクには SpanQuestion が必要です。そのタスクで使うラベルの集合と、スパンを描画する対象のフィールドを定義しました。

利用出来るフィールドや質問の種類、その他の高度な設定（メタデータやベクトルなど）について詳しくは、Argilla のドキュメント を参照してください。

データセットをアップロードする

設定を定義出来たので、データセットを作成します。

dataset = rg.Dataset(name="ag_news", settings=settings)

dataset.create()

データセットが Argilla インスタンスに表示されるようになりましたが、まだ空です。

次に、アノテーション対象のレコード、つまりデータセットの行を追加する必要があります。その為には、データをレコードとして登録（log）し、Hub のデータセットと Argilla のデータセットで名前が異なる要素についてはマッピングを指定します。

dataset.records.log(data, mapping={"label_text": "label"})

このマッピングでは、データセットの label_text 列を、名前が label の質問に対応付けています。こうすることで、データセットに既に在るラベルを事前アノテーションとして使い、より速くアノテーション出来ます。

レコードの登録処理が進んでいる間でも、Argilla の UI でデータセットの作業を開始出来ます。この時点では、次のような表示になっているはずです。

これで、データセットのアノテーションを始める準備が出来ました！
