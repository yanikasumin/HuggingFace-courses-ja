Gradio 入門

この章では、機械学習モデルを インタラクティブなデモ として見せる方法を学びます。

そもそも、何故モデルのデモや GUI を作るのでしょうか。デモがあれば:

  • 機械学習の開発者 は、技術に詳しくないチームや顧客を含む幅広い相手に、自分の成果を分かり易く見せられます
  • 研究者 は、機械学習モデルとその挙動を再現しやすくなります
  • 品質テスター や エンドユーザー は、モデルの失敗ポイントを見つけてデバッグしやすくなります
  • 多様なユーザー が、モデルに潜むアルゴリズムのバイアスを発見出来ます

モデルのデモ作りには Gradio というライブラリを使います。Gradio を使うと、あらゆる機械学習モデルに対応した Web ベースのデモを、全て Python で構築・カスタマイズ・共有出来ます。

Gradio で作られた機械学習デモの例をいくつか紹介します:

  • スケッチを入力すると、描かれているものを推定し、その結果をラベルとして返す スケッチ認識 モデル:
  • 質問の根拠となる文章と質問を入力すると、回答とその確率スコアを返す抽出型の 質問応答 モデル（この種のモデルは Chapter 7 で扱いました）:
  • 画像を入力すると、背景を除去した画像を返す 背景除去 モデル:

この章は、概念 と 応用 の両方を含むセクションで構成されています。各セクションで概念を学んだら、それを応用して、画像分類から音声認識まで、様々な種類のデモを作ります。この章を終えるころには、わずか数行の Python コードでこれらのデモ（そしてもっと多くのデモ！）を作れるようになるはずです。
