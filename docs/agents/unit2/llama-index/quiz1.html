Q1: QueryEngine とは何ですか？

QueryEngine コンポーネントを最もよく説明しているのは、次のうちどれですか？

QueryEngine には、関連する情報を検索して処理できることが求められます。
これが QueryEngine コンポーネントの中心的な役割を表しています。
QueryEngine は埋め込みを保存するだけではありません。情報を能動的に検索して取得します。
評価は、QueryEngine の主な役割である検索とは別のものです。

Q2: FunctionTools の目的は何ですか？

FunctionTools は、エージェントにとってなぜ重要ですか？

FunctionTools の主な目的はデータの保存ではありません。
FunctionTools は Python 関数をラップして、エージェントが利用できるようにします。
FunctionTools は、関数をエージェントが利用できるようにするという明確な目的を持っています。
FunctionTools はテキスト処理に限らず、さまざまな種類の関数で使えます。

Q3: LlamaIndex の Toolspecs とは何ですか？

Toolspecs の主な目的は何ですか？

Toolspecs は LlamaIndex のエコシステムで重要な役割を果たしています。
Toolspecs によって、コミュニティでツールを共有し、再利用できます。
Toolspecs はメモリを管理するものではなく、ツールを提供するためのものです。
Toolspecs にはテキスト処理に限らず、さまざまな種類のツールを含めることができます。

Q4: ツールを作成するために必要なものは何ですか？

ツールを作成するときに含めなければならない情報は何ですか？

これらはすべてツールを構成する要素ですが、名前と説明は関数と docstring から読み取ることができます。
ツールを適切にドキュメント化するには、関数と説明／docstring も必要です。
エージェントがツールを選択したときに実行するコードが必要なため、関数が必須です。
名前と説明は、渡された関数の名前と docstring がデフォルトとして使われます。
