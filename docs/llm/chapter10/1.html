Argilla 入門

Chapter 5 では 🤗 Datasets ライブラリを使ってデータセットを構築する方法を学び、Chapter 6 では代表的な NLP タスク向けにモデルをファインチューニングする方法を調べました。この章では、Argilla を使って、モデルの学習や評価に使えるデータセットに アノテーションを付けて整備する方法 を学びます。

性能のよいモデルを学習させる鍵は、質の高いデータです。Hub には学習や評価に使える優れたデータセットもありますが、自分のアプリケーションやユースケースには合わないこともあります。

その場合は、自分の用途に合うデータセットを新たに作成し、整備することも考えられます。Argilla を使えば、それを効率的に行えます。

Argilla を使うと、次のことが出来ます。

  • 構造化されていないデータを、NLP タスクで使える 構造化データ に変換出来ます。
  • 質の低いデータセットを見直し、高品質なデータセット に改善出来ます。
  • LLM やマルチモーダルモデル向けに 人間のフィードバック を集められます。
  • 専門家を Argilla に招待して共同作業したり、アノテーションをクラウドソーシングしたり出来ます！

この章で学ぶ内容の一例です。

  • 自分専用の Argilla インスタンスをセットアップする方法。
  • データセットを読み込み、代表的な NLP タスクに合わせて設定する方法。
  • Argilla の UI を使ってデータセットにアノテーションを付ける方法。
  • 整備したデータセットを活用し、Hub にエクスポートする方法。
