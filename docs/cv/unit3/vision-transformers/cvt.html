Convolutional Vision Transformer (CvT)

このセクションでは、Vision Transformer (ViT) [1] の派生モデルで、コンピュータビジョンの画像分類タスクで広く使われている Convolutional Vision Transformer (CvT) を詳しく見ていきます。

振り返り

CvT に入る前に、前セクションで扱った ViT のアーキテクチャを簡単に振り返っておくと、CvT の特徴が分かりやすくなります。ViT は各画像を固定長のトークン列（重ならないパッチ）に分解し、Multi-head Self Attention と Position-wise Feed-forward module (FFN) からなる標準的な Transformer 層を複数重ねて、分類のための大域的な関係をモデル化します。

概要

Convolutional Vision Transformer (CvT) は、論文 CvT: Introducing Convolutions to Vision Transformers [2] で提案されたモデルです。著者は Haiping Wu、Bin Xiao、Noel Codella、Mengchen Liu、Xiyang Dai、Lu Yuan、Lei Zhang です。CvT は CNN の利点である local receptive fields（局所受容野）、shared weights（重みの共有）、spatial subsampling（空間サブサンプリング）と、shift、scale、distortion invariance（平行移動・スケール・歪みに対する不変性）を取り入れつつ、Transformer の利点である dynamic attention、global context fusion、better generalization（動的アテンション、大域的な文脈の融合、より良い汎化）も保っています。CvT は ViT と比べて計算効率を維持しながら、より高い性能を達成します。さらに、畳み込みによって組み込まれた局所的な文脈構造のおかげで、CvT は位置埋め込みを必要としません。そのため、可変の入力解像度を必要とする幅広いビジョンタスクへの適応で有利になる可能性があります。

アーキテクチャ

（a）全体のアーキテクチャ。Convolutional Token Embedding 層によって実現される階層的な多段階構造を示します。（b）Convolutional Transformer Block の詳細。最初の層として畳み込み射影を含みます。 [2]

上の CvT アーキテクチャの図は、3 段階のパイプラインの主なステップを示しています。CvT の中核は、畳み込みに基づく 2 つの演算を Vision Transformer のアーキテクチャに組み合わせることです。

  • Convolutional Token Embedding: 入力画像を重なり合うパッチに分け、それをトークンに整形して畳み込み層に通します。これによりトークンの数が減り（ダウンサンプリングした画像のピクセル数の減少に似ています）、同時に特徴の豊かさが増します。従来の CNN に似た働きです。他の Transformer とは違い、事前に定めた位置情報をトークンに加えることはせず、空間的な関係の把握は畳み込み演算だけに頼ります。

（a）ViT における線形射影。（b）畳み込み射影。（c）圧縮畳み込み射影（CvT のデフォルト）。 [2]

  • Convolutional Transformer Blocks: CvT の各段階は、これらのブロックを積み重ねたもので構成されます。ここでは ViT で通常使われる線形射影の代わりに、上の図に示すように、self-attention モジュールの「query」「key」「value」の各要素を depth-wise separable convolutions（Convolutional Projection）で処理します。これにより Transformer の利点を保ちながら効率が向上します。なお、最終的な予測に使う「classification token」は最後の段階でのみ加えられます。最後に、標準的な全結合層が最終的な classification token を解析し、画像のクラスを予測します。

主なハイライト

優れた性能と計算効率の達成に役立った CvT の主なハイライトは、次の 4 点です。

  • 新しい Convolutional token embedding を備えた Hierarchy of Transformers（Transformer の階層構造）。
  • Convolutional Projection を活用する Convolutional Transformer block。
  • 畳み込みによって組み込まれた局所的な文脈構造により、Positional Encoding を除去したこと。
  • 他の Vision Transformer アーキテクチャと比べて、パラメータ数が少なく、FLOPs（Floating Point Operations per second）が低いこと。

PyTorch での実装

実際に手を動かしてみましょう。公式実装 [8] に示されている CvT アーキテクチャの主要ブロックを、PyTorch でどう書くかを順に見ていきます。

  1. 必要なライブラリのインポート
from collections import OrderedDict
import torch
import torch.nn as nn
import torch.nn.functional as F
from einops import rearrange
from einops.layers.torch import Rearrange
  1. Convolutional Projection の実装
def _build_projection(self, dim_in, dim_out, kernel_size, padding, stride, method):
    if method == "dw_bn":
        proj = nn.Sequential(
            OrderedDict(
                [
                    (
                        "conv",
                        nn.Conv2d(
                            dim_in,
                            dim_in,
                            kernel_size=kernel_size,
                            padding=padding,
                            stride=stride,
                            bias=False,
                            groups=dim_in,
                        ),
                    ),
                    ("bn", nn.BatchNorm2d(dim_in)),
                    ("rearrage", Rearrange("b c h w -> b (h w) c")),
                ]
            )
        )
    elif method == "avg":
        proj = nn.Sequential(
            OrderedDict(
                [
                    (
                        "avg",
                        nn.AvgPool2d(
                            kernel_size=kernel_size,
                            padding=padding,
                            stride=stride,
                            ceil_mode=True,
                        ),
                    ),
                    ("rearrage", Rearrange("b c h w -> b (h w) c")),
                ]
            )
        )
    elif method == "linear":
        proj = None
    else:
        raise ValueError("Unknown method ({})".format(method))

    return proj

このメソッドは、畳み込み層に関わるいくつかのパラメータ（入力次元と出力次元、カーネルサイズ、パディング、ストライド、メソッドなど）を受け取り、指定されたメソッドに応じた射影ブロックを返します。

  • メソッドが dw_bn（batch normalization を伴う depthwise separable）の場合、depthwise separable な畳み込み層の後に batch normalization を置き、次元の並び替えを行う Sequential ブロックを作成します。

  • メソッドが avg（average pooling）の場合、average pooling 層の後に次元の並び替えを行う Sequential ブロックを作成します。

  • メソッドが linear の場合、None を返し、射影が適用されないことを示します。

次元の並び替えは、入力テンソルを変形する Rearrange 演算で行われます。作成された射影ブロックが返されます。

  1. Convolutional Token Embedding の実装
class ConvEmbed(nn.Module):
    def __init__(
        self, patch_size=7, in_chans=3, embed_dim=64, stride=4, padding=2, norm_layer=None
    ):
        super().__init__()
        patch_size = to_2tuple(patch_size)
        self.patch_size = patch_size

        self.proj = nn.Conv2d(
            in_chans, embed_dim, kernel_size=patch_size, stride=stride, padding=padding
        )
        self.norm = norm_layer(embed_dim) if norm_layer else None

    def forward(self, x):
        x = self.proj(x)

        B, C, H, W = x.shape
        x = rearrange(x, "b c h w -> b (h w) c")
        if self.norm:
            x = self.norm(x)
        x = rearrange(x, "b (h w) c -> b c h w", h=H, w=W)

        return x

このコードは、入力画像に対してパッチ単位の埋め込みを行う ConvEmbed モジュールを定義しています。

  • __init__ メソッドは、patch_size（画像パッチのサイズ）、in_chans（入力チャンネル数）、embed_dim（埋め込まれたパッチの次元数）、stride（畳み込み演算のストライド）、padding（畳み込み演算のパディング）、norm_layer（正規化層、任意）などのパラメータでモジュールを初期化します。

  • コンストラクタでは、パッチサイズ、入力チャンネル、埋め込み次元、ストライド、パディングを含む指定パラメータで 2 次元畳み込み層（nn.Conv2d）を作成し、self.proj に代入します。

  • 正規化層が与えられた場合、その層のインスタンスを embed_dim チャンネルで作成し、self.norm に代入します。

  • forward メソッドは入力テンソル x を受け取り、self.proj を使って畳み込み演算を適用します。出力は rearrange 関数で空間次元を平坦化するように変形されます。正規化層があれば、平坦化された表現に適用されます。最後に、テンソルを元の空間次元に戻して返します。

まとめると、このモジュールは画像のパッチ単位の埋め込みのために設計されており、各パッチは畳み込み層で独立に処理され、埋め込まれた特徴に対して任意で正規化が適用されます。

  1. Vision Transformer ブロックの実装
class VisionTransformer(nn.Module):
    """Vision Transformer with support for patch or hybrid CNN input stage"""

    def __init__(
        self,
        patch_size=16,
        patch_stride=16,
        patch_padding=0,
        in_chans=3,
        embed_dim=768,
        depth=12,
        num_heads=12,
        mlp_ratio=4.0,
        qkv_bias=False,
        drop_rate=0.0,
        attn_drop_rate=0.0,
        drop_path_rate=0.0,
        act_layer=nn.GELU,
        norm_layer=nn.LayerNorm,
        init="trunc_norm",
        **kwargs,
    ):
        super().__init__()
        self.num_features = self.embed_dim = embed_dim

        self.rearrage = None

        self.patch_embed = ConvEmbed(
            patch_size=patch_size,
            in_chans=in_chans,
            stride=patch_stride,
            padding=patch_padding,
            embed_dim=embed_dim,
            norm_layer=norm_layer,
        )

        with_cls_token = kwargs["with_cls_token"]
        if with_cls_token:
            self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        else:
            self.cls_token = None

        self.pos_drop = nn.Dropout(p=drop_rate)
        dpr = [
            x.item() for x in torch.linspace(0, drop_path_rate, depth)
        ]  # stochastic depth の減衰ルール

        blocks = []
        for j in range(depth):
            blocks.append(
                Block(
                    dim_in=embed_dim,
                    dim_out=embed_dim,
                    num_heads=num_heads,
                    mlp_ratio=mlp_ratio,
                    qkv_bias=qkv_bias,
                    drop=drop_rate,
                    attn_drop=attn_drop_rate,
                    drop_path=dpr[j],
                    act_layer=act_layer,
                    norm_layer=norm_layer,
                    **kwargs,
                )
            )
        self.blocks = nn.ModuleList(blocks)

        if self.cls_token is not None:
            trunc_normal_(self.cls_token, std=0.02)

        if init == "xavier":
            self.apply(self._init_weights_xavier)
        else:
            self.apply(self._init_weights_trunc_normal)

        def forward(self, x):
            x = self.patch_embed(x)
            B, C, H, W = x.size()

            x = rearrange(x, "b c h w -> b (h w) c")

            cls_tokens = None
            if self.cls_token is not None:
                cls_tokens = self.cls_token.expand(B, -1, -1)
                x = torch.cat((cls_tokens, x), dim=1)

            x = self.pos_drop(x)

            for i, blk in enumerate(self.blocks):
                x = blk(x, H, W)

            if self.cls_token is not None:
                cls_tokens, x = torch.split(x, [1, H * W], 1)
            x = rearrange(x, "b (h w) c -> b c h w", h=H, w=W)

            return x, cls_tokens

このコードは Vision Transformer モジュールを定義しています。概要は次のとおりです。

  • 初期化: VisionTransformer クラスは、パッチサイズ、埋め込み次元、層の数、アテンションのヘッド数、ドロップアウト率など、モデルのアーキテクチャを決めるさまざまなパラメータで初期化されます。

  • Patch Embedding: モデルにはパッチ埋め込み層 (`patch_embed) が含まれます。これは入力画像を重ならないパッチに分割し、畳み込みを使って埋め込みます。

  • Transformer Blocks: モデルは Transformer ブロック（Block）のスタックで構成されます。ブロックの数は depth パラメータで決まります。各ブロックには multi-head self-attention 機構と feedforward ニューラルネットワークが含まれます。

  • Classification Token: 任意で、学習可能な classification token（cls_token）を入力列に追加できます。このトークンは分類タスクに使われます。

  • Stochastic Depth: Transformer ブロックには stochastic depth が適用され、訓練時にブロックのランダムな部分集合をスキップすることで正則化を改善します。これは drop_path_rate パラメータで制御されます。

  • 重みの初期化: モデルの重みは、切断正規分布（trunc_norm）または Xavier 初期化（xavier）のいずれかで初期化されます。

  • Forward メソッド: forward メソッドは、入力をパッチ埋め込みで処理し、次元を並び替え、classification token があれば加え、ドロップアウトを適用した後、Transformer ブロックのスタックにデータを通します。最後に、出力を元の形に並び替え、classification token があれば残りの列から分離して、出力を返します。

  1. Convolutional Vision Transformer ブロック（Hierarchy of Transformers）の実装
class ConvolutionalVisionTransformer(nn.Module):
    def __init__(
        self,
        in_chans=3,
        num_classes=1000,
        act_layer=nn.GELU,
        norm_layer=nn.LayerNorm,
        init="trunc_norm",
        spec=None,
    ):
        super().__init__()
        self.num_classes = num_classes

        self.num_stages = spec["NUM_STAGES"]
        for i in range(self.num_stages):
            kwargs = {
                "patch_size": spec["PATCH_SIZE"][i],
                "patch_stride": spec["PATCH_STRIDE"][i],
                "patch_padding": spec["PATCH_PADDING"][i],
                "embed_dim": spec["DIM_EMBED"][i],
                "depth": spec["DEPTH"][i],
                "num_heads": spec["NUM_HEADS"][i],
                "mlp_ratio": spec["MLP_RATIO"][i],
                "qkv_bias": spec["QKV_BIAS"][i],
                "drop_rate": spec["DROP_RATE"][i],
                "attn_drop_rate": spec["ATTN_DROP_RATE"][i],
                "drop_path_rate": spec["DROP_PATH_RATE"][i],
                "with_cls_token": spec["CLS_TOKEN"][i],
                "method": spec["QKV_PROJ_METHOD"][i],
                "kernel_size": spec["KERNEL_QKV"][i],
                "padding_q": spec["PADDING_Q"][i],
                "padding_kv": spec["PADDING_KV"][i],
                "stride_kv": spec["STRIDE_KV"][i],
                "stride_q": spec["STRIDE_Q"][i],
            }

            stage = VisionTransformer(
                in_chans=in_chans,
                init=init,
                act_layer=act_layer,
                norm_layer=norm_layer,
                **kwargs,
            )
            setattr(self, f"stage{i}", stage)

            in_chans = spec["DIM_EMBED"][i]

        dim_embed = spec["DIM_EMBED"][-1]
        self.norm = norm_layer(dim_embed)
        self.cls_token = spec["CLS_TOKEN"][-1]

        # 分類ヘッド
        self.head = (
            nn.Linear(dim_embed, num_classes) if num_classes > 0 else nn.Identity()
        )
        trunc_normal_(self.head.weight, std=0.02)

    def forward_features(self, x):
        for i in range(self.num_stages):
            x, cls_tokens = getattr(self, f"stage{i}")(x)

        if self.cls_token:
            x = self.norm(cls_tokens)
            x = torch.squeeze(x)
        else:
            x = rearrange(x, "b c h w -> b (h w) c")
            x = self.norm(x)
            x = torch.mean(x, dim=1)

        return x

    def forward(self, x):
        x = self.forward_features(x)
        x = self.head(x)

        return x

このコードは ConvolutionalVisionTransformer という PyTorch モジュールを定義しています。

  • モデルは複数の段階で構成され、各段階は VisionTransformer クラスのインスタンスで表されます。
  • 各段階は、spec 辞書で指定される、パッチサイズ、ストライド、深さ、ヘッド数などの異なる設定を持ちます。
  • forward_features メソッドは入力 x をすべての段階に通し、最終的な表現を集約します。
  • このクラスには、最終出力を生成するために線形変換を行う分類ヘッドがあります。
  • forward メソッドは forward_features を呼び出し、その結果を分類ヘッドに通します。
  • Vision Transformer の段階は stage0、stage1 のように順に名付けられ、各段階が VisionTransformer クラスのインスタンスとなって、Transformer の階層を形成します。

使い方

COCO 2017 データセットの画像を 1,000 個の ImageNet クラスのいずれかに分類するために CvT モデルを使う方法は、次のとおりです。

from transformers import AutoFeatureExtractor, CvtForImageClassification
from PIL import Image
import requests

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

feature_extractor = AutoFeatureExtractor.from_pretrained("microsoft/cvt-13")
model = CvtForImageClassification.from_pretrained("microsoft/cvt-13")

inputs = feature_extractor(images=image, return_tensors="pt")
outputs = model(**inputs)
logits = outputs.logits
# モデルは 1000 個の ImageNet クラスのいずれかを予測します
predicted_class_idx = logits.argmax(-1).item()
print("Predicted class:", model.config.id2label[predicted_class_idx])
