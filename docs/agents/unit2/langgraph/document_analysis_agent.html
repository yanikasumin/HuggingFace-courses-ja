ドキュメント分析グラフ

Alfred がお仕えします。Mr. Wayne の信頼できる執事として、私は Mr. Wayne のさまざまなドキュメントに関するニーズをどのようにお手伝いしているかを、ここに記録しておきました。彼が…夜間の活動に出かけている間、私は彼の書類やトレーニングスケジュール、栄養プランがすべて適切に分析され、整理されていることを確認します。

出かける前に、彼はその週のトレーニングプログラムを記したメモを残していきました。そこで私は、明日の食事の メニュー を考える責任を引き受けることにしました。

今後このようなことがあったときのために、LangGraph を使って Mr. Wayne のニーズに応えるドキュメント分析システムを作りましょう。このシステムでは次のことができます。

  1. 画像ドキュメントを処理する
  2. ビジョンモデル（Vision Language Model）を使ってテキストを抽出する
  3. 必要に応じて計算を行う（通常のツールの使い方を示すため）
  4. 内容を分析し、簡潔な要約を提供する
  5. ドキュメントに関連する具体的な指示を実行する

import base64
from typing import List, TypedDict, Annotated, Optional
from langchain_openai import ChatOpenAI
from langchain_core.messages import AnyMessage, SystemMessage, HumanMessage
from langgraph.graph.message import add_messages
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import ToolNode, tools_condition
from IPython.display import Image, display

エージェントの State を定義する

この State は、これまで見てきたものより少し複雑です。 AnyMessage は Langchain がメッセージを定義するクラスで、add_messages は、最新の State で上書きするのではなく、最新のメッセージを追加する演算子です。

これは LangGraph の新しい概念で、State の中に演算子を追加して、それらがどのように連携すべきかを定義できます。

class AgentState(TypedDict):
    # 提供されたドキュメント
    input_file: Optional[str]  # ファイルパス（PDF/PNG）を含みます
    messages: Annotated[list[AnyMessage], add_messages]

ツールの準備

vision_llm = ChatOpenAI(model="gpt-4o")

def extract_text(img_path: str) -> str:
    """
    マルチモーダルモデルを使って、画像ファイルからテキストを抽出します。

    Master Wayne は、トレーニングメニューや食事プランのメモを残すことがよくあります。
    これにより、その内容を適切に分析できます。
    """
    all_text = ""
    try:
        # 画像を読み取り、base64 でエンコードします
        with open(img_path, "rb") as image_file:
            image_bytes = image_file.read()

        image_base64 = base64.b64encode(image_bytes).decode("utf-8")

        # base64 の画像データを含むプロンプトを用意します
        message = [
            HumanMessage(
                content=[
                    {
                        "type": "text",
                        "text": (
                            "Extract all the text from this image. "
                            "Return only the extracted text, no explanations."
                        ),
                    },
                    {
                        "type": "image_url",
                        "image_url": {
                            "url": f"data:image/png;base64,{image_base64}"
                        },
                    },
                ]
            )
        ]

        # ビジョン対応モデルを呼び出します
        response = vision_llm.invoke(message)

        # 抽出したテキストを追加します
        all_text += response.content + "\n\n"

        return all_text.strip()
    except Exception as e:
        # 執事らしく、エラーは穏やかに処理します
        error_msg = f"Error extracting text: {str(e)}"
        print(error_msg)
        return ""

def divide(a: int, b: int) -> float:
    """a を b で割ります。Master Wayne のときどきの計算用です。"""
    return a / b

# 執事にツールを持たせます
tools = [
    divide,
    extract_text
]

llm = ChatOpenAI(model="gpt-4o")
llm_with_tools = llm.bind_tools(tools, parallel_tool_calls=False)

ノード

def assistant(state: AgentState):
    # システムメッセージ
    textual_description_of_tool="""
extract_text(img_path: str) -> str:
    Extract text from an image file using a multimodal model.

    Args:
        img_path: A local image file path (strings).

    Returns:
        A single string containing the concatenated text extracted from each image.
divide(a: int, b: int) -> float:
    Divide a and b
"""
    image=state["input_file"]
    sys_msg = SystemMessage(content=f"You are a helpful butler named Alfred that serves Mr. Wayne and Batman. You can analyse documents and run computations with provided tools:\n{textual_description_of_tool} \n You have access to some optional images. Currently the loaded image is: {image}")

    return {
        "messages": [llm_with_tools.invoke([sys_msg] + state["messages"])],
        "input_file": state["input_file"]
    }

ReAct パターン: Mr. Wayne をどのようにお手伝いするか

このエージェントのアプローチについて説明します。このエージェントは、ReAct パターン（Reason-Act-Observe）として知られる方式に従います。

  1. Reason: 彼のドキュメントとリクエストについて推論します
  2. Act: 適切なツールを使って行動します
  3. Observe: 結果を観察します
  4. Repeat: 彼のニーズに完全に対処できるまで、必要に応じて繰り返します

これは、LangGraph を使ったエージェントのシンプルな実装です。

# グラフ
builder = StateGraph(AgentState)

# ノードを定義します: これらが処理を行います
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# エッジを定義します: これらが制御フローの動きを決めます
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # 最新のメッセージがツールを必要とする場合は tools へルーティングします
    # それ以外の場合は直接応答します
    tools_condition,
)
builder.add_edge("tools", "assistant")
react_graph = builder.compile()

# 執事の思考過程を表示します
display(Image(react_graph.get_graph(xray=True).draw_mermaid_png()))

ツールのリストを使って tools ノードを定義します。assistant ノードは、ツールをバインドしたモデルそのものです。 assistant ノードと tools ノードでグラフを作成します。

tools_condition エッジを追加します。これは、assistant がツールを呼び出すかどうかに基づいて、End または tools へルーティングします。

ここで、新しいステップを 1 つ追加します。

tools ノードを assistant へ戻すよう接続し、ループを形成します。

  • assistant ノードが実行されたあと、tools_condition が、モデルの出力がツール呼び出しかどうかを確認します。
  • ツール呼び出しの場合は、フローは tools ノードへ向けられます。
  • tools ノードは assistant へ戻るよう接続されています。
  • このループは、モデルがツールを呼び出すと判断する限り続きます。
  • モデルの応答がツール呼び出しでない場合は、フローは END へ向けられ、処理が終了します。

LangGraph でツールを使うエージェントの、シンプルなユースケースを示す例です。

messages = [HumanMessage(content="Divide 6790 by 5")]
messages = react_graph.invoke({"messages": messages, "input_file": None})

# メッセージを表示します
for m in messages['messages']:
    m.pretty_print()

Tool Response: 1358.0

Alfred: The result of dividing 6790 by 5 is 1358.0.

重要なポイント

自分専用のドキュメント分析執事を作りたい場合は、次の点が重要です。

  1. 明確なツールを定義する: ドキュメント関連の具体的なタスク向けのもの
  2. 堅牢な State トラッカーを作成する: ツール呼び出しの間でコンテキストを維持するために
  3. エラー処理を検討する: ツールの失敗に備えて
  4. コンテキストの認識を維持する: これまでのやり取りについて（演算子 add_messages によって確保されます）

これらの原則があれば、Wayne Manor にふさわしい模範的なドキュメント分析サービスを提供できます。
