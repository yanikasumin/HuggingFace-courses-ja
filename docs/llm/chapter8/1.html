はじめに

🤗 Transformers を使って代表的な NLP タスクに取り組む方法は、これまでの章で扱いました。ここからは、自分のプロジェクトに取り組む段階です。この章では、作業中に問題が発生したときの対処法を扱います。コードと学習のデバッグの進め方と、自分だけでは解決出来ない場合にコミュニティへ助けを求める方法を説明します。Hugging Face のライブラリにバグを見つけたと思われる場合は、問題が出来るだけ早く解決するように報告する方法も説明します。

具体的には、この章では次の内容を学びます。

  • エラーが発生したときに最初に行うこと
  • フォーラムで助けを求める方法
  • 学習パイプラインのデバッグ方法
  • よい Issue の書き方

この章の内容は、🤗 Transformers や Hugging Face のエコシステムに限ったものではありません。殆どのオープンソースプロジェクトにも当てはまります。
