データセットを Argilla に読み込む

取り組む NLP タスクや、具体的なユースケース・アプリケーションによって、データの形もアノテーションタスクの内容も変わります。このセクションでは、ニュースを集めたデータセット を使って2つのタスクを行います。各テキストの話題を判定するテキスト分類と、文中に言及されている固有表現を特定するトークン分類です。

Hub からのインポートは Argilla の UI でも直接出来ますが、ここでは SDK を使います。後でデータに手を加える必要が出た場合の方法も、一緒に学べる為です。

データセットを設定する

最初のステップは、前のセクションで行ったように Argilla インスタンスに接続することです。

import argilla as rg

HF_TOKEN = "..."  # プライベートな Space の場合のみ

client = rg.Argilla(
    api_url="...",
    api_key="...",
    headers={"Authorization": f"Bearer {HF_TOKEN}"},  # プライベートな Space の場合のみ
)

次に、Argilla 上でのデータセットの設定を決めます。設定は、データに対して行うアノテーションタスクそのものを表します。設定を誤らないよう、まず Hub からデータセットを読み込み、features を確認します。これには列の構成やデータ型が示されています。

from datasets import load_dataset

data = load_dataset("SetFit/ag_news", split="train")
data.features

データセットの特徴は次の通りです。

```python out {'text': Value(dtype='string', id=None), 'label': Value(dtype='int64', id=None), 'label_text': Value(dtype='string', id=None)}

このデータセットには `text` と、テキスト分類に使う初期ラベルが含まれています。設定にはこれらを取り込み、固有表現を対象とするスパン形式の質問も加えます。

```python
settings = rg.Settings(
    fields=[rg.TextField(name="text")],
    questions=[
        rg.LabelQuestion(
            name="label", title="Classify the text:", labels=data.unique("label_text")
        ),
        rg.SpanQuestion(
            name="entities",
            title="Highlight all the entities in the text:",
            labels=["PERSON", "ORG", "LOC", "EVENT"],
            field="text",
        ),
    ],
)

（質問文の訳：テキストを分類する：）

（質問文の訳：テキスト中の全ての固有表現をハイライトする：）

これらの設定が何を意味するのか、もう少し詳しく見ていきましょう。

まず fields（フィールド） を定義しました。フィールドには、アノテーションの対象となる情報が入ります。今回はフィールドが1つだけで、その内容はテキストである為、TextField を選びました。

次に、データに対して行いたいタスクを表す questions（質問） を定義します。

  • テキスト分類タスクには LabelQuestion を選びました。ラベルには label_text 列のユニークな値を使います。データセットに既に含まれているラベルと、質問のラベルを一致させる為です。
  • トークン分類タスクには SpanQuestion が必要です。そのタスクで使うラベルの集合と、スパンを描画する対象のフィールドを定義しました。

利用出来るフィールドや質問の種類、その他の高度な設定（メタデータやベクトルなど）について詳しくは、Argilla のドキュメント を参照してください。

データセットをアップロードする

設定を定義出来たので、データセットを作成します。

dataset = rg.Dataset(name="ag_news", settings=settings)

dataset.create()

データセットが Argilla インスタンスに表示されるようになりましたが、まだ空です。

次に、アノテーション対象のレコード、つまりデータセットの行を追加します。追加はデータをレコードとして登録（log）することで行い、Hub 側と Argilla 側で名前が異なる要素にはマッピングを指定します。

dataset.records.log(data, mapping={"label_text": "label"})

このマッピングでは、データセットの label_text 列を、名前が label の質問に対応付けています。これにより、データセットに既に在るラベルを事前のアノテーションとして利用でき、アノテーションの作業を速く進められます。

レコードの登録が続いている間も、Argilla の UI でデータセットの作業を始められます。この時点では、次のような表示になっているはずです。

これで、データセットのアノテーションを始める準備が出来ました！
