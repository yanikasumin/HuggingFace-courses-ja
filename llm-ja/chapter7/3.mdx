Transformer モデルを使う NLP アプリケーションの多くでは、Hugging Face Hub の事前学習済みモデルを使い、手元のタスクに合わせて自分のデータで直接ファインチューニングします。事前学習のコーパスとファインチューニングのコーパスが大きく異ならなければ、転移学習で通常は良い結果が得られます。

但し、タスク固有のヘッドを学習する前に、まず自分のデータで言語モデル自体をファインチューニングした方がよい場合があります。例えば、データセットに法律の契約書や科学論文が含まれている場合です。BERT のような通常の Transformer モデルは、ドメイン固有の単語を珍しいトークンとして扱うことが多く、十分な性能が得られない場合があります。ドメイン内のデータで言語モデルをファインチューニングしておけば、多くの下流タスクの性能が上がります。この作業は通常、一度行えば済みます。

事前学習済みの言語モデルをドメイン内のデータでファインチューニングする作業は、一般に*ドメイン適応*と呼ばれます。ドメイン適応は 2018 年に [ULMFiT](https://arxiv.org/abs/1801.06146) が広めた手法です。ULMFiT は、NLP で転移学習を機能させた初期のニューラルアーキテクチャの1つで、LSTM を基にしています。下の画像は、ULMFiT によるドメイン適応の例です。このセクションでも同じ考え方を使います。但し、LSTM の代わりに Transformer を使います。

## マスク言語モデリング用の事前学習済みモデルの選択[[picking-a-pretrained-model-for-masked-language-modeling]]

まず、マスク言語モデリングに適した事前学習済みモデルを選びます。[Hugging Face Hub](https://huggingface.co/models?pipeline_tag=fill-mask&sort=downloads) で「Fill-Mask」フィルタを適用すると、次のスクリーンショットのように候補の一覧が表示されます。

最も多くダウンロードされているのは BERT と RoBERTa のファミリーのモデルです。但し、ここでは [DistilBERT](https://huggingface.co/distilbert-base-uncased)
というモデルを使います。下流タスクの性能を殆ど落とさずに、はるかに速く学習出来る為です。

このモデルは、[*知識蒸留*](https://en.wikipedia.org/wiki/Knowledge_distillation)と呼ばれる手法で学習されています。知識蒸留とは、BERT のような大きな「教師モデル」を使い、パラメータの少ない「生徒モデル」の学習を導く手法です。詳細はこのセクションの範囲を超える為、興味のある方は [_Natural Language Processing with Transformers_](https://www.oreilly.com/library/view/natural-language-processing/9781098136789/)（通称 Transformers の教科書）を参照してください。

人間であれば、`[MASK]` トークンには「day」「ride」「painting」など多くの候補が考えられます。事前学習済みモデルの予測は、学習に使ったコーパスに依存します。モデルは、データに存在する統計的なパターンを学習する為です。DistilBERT は BERT と同様に、 [English Wikipedia](https://huggingface.co/datasets/wikipedia) と [BookCorpus](https://huggingface.co/datasets/bookcorpus) のデータセットで事前学習されています。その為、`[MASK]` の予測にはこれらのドメインが反映されると予想されます。

マスクを予測するには、モデルへの入力を作る為のトークナイザが必要です。DistilBERT のトークナイザも Hub からダウンロードします。


トークナイザとモデルが揃いました。テキストの例をモデルに渡してロジットを取り出し、上位5つの候補を表示します。

{#if fw === 'pt'}

```python
import torch

inputs = tokenizer(text, return_tensors="pt")
token_logits = model(**inputs).logits
# [MASK] の位置を見つけ、そのロジットを取り出す
mask_token_index = torch.where(inputs["input_ids"] == tokenizer.mask_token_id)[1]
mask_token_logits = token_logits[0, mask_token_index, :]
# ロジットが最も高い [MASK] の候補を選ぶ
top_5_tokens = torch.topk(mask_token_logits, 5, dim=1).indices[0].tolist()

for token in top_5_tokens:
    print(f"'>>> {text.replace(tokenizer.mask_token, tokenizer.decode([token]))}'")
```

## データの前処理[[preprocessing-the-data]]

<Youtube id="8PmhEIXhBvI"/>

因果言語モデリングでもマスク言語モデリングでも、前処理では全てのサンプルを連結し、コーパス全体を等しいサイズのチャンクに分割するのが一般的です。個々のサンプルを単にトークン化する通常の方法とは異なります。連結する理由は、個々のサンプルが長過ぎると切り捨てられ、言語モデリングに役立つ情報が失われる為です。

まず、通常通りコーパスをトークン化します。但し、トークナイザの `truncation=True` オプションは*設定しません*。単語 ID が利用出来る場合は、併せて取得しておきます。高速トークナイザを使えば利用出来ます（[Chapter 6](/course/chapter6/3) で説明しました）。単語 ID は、後で行う全単語マスキングに必要です。以上の処理を単純な関数にまとめ、その中で、不要になった `text` 列と `label` 列も取り除きます。

```python
def tokenize_function(examples):
    result = tokenizer(examples["text"])
    if tokenizer.is_fast:
        result["word_ids"] = [result.word_ids(i) for i in range(len(result["input_ids"]))]
    return result


# batched=True を使って高速なマルチスレッディングを有効化！
tokenized_datasets = imdb_dataset.map(
    tokenize_function, batched=True, remove_columns=["text", "label"]
)
tokenized_datasets
```

合計の長さが一致しました。次に、連結したレビューを `chunk_size` のサイズのチャンクに分割します。`concatenated_examples` の各フィールドを処理し、リスト内包表記で各フィールドのスライスを作ります。結果は、フィールドごとのチャンクを集めた辞書です。

```python
chunks = {
    k: [t[i : i + chunk_size] for i in range(0, total_length, chunk_size)]
    for k, t in concatenated_examples.items()
}

for chunk in chunks["input_ids"]:
    print(f"'>>> チャンクの長さ: {len(chunk)}'")
```

```python out

'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 128'
'>>> チャンクの長さ: 55'
```

この例のように、最後のチャンクは通常、最大のチャンクサイズより小さくなります。対処法は主に2つあります。

* 最後のチャンクが `chunk_size` より小さい場合は破棄する。
* 最後のチャンクを、その長さが `chunk_size` と等しくなるまでパディングする。

ここでは1つ目の方法を取ります。以上の処理を、トークン化したデータセットに適用出来る関数にまとめます。

```python
def group_texts(examples):
    # すべてのテキストを連結する
    concatenated_examples = {k: sum(examples[k], []) for k in examples.keys()}
    # 連結したテキストの長さを計算する
    total_length = len(concatenated_examples[list(examples.keys())[0]])
    # 最後のチャンクが chunk_size より小さい場合は破棄する
    total_length = (total_length // chunk_size) * chunk_size
    # max_len のチャンクに分割する
    result = {
        k: [t[i : i + chunk_size] for i in range(0, total_length, chunk_size)]
        for k, t in concatenated_examples.items()
    }
    # 新しい labels 列を作成する
    result["labels"] = result["input_ids"].copy()
    return result
```

`group_texts()` の最後のステップでは、`input_ids` 列のコピーとして新しい `labels` 列を作成しています。マスク言語モデリングの目的は、入力バッチ内でランダムにマスクされたトークンを予測することです。`labels` 列があることで、言語モデルに学習用の正解を与えられます。

マスク言語モデルの学習では、個々のトークンではなく単語全体をまとめてマスクする手法も使えます。この手法は*全単語マスキング*と呼ばれます。全単語マスキングを使う場合は、データコレータを自分で用意します。データコレータは、サンプルのリストを受け取ってバッチに変換する関数です。先に計算した単語 ID を使い、単語のインデックスと対応するトークンの対応表を作ります。次に、どの単語をマスクするかをランダムに決め、入力に適用します。ラベルは全て `-100` とし、マスクする単語に対応するラベルだけを例外とします。

{#if fw === 'pt'}

```py
import collections
import numpy as np

from transformers import default_data_collator

wwm_probability = 0.2


def whole_word_masking_data_collator(features):
    for feature in features:
        word_ids = feature.pop("word_ids")

        # 単語と対応するトークンのインデックスの間のマップを作成する
        mapping = collections.defaultdict(list)
        current_word_index = -1
        current_word = None
        for idx, word_id in enumerate(word_ids):
            if word_id is not None:
                if word_id != current_word:
                    current_word = word_id
                    current_word_index += 1
                mapping[current_word_index].append(idx)

        # 単語をランダムにマスクする
        mask = np.random.binomial(1, wwm_probability, (len(mapping),))
        input_ids = feature["input_ids"]
        labels = feature["labels"]
        new_labels = [-100] * len(labels)
        for word_id in np.where(mask)[0]:
            word_id = word_id.item()
            for idx in mapping[word_id]:
                new_labels[idx] = labels[idx]
                input_ids[idx] = tokenizer.mask_token_id
        feature["labels"] = new_labels

    return default_data_collator(features)
```

### 言語モデルのパープレキシティ[[perplexity-for-language-models]]

<Youtube id="NURcDHhYe98"/>

テキスト分類や質問応答では、学習用のラベル付きコーパスが与えられます。言語モデリングには、明示的なラベルがありません。良い言語モデルは、スマートフォンの自動修正機能と同様に、文法的に正しい文には高い確率を割り当て、意味をなさない文には低い確率を割り当てます。オンラインでは「autocorrect fails」という事例集が見つかります。スマートフォンのモデルが、面白い補完や不適切な補完を生み出した事例を集めたものです。

{#if fw === 'pt'}

テストセットが主に文法的に正しい文で構成されているとします。言語モデルの品質を測る方法は1つあります。テストセットの全ての文について、次の単語にモデルが割り当てる確率を計算する方法です。確率が高いことは、モデルが見たことの無いサンプルに「驚いて」おらず、つまり「困惑（perplexed）」していないことを意味します。その言語の文法の基本パターンを学習したと考えられます。

ここまでの例では、学習ループに特別な処理は必要ありませんでした。但し、場合によっては独自の処理を実装する必要があります。そのような用途には Accelerate が使えます。以下で説明します。

## DistilBERT を 🤗 Accelerate でファインチューニングする[[fine-tuning-distilbert-with-accelerate]]

`Trainer` で見たように、マスク言語モデルのファインチューニングは、[Chapter 3](/course/chapter3) のテキスト分類の例と非常によく似ています。注意点は専用のデータコレータを使う点だけであり、このセクションで既に扱いました。

但し、`DataCollatorForLanguageModeling` は評価のたびにもランダムマスキングを適用します。その為、学習を実行するたびにパープレキシティのスコアが変動します。この変動を取り除く方法が1つあります。テストセット全体にマスキングを*一度だけ*適用し、評価では Transformers の既定のデータコレータでバッチを集める方法です。仕組みを確認する為、`DataCollatorForLanguageModeling` を最初に使った時と同様に、バッチへマスキングを適用する単純な関数を実装します。

```python
def insert_random_mask(batch):
    features = [dict(zip(batch, t)) for t in zip(*batch.values())]
    masked_inputs = data_collator(features)
    # データセットの各列について、新しい「masked」列を作成する
    return {"masked_" + k: v.numpy() for k, v in masked_inputs.items()}
```

次に、この関数をテストセットに適用します。マスクされていない列は取り除き、マスクされた列に置き換えます。上の `data_collator` を適切なものに置き換えれば、全単語マスキングも使えます。その場合は、ここの最初の行を取り除いてください。

```py
downsampled_dataset = downsampled_dataset.remove_columns(["word_ids"])
eval_dataset = downsampled_dataset["test"].map(
    insert_random_mask,
    batched=True,
    remove_columns=downsampled_dataset["test"].column_names,
)
eval_dataset = eval_dataset.rename_columns(
    {
        "masked_input_ids": "input_ids",
        "masked_attention_mask": "attention_mask",
        "masked_labels": "labels",
    }
)
```

次に、通常通りデータローダを設定します。評価セットには、Transformers の `default_data_collator` を使います。

```python
from torch.utils.data import DataLoader
from transformers import default_data_collator

batch_size = 64
train_dataloader = DataLoader(
    downsampled_dataset["train"],
    shuffle=True,
    batch_size=batch_size,
    collate_fn=data_collator,
)
eval_dataloader = DataLoader(
    eval_dataset, batch_size=batch_size, collate_fn=default_data_collator
)
```

ここからは、Accelerate の標準的な手順に従います。まず、事前学習済みモデルの新しいコピーを読み込みます。

```
model = AutoModelForMaskedLM.from_pretrained(model_checkpoint)
```

次に、オプティマイザを指定します。標準の `AdamW` を使います。

```python
from torch.optim import AdamW

optimizer = AdamW(model.parameters(), lr=5e-5)
```

これらのオブジェクトを `Accelerator` オブジェクトに渡し、学習の準備をします。

```python
from accelerate import Accelerator

accelerator = Accelerator()
model, optimizer, train_dataloader, eval_dataloader = accelerator.prepare(
    model, optimizer, train_dataloader, eval_dataloader
)
```

モデル、オプティマイザ、データローダを設定しました。次に、学習率スケジューラを次のように指定します。

```python
from transformers import get_scheduler

num_train_epochs = 3
num_update_steps_per_epoch = len(train_dataloader)
num_training_steps = num_train_epochs * num_update_steps_per_epoch

lr_scheduler = get_scheduler(
    "linear",
    optimizer=optimizer,
    num_warmup_steps=0,
    num_training_steps=num_training_steps,
)
```

学習の前に行うことはあと1つだけです。Hugging Face Hub にモデルリポジトリを作成します。Hub ライブラリを使い、まずリポジトリの完全な名前を生成します。

```python
from huggingface_hub import get_full_repo_name

model_name = "distilbert-base-uncased-finetuned-imdb-accelerate"
repo_name = get_full_repo_name(model_name)
repo_name
```

```python out

```

次に、Hub の `Repository` クラスを使い、リポジトリを作成してクローンします。

```python
from huggingface_hub import Repository

output_dir = model_name
repo = Repository(output_dir, clone_from=repo_name)
```

残る作業は、学習ループと評価ループを全て書くことです。

```python
from tqdm.auto import tqdm
import torch
import math

progress_bar = tqdm(range(num_training_steps))

for epoch in range(num_train_epochs):
    # 学習
    model.train()
    for batch in train_dataloader:
        outputs = model(**batch)
        loss = outputs.loss
        accelerator.backward(loss)

        optimizer.step()
        lr_scheduler.step()
        optimizer.zero_grad()
        progress_bar.update(1)

    # 評価
    model.eval()
    losses = []
    for step, batch in enumerate(eval_dataloader):
        with torch.no_grad():
            outputs = model(**batch)

        loss = outputs.loss
        losses.append(accelerator.gather(loss.repeat(batch_size)))

    losses = torch.cat(losses)
    losses = losses[: len(eval_dataset)]
    try:
        perplexity = math.exp(torch.mean(losses))
    except OverflowError:
        perplexity = float("inf")

    print(f">>> エポック {epoch}: パープレキシティ: {perplexity}")

    # 保存とアップロード
    accelerator.wait_for_everyone()
    unwrapped_model = accelerator.unwrap_model(model)
    unwrapped_model.save_pretrained(output_dir, save_function=accelerator.save)
    if accelerator.is_main_process:
        tokenizer.save_pretrained(output_dir)
        repo.push_to_hub(
            commit_message=f"Training in progress epoch {epoch}", blocking=False
        )
```

