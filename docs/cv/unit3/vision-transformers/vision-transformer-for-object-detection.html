Vision Transformers を使った物体検出

このセクションでは、Vision Transformers を使って物体検出タスクを行う方法を説明します。事前学習済みの物体検出モデルを、自分のユースケースに合わせてファインチューニングする方法を理解していきます。始める前に、最終的な出力結果を試せるこちらの Hugging Face Space も確認してみてください。

はじめに

物体検出は、画像や動画の中にある物体を識別し、その位置を特定するコンピュータビジョンのタスクです。主に次の2つのステップで構成されます。

  • 1つ目は、車や人、動物など、どんな種類の物体があるかを認識することです。
  • 2つ目は、バウンディングボックスで囲んで、その正確な位置を求めることです。

これらのモデルは通常、画像（静止画や動画のフレーム）を入力として受け取り、各画像には複数の物体が含まれています。たとえば、車や人、自転車など複数の物体を含む画像を考えてみてください。入力を処理すると、モデルは次の情報を表す数値の集合を出力します。

  • 物体の位置（バウンディングボックスの XY 座標）
  • 物体のクラス

物体検出には多くの応用があります。代表的な例が自動運転の分野です。物体検出を使って車の周囲にある歩行者や道路標識、信号機などの物体を検出し、それを意思決定の入力の1つとして使います。

物体検出の仕組みをより深く理解するには、物体検出に関する専用の章も確認してみてください 🤗。

物体検出でモデルをファインチューニングする必要性 🤔

新しいモデルを作るべきか、それとも既存のモデルを改変すべきか。これはとても良い問いです。物体検出モデルをゼロから学習させるということは、次のようなことを意味します。

  • すでに終わっている研究を、何度もやり直すことになります。
  • モデルのコードを繰り返し書いて学習させ、ユースケースごとに別々のリポジトリを維持することになります。
  • 多くの実験が必要になり、リソースも無駄になります。

こうした作業をする代わりに、性能の良い事前学習済みモデル（一般的な特徴の認識が得意なモデル）を用意し、その重み（または重みの一部）を調整して、自分のユースケースに適応させます。事前学習済みモデルは、画像の中から物体の位置特定と分類に役立つ重要な特徴を抽出する方法を、すでに十分に学習していると考えられます。そのため、新しい物体が加わっても、すでに学習した特徴と新しい特徴を使って、短時間の学習と少ない計算でその物体を検出できるようになります。

このチュートリアルが終わる頃には、物体検出のユースケースについて、データセットの読み込みからモデルのファインチューニング、推論までを行う一連の pipeline を作れるようになります。

1つのデータ点に何が含まれているかが分かったので、まずはそのサンプルを描画してみましょう。ここでは、最初に画像を描き、次に対応するバウンディングボックスも描きます。

行うことは次のとおりです。

  1. 画像と、それに対応する高さと幅を取得します。
  2. 画像上にテキストや線を簡単に描ける描画オブジェクトを作ります。
  3. サンプルからアノテーションの辞書を取得します。
  4. それを反復処理します。
  5. 各要素について、バウンディングボックスの座標を取得します。これは x（バウンディングボックスが横方向に始まる位置）、y（バウンディングボックスが縦方向に始まる位置）、w（バウンディングボックスの幅）、h（バウンディングボックスの高さ）です。
  6. バウンディングボックスの値が正規化されている場合はスケーリングし、そうでない場合はそのままにします。
  7. 最後に、矩形とクラスのカテゴリのテキストを描きます。
import numpy as np
from PIL import Image, ImageDraw


def draw_image_from_idx(dataset, idx):
    sample = dataset[idx]
    image = sample["image"]
    annotations = sample["objects"]
    draw = ImageDraw.Draw(image)
    width, height = sample["width"], sample["height"]

    for i in range(len(annotations["id"])):
        box = annotations["bbox"][i]
        class_idx = annotations["id"][i]
        x, y, w, h = tuple(box)
        if max(box) > 1.0:
            x1, y1 = int(x), int(y)
            x2, y2 = int(x + w), int(y + h)
        else:
            x1 = int(x * width)
            y1 = int(y * height)
            x2 = int((x + w) * width)
            y2 = int((y + h) * height)
        draw.rectangle((x1, y1, x2, y2), outline="red", width=1)
        draw.text((x1, y1), annotations["category"][i], fill="white")
    return image

    plt.show()

AutoImageProcessor

モデルをファインチューニングする前に、事前学習時に使われた方法と正確に一致するようにデータを前処理しなければなりません。Hugging Face の AutoImageProcessor が画像データの処理を担い、DETR モデルが学習に使える pixel_values、pixel_mask、labels を作成します。

では、ファインチューニングに使いたいモデルと同じチェックポイントから、イメージプロセッサをインスタンス化しましょう。

from transformers import AutoImageProcessor

checkpoint = "facebook/detr-resnet-50-dc5"
image_processor = AutoImageProcessor.from_pretrained(checkpoint)

データセットの前処理

画像を image_processor に渡す前に、画像とそれに対応するバウンディングボックスに対して、さまざまな種類のデータ拡張も適用しましょう。

簡単に言うと、データ拡張とは、回転やリサイズなどのランダムな変換の集合です。これらを適用することでサンプル数を増やし、ビジョンモデルを画像のさまざまな条件に対して頑健にします。これには albumentations ライブラリを使います。画像にランダムな変換を作成できるため、学習用のサンプルサイズを増やせます。

import albumentations
import numpy as np
import torch

transform = albumentations.Compose(
    [
        albumentations.Resize(480, 480),
        albumentations.HorizontalFlip(p=1.0),
        albumentations.RandomBrightnessContrast(p=1.0),
    ],
    bbox_params=albumentations.BboxParams(format="coco", label_fields=["category"]),
)

すべての変換を初期化したら、アノテーションを整形し、非常に特定の形式のアノテーションのリストを返す関数を作る必要があります。

これは、image_processor がアノテーションを次の形式で受け取ることを想定しているためです。{'image_id': int, 'annotations': List[Dict]} という形式で、各辞書が COCO の物体アノテーションです。

def formatted_anns(image_id, category, area, bbox):
    annotations = []
    for i in range(0, len(category)):
        new_ann = {
            "image_id": image_id,
            "category_id": category[i],
            "isCrowd": 0,
            "area": area[i],
            "bbox": list(bbox[i]),
        }
        annotations.append(new_ann)

    return annotations

最後に、画像の変換とアノテーションの変換を組み合わせて、データセットのバッチ全体に対して変換を行います。

そのための最終的なコードは次のとおりです。

# バッチを変換する


def transform_aug_ann(examples):
    image_ids = examples["image_id"]
    images, bboxes, area, categories = [], [], [], []
    for image, objects in zip(examples["image"], examples["objects"]):
        image = np.array(image.convert("RGB"))[:, :, ::-1]
        out = transform(image=image, bboxes=objects["bbox"], category=objects["id"])

        area.append(objects["area"])
        images.append(out["image"])
        bboxes.append(out["bboxes"])
        categories.append(out["category"])

    targets = [
        {"image_id": id_, "annotations": formatted_anns(id_, cat_, ar_, box_)}
        for id_, cat_, ar_, box_ in zip(image_ids, categories, area, bboxes)
    ]

    return image_processor(images=images, annotations=targets, return_tensors="pt")

最後に、この前処理関数をデータセット全体に適用するだけです。Hugging Face 🤗 の Datasets with transform メソッドを使うことで実現できます。

あと少しです 🚀。最後の前処理ステップとして、カスタムの collate_fn を書く必要があります。では、collate_fn とは何でしょうか？

collate_fn は、データセットからサンプルのリストを受け取り、モデルの入力形式に適したバッチへ変換する役割を担います。

一般に、DataCollator はパディングや切り捨てなどのタスクを行います。カスタムの collate 関数では、データをバッチにまとめる方法、つまり各バッチをどのように表すかを定義することがよくあります。

データコレーターは主にデータをまとめ、それから前処理を行います。collate 関数を作りましょう。

def collate_fn(batch):
    pixel_values = [item["pixel_values"] for item in batch]
    encoding = image_processor.pad(pixel_values, return_tensors="pt")
    labels = [item["labels"] for item in batch]
    batch = {}
    batch["pixel_values"] = encoding["pixel_values"]
    batch["pixel_mask"] = encoding["pixel_mask"]
    batch["labels"] = labels
    return batch

DETR モデルの学習

ここまでの重い作業は終わりました。あとはパズルのピースを1つずつ組み立てるだけです。始めましょう。

学習の手順は次のステップで構成されます。

  1. 前処理で使ったのと同じチェックポイントを使って、AutoModelForObjectDetection でベースの（事前学習済みの）モデルを読み込みます。

  2. TrainingArguments の中で、すべてのハイパーパラメータと追加の引数を定義します。

  3. 学習用の引数を、モデル、データセット、画像とともに Hugging Face Trainer に渡します。

  4. train() メソッドを呼び出して、モデルをファインチューニングします。

前処理で使ったのと同じチェックポイントからモデルを読み込む際は、データセットのメタデータから先に作成した label2id と id2label のマップを渡すのを忘れないでください。さらに、ignore_mismatched_sizes=True を指定して、既存の分類ヘッドを新しいものに置き換えます。

from transformers import AutoModelForObjectDetection

id2label = {0: "head", 1: "helmet", 2: "person"}
label2id = {v: k for k, v in id2label.items()}


model = AutoModelForObjectDetection.from_pretrained(
    checkpoint,
    id2label=id2label,
    label2id=label2id,
    ignore_mismatched_sizes=True,
)

次に進む前に、Hugging Face Hub にログインして、学習中にモデルをその場でアップロードできるようにしましょう。こうすれば、チェックポイントを扱ったり、どこかに保存したりする必要がなくなります。

from huggingface_hub import notebook_login

notebook_login()

完了したら、モデルの学習を始めましょう。まず学習用の引数を定義し、それらの引数を使って学習を行う trainer オブジェクトを定義します。次に示すとおりです。

from transformers import TrainingArguments
from transformers import Trainer

# 学習用の引数を定義する

training_args = TrainingArguments(

    save_steps=10,

trainer = Trainer(

では、結果を画像上に描画する非常に簡単な関数を作りましょう。results から score、label、対応するバウンディングボックスの座標を取得し、それを使って画像に描画します。

def plot_results(image, results, threshold=0.7):
    image = Image.fromarray(np.uint8(image))
    draw = ImageDraw.Draw(image)
    for result in results:
        score = result["score"]
        label = result["label"]
        box = list(result["box"].values())
        if score > threshold:
            x, y, x2, y2 = tuple(box)
            draw.rectangle((x, y, x2, y2), outline="red", width=1)
            draw.text((x, y), label, fill="white")
            draw.text(
                (x + 0.5, y - 0.5),
                text=str(score),
                fill="green" if score > 0.7 else "red",
            )
    return image

def predict(image, pipeline, threshold=0.7):
    results = pipeline(image)
    return plot_results(image, results, threshold)

from tqdm.auto import tqdm


def plot_images(dataset, indices):
    """
    画像とそのアノテーションを描画する。
    """
    num_rows = len(indices) // 3
    num_cols = 3
    fig, axes = plt.subplots(num_rows, num_cols, figsize=(15, 10))

    for i, idx in tqdm(enumerate(indices), total=len(indices)):
        row = i // num_cols
        col = i % num_cols

        # 画像を描画する
        image = predict(dataset[idx]["image"], obj_detector)

        # 対応するサブプロットに画像を表示する
        axes[row, col].imshow(image)
        axes[row, col].axis("off")

    plt.tight_layout()
    plt.show()
