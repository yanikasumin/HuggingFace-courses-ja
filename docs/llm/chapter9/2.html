最初のデモを作る

まずは Gradio をインストールしましょう！Python パッケージなので、次を実行するだけです:

$ pip install gradio

Gradio はどこでも実行できます。お気に入りの Python IDE でも、Jupyter ノートブックでも、Google Colab でも 🤯！ Python が動く場所ならどこでも、Gradio をインストールして使えます。

Gradio の構文に慣れるために、シンプルな「Hello World」の例から始めましょう:

import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()

上のコードを順に見ていきましょう:

  • まず、greet() という関数を定義します。ここでは名前の前に "Hello" を付けるだけのシンプルな関数ですが、一般的には どんな Python 関数でも構いません。たとえば機械学習の応用では、入力に対して モデルを呼び出して予測を行い、出力を返す関数になるでしょう。
  • 次に、fn、inputs、outputs の3つの引数で Gradio の Interface を作成します。これらの引数で、予測関数と、使いたい入出力コンポーネントの 種類 を定義します。今回の例では、どちらのコンポーネントもシンプルなテキストボックスです。
  • 最後に、作成した Interface に対して launch() メソッドを呼びます。

このコードを実行すると、Jupyter/Colab のノートブックでは下のようなインターフェースが自動的に表示され、スクリプトから実行した場合はブラウザで http://localhost:7860 が開きます。

自分の名前や他の入力で、この GUI を今すぐ試してみてください！

この GUI では、Gradio が入力パラメータの名前（name）を自動で推測し、テキストボックスの上のラベルとして適用していることに気づくでしょう。これを変更したい場合はどうすればよいでしょうか？テキストボックスを他の方法でカスタマイズしたい場合は？その場合は、入力コンポーネントに対応するクラスからインスタンスを作成します。

下の例を見てみましょう:

import gradio as gr


def greet(name):
    return "Hello " + name


# Textbox クラスをインスタンス化します
textbox = gr.Textbox(label="Type your name here:", placeholder="John Doe", lines=2)

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()

ここでは、ラベル、プレースホルダ、行数を指定した入力テキストボックスを作成しました。 出力テキストボックスについても同じことができますが、ここでは省略します。

わずか数行のコードで、Gradio を使えばあらゆる種類の入出力を持つ関数にシンプルなインターフェースを付けられることが分かりました。このセクションではシンプルなテキストボックスから始めましたが、次のセクションでは他の種類の入出力を扱います。次は、Gradio アプリケーションに NLP を取り入れてみましょう。

🤖 モデルの予測を取り入れる

ここでは、GPT-2 のような テキスト生成 モデルのデモができる、シンプルなインターフェースを作ります。

モデルは 🤗 Transformers の pipeline() 関数を使って読み込みます。 手早く復習したい場合は、Chapter 1 の該当セクション に戻ってください。

まず、テキストプロンプトを受け取り、補完されたテキストを返す予測関数を定義します:

from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion

この関数は、与えたプロンプトを補完します。自分の入力プロンプトで実行して、動作を確認してみてください。例はこちらです（補完結果は異なる場合があります）:

predict("My favorite programming language is")

>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.

予測を生成する関数ができたら、先ほどと同じ方法で Interface を作成して起動できます:

import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()

これだけです！下のように、このインターフェースを使って GPT-2 モデルでテキストを生成できます 🤯。

Gradio で他の種類のデモを作る方法は、このまま読み進めてください！
