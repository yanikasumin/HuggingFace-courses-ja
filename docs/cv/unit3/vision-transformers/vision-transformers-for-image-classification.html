画像分類のための Vision Transformer の転移学習とファインチューニング

はじめに

Transformers アーキテクチャは、自然言語処理でうまくスケールしました。そこで、同じアーキテクチャを画像にも適用する試みが生まれました。画像を小さなパッチに分割し、トークンとして扱う方法です。その結果生まれたのが Vision Transformer（ViT）です。転移学習とファインチューニングの概念に入る前に、畳み込みニューラルネットワーク（CNN）と Vision Transformer を比較します。

Vision Transformer（VT）の概要

まとめると、Vision Transformer では画像をパッチの2次元グリッドとして再構成します。モデルはそのパッチで学習します。

CNN と Vision Transformer の違いは何ですか？

帰納バイアス

帰納バイアスは機械学習の用語です。学習アルゴリズムが予測を行うために使う前提の集合を指します。簡単に言えば、帰納バイアスは近道のようなものです。これまでに見た情報をもとに、機械学習モデルが根拠のある推測を行う助けになります。

CNN で見られる帰納バイアスには、次のようなものがあります。

  • 並進同変性：物体は画像のどこに現れてもよく、CNN はその特徴を検出できます。
  • 局所性：画像のピクセルは、主に周辺のピクセルと相互作用して特徴を形成します。

CNN モデルは、この2つのバイアスをとてもうまく扱えます。ViT にはこの前提がありません。そのため、データセットの規模がある閾値までは、実際には CNN の方が ViT より優れています。しかし、ViT には別の強みがあります。 Transformer アーキテクチャは（主に）異なる種類の線形関数で構成されています。そのため、ViT は拡張性が非常に高くなります。そしてその拡張性によって、膨大な量のデータを使えば、上記の2つの帰納バイアスを持たないという問題を克服できます。

では、誰もが大規模なデータセットを利用できるのでしょうか？

優れた性能を得るために何百万枚もの画像で Vision Transformer を学習させることは、誰にでもできることではありません。代わりに、Hugging Face Hub のような場所で公開されているモデルの重みを利用できます。

事前学習済みモデルをどう使うのでしょうか。転移学習を適用してファインチューニングします。

画像分類のための転移学習とファインチューニング

転移学習の考え方はシンプルです。非常に大規模なデータセットで学習した Vision Transformer が獲得した特徴を活用し、その特徴を自分のデータセットに適用します。これにより、モデルの性能が大きく向上することがあります。特に、学習に使えるデータが限られているデータセットでは効果的です。

学習済みの特徴を活用するため、モデル全体を更新する必要もありません。重みの大部分を凍結すれば、一部の層だけを学習するだけで、学習時間を短くし、GPU の消費も抑えながら優れた性能が得られます。
