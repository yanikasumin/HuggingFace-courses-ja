# LeRobot を始める

このコースでは LeRobot を使います。LeRobot は Hugging Face が提供する総合的なオープンソースのロボティクスライブラリで、最先端のロボット学習手法を誰もが利用できるようにします。LeRobot は、ロボティクスの教育や研究における大きな障壁の一つである、実際のロボットシステムやデータを扱う際の複雑さの解消に取り組んでいます。

このライブラリではデータセットを直感的に扱えるため、複雑なロボット関連のデータも、従来の機械学習でテキストや画像を扱うのと同じくらい簡単に扱えます。事前学習済みモデルも利用できるので、自分のプロジェクトを始める際には、ゼロから開発する代わりに、実績のあるアルゴリズムを土台にできます。LeRobot は実機へのデプロイもサポートし、シミュレーションと実世界の応用の間のギャップを埋めます。そして何より、ロボット学習に取り組む人々が集まる、拡大を続けるコミュニティに参加できることも大きな利点です。そこには、一流の研究機関に所属する研究者から、自宅で独創的なプロジェクトを手がける愛好家まで、さまざまな人が参加しています。

> [!TIP]
> **インストール方法の紹介：** LeRobot のインストール手順はユニット2で詳しく説明しますが、すぐに試したい方は次のコマンドを実行してください。
>
> ```bash
> pip install lerobot
> ```
>
> 詳しくは [LeRobot の GitHub リポジトリ](https://github.com/huggingface/lerobot) を参照してください。

ロボット学習を始める準備はできましたか？ まずは、古典的なロボティクスの手法にどのような限界があり、学習によってそれをどう克服できるのかを見ていきましょう。
