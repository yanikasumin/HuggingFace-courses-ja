（任意）Discord 101

このガイドは、ゲームや ML のコミュニティで人気の無料チャットサービス「Discord」を初めて使う人のための入門ガイドです。

こちらをクリックして、メンバーが100,000人を超える Hugging Face コミュニティの Discord サーバーに参加しましょう。他の人とつながるのに最適な場所です！

Hugging Face の Discord コミュニティにある Agents コースのチャンネル

Discord を初めて使うと、少し戸惑うかもしれません。そこで、迷わず利用できるように簡単なガイドを用意しました。

HF コミュニティサーバーには、さまざまな分野に興味を持つ人々が集まっています。論文について議論したり、イベントに参加したりしながら学ぶことができます。

登録したら、#introduce-yourself チャンネルで自己紹介してください。

Agents コース用に4つのチャンネルを用意しました。

  • agents-course-announcements: コースの最新情報用。
  • 🎓-agents-course-general: 一般的な議論や雑談用。
  • agents-course-questions: 質問したり、クラスメイトを助けたりするためのもの。
  • agents-course-showcase: 自信作のエージェントを披露するためのもの。

あわせて、次もチェックできます。

  • smolagents: ライブラリに関する議論とサポート用。

Discord を効果的に使うためのヒント

サーバーへの参加方法

Discord にあまり慣れていない場合は、サーバーへの参加方法についてのガイドを確認するとよいでしょう。

手順の概要は次のとおりです。

  1. 招待リンクをクリックする。
  2. Discord アカウントでサインインする（アカウントがなければ作成する）。
  3. AIエージェントではないことを確認する！
  4. ニックネームとアバターを設定する。
  5. 「Join Server」をクリックする。

Discord の効果的な使い方

Discord を効果的に使うためのヒントをいくつか紹介します。

  • ボイスチャンネルも使えますが、テキストチャットのほうが一般的です。
  • Markdown 形式でテキストを装飾でき、特にコードを書くときに便利です。ただし、Markdown はリンクにはあまり向いていません。
  • 長い会話ではスレッドを開くと、議論が整理されて便利です。

このガイドが役立てば幸いです！質問があれば、Discord で気軽に聞いてください 🤗。
