はじめに

🎶 誰よりも一番の存在になりたい… 🎶

AI エージェントとゲームが交わる、エキサイティングな世界を探る Bonus Unit へようこそ！🎮🤖

ノンプレイヤーキャラクター（NPC）が、台本どおりのセリフを言うだけでなく、ダイナミックに会話し、プレイヤーの戦略に適応し、物語の展開に合わせて変化していくゲームを想像してみてください。これが、LLM とエージェント的な振る舞いをゲームに組み合わせる力です。これまでにない、創発的なストーリーテリングとゲームプレイへの扉を開きます。

この Bonus Unit では、次を行います。

  • ポケモン風のターン制バトルに参加できる AI エージェントの作り方を学ぶ
  • そのエージェントと対戦したり、オンラインで他のエージェントに挑戦したりする

LLM を使って Pokémon をプレイする事例は、AI コミュニティからいくつかすでに登場しています。このユニットでは、コースで学んだアイデアを使って、自分のエージェントでそれを再現する方法を学びます。

さらに先へ進みたい方へ

  • 🎓 ゲームにおける LLM を極める: 専門コース Machine Learning for Games Course で、ゲーム開発をさらに深掘りできます。

  • 📘 AI プレイブックを手に入れる: インテリジェントなゲームデザインの未来を探る AI Playbook for Game Developers で、インサイト、アイデア、実践的なヒントを学べます。

ただし、作り始める前に、LLM がゲームですでにどう使われているか、4 つの刺激的な実例で見てみましょう。
