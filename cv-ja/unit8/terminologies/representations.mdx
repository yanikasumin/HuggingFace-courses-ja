# 3Dデータの表現方法

3Dデータにはさまざまな表現方法があり、用途に応じて使い分けられます。
ここでは、代表的なものをいくつか紹介します。

## 点群

点群は、3D空間内にある点の集まりでデータを表す方法です。それぞれの点には座標があり、場合によってはほかの属性も付いています。点は物体の表面だけに分布することもあれば、物体の内部にまで広がることもあります。点群は一般に、LiDAR などの3Dスキャン技術によって生成されます。ただし、点同士がどのようにつながっているかという情報は持っていません。そのため、物体の表面の形状やトポロジーを特定するのが難しい場合があります。

## メッシュ

メッシュはコンピュータグラフィックスでよく使われ、3次元空間内の頂点を結んだ（通常は三角形の）面の集合として物体の表面を表現します。法線、色、テクスチャ座標といった追加情報は、頂点と面のどちらにも付随させることができます。特にテクスチャを使う場合、メッシュは立体物を保存する非常に効率的な方法となり、ゲームやその他のコンピュータグラフィックスの応用でよく使われます。

Python の `trimesh` パッケージには、メッシュデータを扱う便利な関数が数多く含まれており、特に一般的なデータ形式の読み込みと保存に役立ちます。

## ボリュームデータ

ボリュームデータは、雲や炎のような透明な物体を表現する際によく使われます。基本的には、3D空間内の位置を受け取り、その位置の密度や色、場合によってはその他の属性を返す関数 \\( f(x,y,z) \\) で表せます。

こうしたデータを表現する単純な方法の1つが、ボクセルグリッドです。空間を格子状に分割し、各点の値を、その点が含まれるボクセルの8つの頂点の値から三線形補間（trilinear interpolation）によって求めます。

後の NeRF の章で見るように、ボリューム表現は立体物の表現にも効果的に使えます。もっと高度な表現も可能で、たとえば小さな MLP や、Instant-ngp のような複雑なハッシュグリッドが使われます。

## 陰関数曲面

ボリューム表現の柔軟性を活かしながら、物体の表面だけを表したい場合もあります。そこで使われるのが陰関数曲面です。

陰関数曲面はボリュームデータと似ていますが、関数 \\( f(x,y,z) \\) は空間内の各点に対して1つの数値を返します。そして、この関数の値が0になる点の集まりが物体の表面になります。

計算を効率化するために、この関数を符号付き距離関数（SDF）にすることがあります。SDF は、各点から物体の表面までの最短距離を表す関数です。物体の外側では正、内側では負の値を取ります。ただし、正負の決め方は慣例であり、逆になる場合もあります。

関数がこの条件を満たすように保つのは簡単ではありませんが、スフィアトレーシング（sphere tracing）というアルゴリズムを使えば、直線と物体の表面との交点をより高速に計算できます。
