LangGraph とは？

LangGraph は LangChain が開発したフレームワークで、LLM を組み込んだアプリケーションの制御フローを管理する ためのものです。

LangGraph は LangChain と違うのですか？

LangChain は、モデルやその他のコンポーネントとやり取りするための標準インターフェースを提供し、検索、LLM の呼び出し、ツールの呼び出しなどに役立ちます。 LangChain のクラスは LangGraph で使うこともできますが、必ず使わなければならないわけではありません。

これらのパッケージは別物で、それぞれ単独でも使えますが、結局のところ、オンラインで見つかるリソースはどれも両方のパッケージを組み合わせて使っています。

LangGraph はいつ使うべきですか？

制御と自由

AI アプリケーションを設計する際には、制御 と 自由 の間にある根本的なトレードオフに直面します。

  • 自由 があれば、LLM はより創造的に振る舞い、予期しない問題にも取り組めます。
  • 制御 があれば、予測可能な動作を確保し、ガードレールを維持できます。

smolagents で見られるような Code Agent は、非常に自由度が高いのが特徴です。1 回のアクションステップで複数のツールを呼び出したり、自分でツールを作成したりできます。ただし、その分、JSON を使って動作する通常の Agent と比べて予測しにくく、制御もしにくくなります！

LangGraph はその対極にあります。エージェントの実行に対して 「制御」 が必要な場面で真価を発揮します。

LangGraph は、アプリケーションに対する制御 が必要な場合に特に役立ちます。LLM の力を活かしながら、予測可能なプロセスに従うアプリケーションを構築するためのツールを提供します。

簡単に言えば、アプリケーションが特定の方法でオーケストレーションすべき一連のステップから構成され、各分岐点で意思決定を行う必要がある場合、LangGraph が必要な構造を提供します。

例として、ドキュメントに関する質問に答えられる LLM アシスタントを構築する場合を考えてみましょう。

LLM が最も得意とするのはテキストの理解です。そのため、質問に答える前に、他の複雑なモダリティ（グラフや表など）をテキストに変換する必要があります。ただし、その方法は、扱うドキュメントの種類によって変わります！

この分岐は決定的ですが、LLM の出力に基づいて条件付けされる分岐を設計することもでき、その場合は非決定的な分岐になります。

LangGraph が真価を発揮する主なシナリオは次のとおりです。

  • フローに対する明示的な制御が必要な 多段階の推論プロセス
  • ステップ間で 状態の永続化が必要なアプリケーション
  • 決定論的なロジックと AI の機能を組み合わせたシステム
  • human-in-the-loop による介入が必要なワークフロー
  • 複数のコンポーネントが連携する 複雑なエージェントアーキテクチャ

要するに、可能な限り、人間として、各アクションの出力に基づいてアクションのフローを設計し、それに応じて次に実行するものを決めてください。そのような場合に、LangGraph が最適なフレームワークです！

私見では、LangGraph は市場で最も本番環境に対応したエージェントフレームワークです。

LangGraph の仕組み

LangGraph の核となるのは、有向グラフ構造を使ってアプリケーションのフローを定義することです。

  • ノード は個々の処理ステップを表します（LLM の呼び出し、ツールの使用、意思決定など）。
  • エッジ はステップ間の遷移の可能性を定義します。
  • 状態（State） はユーザーが定義し、保持され、実行中にノード間で受け渡されます。次にどのノードへ進むかを決める際には、この現在の状態を参照します。

これらの基本的な構成要素については、次の章で詳しく見ていきます！

通常の Python とは何が違うのですか？なぜ LangGraph が必要なのですか？

「if-else 文を使った通常の Python コードで、これらのフローをすべて処理できるのではないか」と思うかもしれません。

技術的にはそのとおりですが、複雑なシステムを構築するうえでは、LangGraph には通常の Python にはない 利点 があります。LangGraph なしでも同じアプリケーションは構築できますが、LangGraph はより扱いやすいツールや抽象化を提供します。

状態管理、可視化、ログ（トレース）、組み込みの human-in-the-loop など、さまざまな機能が含まれています。
