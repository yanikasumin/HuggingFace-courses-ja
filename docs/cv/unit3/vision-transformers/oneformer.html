OneFormer: 汎用画像セグメンテーションを統べる1つの Transformer

はじめに

OneFormer は、画像セグメンテーションに対する画期的なアプローチです。画像セグメンテーションは、画像を意味のある領域に分割するコンピュータビジョンのタスクです。従来の手法では、物体を識別する処理（instance segmentation）や領域にラベルを付ける処理（semantic segmentation）など、セグメンテーションのタスクごとに別々のモデルとアーキテクチャを使っていました。より最近の試みでは、アーキテクチャを共有してこれらのタスクを統一しようとしましたが、それでもタスクごとに別々の訓練が必要でした。

ここに登場する OneFormer は、こうした課題を克服するために設計された汎用画像セグメンテーションのフレームワークです。独自のマルチタスクのアプローチを導入し、semantic、instance、panoptic の各セグメンテーションタスクを、タスクごとに別々に訓練することなく、1つのモデルで処理できます。中核となる工夫は、タスク条件付きの共同訓練の戦略です。モデルはタスク入力によって誘導され、訓練時も推論時も、異なるタスクに動的に対応できます。

この進歩により、訓練プロセスがシンプルになるだけでなく、さまざまなデータセットで既存のモデルを上回る性能が得られます。OneFormer は、すべてのタスクに必要な正解情報を統一する panoptic アノテーションを使うことでこれを実現しています。さらに、このフレームワークは query-text 対照学習を導入し、タスク同士の区別をより明確にして、全体の性能を高めています。

OneFormer の背景

OneFormer 論文から引用した画像

OneFormer の重要性を理解するために、画像セグメンテーションの背景を見ていきます。画像処理において、セグメンテーションは画像を異なる部分に分割する処理で、物体の認識やシーンの内容理解といったタスクに欠かせません。従来、セグメンテーションの主なタスクは2種類でした。1つは semantic segmentation で、ピクセルに「道路」や「空」のようなカテゴリのラベルを付けます。もう1つは instance segmentation で、明確な境界を持つ物体を識別します。

その後、研究者らは semantic segmentation と instance segmentation を統一する方法として panoptic segmentation を提案しました。しかし、こうした進歩があっても課題は残りました。panoptic segmentation 向けに設計された既存のモデルでも、タスクごとに別々の訓練が必要で、せいぜい半汎用にとどまっていたのです。

ここで OneFormer が状況を変えます。新しいアプローチとして、マルチタスクの汎用アーキテクチャを導入しました。考え方はシンプルです。このフレームワークを、1つの汎用アーキテクチャ、1つのモデル、1つのデータセットだけで、1回だけ訓練します。すると OneFormer は、semantic、instance、panoptic の各セグメンテーションタスクで、特化したフレームワークを上回ります。この進歩は、単に精度が上がるという話ではありません。画像セグメンテーションをより汎用的で効率的なものにする点に意味があります。OneFormer があれば、タスクごとに大量のリソースを使って別々に訓練する必要は過去のものになります。

OneFormer の中核となる概念

OneFormer を際立たせている主な特徴を分解して見ていきます。

Task-Dynamic Mask

OneFormer は「Task-Dynamic Mask」と呼ばれる巧妙な仕組みを使い、さまざまな種類の画像セグメンテーションタスクをよりよく理解し、処理します。モデルが画像に接すると、この「Task-Dynamic Mask」を使って、シーン全体に注目すべきか、明確な境界を持つ特定の物体を識別すべきか、その両方を組み合わせるべきかを判断します。

Task-Conditioned Joint Training

OneFormer の画期的な特徴の1つが、タスク条件付き共同訓練の戦略です。semantic、instance、panoptic のセグメンテーションを別々に訓練するのではなく、OneFormer は訓練中にタスクを一様にサンプリングします。この戦略により、モデルは異なるセグメンテーションタスクを同時に学習し、汎化できます。タスクトークンを通してアーキテクチャにタスクの条件を与えることで、OneFormer は訓練プロセスを統一し、タスク固有のアーキテクチャ、モデル、データセットの必要性を減らします。この革新的なアプローチにより、訓練パイプラインと必要なリソースは大きく効率化されます。

Query-Text Contrastive Loss

最後に、「Query-Text Contrastive Loss」について説明します。OneFormer がタスクやクラス同士の違いを自ら学ぶための方法、と考えてください。訓練プロセスでは、モデルは画像から取り出した特徴（クエリ）と、対応するテキスト記述（「車が写った写真」のようなもの）を比較します。これにより、モデルは各タスクの固有の特徴を理解し、異なるクラス同士の混同を減らせます。OneFormer の「Task-Dynamic Mask」は、マルチタスクのアシスタントのように汎用的に振る舞えるようにするものです。そして「Query-Text Contrastive Loss」は、視覚的な特徴とテキスト記述を比べることで、各タスクの具体的な内容を学ぶ助けになります。

これらの中核となる概念を組み合わせることで、OneFormer は画像セグメンテーションのための賢く効率的なツールになり、プロセスをより汎用的で身近なものにします。

まとめ

OneFormer 論文から引用した画像

まとめると、OneFormer フレームワークは画像セグメンテーション分野における画期的なアプローチです。さまざまな領域にわたってこのタスクをシンプルにし、統一することを目指しています。セグメンテーションタスクごとに特化したアーキテクチャに頼る従来の手法とは異なり、OneFormer は新しいマルチタスクの汎用アーキテクチャを導入しました。汎用データセットで1回だけ訓練した1つのモデルで、既存のフレームワークを上回ります。さらに、訓練時に query-text 対照損失を取り入れることで、モデルがタスク間およびクラス間の違いを学習する能力が高まります。OneFormer は、コンピュータビジョンにおける最近の成功に着想を得た Transformer ベースのアーキテクチャを使い、タスクへの感度を高めるためにタスク誘導クエリを導入しています。結果は目覚ましく、OneFormer は ADE20k、Cityscapes、COCO といったベンチマークデータセットで、semantic、instance、panoptic の各セグメンテーションタスクにおいて最先端のモデルを上回ります。このフレームワークの性能は、新しい ConvNeXt および DiNAT バックボーンによってさらに高まります。

要するに、OneFormer は汎用的で身近な画像セグメンテーションに向けた大きな一歩です。多様なセグメンテーションタスクを処理できる1つのモデルを導入することで、このフレームワークはセグメンテーションプロセスを効率化し、必要なリソースを減らします。

モデルの使用例

モデルの使用例を見ていきます。Dinat バックボーンには Natten ライブラリが必要で、インストールに時間がかかる場合があります。

!pip install -q natten

セグメンテーションの種類に応じた推論コードを次に示します。

from transformers import OneFormerProcessor, OneFormerForUniversalSegmentation
from PIL import Image
import requests
import matplotlib.pyplot as plt


def run_segmentation(image, task_type):
    """Performs image segmentation based on the given task type.

    Args:
        image (PIL.Image): The input image.
        task_type (str): The type of segmentation to perform ('semantic', 'instance', or 'panoptic').

    Returns:
        PIL.Image: The segmented image.

    Raises:
        ValueError: If the task type is invalid.
    """

    processor = OneFormerProcessor.from_pretrained(
        "shi-labs/oneformer_ade20k_dinat_large"
    )  # ここで1回だけ読み込みます
    model = OneFormerForUniversalSegmentation.from_pretrained(
        "shi-labs/oneformer_ade20k_dinat_large"
    )

    if task_type == "semantic":
        inputs = processor(images=image, task_inputs=["semantic"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_semantic_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]

    elif task_type == "instance":
        inputs = processor(images=image, task_inputs=["instance"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_instance_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]["segmentation"]

    elif task_type == "panoptic":
        inputs = processor(images=image, task_inputs=["panoptic"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_panoptic_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]["segmentation"]

    else:
        raise ValueError(
            "Invalid task type. Choose from 'semantic', 'instance', or 'panoptic'"
        )

    return predicted_map


def show_image_comparison(image, predicted_map, segmentation_title):
    """Displays the original image and the segmented image side-by-side.

    Args:
        image (PIL.Image): The original image.
        predicted_map (PIL.Image): The segmented image.
        segmentation_title (str): The title for the segmented image.
    """

    plt.figure(figsize=(12, 6))
    plt.subplot(1, 2, 1)
    plt.imshow(image)
    plt.title("Original Image")
    plt.axis("off")
    plt.subplot(1, 2, 2)
    plt.imshow(predicted_map)
    plt.title(segmentation_title + " Segmentation")
    plt.axis("off")
    plt.show()


url = "https://huggingface.co/datasets/shi-labs/oneformer_demo/resolve/main/ade20k.jpeg"
response = requests.get(url, stream=True)
response.raise_for_status()  # HTTP エラーを確認します
image = Image.open(response.raw)

task_to_run = "semantic"
predicted_map = run_segmentation(image, task_to_run)
show_image_comparison(image, predicted_map, task_to_run)
