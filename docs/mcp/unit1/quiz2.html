クイズ 2: MCP SDK

MCP SDK とその機能に関する知識をテストしましょう。

Q1: MCP SDK の主な目的は何ですか？

SDK はプロトコルを実装するもので、定義するものではありません。仕様は別に存在します。
正解！SDK は低レベルのプロトコルの詳細を抽象化します。
一部のツールにはこの機能があるかもしれませんが（MCP Inspector など）、SDK 自体の主な目的ではありません。
SDK はプログラミング言語の中で使われるライブラリです。

Q2: MCP SDK が通常処理する機能は次のうちどれですか？

正解！これは JSON-RPC メッセージを処理するためのコア機能です。
MCP は LLM への接続を可能にしますが、SDK 自体がそれらをホストするわけではありません。

Q3: 提供されたテキストによると、MCP の公式 Python SDK を管理している会社はどこですか？

テキストでは、メンテナとして Anthropic が挙げられています。
正解！コース教材によると、Anthropic が Python SDK を管理しています。
テキストによると、Microsoft は C# SDK を管理しています。
テキストによると、JetBrains は Kotlin SDK を管理しています。

Q4: server.py という名前の Python ファイルを使って開発用 MCP サーバーを起動するコマンドはどれですか？

Python スクリプトは `python` で実行しますが、MCP には専用の CLI コマンドがあります。
コマンドは `mcp start` ではなく `mcp dev` です。
正解！このコマンドで開発サーバーが初期化されます。
これはコース教材で示された標準の MCP CLI コマンドではありません。

Q5: MCP における JSON-RPC 2.0 の役割は何ですか？

HTTP+SSE や Streamable HTTP がトランスポート機構であり、JSON-RPC はメッセージフォーマットです。
正解！MCP はメッセージの構造化に JSON-RPC 2.0 を使います。
人間が読める性質は通信のデバッグに役立ちますが、AI モデル自体のデバッグツールではありません。
機能はそれぞれ独自のスキーマで定義されます。JSON-RPC はそれらを呼び出したりデータを交換したりするために使われます。
