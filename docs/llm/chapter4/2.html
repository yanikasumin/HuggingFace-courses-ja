Model Hub では目的に合ったモデルを簡単に選べます。選んだモデルは、実際のタスクで使う様々なライブラリでも、わずか数行のコードで利用出来ます。ここからは、モデルの具体的な使い方と、コミュニティに貢献する方法を見ていきましょう。

フランス語に対応し、文章中のマスクされた部分を予測出来るモデルを探しているとしましょう。

ここでは camembert-base チェックポイントを試してみます。使う為に必要なのは、モデル識別子として camembert-base を指定することだけです。前の章で見たように、pipeline() 関数で読み込めます。

from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")

```python out [ {'sequence': 'Le camembert est délicieux :)', 'score': 0.49091005325317383, 'token': 7200, 'token_str': 'délicieux'}, {'sequence': 'Le camembert est excellent :)', 'score': 0.1055697426199913, 'token': 2183, 'token_str': 'excellent'}, {'sequence': 'Le camembert est succulent :)', 'score': 0.03453313186764717, 'token': 26202, 'token_str': 'succulent'}, {'sequence': 'Le camembert est meilleur :)', 'score': 0.0330314114689827, 'token': 528, 'token_str': 'meilleur'}, {'sequence': 'Le camembert est parfait :)', 'score': 0.03007650189101696, 'token': 1654, 'token_str': 'parfait'} ]

（入力文の訳：カマンベールは <mask> です :)。出力の訳：補完された文は「カマンベールは美味しいです :)」「カマンベールは素晴らしいです :)」「カマンベールはとても美味しいです :)」「カマンベールはより良いです :)」「カマンベールは完璧です :)」です）

このように、パイプラインを使えばモデルを簡単に読み込めます。但し、チェックポイントが目的のタスクに適しているかどうかには注意してください。

例えば、`camembert-base` チェックポイントは `fill-mask` パイプラインでは問題なく使えます。一方、`text-classification` パイプラインで使っても、`camembert-base` のヘッドがテキスト分類に対応していない為、意味の有る結果は得られません。

適切なチェックポイントを選ぶには、Hugging Face Hub の画面に在るタスクセレクタを使うことをお勧めします。

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/tasks.png" alt="Web インターフェースのタスクセレクタ。" width="80%"/>
</div>

チェックポイントは、モデルのアーキテクチャを直接使ってインスタンス化することも出来ます。

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")

但し、特定のモデルアーキテクチャに依存しない Auto* クラス を使う方がお勧めです。先程のコードでは CamemBERT アーキテクチャに対応するチェックポイントしか読み込めませんが、Auto* クラスならチェックポイントに応じて適切なクラスが自動で選ばれる為、別のチェックポイントにも簡単に切り替えられます。

from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")

{:else}

from transformers import CamembertTokenizer, TFCamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = TFCamembertForMaskedLM.from_pretrained("camembert-base")

但し、特定のモデルアーキテクチャに依存しない TFAuto* クラス を使う方がお勧めです。先程のコードでは CamemBERT アーキテクチャに対応するチェックポイントしか読み込めませんが、TFAuto* クラスならチェックポイントに応じて適切なクラスが自動で選ばれる為、別のチェックポイントにも簡単に切り替えられます。

from transformers import AutoTokenizer, TFAutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = TFAutoModelForMaskedLM.from_pretrained("camembert-base")

💡 ヒント

事前学習済みモデルを使う時は、そのモデルがどのように学習され、どのデータセットが使われたか、また、どんな制限やバイアスが有るかを確認してください。こうした情報はモデルカードに記載されているはずです。
