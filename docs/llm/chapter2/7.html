ここまでよくついてきました。この章で学んだことを振り返りましょう。

  • Transformer モデルの基本的な構成要素を学びました。
  • トークン化のパイプラインが何から成り立っているかを学びました。
  • Transformer モデルを実際にどう使うかを見ました。
  • トークナイザを使って、テキストをモデルが理解できるテンソルに変換する方法を学びました。
  • トークナイザとモデルを組み合わせて、テキストから予測を得るまでの流れを組み立てました。
  • 入力 ID の限界と、アテンションマスクについて学びました。
  • さまざまな用途に対応し、設定を柔軟に変更できるトークナイザのメソッドを試しました。

これからは、🤗 Transformers のドキュメントを自由に読み進められるはずです。用語にもなじみが出てきたでしょうし、普段よく使うメソッドはすでに一通り見てきました。
