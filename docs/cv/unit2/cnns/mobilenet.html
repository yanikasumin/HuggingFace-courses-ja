MobileNet

MobileNet は、モバイルデバイス向けに設計されたニューラルネットワークアーキテクチャの一種です。Google の研究チームによって開発され、2017年に初めて導入されました。MobileNet の主な目標は、スマートフォン、タブレット、その他のリソースに制約のあるデバイス上で、高性能かつ低レイテンシの画像分類と物体検出を提供することです。

MobileNet は、深さ方向分離可能畳み込み（depthwise separable convolution）を使うことでこれを達成します。これは標準的な畳み込みのより効率的な代替手段です。深さ方向分離可能畳み込みは、計算を深さ方向畳み込みとポイントワイズ畳み込みという2つの別々のステップに分解します。これによりパラメータ数と計算の複雑さが大幅に削減され、MobileNet がモバイルデバイス上で効率的に動作できるようになります。

MobileNet の畳み込みの種類

通常の畳み込み層をこれらの深さ方向分離可能畳み込みとポイントワイズ畳み込みに置き換えることで、MobileNet は計算オーバーヘッドを最小限に抑えながら高い精度を達成し、モバイルデバイスやその他のリソースに制約のあるプラットフォームに適したものになります。MobileNet で使われる畳み込みは2種類あります。

深さ方向分離可能畳み込み

従来の畳み込み層では、各フィルタが入力のすべてのチャンネルに同時に重みを適用します。深さ方向分離可能畳み込みは、これを深さ方向畳み込みとポイントワイズ畳み込みという2つのステップに分解します。

このステップでは、入力画像のチャンネル（単一の色や特徴）ごとに、小さなフィルタ（通常は 3x3）を使って別々に畳み込みを行います。このステップの出力は入力と同じ大きさですが、チャンネル数は少なくなります。

ポイントワイズ分離可能畳み込み

この種の畳み込みは、入力層と出力層の両方で、すべてのチャンネルに対して単一のフィルタ（通常は 1x1）を適用します。通常の畳み込みよりパラメータが少なく、全結合層の代替と見ることができるため、計算リソースが限られたモバイルデバイスに適しています。

深さ方向畳み込みの後、このステップでは別の 1x1 畳み込み層を使って、前のステップでフィルタリングされた出力を組み合わせます。この演算は、深さ方向畳み込みで学習した特徴をより小さな特徴の集合へ効果的に集約し、重要な情報を保持しながら全体の複雑さを下げます。

なぜ通常の畳み込みではなくこれらの畳み込みを使うのか？

よりよく理解するために、単純化して説明しましょう。

通常の畳み込み（大きくてオールインワンのフィルタ）

大きくて厚いフィルタ（何層もあるスポンジのようなもの）を想像してください。このフィルタは画像全体に適用されます。画像のすべての部分と、そのすべての特徴（色など）を一度に処理します。これには多くの作業（計算）と大きなフィルタ（メモリ）が必要です。

深さ方向分離可能畳み込み（2ステップで軽い処理）：

MobileNet はこの処理を基本に立ち返って行います。大きなフィルタを、より小さく単純な2つのステップに分割します。

  • ステップ1 - 深さ方向畳み込み： まず、画像の特徴ごとに薄いフィルタ（スポンジの単層のようなもの）を別々に使います（色を個別に処理するようなものです）。各フィルタが小さく単純なため、作業量は少なくなります。

  • ステップ2 - ポイントワイズ畳み込み： 次に、もう1つの小さなフィルタ（単なる小さな点）を使って、これらの特徴を再び混ぜ合わせます。このステップは、最初のフィルタが見つけたものの要約を作るようなものです。

これらのステップは何をするものか？

MobileNet は、1つの大きなステップの代わりにこの2つの小さなステップを使うことで、通常の畳み込みで必要な作業の軽量版を行うようなものになります。特にスマートフォンのような強力でないデバイスでは、より効率的です。

フィルタが小さいため、MobileNet はそれほど多くのメモリを必要としません。すべての道具を収めるのにより小さな箱で済むようなもので、小さなデバイスに収めやすくなります。

1x1 畳み込みは通常の畳み込みと比べてどう機能するか？

通常の畳み込み

  • 通常の畳み込みは、大きなカーネル（3x3 や 5x5 など）を使って画像内のピクセルの集まりを一度に見ます。場面の一部を理解するために絵の小さな一区画を観察するようなものです。
  • これらの畳み込みは、ピクセル同士の並び方を分析することで、エッジ、角、テクスチャなどの特徴を理解するのに向いています。

1x1 畳み込み

  • 1x1 畳み込みは、一度に1ピクセルだけを見ます。隣り合うピクセルの並びを理解しようとはしません。
  • 1ピクセルしか見ていなくても、異なるチャンネル（カラー画像の RGB チャンネルなど）のすべての情報を考慮します。これらのチャンネルを組み合わせて、そのピクセルの新しいバージョンを作ります。
  • 1x1 畳み込みは、チャンネル数を増やすことも減らすこともできます。つまり、（チャンネルを減らして）情報を単純化することも、（チャンネルを増やして）より複雑な情報を作ることもできます。

主な違い

  • 焦点の範囲： 通常の畳み込みはピクセルの集合をまとめて分析してパターンを理解しますが、1x1 畳み込みは個々のピクセルに焦点を当て、異なるチャンネルの情報を組み合わせます。
  • 目的： 通常の畳み込みは、画像内のパターンや特徴の検出に使われます。対照的に、1x1 畳み込みは主にチャンネルの深さを変更するために使われ、性能の弱いデバイスでの効率のために、ニューラルネットワークの後段の層に向けて情報の複雑さを調整する助けになります。

MobileNet は、チャンネルごとの線形ボトルネック層などの手法も採用しており、パラメータ数を削減しながらモデルの精度を向上させています。このアーキテクチャは、CPU、GPU、さらには Google の Tensor Processing Unit（TPU）のような特殊なハードウェアを含む、さまざまなハードウェアプラットフォーム向けの最適化を備えて設計されています。

チャンネルごとの線形ボトルネック層

チャンネルごとの線形ボトルネック層は、画像分類タスクで高い精度を維持しながら、パラメータ数と計算コストをさらに削減する助けになります。

チャンネルごとの線形ボトルネック層は、順に適用される3つの主な演算から構成されます。
1. 深さ方向畳み込み： このステップでは、入力画像のチャンネル（単一の色や特徴）ごとに、小さなフィルタ（通常は 3x3）を使って別々に畳み込みを行います。このステップの出力は入力と同じ大きさですが、チャンネル数は少なくなります。
2. バッチ正規化： この演算は、各チャンネルにわたって活性化値を正規化し、訓練プロセスの安定化と汎化性能の向上を助けます。
3. 活性化関数： 通常、バッチ正規化の後に ReLU（Rectified Linear Unit）活性化関数が使われ、ネットワークに非線形性を導入します。

ReLU は何をするのか？

訓練中にはいくつかの問題が起こり得ます。まずそれらを説明し、次に ReLU がこれらの問題に対して何をするかを説明します。

勾配消失問題

深いニューラルネットワークでは、特にバックプロパゲーション中に、勾配消失問題が起こり得ます。これは、勾配（ネットワークの重みを更新するために使われます）がネットワークの層を逆方向に伝わるにつれて非常に小さくなるときに発生します。これらの勾配が小さくなりすぎると「消失」し、ネットワークが重みを効果的に学習・調整することが難しくなります。

ReLU は、正の値に対して線形で飽和しない形（正の入力はそのまま出力されます）であるため、勾配が小さくなりすぎることがなく、ネットワークでのより速い学習とより効果的な重みの調整が可能になります。

非線形性

非線形性がなければ、ニューラルネットワークは、たとえ何層あっても線形モデルとして機能し、複雑なパターンを学習できません。

ReLU のような非線形関数により、ニューラルネットワークはデータ中の複雑な関係を捉えて学習できます。

推論

以下に示すように、Hugging Face transformers を使って transformers モデルのバリエーションで推論できます。

from transformers import AutoImageProcessor, AutoModelForImageClassification
from PIL import Image
import requests

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

# プロセッサとモデルを初期化する
preprocessor = AutoImageProcessor.from_pretrained("google/mobilenet_v2_1.0_224")
model = AutoModelForImageClassification.from_pretrained("google/mobilenet_v2_1.0_224")

# 入力を前処理する
inputs = preprocessor(images=image, return_tensors="pt")

# 出力とクラスラベルを取得する
outputs = model(**inputs)
logits = outputs.logits

predicted_class_idx = logits.argmax(-1).item()
print("予測クラス:", model.config.id2label[predicted_class_idx])

予測クラス: tabby, tabby cat

PyTorch を使った実装例

以下は PyTorch 向けの MobileNet の実装例です。

import torch
import torch.nn as nn
import torch.nn.functional as F


class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_channels, out_channels, stride):
        super().__init__()
        self.depthwise = nn.Conv2d(
            in_channels,
            in_channels,
            kernel_size=3,
            stride=stride,
            padding=1,
            groups=in_channels,
        )
        self.pointwise = nn.Conv2d(
            in_channels, out_channels, kernel_size=1, stride=1, padding=0
        )

    def forward(self, x):
        x = self.depthwise(x)
        x = self.pointwise(x)
        return x


class MobileNet(nn.Module):
    def __init__(self, num_classes=1000):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, stride=2, padding=1)

        # MobileNet の本体
        self.dw_conv2 = DepthwiseSeparableConv(32, 64, 1)
        self.dw_conv3 = DepthwiseSeparableConv(64, 128, 2)
        self.dw_conv4 = DepthwiseSeparableConv(128, 128, 1)
        self.dw_conv5 = DepthwiseSeparableConv(128, 256, 2)
        self.dw_conv6 = DepthwiseSeparableConv(256, 256, 1)
        self.dw_conv7 = DepthwiseSeparableConv(256, 512, 2)

        # ストライド1の深さ方向分離可能畳み込みが5つ
        self.dw_conv8 = DepthwiseSeparableConv(512, 512, 1)
        self.dw_conv9 = DepthwiseSeparableConv(512, 512, 1)
        self.dw_conv10 = DepthwiseSeparableConv(512, 512, 1)
        self.dw_conv11 = DepthwiseSeparableConv(512, 512, 1)
        self.dw_conv12 = DepthwiseSeparableConv(512, 512, 1)

        self.dw_conv13 = DepthwiseSeparableConv(512, 1024, 2)
        self.dw_conv14 = DepthwiseSeparableConv(1024, 1024, 1)

        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Linear(1024, num_classes)

    def forward(self, x):
        x = self.conv1(x)
        x = F.relu(x)

        x = self.dw_conv2(x)
        x = F.relu(x)
        x = self.dw_conv3(x)
        x = F.relu(x)
        x = self.dw_conv4(x)
        x = F.relu(x)
        x = self.dw_conv5(x)
        x = F.relu(x)
        x = self.dw_conv6(x)
        x = F.relu(x)
        x = self.dw_conv7(x)
        x = F.relu(x)

        x = self.dw_conv8(x)
        x = F.relu(x)
        x = self.dw_conv9(x)
        x = F.relu(x)
        x = self.dw_conv10(x)
        x = F.relu(x)
        x = self.dw_conv11(x)
        x = F.relu(x)
        x = self.dw_conv12(x)
        x = F.relu(x)

        x = self.dw_conv13(x)
        x = F.relu(x)
        x = self.dw_conv14(x)
        x = F.relu(x)

        x = self.avg_pool(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)

        return x


# モデルを作成する
mobilenet = MobileNet(num_classes=1000)
print(mobilenet)
