# LlamaIndex でエージェントを使う

先ほど登場した、頼れる執事エージェントの Alfred を覚えていますか？ 彼はこれからアップグレードされます！LlamaIndex で使えるツールを理解したので、Alfred に新しい能力を与え、更に役立つエージェントに出来ます。

その前に、Alfred のようなエージェントがどう成り立っているかを思い出しておきましょう。Unit 1 では、次のことを学びました。

> エージェントとは、AI モデルを活用して環境と対話し、ユーザーが定義した目標を達成するシステムです。推論、計画、アクションの実行（多くの場合は外部ツールを介します）を組み合わせて、タスクを遂行します。

LlamaIndex は、**推論を行うエージェントを主に次の 3 種類**サポートしています。

![エージェント](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/llama-index/agents.png)

1. `Function Calling Agents`：特定の関数を呼び出すことが出来る AI モデルと連携して動作します。
2. `ReAct Agents`：チャット又はテキスト生成用のエンドポイントを備えたあらゆる AI と連携出来、複雑な推論タスクを扱えます。
3. `Advanced Custom Agents`：より複雑なタスクやワークフローを扱う為に、より高度な手法を使います。

> [!TIP]
> 高度なエージェントについての詳細は、<a href="https://github.com/run-llama/llama_index/blob/main/llama-index-core/llama_index/core/agent/workflow/base_agent.py">BaseWorkflowAgent</a> で確認出来ます

## エージェントを初期化する

> [!TIP]
> コードは Google Colab で実行出来る <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/llama-index/agents.ipynb" target="_blank">このノートブック</a> で確認出来ます。

エージェントを作成するには、先ず**その能力を定義する関数やツールのセット**を与えます。基本的なツールを使ったエージェントの作成方法を見ていきましょう。この記事の執筆時点では、エージェントは function calling API を利用出来る場合には自動的に使い、利用出来ない場合には標準的な ReAct エージェントのループを使います。

ツールや関数を呼び出す API に対応した LLM は、比較的新しいものです。しかし、ツール呼び出しの為に特別なプロンプトを用意する必要がなく、与えられたスキーマに基づいて LLM にツール呼び出しを生成させられる為、強力なツール実行の仕組みとなっています。

ReAct エージェントも複雑な推論タスクを得意とし、チャットやテキスト補完に対応したあらゆる LLM と連携出来ます。出力は長くなりますが、特定のアクションを選んだ理由も示してくれます。

```python
from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
from llama_index.core.agent.workflow import AgentWorkflow
from llama_index.core.tools import FunctionTool

# サンプルの Tool を定義します -- 型アノテーション、関数名、docstring はすべて、解析されるスキーマに含まれます！
def multiply(a: int, b: int) -> int:
    """Multiplies two integers and returns the resulting integer"""
    return a * b

# LLM を初期化します
llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")

# エージェントを初期化します
agent = AgentWorkflow.from_tools_or_functions(
    [FunctionTool.from_defaults(multiply)],
    llm=llm
)
```

（ツール説明の訳：`multiply` の docstring は「2つの整数を掛けて、結果の整数を返します」です）

**エージェントはデフォルトではステートレス**ですが、`Context` オブジェクトを使うことで過去のやり取りを記憶出来ます。これは、過去のやり取りを記憶する必要があるエージェントを使う場合に役立ちます。例えば、複数のメッセージにわたって文脈を保持するチャットボットや、長期間の進捗を追跡するタスクマネージャーなどです。

```python
# ステートレス
response = await agent.run("What is 2 times 2?")

# 状態を記憶します
from llama_index.core.workflow import Context

ctx = Context(agent)

response = await agent.run("My name is Bob.", ctx=ctx)
response = await agent.run("What was my name again?", ctx=ctx)
```

（入力文の訳：「2 かける 2 はいくつですか」／「私の名前は Bob です」／「私の名前は何でしたか」）

LlamaIndex のエージェントが非同期で動作することにお気づきでしょうか。上のコードで Python の `await` 演算子を使っていることからも分かります。Python の非同期コードに慣れていない場合や復習したい場合は、[非同期処理の分かり易いガイド](https://docs.llamaindex.ai/en/stable/getting_started/async_python/)を参考にして下さい。

基本を押さえたので、次はエージェントでより複雑なツールを使う方法を見ていきましょう。

## QueryEngineTools を使って RAG エージェントを作成する

**Agentic RAG は、エージェントを使って自分のデータに関する質問に答える強力な方法です。** Alfred に様々なツールを渡せば、質問に答える際にそれらを活用してもらえます。但し、ドキュメントに基づいて自動的に質問に答えるのではなく、Alfred は質問に答える為に他のツールやフローを使うかどうかを判断出来ます。

![Agentic RAG](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/llama-index/agentic-rag.png)

**`QueryEngine` をエージェントのツールとしてラップする**のは簡単です。その際には、**名前と説明を定義する**必要があります。LLM はこの情報を使って、ツールを正しく使います。

[コンポーネントのセクション](components)で作成した `QueryEngine` を使って、`QueryEngineTool` を作成する方法を見ていきましょう。

```python
from llama_index.core.tools import QueryEngineTool

query_engine = index.as_query_engine(llm=llm, similarity_top_k=3) # LlamaIndex のコンポーネントのセクションで示したもの

query_engine_tool = QueryEngineTool.from_defaults(
    query_engine=query_engine,
    name="name",
    description="a specific description",
    return_direct=False,
)
query_engine_agent = AgentWorkflow.from_tools_or_functions(
    [query_engine_tool],
    llm=llm,
    system_prompt="You are a helpful assistant that has access to a database containing persona descriptions. "
)
```

（システムプロンプトの訳：あなたは、人物の説明を含むデータベースにアクセス出来る、親切なアシスタントです。`name` と `description` の値は設定例のプレースホルダです）

## マルチエージェントシステムを作成する

`AgentWorkflow` クラスは、マルチエージェントシステムも直接サポートしています。各エージェントに名前と説明を与えることで、システムは一度に発言するエージェントを 1 つに限定し、各エージェントが別のエージェントへ処理を引き継げるようにします。

各エージェントの範囲を絞ることで、ユーザーのメッセージに応答する際の全体的な精度を高めることが出来ます。

**LlamaIndex のエージェントは、他のエージェントのツールとして直接使うことも出来ます。**これにより、より複雑でカスタムなシナリオに対応出来ます。

```python
from llama_index.core.agent.workflow import (
    AgentWorkflow,
    FunctionAgent,
    ReActAgent,
)

# ツールをいくつか定義します
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b


def subtract(a: int, b: int) -> int:
    """Subtract two numbers."""
    return a - b


# エージェントの設定を作成します
# NOTE: ここでは FunctionAgent または ReActAgent を使えます。
# FunctionAgent は function calling API を持つ LLM で動作します。
# ReActAgent はあらゆる LLM で動作します。
calculator_agent = ReActAgent(
    name="calculator",
    description="Performs basic arithmetic operations",
    system_prompt="You are a calculator assistant. Use your tools for any math operation.",
    tools=[add, subtract],
    llm=llm,
)

query_agent = ReActAgent(
    name="info_lookup",
    description="Looks up information about XYZ",
    system_prompt="Use your tool to query a RAG system to answer information about XYZ",
    tools=[query_engine_tool],
    llm=llm
)

# ワークフローを作成して実行します
agent = AgentWorkflow(
    agents=[calculator_agent, query_agent], root_agent="calculator"
)

# システムを実行します
response = await agent.run(user_msg="Can you add 5 and 3?")
```

（エージェント設定と入力文の訳：calculator の説明は「基本的な算術演算を行います」、システムプロンプトは「あなたは計算アシスタントです。数学の演算にはツールを使って下さい」です。info_lookup の説明は「XYZ についての情報を調べます」、システムプロンプトは「ツールを使って RAG システムに問い合わせ、XYZ についての情報に答えて下さい」です。ツールの docstring は「2つの数を足します」「2つの数を引きます」です。入力文は「5 と 3 を足せますか」です）
