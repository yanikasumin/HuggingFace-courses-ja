## NLP と LLM について[[understanding-nlp-and-llms]]

このコースは元々、自然言語処理（NLP）を中心に据えた内容でした。その後、この分野の最新の進歩である大規模言語モデル（LLM）へ重点を移し、発展してきました。

**両者の違いは？**

- **NLP（Natural Language Processing：自然言語処理）** は、より広い対象を持つ分野です。コンピュータに人間の言語を理解・解釈・生成させる技術を扱い、感情分析、固有表現認識、機械翻訳など、多くの技術とタスクを含みます。
- **LLM（Large Language Models：大規模言語モデル）** は、NLP モデルの中でも強力な一群です。巨大な規模と膨大な学習データを特徴とし、タスク固有の追加学習を殆ど行わずに、幅広い言語タスクをこなせます。Llama、GPT、Claude の各シリーズがその例で、NLP で出来ることの範囲を大きく変えました。

このコースでは、従来の NLP の概念と、最先端の LLM の技術の両方を学びます。LLM を効果的に使いこなすには、NLP の基礎の理解が欠かせない為です。

- Chapter 1 から 4 では、🤗 Transformers ライブラリの主要な概念を導入します。このパートを終えると、Transformer モデルの動作の仕組みが分かり、[Hugging Face Hub](https://huggingface.co/models) のモデルを使い、データセットでファインチューニングし、結果を Hub で共有出来るようになります。
- Chapter 5 から 8 では、🤗 Datasets と 🤗 Tokenizers の基礎を学んだ上で、古典的な NLP タスクと LLM の技術へ進みます。このパートを終えると、最も一般的な言語処理の課題に自力で取り組めるようになります。
- Chapter 9 では NLP を超えて、モデルのデモを 🤗 Hub で構築し、共有する方法を扱います。このパートを終えると、自分の 🤗 Transformers アプリケーションを世界へ披露する準備が整います。
- Chapter 10 から 12 では、ファインチューニング、高品質なデータセットのキュレーション、推論モデルの構築など、LLM の高度な話題を掘り下げます。

受講の前提は次の通りです。

* Python の十分な知識が必要です
* 深層学習の入門コースを先に受けておくと進めやすくなります。例えば [fast.ai](https://www.fast.ai/) の [Practical Deep Learning for Coders](https://course.fast.ai/) や、[DeepLearning.AI](https://www.deeplearning.ai/) が開発したプログラムです
* [PyTorch](https://pytorch.org/) や [TensorFlow](https://www.tensorflow.org/) の事前知識は前提としませんが、どちらかに慣れていると理解の助けになります

このコースを終えたら、DeepLearning.AI の [Natural Language Processing Specialization](https://www.coursera.org/specializations/natural-language-processing?utm_source=deeplearning-ai&utm_medium=institutions&utm_campaign=20211011-nlp-2-hugging_face-page-nlp-refresh) も確認することをお勧めします。ナイーブベイズや LSTM など、知っておく価値の有る従来の NLP モデルを幅広く扱っています。

よくある質問への回答は次の通りです。

現在、このコースに認定資格はありません。但し、Hugging Face エコシステム向けの認定プログラムを準備中です。続報をお待ちください。

このコースの各章は、週に約6〜8時間の学習で1週間で終えられるように設計されています。但し、自分のペースで、必要なだけ時間をかけて進めて構いません。

## さあ、始めましょう

準備はいいですか？この章では、次のことを学びます。

* テキスト生成や分類などの NLP タスクを解く為の `pipeline()` 関数の使い方
* Transformer アーキテクチャについて
* エンコーダ、デコーダ、エンコーダ・デコーダの各アーキテクチャの違いと、それぞれの使いどころ
