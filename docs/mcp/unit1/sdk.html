MCP SDK

Model Context Protocol は、JavaScript、Python、その他の言語向けの公式 SDK を提供しています。これにより、アプリケーションに MCP クライアントとサーバーを簡単に実装出来ます。これらの SDK は低レベルのプロトコルの詳細を処理する為、アプリケーションの機能の構築に集中出来ます。

SDK の概要

両 SDK は、前に説明した MCP プロトコル仕様に従い、同様のコア機能を提供します。SDK が処理するのは次の通りです。

  • プロトコルレベルの通信
  • 機能の登録と発見
  • メッセージのシリアライズとデシリアライズ
  • 接続管理
  • エラーハンドリング

コアプリミティブの実装

両 SDK を使って、コアプリミティブ（ツール、リソース、プロンプト）のそれぞれを実装する方法を見ていきましょう。

python

from mcp.server.fastmcp import FastMCP

# MCP サーバーを作成する
mcp = FastMCP("Weather Service")

# ツールの実装
@mcp.tool()
def get_weather(location: str) -> str:
    """指定した場所の現在の天気を取得します。"""
    return f"Weather in {location}: Sunny, 72°F"

# リソースの実装
@mcp.resource("weather://{location}")
def weather_resource(location: str) -> str:
    """天気データをリソースとして提供します。"""
    return f"Weather data for {location}: Sunny, 72°F"

# プロンプトの実装
@mcp.prompt()
def weather_report(location: str) -> str:
    """天気レポートのプロンプトを作成します。"""
    return f"""You are a weather reporter. Weather report for {location}?"""


# サーバーを実行する
if __name__ == "__main__":
    mcp.run()
サーバーを実装したら、サーバースクリプトを実行して起動出来ます。 
mcp dev server.py

javascript

// index.mjs
import {
  McpServer,
  ResourceTemplate,
} from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

// MCP サーバーを作成する
const server = new McpServer({
  name: "Weather Service",
  version: "1.0.0",
});

// ツールの実装
server.tool("get_weather", { location: z.string() }, async ({ location }) => ({
  content: [
    {
      type: "text",
      text: `Weather in ${location}: Sunny, 72°F`,
    },
  ],
}));

// リソースの実装
server.resource(
  "weather",
  new ResourceTemplate("weather://{location}", { list: undefined }),
  async (uri, { location }) => ({
    contents: [
      {
        uri: uri.href,
        text: `Weather data for ${location}: Sunny, 72°F`,
      },
    ],
  })
);

// プロンプトの実装
server.prompt(
  "weather_report",
  { location: z.string() },
  async ({ location }) => ({
    messages: [
      {
        role: "assistant",
        content: {
          type: "text",
          text: "You are a weather reporter.",
        },
      },
      {
        role: "user",
        content: {
          type: "text",
          text: `Weather report for ${location}?`,
        },
      },
    ],
  })
);

// サーバーを実行する
const transport = new StdioServerTransport();
await server.connect(transport);
サーバーを実装したら、サーバースクリプトを実行して起動出来ます。 
npx @modelcontextprotocol/inspector node ./index.mjs

MCP SDK 一覧

MCP は言語に依存しないよう設計されており、いくつかの人気プログラミング言語向けに公式 SDK が提供されています。

言語 リポジトリ メンテナー 状態
TypeScript github.com/modelcontextprotocol/typescript-sdk Anthropic 提供中
Python github.com/modelcontextprotocol/python-sdk Anthropic 提供中
Java github.com/modelcontextprotocol/java-sdk Spring AI (VMware) 提供中
Kotlin github.com/modelcontextprotocol/kotlin-sdk JetBrains 提供中
C# github.com/modelcontextprotocol/csharp-sdk Microsoft 提供中（プレビュー版）
Swift github.com/modelcontextprotocol/swift-sdk loopwork-ai 提供中
Rust github.com/modelcontextprotocol/rust-sdk Anthropic/Community 提供中
Dart https://github.com/leehack/mcp_dart Flutter Community 提供中

これらの SDK は言語固有の抽象化を提供し、MCP プロトコルの扱いを簡素化します。その為、低レベルのプロトコルの詳細に対処するのではなく、サーバーやクライアントのコアロジックの実装に集中出来ます。
