# はじめに

ここまで、CNN から Transformer、マルチモーダルなアーキテクチャ、生成 AI まで、コンピュータビジョン向けのさまざまなニューラルネットワークアーキテクチャを学んできました。
このユニットでは、画像分類、物体検出、画像セグメンテーションといった基本的なコンピュータビジョンのタスクを概観します。

このユニットの目標は、各タスクで何を行うのか、また、どのような種類があるのかを詳しく理解することです。たとえば、画像セグメンテーションには、セマンティックセグメンテーションやインスタンスセグメンテーションがあります。
あわせて、各タスクでよく使われるデータセットや評価方法も紹介します。もちろん、それぞれのタスクで人気のある代表的なモデルも取り上げます。
