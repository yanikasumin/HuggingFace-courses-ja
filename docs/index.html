Hugging Face の学習コースを日本語で学ぶ

このサイトは、AI 開発プラットフォーム Hugging Face が公開している無料の学習コース（英語）の日本語訳です。LLM（大規模言語モデル）、AI エージェント、コンピュータビジョンなど、5つのコース・全 316 セクションを日本語で読めます。

Hugging Face の公式コースは、世界中の開発者や研究者に利用されている機械学習の教材です。このサイトでは、英語の教材を読み進める負担を減らすため、公式コースを日本語に翻訳して公開しています。各ページには公式の英語ページへのリンクもあり、日本語訳と原文を見比べながら学べます。

Hugging Face とは何か

Hugging Face は、機械学習のモデルやデータセットを公開・共有するためのプラットフォーム（Hugging Face Hub）を運営する企業であり、その周辺のオープンソースライブラリを開発するコミュニティの中心です。

位置付けをひと言でいえば、「機械学習版の GitHub」です。世界中の研究者や企業が学習済みモデルを Hub に公開しており、公開されているモデルは100万を超えます。誰でもそれらをダウンロードして自分のプログラムから使え、自分が作ったモデルを公開することもできます。あわせて、モデルを扱うためのライブラリ群（Transformers、Datasets、Tokenizers、Accelerate など）がオープンソースで開発されており、現在の機械学習の実務と研究では、事実上の標準的な道具立てになっています。

このサイトで翻訳している学習コースは、その Hugging Face が公式に提供している教材です。ライブラリの使い方だけでなく、その前提となる機械学習の考え方から学べるよう構成されています。

このサイトの目的

このサイトは、機械学習を日本語で順序立てて学べるようにすることを目的としています。まず日本語訳で内容を理解し、必要に応じて各ページのリンクから公式の英語原文を確認できます。英語に不慣れな人も、原典に触れながら学習を進められるようにしています。

初学者におすすめである理由

  • 無料で、順番が決まっている：全コース無料で、登録なしで読めます。何から手を付けるかで迷う初学者にとって、「順番に読めば基礎から応用まで進める」構成そのものがありがたい教材です。
  • 理論と実装が離れていない：仕組みの説明のすぐ後に、実際に動くコードが出てきます。読んで終わりではなく、手を動かして確かめながら進めます。
  • 学んだことがそのまま実務の道具になる：教材で使うライブラリや Hub のモデルは、実際の開発現場で使われているものと同じです。学習用の簡略化された道具ではありません。
  • 出口が用意されている：モデルの公開、デモの作成と共有まで教材に含まれているので、「作って公開する」という初学者がつまずきやすい最後の一歩までたどり着けます。

このコースで学べること

中心となる LLM コースでは、大規模言語モデル（LLM）の土台である Transformer の仕組み、Transformers ライブラリによるモデルの利用と調整（ファインチューニング）、データセットとトークナイザの扱い、古典的な自然言語処理のタスク、モデルの共有とデモの公開、そして発展的な話題として LLM のファインチューニングや推論モデルの構築までを扱います。専門コースでは、AI エージェントの構築（Agents）、LLM と外部ツールをつなぐ規格（MCP）、画像分野（CV）、ロボット学習（Robotics）が学べます。

作れるようになるもの

  • 文章の分類、要約、質問応答などを行うプログラム（LLM コースの古典的 NLP とファインチューニング）
  • 公開モデルを使った対話・文章生成の仕組みと、自分のデータで調整した独自モデル
  • 画像の分類、物体検出、画像生成などの画像処理プログラム（CV コース）
  • 外部ツールを使って作業する AI エージェント（Agents コース）、ツール連携の仕組み（MCP コース）
  • 作ったモデルやデモを Hugging Face Hub / Spaces で公開し、他人に使ってもらえる形にすること

学習環境の作り方

  1. Python の基礎：変数、関数、リストや辞書、クラスの読み書きができれば十分です。不安な人は、先に Progate やドットインストールの Python 入門で感覚をつかんでください。
  2. 実行環境：最初はブラウザだけで使える Google Colab が手軽です。無料で GPU も使えます。慣れてきたら、自分のパソコンに Python と仮想環境を用意し、pip install transformers datasets のように必要なライブラリを入れる形に移行します。各コースの第0章・Unit 0 にも環境構築の説明があります。
  3. Hugging Face のアカウント：読むだけなら不要ですが、モデルを公開したり、制限付きモデルを使うには無料アカウントとアクセストークンが必要です。コースの途中で必要になった時点で作れば間に合います。
  4. 進め方：コードは写して終わりにせず、数値やデータを変えて結果の違いを見ること。分からない用語はこのサイトの用語集と公式ドキュメントで引くこと。この2つで定着が大きく変わります。

学習ロードマップ

全体の進み方は、次の図のとおりです。まず Python と環境の準備をし、LLM コースで基礎から発展までを一通り学び、最後に興味のある専門コースへ進みます。

どのコースから始めるか

  • 機械学習や LLM を基礎から学びたい → LLM コース。第1章から順に読むのが基本の進め方です。
  • AI エージェントを作りたい → Agents コース。LLM コースの第1〜2章程度の知識があると進めやすくなります。
  • 画像認識や画像生成に興味がある → Community CV コース。基礎の Unit 1 から始めてください。
  • LLM に外部ツールをつなぐ仕組みを知りたい → MCP コース。短めのコースなので、他のコースと並行しても進められます。
  • ロボットを学習させたい → Robotics コース。全11セクションの短い入門編です。

使い方と学び方

  1. 目次から読む：各コースは章・ユニットの順番どおりに進む構成です。前後のセクションへは、ページ上下のナビゲーションで移動できます。
  2. クイズで確認する：多くのセクションにクイズがあり、その場で答え合わせができます。
  3. コードを動かす：コードは、実際に動かしながら学ぶのがおすすめです。本文に掲載されているコードは、Google Colab や自分のパソコンなどで実行できます。ただし、このサイト自体にはコードを実行する機能はありません。ブラウザ上でコードを実行できるノートブックへのリンクが付いている節もあります。
  4. 原文と比べる：各ページ上部のボタンから、Hugging Face 公式の英語ページをすぐ開けます。専門用語の英語表現を確認したいときに便利です。
  5. 分からない言葉は用語集で：コースごとに、日本語版独自の用語集を用意しています。本文の検索も、ページ上部の検索窓からできます。

なぜ翻訳しようと思ったか

翻訳者自身が機械学習を独学する中で、このコースを使おうとして、日本語版がないことを不便に感じたのが出発点です。英語の教材は、内容以前に「読み進める速度が落ちる」「用語を引くたびに手が止まる」という負担が積み重なります。初学者の段階では、その負担がそのまま挫折の理由になります。

公式コースほどの規模と質の教材が、言語の壁だけで日本語話者に届いていないのは惜しい。そう考えて、学習の入口だけでも日本語で用意しようと、全コースの翻訳を始めました。翻訳は学習の代わりにはなりませんが、入口の負担を下げれば、原文で学ぶ段階へ進む人も増えるはずだ、というのがこのサイトの考えです。

翻訳方法

この翻訳は、翻訳エージェント（Muse）、審査役（ChatGPT）、翻訳者（霞ヶ関京）の3者で工程を分担し、単元ごとに「翻訳 → レビュー → 照合と修正 → 再チェック」を繰り返して作りました。機械翻訳の出力をそのまま載せるのではなく、指摘と照合の往復で一文ずつ確定していく方法です。

工程の詳細

  1. 原典の固定（Muse）：各コースの英語版リポジトリを特定のコミットに固定し、翻訳対象の版を確定しました。固定したコミットは、コースごとにリポジトリの README に記載しています。原典が後から更新されても、翻訳の基準がぶれないようにするためです。
  2. 翻訳（Muse）：全316セクションを翻訳しました。見出しのアンカー、コード、数式、数値、URL、データは原文のまま保持し、本文と画面表示のラベルを訳します。モデルへの入力文のように「データ」として扱うべき英文は訳しません。
  3. レビュー（ChatGPT）：翻訳文を単元ごとにまとめ、ChatGPT の思考モードで審査しました。審査基準は、(1) 日本語の自然さ（『とほほのWWW入門』のような平易な解説文が手本）、(2) 意味の誤り、(3) 用語と表記、(4) 改行や記号の配置など日本語読者向けの組版、の4点です。指摘は、対象ファイルと行番号、現在の文の正確な引用、問題点、修正案の全文をセットで出させました。
  4. 照合と修正（Muse）：レビューの指摘は、そのままでは適用しません。1件ずつ実ファイルで引用が実在するかを確認し、原典と突き合わせてから修正しました。引用が実在しない指摘や、原典の内容と合わない修正案は、根拠がないものとして適用せず、審査側に再提示を求めました。
  5. 機械検証（Muse）：修正のたびに、コード・リンク・アンカー・画像が原典と一致しているかを自動で照合し、翻訳の過程で文書の構造が壊れていないことを確認しました。
  6. 再チェック（ChatGPT）：修正後の文を再び審査し、指摘が解消したかを判定しました。合格にならない場合は「照合と修正」に戻り、解消するまで繰り返しました。意図的に原文どおり残した箇所（原典由来の表現など）は、その理由を添えて再チェックにかけています。
  7. 公開（霞ヶ関京）：合格した文をサイトに反映して公開しました。文体の方針、用語の採否、原典自体に誤りがある場合の扱い（勝手に直さず原文に忠実に訳す）など、判断が要る点は翻訳者が決めています。

役割分担

  • Muse：翻訳の実務。翻訳、指摘の照合と修正、構造の機械検証、サイトの構築と公開作業を担当しました。
  • ChatGPT：第三者としての審査。翻訳者とは別の立場から、自然さと正確さを単元ごとにチェックしました。
  • 霞ヶ関京：翻訳者。文体の方針（平易な解説文）、用語の採否、原典の誤りの扱いなど、工程全体の方針と最終判断を担当しました。

公開後も、漢字と仮名の使い分けや改行の位置といった表記の整備を続けています。

このサイトについて

このサイトは、Hugging Face が公開している公式コースを日本語に翻訳した非公式サイトです。翻訳には、Hugging Face の各コースリポジトリ（Apache-2.0 ライセンス）で公開されている教材を使用しました。全ページを英語原典と照合していますが、翻訳後に原典が更新されている場合は、最新の内容と異なることがあります。最新の情報は公式ページで確認してください。

本サイトの課題

  • 非公式の翻訳であること：内容の正はあくまで公式の英語版です。重要な判断に使う場合は、各ページの公式リンクから原文を確認してください。
  • 原典の更新に即時には追従できないこと：翻訳は原典の版を固定して行っているため、原典の改訂がすぐには反映されません。版の情報は README に記載しています。
  • 翻訳の自然さは改善を続けていること：公開後も、漢字と仮名の使い分け、改行、語順といった日本語の自然さの整備を続けています。気になる箇所があれば、GitHub リポジトリの Issue で知らせてください。
  • 実行環境と質問窓口がないこと：このサイトではコードを実行できません（実行は Colab など各自の環境で）。質問や議論は、公式コースのフォーラムやコミュニティが適切です。
  • 補足情報は今後の拡充課題であること：各セクションに関連する教材、注目論文や新リリース、実際のサービスへの応用例といった補足は、今後少しずつ追加していく予定です。

併用したい無料の学習サービス

このサイトと並行して使うと効果的な、無料の学習サービスを紹介します。ロードマップの段階ごとに対応させています。日本語で学べるものを優先しました。

  • 準備（Python 入門）：Progate、ドットインストール。ブラウザ上でコードを書きながら Python の基礎を短時間でつかめます。
  • 実行環境：Google Colab。環境構築なしで GPU が使えるノートブック環境で、このサイトのコードを試す場所として最適です。
  • 基礎固め（機械学習全般）：Kaggle Learn（英語）。短い無料講座と演習で、機械学習とデータ分析の基礎を手を動かして固められます。実践の場としての Kaggle のコンペティションも、応用段階の目標になります。
  • 深掘り（深層学習）：PyTorch 公式チュートリアル（英語。一部は日本語訳もあります）、fast.ai（英語）。LLM コースの発展段階で、フレームワーク側の理解を深めるのに向いています。
  • 数学の補強：YouTube の「ヨビノリたくみ」など、日本語の数学解説チャンネル。線形代数と確率の基礎は、Transformer の仕組みを理解する土台になります。
