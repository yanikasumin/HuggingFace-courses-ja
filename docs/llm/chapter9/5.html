Hugging Face Hub との連携

作業をさらに楽にするために、Gradio は Hugging Face Hub および Hugging Face Spaces と直接連携しています。Hub や Spaces のデモは、わずか1行のコード で読み込めます。

Hugging Face Hub からモデルを読み込む

まず、Chapter 4 で説明したように、Hugging Face が Hub を通じて提供する何千ものモデルから1つを選びます。

特別な Interface.load() メソッドでは、"model/"（または等価な "huggingface/"）の後にモデル名を続けます。 たとえば、大規模言語モデル GPT-J のデモを作り、入力例をいくつか加えるコードは次のとおりです:

import gradio as gr

title = "GPT-J-6B"
description = "Gradio Demo for GPT-J 6B, a transformer model trained using Ben Wang's Mesh Transformer JAX. 'GPT-J' refers to the class of model, while '6B' represents the number of trainable parameters. To use it, simply add your text, or click one of the examples to load them. Read more at the links below."
article = "<p style='text-align: center'><a href='https://github.com/kingoflolz/mesh-transformer-jax' target='_blank'>GPT-J-6B: A 6 Billion Parameter Autoregressive Language Model</a></p>"

gr.Interface.load(
    "huggingface/EleutherAI/gpt-j-6B",
    inputs=gr.Textbox(lines=5, label="Input Text"),
    title=title,
    description=description,
    article=article,
).launch()

上のコードを実行すると、下のインターフェースが生成されます:

この方法でモデルを読み込むと、モデルをメモリに読み込む代わりに、Hugging Face の Inference API が使われます。これは、GPT-J や T0pp のような、大量の RAM を必要とする巨大なモデルに最適です。

Hugging Face Spaces から読み込む

Hugging Face Hub 上の任意の Space を読み込んでローカルで再現するには、Interface.load() に spaces/ と Space 名を組み合わせた文字列を渡します。

セクション1で見た、画像の背景を除去するデモを覚えていますか？これを Hugging Face Spaces から読み込んでみましょう:

gr.Interface.load("spaces/abidlabs/remove-bg").launch()

Hub や Spaces からデモを読み込む便利な点の1つは、パラメータを上書きしてカスタマイズできることです。ここではタイトルを追加し、代わりに Web カメラで動作するようにしてみます:

gr.Interface.load(
    "spaces/abidlabs/remove-bg", inputs="webcam", title="Remove your webcam background!"
).launch()
