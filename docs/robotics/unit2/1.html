古典ロボティクス

このセクションでは、学習ベースの手法がなぜ強力なのかを理解するための土台として、古典ロボティクスの基礎を築きます。

ロボットがどのように運動を生成するかを探り、一般的な運動の種類を見たうえで具体例を掘り下げ、最後に現代的なアプローチの動機となる限界について議論します。

💡 ヒント

要点

ロボティクスへの学習ベースのアプローチは、従来の手法が苦手としてきた根本的な課題に対処します。

現代のロボティクスには、タスクやロボットの種類が変わっても使える手法が必要です。問題ごとに専用の解決策を開発するのではなく、同じ手法をさまざまな状況に適用できることが求められます。また、状況に応じてルールやモデルを手作業で設計する専門家への依存も減らさなければなりません。さらに、急速に増え続けるロボティクスデータセットを活用し、大規模なデータに蓄積された知見から学習できる手法も必要です。

ロボットの運動に対するさまざまなアプローチ

まず全体像から始めましょう。アプローチごとに、ロボットをどう動かしているのでしょうか。

ロボットの運動を生成する手法は、明示的な数理モデルを使うか、データからパターンを暗黙的に学ぶかでグループ化できます。

ここで紹介したのはロボットの運動を生成する主な手法の一部であり、すべてを網羅しているわけではありません。それでも、代表的なアプローチを理解するためのよい出発点になります。特に重要なのは、ロボットと環境の相互作用を明示的なモデルで表す手法（動力学ベース）と、データから暗黙的に学習する手法（学習ベース）の区別です。

機械工学、電気工学、ソフトウェア工学に加え、剛体力学や制御理論の知識は、1950年代にロボティクスという分野が生まれて以来、不可欠な役割を果たしてきました。近年では機械学習（ML）もロボティクスで成果を上げ、こうした従来の学問分野を補完しています。

ロボティクスは、少なくともハードウェアとソフトウェアの両方を扱う学際的な分野です。そのため、さまざまな手法が発展してきました。いずれの手法も、物理世界に人工的な運動を生み出す という共通の目的を持っています。

このセクションでは、古典的な手法がどのような状況で力を発揮し、どのような状況で限界に直面するのかを説明します。そのうえで、学習ベースのアプローチ がなぜ役立つのかを考えます。

💡 ヒント

明示的モデルと暗黙的モデル:

暗黙的（学習ベース）アプローチは、明示的な数理モデルを必要とせず、データから直接パターンを学ぶという根本的に異なる戦略を取ります。これらの手法では、対象分野に合わせて専用のモデルや処理を設計する作業が比較的少なくて済み、解析的にモデル化するのが難しい複雑で不確かな環境にも適応できます。ニューラルネットワークと強化学習アルゴリズムがその代表例です。

明示的（動力学ベース）アプローチは、人間が設計した物理現象の数理モデルに依存するため、効果的に実装するには対象分野に関する高度な専門知識が必要です。物理現象を正確にモデル化でき、十分に理解・管理された環境では、非常に優れた性能を発揮します。代表例には PID コントローラやモデル予測制御システムがあり、数十年にわたって産業用ロボティクスを支えてきました。

ハイブリッドアプローチは、物理モデルに基づく手法の信頼性と、学習システムの適応性を兼ね備えています。物理法則に関する知識を使って学習の方向を定めたり制約を加えたりすることで、どちらか一方の手法だけを使う場合よりも優れた性能を発揮することがあります。

さまざまな運動の種類

ここまでで全体像を確認しました。次に、ロボットが実際にどのような運動を行うのかを考えてみましょう。

運動の種類によって、使用されるロボットプラットフォームは大きく異なります。画像には、左から右、上から下の順に、ViperX、SO-100、Boston Dynamics の Spot、Open-Duck、1X の NEO、Boston Dynamics の Atlas が示されています。これらはあくまで一例であり、ロボットプラットフォームの種類はほかにも数多くあります。

大まかに言えば、扱うロボットシステムのほとんどは次の3つのカテゴリのいずれかに分類できます。対象のシステムがどのカテゴリに属するかを理解すれば、適切なモデル、データセット、コントローラを選びやすくなります。

ロボティクスでは多くの場合、ほぼ剛体とみなせるリンクを関節でつなぎ、その関節を駆動することで運動を生み出します。ロボティクスの対象は、生成する運動の目的によって大きく分けられます。物体を巧みに操作して周囲の環境そのものを変えるのか、移動によって環境に対するロボットの位置や姿勢を変えるのか、あるいはその両方を行うのか、という違いです。

マニピュレーションとは、ロボットが物体や周囲の環境に働きかけ、意図した変化を生み出すための運動です。例えば、ロボットアームで物体をつかむ、部品を組み立てる、ドライバーなどの道具を使うといった操作が含まれます。ロボット自体は同じ場所にとどまりながら、周囲の環境を変化させます。

ロコモーションとは、ロボットが周囲の環境の中を移動し、自身の位置を変える運動です。移動方法によって、車輪型ロコモーション（移動ベースや自動運転車など）と 脚型ロコモーション（歩行ロボットや四足歩行ロボットなど）に大きく分けられます。

💡 ヒント

簡単な見分け方は、「何が変化するか」を考えることです。主に周囲の環境（物体の位置・姿勢や状態）が変化するならマニピュレーション、主にロボット自身の状態が変化するならロコモーションです。タスクの中で両方が重要な役割を持つなら、モバイルマニピュレーションに分類できます。この考え方は、観測、行動、評価方法を設計する際に役立ちます。

この分類は、今後のセクションで、データセットに必要なセンサーや、方策が予測する行動空間を考える際にも役立ちます。

例: 平面マニピュレーション

理解を深めるために、できるだけ単純な例を取り上げ、順を追って考えてみましょう。

ロボットマニピュレータは通常、複数のリンクと関節を鎖状につないだ構造を持ち、その先端には エンドエフェクタ が取り付けられています。関節を駆動することでリンクを動かし、エンドエフェクタを使って目的の位置で作業を行います。例えば、グリッパーを開閉して物体をつかんだり放したりするほか、ドライバーなどの専用工具を使用することもできます。

最近では、ALOHA、ALOHA-2、SO-100/SO-101 といった低価格マニピュレータの登場により、Franka Emika Panda アームのような従来のプラットフォームと比べて入手しやすくなり、ロボティクスへの参入障壁が大きく下がりました。

予算や設備が限られた環境では、安価で入手しやすいロボットの導入が進み、Panda アームのような従来型プラットフォームに匹敵するほど普及し始めています。特に SO-100 は数百ユーロで入手でき、数時間で全体を3Dプリントできます。一方、工業製品として製造される Panda アームは数万ユーロと高価で、オープンな形では提供されていません。

順運動学と逆運動学

一部の関節が動かないようにすることで、SO-100 アームを2次元の平面マニピュレータに単純化したもの。

SO-100 の一部の関節を固定し、構造を単純化したモデルを考えます。これにより、制御する自由度は6自由度から2自由度（＋グリッパー）に減ります。制御する2つの関節角度を θ₁、θ₂ とすると、ロボットのコンフィギュレーションは q = [θ₁, θ₂] で表されます。

この例では、エンドエフェクタの位置 $p \in \mathbb{R}^2$ を、ロボットのコンフィギュレーション $q$ の関数 $p = p(q)$ として、次のように数式で表せます。

$$p(q) = \begin{pmatrix} l \cos(\theta_1) + l \cos(\theta_1 + \theta_2) \ l \sin(\theta_1) + l \sin(\theta_1 + \theta_2) \end{pmatrix}$$

順運動学（FK） はロボットのコンフィギュレーションを対応するエンドエフェクタの姿勢に写像し、一方で 逆運動学（IK） はエンドエフェクタの姿勢が与えられたときにコンフィギュレーションを復元するために使われます。

今回のように単純化した場合は、$p(q) = p^$ を満たす $q$ を解析的に求めることで、エンドエフェクタを目標位置 $p^$ に到達させる関節角度を計算できます。しかし、一般的なロボットでは解析的に解けるとは限らず、通常は反復的な最適化手法を利用します。

$$\min_{q \in \mathcal{Q}} |p(q) - p^*|_2^2$$

ロボットの作業空間に障害物があると、$q$ の取りうる値にも制約が加わります。そのため、IK の厳密な解析解を求める方法は、さらに使いにくくなります。

💡 ヒント

数式が難しく感じられたら、何を何に対応させる計算なのかに注目してください。FK は「関節角度が分かれば、手の位置はどこになるか」、IK は「手をその位置に動かすには、関節角度をどうすればよいか」を考えるものです。このユニットでは、実際のロボットを扱うときに IK が難しくなる理由を説明していきます。

微分逆運動学

IK を直接解くのが難しい場合でも、絶対位置の代わりに小さな動き（速度）を扱うことで、解を求めやすくなることがあります。

$J(q)$ を、順運動学の関数 $p(q)$ の偏導関数からなるヤコビアン行列とします。$p(q)$ に連鎖律を適用すると $\dot{p} = J(q) \dot{q}$ が得られ、ロボットの関節速度とエンドエフェクタの速度の関係を表せます。

目標となるエンドエフェクタの軌道が与えられたとき、微分 IK では、関節の コンフィギュレーション そのものではなく、関節の 速度 $\dot{q}(t)$ を求めます。

$$\dot{q}(t) = \arg\min_\nu |J(q(t)) \nu - \dot{p}^*(t)|_2^2$$

これはしばしば閉形式の解 $\dot{q} = J(q)^+ \dot{p}^*$ を持ちます。ここで $J^+(q)$ は $J(q)$ のムーア・ペンローズ擬似逆行列を表します。

フィードバックループの追加

微分 IK は、目標軌道が明確に与えられている場合には非常に効果的です。ただし、モデルの誤差や軌道追従の誤差、環境内のモデル化されていない動力学の影響によって、性能が大きく低下することがあります。

モデリング誤差、センサーノイズ、その他の外乱の影響を減らすため、古典的な制御システムでは、微分 IK にフィードバック制御を組み合わせます。具体的には、目標姿勢と実際に測定した姿勢との差 $\Delta p = p^* - p(q)$ を制御に反映させます。例えば、関節速度の指令値を $\dot{q} = J(q)^+ (\dot{p}^* + k_p \Delta p)$ とすることで、目標軌道からのずれを補正できます。ここで $k_p$ は比例ゲインです。

軌道追従を安定させ、中程度の外乱の影響を抑えるために、フィードバック線形化、PID 制御、線形二次レギュレータ（LQR）、モデル予測制御（MPC）といった、より高度な制御技術も利用できます。

動力学ベースのロボティクスの限界

ここまでの内容を踏まえ、古典的な手法の限界を考えてみましょう。これらの手法は実際のロボット制御でどのような課題に直面し、それがなぜ学習ベースの手法を開発する動機となるのでしょうか。

ロボティクスの研究には60年以上の歴史がありますが、自律ロボットはいまだに、人間と同等の水準でさまざまな作業をこなすことがほとんどできません。特に、(1) 異なるロボットのエンボディメント（さまざまなマニピュレータやロコモーションプラットフォームなど）と、(2) 異なるタスク（靴ひもを結ぶ、多様な物体を操作するなど）の両方に対応できる汎化能力が不足しています。

動力学ベースのロボティクス手法には、主に4つの限界があります。(1) 多数の構成要素を連携させることが難しい、(2) センサーの種類やタスクごとに専用の処理パイプラインが必要となり、規模を拡大しにくい、(3) 単純化した物理モデルでは実世界の複雑さを十分に表現できず、性能が制限される、という問題です。さらに (4) ロボティクスデータの公開や蓄積が急速に進んでいるにもかかわらず、その利点を十分に活用できないという限界もあります。

主な限界

1. 統合の課題 動力学ベースのロボティクスでは、歴史的に、目的の異なる構成要素を個別に設計し、順につなぎ合わせることで制御システムを発展させてきました。現在の多くのアーキテクチャもこの構造を受け継いでいます。センシング、状態推定、マッピング、計画、（微分）IK、低レベル制御は、それぞれ固定されたインターフェースを持つ独立したモジュールとして開発されてきました。しかし、こうしたモジュールを連結すると誤差が発生・蓄積しやすく、システムに変更を加えた際にも動作が不安定になりやすいという問題があります。

2. 限られたスケーラビリティ 古典的なプランナーは通常、計画に必要な情報を十分に含んでいると仮定した、簡潔な状態表現を利用します。しかし、形式が異なり、ノイズも含まれる生データを直接処理できるように拡張することは容易ではありません。そのため、マルチモーダルデータや複数のタスクに対応する際の拡張性には限界があります。従来は、RGB 画像、深度情報、触覚、音声などの高次元データを制御に利用するために、有用な特徴を取り出す処理を個別に設計する必要があり、多大な開発作業が求められていました。

3. モデリングの限界 システムの統合や拡張性だけでなく、複雑なシステムにおける接触、摩擦、コンプライアンスを正確にモデル化することも依然として困難です。物体が変形する場合には剛体近似が不十分になることも多く、近似モデルへの依存は、開発した手法を実世界に適用する際の妨げとなります。

4. データトレンドの見落とし 最後に、動力学ベースの手法は、近年の公開ロボティクスデータセットの急速な増加を十分に活用できていません。従来、学術研究用データセットは主にロボティクスの専門家からなる大規模な組織が集中的に整備してきました。しかし現在では、それに加えて、さまざまな専門知識を持つ個人がそれぞれ独立して提供するロボティクスデータセットも増えています。

こうした限界があるからこそ、次のような能力を持つ学習ベースのアプローチを研究する意義があります。 1. 知覚と制御をより緊密に統合する 2. 専門家のモデリング介入を減らしながら タスクとエンボディメントをまたいで適応する 3. ロボティクスデータの増加に応じて 性能を着実に向上させる
