自分だけの Pokémon バトルエージェントを作ろう

ゲームにおけるエージェンティック AI の可能性と限界を探ってきたので、次は実践です。このセクションでは、コースを通じて学んだすべてを使い、ポケモン風のターン制バトルで戦う、あなた自身の AI エージェントを構築します。

システムを、4 つの重要な構成要素に分けます。

  • Poke-env: ルールベースまたは強化学習の Pokémon ボットを訓練するために設計された Python ライブラリ。

  • Pokémon Showdown: エージェントが戦う、オンラインバトルシミュレータ。

  • LLMAgentBase: LLM と Poke-env のバトル環境を接続するために用意した、カスタムの Python クラス。

  • TemplateAgent: 独自のバトルエージェントを作るために完成させる、スターターテンプレート。

それぞれのコンポーネントを、詳しく見ていきましょう。

🧠 Poke-env

Poke-env は、もともと Haris Sahovic が強化学習ボットの訓練用に構築した Python インターフェースですが、ここではエージェンティック AI 用に転用します。
シンプルな API を通じて、エージェントが Pokémon Showdown とやり取りできるようにします。

グラフィカルインターフェースとの通信に必要なすべてを備えた Player クラスを提供しており、エージェントはこれを継承します。

ドキュメント: poke-env.readthedocs.io
リポジトリ: github.com/hsahovic/poke-env

⚔️ Pokémon Showdown

Pokémon Showdown は、エージェントが実際の Pokémon バトルをプレイする、オープンソースのバトルシミュレータです。
バトルをリアルタイムにシミュレーションし、表示するための完全なインターフェースを提供します。このチャレンジでは、ボットは人間のプレイヤーとまったく同じように、ターンごとに技を選んで行動します。

参加者全員がバトルに使うサーバーを用意しました。最高の AI バトルエージェントを作るのは誰か、競い合いましょう。

リポジトリ: github.com/smogon/Pokemon-Showdown
ウェブサイト: pokemonshowdown.com

🔌 LLMAgentBase

LLMAgentBase は、Poke-env の Player クラスを拡張した Python クラスです。
LLM と Pokémon バトルシミュレータの橋渡し役を務め、入出力の整形とバトルのコンテキストの保持を担当します。

このベースエージェントは、環境とやり取りするためのツール群（STANDARD_TOOL_SCHEMA で定義）を提供します。

  • choose_move: バトル中の技の選択用
  • choose_switch: ポケモンの交代用

LLM は、対戦中の意思決定にこれらのツールを使う必要があります。

🧠 コアロジック

  • choose_move(battle: Battle): 毎ターン呼び出されるメインメソッドです。Battle オブジェクトを受け取り、LLM の出力に基づいた行動文字列を返します。

🔧 主要な内部メソッド

  • _format_battle_state(battle): 現在のバトルの状態を文字列に変換し、LLM に送れる形にします。

  • _find_move_by_name(battle, move_name): 名前で技を探します。choose_move を呼び出す LLM の応答で使われます。

  • _find_pokemon_by_name(battle, pokemon_name): LLM の交代コマンドに基づき、交代先のポケモンを特定します。

  • _get_llm_decision(battle_state): ベースクラスでは抽象メソッドです。次のセクションで説明するように、自分のエージェントで実装する必要があります。そこでは、LLM への問い合わせ方法と、その応答の解析方法を定義します。

その意思決定の仕組みを示す抜粋がこちらです。

STANDARD_TOOL_SCHEMA = {
    "choose_move": {
        ...
    },
    "choose_switch": {
        ...
    },
}

class LLMAgentBase(Player):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.standard_tools = STANDARD_TOOL_SCHEMA
        self.battle_history = []

    def _format_battle_state(self, battle: Battle) -> str:
        active_pkmn = battle.active_pokemon
        active_pkmn_info = f"Your active Pokemon: {active_pkmn.species} " \
                           f"(Type: {'/'.join(map(str, active_pkmn.types))}) " \
                           f"HP: {active_pkmn.current_hp_fraction * 100:.1f}% " \
                           f"Status: {active_pkmn.status.name if active_pkmn.status else 'None'} " \
                           f"Boosts: {active_pkmn.boosts}"

        opponent_pkmn = battle.opponent_active_pokemon
        opp_info_str = "Unknown"
        if opponent_pkmn:
            opp_info_str = f"{opponent_pkmn.species} " \
                           f"(Type: {'/'.join(map(str, opponent_pkmn.types))}) " \
                           f"HP: {opponent_pkmn.current_hp_fraction * 100:.1f}% " \
                           f"Status: {opponent_pkmn.status.name if opponent_pkmn.status else 'None'} " \
                           f"Boosts: {opponent_pkmn.boosts}"
        opponent_pkmn_info = f"Opponent's active Pokemon: {opp_info_str}"

        available_moves_info = "Available moves:\n"
        if battle.available_moves:
            available_moves_info += "\n".join(
                [f"- {move.id} (Type: {move.type}, BP: {move.base_power}, Acc: {move.accuracy}, PP: {move.current_pp}/{move.max_pp}, Cat: {move.category.name})"
                 for move in battle.available_moves]
            )
        else:
             available_moves_info += "- None (Must switch or Struggle)"

        available_switches_info = "Available switches:\n"
        if battle.available_switches:
              available_switches_info += "\n".join(
                  [f"- {pkmn.species} (HP: {pkmn.current_hp_fraction * 100:.1f}%, Status: {pkmn.status.name if pkmn.status else 'None'})"
                   for pkmn in battle.available_switches]
              )
        else:
            available_switches_info += "- None"

        state_str = f"{active_pkmn_info}\n" \
                    f"{opponent_pkmn_info}\n\n" \
                    f"{available_moves_info}\n\n" \
                    f"{available_switches_info}\n\n" \
                    f"Weather: {battle.weather}\n" \
                    f"Terrains: {battle.fields}\n" \
                    f"Your Side Conditions: {battle.side_conditions}\n" \
                    f"Opponent Side Conditions: {battle.opponent_side_conditions}"
        return state_str.strip()

    def _find_move_by_name(self, battle: Battle, move_name: str) -> Optional[Move]:
        normalized_name = normalize_name(move_name)
        # 完全な ID 一致を優先する
        for move in battle.available_moves:
            if move.id == normalized_name:
                return move
        # フォールバック: 表示名で確認する（信頼性は低め）
        for move in battle.available_moves:
            if move.name.lower() == move_name.lower():
                print(f"Warning: Matched move by display name '{move.name}' instead of ID '{move.id}'. Input was '{move_name}'.")
                return move
        return None

    def _find_pokemon_by_name(self, battle: Battle, pokemon_name: str) -> Optional[Pokemon]:
        normalized_name = normalize_name(pokemon_name)
        for pkmn in battle.available_switches:
            # 比較のために種族名を正規化する
            if normalize_name(pkmn.species) == normalized_name:
                return pkmn
        return None

    async def choose_move(self, battle: Battle) -> str:
        battle_state_str = self._format_battle_state(battle)
        decision_result = await self._get_llm_decision(battle_state_str)
        print(decision_result)
        decision = decision_result.get("decision")
        error_message = decision_result.get("error")
        action_taken = False
        fallback_reason = ""

        if decision:
            function_name = decision.get("name")
            args = decision.get("arguments", {})
            if function_name == "choose_move":
                move_name = args.get("move_name")
                if move_name:
                    chosen_move = self._find_move_by_name(battle, move_name)
                    if chosen_move and chosen_move in battle.available_moves:
                        action_taken = True
                        chat_msg = f"AI Decision: Using move '{chosen_move.id}'."
                        print(chat_msg)
                        return self.create_order(chosen_move)
                    else:
                        fallback_reason = f"LLM chose unavailable/invalid move '{move_name}'."
                else:
                     fallback_reason = "LLM 'choose_move' called without 'move_name'."
            elif function_name == "choose_switch":
                pokemon_name = args.get("pokemon_name")
                if pokemon_name:
                    chosen_switch = self._find_pokemon_by_name(battle, pokemon_name)
                    if chosen_switch and chosen_switch in battle.available_switches:
                        action_taken = True
                        chat_msg = f"AI Decision: Switching to '{chosen_switch.species}'."
                        print(chat_msg)
                        return self.create_order(chosen_switch)
                    else:
                        fallback_reason = f"LLM chose unavailable/invalid switch '{pokemon_name}'."
                else:
                    fallback_reason = "LLM 'choose_switch' called without 'pokemon_name'."
            else:
                fallback_reason = f"LLM called unknown function '{function_name}'."

        if not action_taken:
            if not fallback_reason:
                 if error_message:
                     fallback_reason = f"API Error: {error_message}"
                 elif decision is None:
                      fallback_reason = "LLM did not provide a valid function call."
                 else:
                      fallback_reason = "Unknown error processing LLM decision."

            print(f"Warning: {fallback_reason} Choosing random action.")

            if battle.available_moves or battle.available_switches:
                 return self.choose_random_move(battle)
            else:
                 print("AI Fallback: No moves or switches available. Using Struggle/Default.")
                 return self.choose_default_move(battle)

    async def _get_llm_decision(self, battle_state: str) -> Dict[str, Any]:
        raise NotImplementedError("Subclasses must implement _get_llm_decision")

🧪 TemplateAgent

いよいよ楽しい部分です。LLMAgentBase を土台にして、リーダーボードを駆け上がる独自の戦略を持った、あなた自身のエージェントを実装しましょう。

このテンプレートを出発点に、独自のロジックを構築します。手引きとして、OpenAI、Mistral、Gemini のモデルを使った 3 つの完全な例も用意しています。

テンプレートの簡略版がこちらです。

    def __init__(self, api_key: str = None, model: str = "model-name", *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.model = model
        self.template_client = TemplateModelProvider(api_key=...)
        self.template_tools = list(self.standard_tools.values())

    async def _get_llm_decision(self, battle_state: str) -> Dict[str, Any]:
        """状態を LLM に送り、関数呼び出しの意思決定結果を受け取る。"""
        system_prompt = (
            "You are a ..."
        )
        user_prompt = f"..."

        try:
            response = await self.template_client.chat.completions.create(
                model=self.model,
                messages=[
                    {"role": "system", "content": system_prompt},
                    {"role": "user", "content": user_prompt},
                ],
            )
