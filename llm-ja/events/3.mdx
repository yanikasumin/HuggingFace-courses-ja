# Gradio Blocks パーティー[[gradio-blocks-party]]

コースで Gradio を扱う章の公開に合わせて、Hugging Face はコミュニティイベントを開催しました。内容は、新しい Gradio Blocks 機能を使った、魅力的な機械学習デモの制作です。

コミュニティが作成したデモは、Hub 上の [`Gradio-Blocks`](https://huggingface.co/Gradio-Blocks) オーガニゼーションで全て見ることが出来ます。ここでは、受賞作品の中からいくつかを紹介します。
