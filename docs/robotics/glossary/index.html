Robotics コース

用語集

この用語集は日本語版独自の補足です。原典には含まれていません。本文を読む際の助けとして、平易な言葉で説明しています。

LeRobot
Hugging Face が開発する、ロボット学習のためのオープンソースライブラリ。データセット、学習、評価の道具がそろっています。
センサー
ロボットの周囲や自身の状態を測る装置。カメラ、力センサー、エンコーダなど。目や耳にあたる役割を持ちます。
アクチュエータ
モーターなど、ロボットを実際に動かす装置。手や足にあたる役割を持ちます。
運動学（キネマティクス）
関節の角度と手先の位置・姿勢の関係を扱う分野。力を扱わない点が動力学と異なります。
順運動学 / 逆運動学
関節角度から手先位置を求めるのが順運動学、その逆が逆運動学です。
制御システム
センサーの値をもとに、目標に近づくようアクチュエータへ指令を出す仕組みです。
フィードバック制御
出力（実際の状態）を測って指令に反映させる制御。「ずれたら直す」を繰り返します。
模倣学習（イミテーションラーニング）
人間のお手本の動きを記録し、それを真似るようにモデルを学習させる方法です。
強化学習
試行錯誤と報酬によって、よい行動を学ばせる学習方法です。
LeRobotDataset
ロボットの観測と行動を時系列で記録する、LeRobot のデータセット形式です。
テレオペレーション
人間が遠隔でロボットを操作すること。模倣学習のお手本データ集めによく使います。
シミュレーション
実機の代わりにコンピュータ上でロボットと環境を再現し、実験や学習を行うことです。
