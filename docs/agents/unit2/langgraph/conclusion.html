まとめ

Unit 2 の LangGraph モジュールを修了しました。おめでとうございます！

LangGraph を使って構造化されたワークフローを構築する為の基礎を身につけました。これで、作成したワークフローを本番環境に導入することも出来るようになります。

LangGraph の学習は、このモジュールで終わりではありません。更に高度な内容を学びたい方には、次の取り組みをお勧めします。

  • LangGraph の公式ドキュメント を読む
  • LangChain Academy の総合コース Introduction to LangGraph を受講する
  • 自分で何かを作ってみる！

次のユニットでは、実際のユースケースを詳しく見ていきます。理論の学習から離れて、いよいよ実践に進みましょう！

このコースについての感想や、改善の為のご意見を是非聞かせてください。フィードバックが有る場合は、こちらのフォーム にご記入ください。

これからも学び続けて、素敵な自分でいよう！ 🤗
