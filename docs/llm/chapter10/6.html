Argilla、チェック！

以上です。おめでとうございます！ 👏

この章では、次の基本的なステップを学びました。 - Argilla をセットアップする。 - アノテーションを付けてデータセットの質を高める。 - 既存のデータセットを別の NLP タスクに合わせて調整し、再利用する。 - アノテーション済みデータセットを Hugging Face Hub でコミュニティと共有する。

次のステップ

  • その他の代表的なタスクについても、チュートリアルページ で手順を追って学べます。
  • ほかのデータセットの例は、こちらのデモ でも確認できます。
  • Argilla についてさらに学び、より高度な機能を知りたい場合は、Argilla のドキュメント を確認してください。
