LLM コース

用語集

この用語集は日本語版独自の補足です。原典には含まれていません。本文を読む際の助けとして、平易な言葉で説明しています。

LLM（大規模言語モデル）
大量のテキストで学習した、文章の理解と生成を行うニューラルネットワークモデル。次のトークンを予測する学習を通じて言語能力を獲得します。
NLP（自然言語処理）
人間の言語をコンピュータに処理させる技術分野の総称。翻訳、要約、質問応答、感情分析などを含みます。
Transformer
2017年に提案されたニューラルネットワークの構造。Attention の仕組みを中心に、文章全体の関係を並列に処理できます。
Attention（注意機構）
文章中の各トークンが、ほかのどのトークンにどれだけ注目すべきかを重みで表す仕組みです。
トークン
モデルがテキストを扱う最小単位。単語そのものではなく、単語の一部や文字の並びになることもあります。
トークナイザ
テキストをトークン列に分割し、数値IDに変換する部品。モデルごとに語彙が決まっています。
語彙（ボキャブラリー）
トークナイザが知っているトークンの一覧。テキストはこの範囲のトークンで表現されます。
埋め込み（エンベディング）
トークンや文章を、意味の近さが距離に表れる数値ベクトルに変換したものです。
事前学習（プリトレーニング）
大量のテキストでモデルをあらかじめ学習させること。この段階で言語の一般的な能力が身につきます。
ファインチューニング
事前学習済みモデルを、特定のタスクやデータで追加学習させることです。
パイプライン（pipeline）
🤗 Transformers が提供する、複雑な処理を数行で実行できる高水準APIです。
推論（インファレンス）
学習済みモデルを使って、入力から出力（予測や生成）を行うことです。
ハルシネーション（幻覚）
モデルが、事実ではない内容をもっともらしく生成してしまう現象です。
プロンプト
モデルへの入力として与える指示や文章。書き方によって出力が大きく変わります。
コンテキストウィンドウ
モデルが一度に扱えるトークン数の上限。会話履歴や文書はこの範囲に収める必要があります。
温度（temperature）
生成時のランダムさを調整する値。高いほど多様で、低いほど決まった出力になりやすいです。
BPE（バイトペア符号化）
頻出する文字列の組を繰り返し結合して語彙を作る、サブワード分割の代表的な手法です。
SentencePiece
言語に依存しないトークナイザの実装。空白を前提としないため、日本語のような言語にも使えます。
データセット
モデルの学習や評価に使うデータの集まり。🤗 Datasets ライブラリで読み込みや加工ができます。
Trainer API
🤗 Transformers の学習を簡略化する仕組み。学習ループを自分で書かずにファインチューニングできます。
LoRA
大規模モデルの重みの一部だけを効率よく学習する手法。学習コストを大幅に下げられます。
量子化（クオンタイゼーション）
モデルの重みを少ないビット数で表し、メモリ使用量と計算量を減らす技術です。
Hub（Hugging Face Hub）
モデルやデータセット、デモ（Space）を公開・共有するプラットフォームです。
ゼロショット / フューショット
例を示さずにタスクを解かせるのがゼロショット、数例を示すのがフューショットです。
