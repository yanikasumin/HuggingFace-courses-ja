パート2公開イベント

コースのパート2の公開を記念して、ファインチューニングスプリントに先立ち、2日間のライブ講演イベントを開催しました。見逃した方も、以下の講演動画から内容を振り返ることができます！

Day 1: Transformer モデルの全体像と学習させる方法

Thomas Wolf: Transfer Learning and the birth of the Transformers library

Thomas Wolf は Hugging Face の共同創設者であり、Chief Science Officer（最高科学責任者）です。Thomas Wolf と Hugging Face チームが開発したツールは、Facebook Artificial Intelligence Research、Google Research、DeepMind、Amazon Research、Apple、Allen Institute for Artificial Intelligence など5,000を超える研究機関や、ほとんどの大学の学科で使われています。Thomas Wolf は、人工知能分野で史上最大の研究コラボレーションである 「BigScience」 の発起人でありシニアチェアを務めるほか、広く使われているライブラリやツール群の開発にも携わっています。また、精力的な教育者であり、AI・自然言語処理分野で影響力を持つ専門家として、世界中のカンファレンスに招待講演者として定期的に登壇しています https://thomwolf.io。

Jay Alammar: A gentle visual intro to Transformers models

人気の ML ブログを通じて、Jay は何百万人もの研究者やエンジニアが機械学習のツールや概念を視覚的に理解する手助けをしてきました。Jay が図解してきたテーマは、NumPy や Pandas のドキュメントにも取り上げられるような基礎的な内容から、Transformers、BERT、GPT-3 といった最先端の技術まで多岐にわたります。

Margaret Mitchell: On Values in ML Development

Margaret Mitchell は Ethical AI（倫理的な AI）に取り組む研究者で、現在はテクノロジー分野における倫理を踏まえた AI 開発の実際をテーマにしています。自然言語生成、支援技術、コンピュータービジョン、AI 倫理の分野で50本以上の論文を発表し、会話生成や感情分類の領域で複数の特許を持っています。以前は Google AI のスタッフ研究員（Staff Research Scientist）として、Google の Ethical AI グループを設立して共同リーダーを務め、AI 倫理の基礎研究と、Google 社内での AI 倫理の実践化に取り組みました。Google 入社前は Microsoft Research で視覚情報から自然言語を生成する技術を研究し、その前は Johns Hopkins 大学のポスドクとしてベイズモデリングと情報抽出に取り組んでいました。University of Aberdeen でコンピューターサイエンスの博士号を、University of Washington で計算言語学の修士号を取得しています。学位取得の過程では、2005年から2012年にかけて Oregon Health and Science University で機械学習、神経疾患、支援技術の研究にも携わりました。多様性、インクルージョン、コンピューターサイエンス、倫理が交わる領域で、数多くのワークショップや活動を主導してきました。彼女の研究成果は、Ash Carter 国防長官や American Foundation for the Blind から表彰され、複数のテクノロジー企業でも実際に採用されています。ガーデニングと犬と猫が好きです。

Matthew Watson and Chen Qian: NLP workflows with Keras

Matthew Watson は Keras チームの機械学習エンジニアで、高水準のモデル構築 API に注力しています。学部ではコンピューターグラフィックスを学び、Stanford University で修士号を取得しました。もともとは英文学を専攻する寸前でしたが、コンピューターサイエンスに転向しました。分野を横断して仕事に取り組むことと、NLP をより多くの人に身近なものにすることに情熱を注いでいます。

Chen Qian は Keras チームのソフトウェアエンジニアで、高水準のモデル構築 API に注力しています。Stanford University で電気工学の修士号を取得しており、ML タスクのコード実装の簡素化と大規模 ML に特に関心があります。

Mark Saroufim: How to Train a Model with Pytorch

Mark Saroufim は PyTorch の Partner Engineer で、TorchServe や PyTorch Enterprise を含む、本番運用向けのオープンソースツールに取り組んでいます。過去には Graphcore、yuri.ai、Microsoft、NASA の JPL で Applied Scientist や Product Manager を務めてきました。何よりも情熱を注いでいるのは、プログラミングをもっと楽しくすることです。

Jakob Uszkoreit: It Ain't Broke So Don't Fix Let's Break It

Jakob Uszkoreit は Inceptive の共同創設者です。Inceptive は、大規模な深層学習とハイスループット実験を密接に組み合わせ、両者を連携させた反復的なプロセスを通じて、ワクチンや治療薬のための RNA 分子を設計しており、RNA ベースの医薬品をより身近で、より効果的で、より幅広く適用できるものにすることを目指しています。それ以前、Jakob は Google で10年以上働き、Google Brain、Research、Search において、深層学習の基礎、コンピュータービジョン、言語理解、機械翻訳の研究開発チームを率いていました。

Day 2: 使うべきツール

Lewis Tunstall: Simple Training with the 🤗 Transformers Trainer

Lewis は Hugging Face の機械学習エンジニアで、オープンソースツールの開発と、それをより広いコミュニティに届けることに注力しています。O'Reilly の書籍 Natural Language Processing with Transformers の共著者でもあります。Twitter（@_lewtun）では NLP のヒントやコツを発信しています！

Matthew Carrigan: New TensorFlow Features for 🤗 Transformers and 🤗 Datasets

Matt は Transformers における TensorFlow のメンテナンスを担当しています。いずれ現在主流の PyTorch 派に対するクーデターを率いることになるでしょう。その計画は、おそらく彼の Twitter アカウント @carrigmat を通じて調整されるはずです。

Lysandre Debut: The Hugging Face Hub as a means to collaborate on and share Machine Learning projects

Lysandre は Hugging Face の機械学習エンジニアで、多くのオープンソースプロジェクトに関わっています。非常にシンプルな API を持つ強力なツールを開発することで、機械学習を誰にとっても身近なものにすることを目指しています。

Lucile Saulnier: Get your own tokenizer with 🤗 Transformers & 🤗 Tokenizers

Lucile は Hugging Face の機械学習エンジニアで、オープンソースツールの開発と利用支援に携わっています。協調学習や BigScience など、自然言語処理分野の多くの研究プロジェクトにも積極的に関わっています。

Sylvain Gugger: Supercharge your PyTorch training loop with 🤗 Accelerate

Sylvain は Hugging Face のリサーチエンジニアで、🤗 Transformers のコアメンテナーの一人であり、🤗 Accelerate の開発者です。モデルの学習をより身近なものにすることに力を入れています。

Merve Noyan: Showcase your model demos with 🤗 Spaces

Merve は Hugging Face のデベロッパーアドボケイトで、ツールの開発とそれを巡るコンテンツ作りを通じて、機械学習をみんなのものにする活動をしています。

Abubakar Abid: Building Machine Learning Applications Fast

Abubakar Abid は Gradio の CEO です。2015年に MIT で電気工学とコンピューターサイエンスの理学士号を、2021年に Stanford で応用機械学習の博士号を取得しました。Gradio の CEO として、機械学習モデルのデモ、デバッグ、デプロイを容易にすることに取り組んでいます。

Mathieu Desvé: AWS ML Vision: Making Machine Learning Accessible to all Customers

テクノロジー愛好家で、自由な時間にはものづくりをしています。難しい課題に挑戦することや、クライアントやユーザーの問題を解決することにやりがいを感じています。また、才能ある人たちと働きながら日々学ぶことも楽しんでいます。2004年以来、フロントエンド、バックエンド、インフラ、運用、管理とさまざまなポジションを経験してきました。よくある技術的・管理的な課題をアジャイルな手法で解決するよう努めています。

Philipp Schmid: Managed Training with Amazon SageMaker and 🤗 Transformers

Philipp Schmid は Hugging Face の機械学習エンジニア／テックリードで、Amazon SageMaker チームとの連携を率いています。最先端の NLP モデルを誰もが利用できるようにすること、そのモデルを本番環境で活用できるようにすること、そして深層学習をより使いやすくすることに情熱を注いでいます。
