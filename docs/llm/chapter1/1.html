はじめに

🤗 コースへようこそ！

このコースでは、Hugging Face エコシステムのライブラリ（🤗 Transformers、Datasets、Tokenizers、Accelerate）と Hugging Face Hub を使って、大規模言語モデル（LLM）と自然言語処理（NLP）について学びます。

Hugging Face エコシステムの外のライブラリも扱います。いずれも AI コミュニティが生んだ優れたツールで、とても役に立ちます。

完全無料で、広告もありません。

NLP と LLM について

このコースは、元々自然言語処理（NLP）を中心に扱っていました。その後、NLP 分野で大きな進歩を遂げた大規模言語モデル（LLM）にも重点を置く内容へと発展してきました。

両者の違いは？ - NLP（Natural Language Processing：自然言語処理） は、LLM よりも対象範囲の広い分野です。コンピュータが人間の言語を理解・解釈・生成出来るようにする技術を研究します。感情分析、固有表現認識、機械翻訳など、様々なタスクを扱います。 - LLM（Large Language Models：大規模言語モデル） は NLP モデルの一種で、特に高い能力を持ちます。大規模なモデルを膨大なデータで学習させる為、個々のタスクに合わせた追加学習を殆ど行わずに、幅広い言語タスクに対応出来ます。Llama、GPT、Claude などは、NLP で出来ることを大きく変えた LLM のモデルシリーズです。

このコースを通して、従来の NLP の概念と最先端の LLM の技術の両方を学びます。NLP の基礎を理解することは、LLM を効果的に活用する上で欠かせません。

コースの概要

コースの概要を簡単に紹介します。

  • Chapter 1 から 4 では、Transformers ライブラリの主要な概念を紹介します。このパートを終えるころには、Transformer モデルの仕組みに慣れ、Hugging Face Hub からモデルを使う方法、データセットでファインチューニングする方法、そして結果を Hub で共有する方法が分かるようになります。
  • Chapter 5 から 8 では、Datasets と Tokenizers の基礎を学んでから、古典的な NLP タスクや LLM の技術に進みます。このパートを終えるころには、最も一般的な言語処理の課題に自分で取り組めるようになります。
  • Chapter 9 では NLP の範囲を超えて、自分のモデルのデモを Hub で構築・共有する方法を扱います。このパートを終えるころには、自分の Transformers アプリケーションを世界に披露する準備が整います。
  • Chapter 10 から 12 では、ファインチューニング、高品質なデータセットのキュレーション、推論モデルの構築といった、LLM の高度なトピックを深掘りします。

受講にあたっての前提は、次の通りです。

  • Python について十分な知識が必要です
  • fast.ai の Practical Deep Learning for Coders や、DeepLearning.AI が開発したプログラムなど、深層学習の入門コースを先に受けておくと、よりスムーズに学べます
  • PyTorch や TensorFlow の事前知識は前提としていませんが、どちらかに慣れていると理解の助けになります

このコースを終えたら、DeepLearning.AI の Natural Language Processing Specialization をチェックしてみることをお勧めします。ナイーブベイズや LSTM など、知っておく価値の有る従来の NLP モデルを幅広く扱っています。

よくある質問

よくある質問への回答を以下にまとめます。

  • このコースを受けると認定資格が得られますか？ 現在、このコースに認定資格はありません。但し、Hugging Face エコシステムの認定プログラムを準備中です。続報をお楽しみに！

  • このコースにはどれくらいの時間を割くべきですか？ 各章は、1週間に約6〜8時間学習すれば修了出来るように設計されています。但し、自分のペースで必要なだけ時間をかけて進めても構いません。

  • 質問が有る場合は、どこで聞けばいいですか？ コースの各セクションについて質問が有る場合は、ページ上部の「Ask a question」バナーをクリックしてください。自動的に Hugging Face フォーラム の該当セクションに移動します。

なお、コースを終えた後に更に練習したい方向けに、フォーラムにはプロジェクトのアイデア集も用意されています。

  • コースのコードはどこで入手出来ますか？ 各セクションでは、ページ上部のバナーをクリックすると、Google Colab 又は Amazon SageMaker Studio Lab でコードを実行出来ます。

コースの全てのコードを含む Jupyter ノートブックは、huggingface/notebooks リポジトリでホストされています。ローカルでノートブックを生成したい場合は、GitHub の course リポジトリに在る手順を確認してください。

  • コースに貢献するにはどうすればいいですか？ コースに貢献する方法は沢山あります！誤字やバグを見つけた場合は、course リポジトリで Issue を開いてください。コースを母国語に翻訳する手伝いをしたい場合は、こちら の手順を確認してください。

  • 各翻訳では、どのような方針で訳語が選ばれたのですか？ 各翻訳には、機械学習の専門用語などについてどのような選択をしたかを詳しく記した用語集と TRANSLATING.txt ファイルがあります。ドイツ語の例はこちらで確認できます。

  • このコースを再利用出来ますか？ 勿論可能です！このコースは、利用条件が比較的緩やかな Apache 2 ライセンス のもとで公開されています。つまり、適切なクレジットを表示し、ライセンスへのリンクを提供し、変更を加えた場合はその旨を示す必要があります。これらは合理的な方法であればどのように行っても構いませんが、ライセンサーがあなたやあなたの利用方法を推奨しているかのように示す方法は認められません。コースを引用する場合は、次の BibTeX を使用してください。
