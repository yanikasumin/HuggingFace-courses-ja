# はじめに

## 点群とは？

点群（point cloud）は個々の点の集合で、各点は [x, y, z] 座標で表される三次元空間内の表面のサンプルを表します。これらの点は、空間座標だけでなく、法線、RGB カラー、アルベド、双方向反射分布関数（BRDF）などの追加の属性を保持することがよくあります。

アルベドとは、物体の表面が光をどれだけ反射するかを表す値です。表面に入ってくる光に対して、どれだけの光が反射されるかという比率で表します。アルベドが高い雪のような表面は多くの光を反射し、アルベドが低いアスファルトのような表面は多くの光を吸収します。

BRDF は、不透明な表面で光がどのように散乱又は反射されるかを記述する関数です。入射光の方向と出射方向を考慮して、表面上の交点で光がどう反射されるかを詳述します。光沢、粗さ、様々な角度にわたる反射光の分布といった要因を含め、表面の反射特性を数学的に記述します。

これらの属性は、モデリング、レンダリング、シーン理解などの様々なアプリケーションで重要な役割を果たします。

点群データは新しい概念ではなく、コンピュータグラフィックスや物理シミュレーションなどで長年使われてきました。

しかし、近年は主に2つの動向によって、その重要性が大きく高まっています。第一に、安価で扱い易い点群取得機器が普及し、点群データを以前より簡単に取得出来るようになりました。

第二に、拡張現実（AR）や自動運転車の発展によって、点群データの重要性が更に高まっています。

![点群の活用例](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/point_cloud_example.jpeg)

**点群とは何かが分かった所で、それで何が出来るでしょうか？**

3D の点群データは主に自動運転に利用されてきましたが、現在ではドローンやロボットなど、コンピュータビジョンを使う様々な AI システムでも、周囲の環境を認識する為に LiDAR が使われています。

LiDAR は、物体や周囲の環境の 3D モデルや地図を作る為の計測技術です。紫外線、可視光、近赤外光を利用し、光が物体に反射してスキャナーに戻ってくるまでの時間を測ることで、物体との距離や形状などを調べます。

## 点群データの生成と表現方法

Python ライブラリ [point-cloud-utils](https://github.com/fwilliams/point-cloud-utils) と [open-3d](https://github.com/isl-org/Open3D) を使います。これらは次のようにインストール出来ます。

```bash
pip install point-cloud-utils
```

Python ライブラリ open-3d も使います。インストール方法は次の通りです。

```bash
pip install open3d
```

又は、ファイルサイズの小さい CPU 専用版もインストール出来ます。

```bash
pip install open3d-cpu
```

では、まずこれらの点群がどのような形式で保存されるのかを理解する必要があり、その為にはメッシュクラウドを見る必要があります。

**なぜでしょうか？**

- `point-cloud-utils` は一般的なメッシュ形式（PLY、STL、OFF、OBJ、3DS、VRML 2.0、X3D、COLLADA）の読み取りをサポートします。
- [MeshLab](https://github.com/cnr-isti-vclab/meshlab) にインポートできる形式であれば、読み取れます！（同ライブラリの README より）

ファイルの種類は拡張子から推測されます。サポートされている拡張子の一部は次の通りです。

** PLY (Polygon File Format) **

- 単純な PLY オブジェクトは、頂点や面などの要素から構成されます。頂点は (x,y,z) 座標の組として一覧に記録され、面はその頂点一覧を参照するインデックスの組として記録されます。
- 頂点と面は要素の2つの例であり、PLY ファイルの大部分はこの2つの要素で構成されます。
- 新しいプロパティを作成してオブジェクトの要素に付けることも出来ますが、こうした新しいプロパティに遭遇しても古いプログラムが壊れない方法で追加すべきです。

** STL (Standard Tessellation Language) **

- この形式は、立体モデルの表面を三角形で近似します。
- これらの三角形はファセットとも呼ばれ、各ファセットは面の法線方向と、三角形の3つの頂点を表す座標で記述されます。
- 但し、これらのファイルには色やテクスチャの記述がありません。

** OFF (Object File Format) **

- Object File Format（.OFF）ファイルは、モデルの表面のポリゴンを指定することで、モデルの形状を表現する為に使われます。ポリゴンは任意の数の頂点を持つことが出来ます。
- 交換を目的としたオブジェクトの ASCII テキスト版と、読み書きの効率の為のバイナリ版をサポートします。
- .obj 形式とも呼ばれます。

** 3DS (3D Studio) **

- .3ds 拡張子のファイルは、Autodesk 3D Studio で使われる 3D Studio メッシュファイル形式を表します。
- 3DS 形式はバイナリファイル構造を利用しており、テキストベースの形式と比べて処理が速く、ファイルサイズも小さくなります。データはファイル内のチャンクに整理されます。
- これらのチャンクには、3D シーンを構成する形状、照明、視点に関する情報が格納されます。

** X3D (Extensible 3D Graphics) **

- X3D は、3D 情報を表現する為の XML ベースの 3D グラフィックスファイル形式です。モジュール式の標準であり、いくつかの ISO 仕様によって定義されています。
- この形式は、ベクターグラフィックスとラスターグラフィックス、透明度、ライティング効果、回転、フェード、スイングを含むアニメーション設定をサポートします。
- X3D には、カラー 3D プリンタでモデルを印刷する際に使われる色情報をエンコード出来る利点があります（STL とは異なります）。

** DAE (Digital Asset Exchange) **

- DAE ファイルは、オープン標準として定義された XML スキーマに基づいて作られます。
- このファイル形式は、グラフィックスソフトウェアアプリケーション間でデジタルアセットを交換する為のオープン標準 XML スキーマである COLLADA（COLLAborative Design Activity）XML スキーマに基づいています。
- この形式の最大の売りは、複数のプラットフォームにわたる互換性です。
- COLLADA ファイルは1つのプログラムやメーカーに限定されません。代わりに、3D アセットを保存する標準的な方法を提供します。
