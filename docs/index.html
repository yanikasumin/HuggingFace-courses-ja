Hugging Face 学習コース日本語版

Hugging Face が公開している機械学習の学習コースを日本語に翻訳したサイトです。大規模言語モデル（LLM）、AI エージェント、MCP、コンピュータビジョン、ロボット工学の5コース、全316セクションを収録しています。

教材はすべて無料で、登録せずに読むことができます。各ページには英語原典へのリンクがあり、原文と比較しながら学習できます。

Hugging Face とは

Hugging Face は、機械学習のモデルやデータセットを公開・共有するプラットフォームと、開発用のオープンソースライブラリを提供しています。研究者や開発者が公開したモデルを探し、自分のプログラムで利用したり、独自のモデルを公開したりできます。

代表的なライブラリの Transformers を使うと、言語モデルや画像認識モデルなどを Python から利用できます。公式の学習コースでは、ライブラリの使い方だけでなく、モデルの仕組みや学習方法も説明しています。

この翻訳サイトは、私自身が機械学習を独学する際、充実した英語の教材を日本語でも読みたいと考えたことから始めました。専門用語は英語の資料でも通用する表記を残しつつ、本文は日本語として読みやすくなるよう調整しています。

学べるコース

コースは5つあります。いずれも無料で、登録なしで読めます。多くのセクションには理解度を確認するクイズと、実際に動かせるコード例が含まれています。

LLM コース

LLM Course

大規模言語モデル（LLM）の仕組みを基礎から学ぶコースです。Transformer の動作原理から、Hugging Face Transformers の使い方、ファインチューニング、データセットやトークナイザの扱い、音声処理、独自モデルの構築まで学べます。

  • Transformer の仕組みと、モデルができること
  • Transformers ライブラリの実践的な使い方
  • 事前学習モデルのファインチューニングと共有
  • データセットとトークナイザの扱い
  • LLM のファインチューニングと思考モデルの構築

学習の始め方

コードを実行しながら学ぶには、Python の基本的な文法と実行環境が必要です。最初はブラウザ上で Python を動かせる Google Colab を使うと、パソコンに開発環境を構築せずに始められます。

  1. Python の基礎を確認する。

    変数、関数、リスト、辞書、繰り返し処理などに慣れていない場合は、東京大学「Python プログラミング入門」などの無料教材が役立ちます。

  2. Google Colab でノートブックを作る。

    Google Colabを開き、新しいノートブックを作成します。初めは通常の CPU 環境で構いません。GPU が必要な演習では、利用条件を確認して設定してください。

  3. 必要なライブラリを導入する。

    例えば、以下を Colab のコードセルに入力すると、Transformers と Datasets をインストールし、Transformers のバージョンを確認できます。

!pip install transformers datasets

import transformers
print(transformers.__version__)

LLM コースの第0章「はじめに」には、Google Colab の使い方に加え、macOS や Linux で仮想環境を作る方法も掲載しています。実際の演習では、各ページで指定されたライブラリや設定に従ってください。

このサイトではコードを直接実行できません。本文を読み、掲載されたコードを Colab などで動かしてください。クイズのあるページでは理解度を確認でき、分からない用語はサイト内検索や各コースの用語集で調べられます。

Hugging Face のアカウントは閲覧には不要ですが、モデルの公開や一部のモデルの利用では必要になります。Agents コースにはアカウントの準備や Ollama の導入、Robotics コースにはLeRobot の導入についての説明があります。

学習の順番

以下は、初学者が5つのコースを利用する場合の一例です。特定の分野を学びたい場合は、必要な前提知識を補いながら、そのコースから始めても構いません。

  1. Python と数学の基礎

    Python の基本文法を学び、必要に応じて線形代数や確率・統計を復習します。

  2. LLM コース：モデルの仕組みと使い方

    Transformer、トークナイザ、データセット、学習済みモデルの利用方法を学びます。

  3. LLM コース：追加学習と公開

    ファインチューニングやモデルの共有などに取り組み、コードを変更して結果を確かめます。

  4. 目的に応じて専門コースへ

    AI エージェントなら Agents、ツール連携なら MCP、画像認識なら CV、ロボット学習なら Robotics に進みます。

学習中に分からない部分が出てきた場合は、次の無料教材も参考になります。

  • Python Japan「ゼロからの Python 入門講座」 — Python を初めて学ぶ方向けの日本語教材
  • 東京大学「Python プログラミング入門」 — 基本文法とプログラミングの考え方
  • Kaggle Learn — データ分析と機械学習の演習（英語）
  • PyTorch 公式チュートリアル — 深層学習の実装を詳しく学ぶための教材（英語）

翻訳と品質管理

翻訳は、Muse による翻訳・修正、ChatGPT によるレビュー、制作者による方針の決定と最終確認を組み合わせて行いました。翻訳対象の英語原典はコースごとに特定の Git コミットへ固定し、後から内容が更新されても翻訳の基準が分かるようにしています。

    英語の MDX ファイルを翻訳します。コード、数式、URL、見出しのアンカーなど、変更してはいけない箇所を保持します。

  2. 訳文のレビュー 担当：ChatGPT

    原文との意味の対応、日本語の自然さ、専門用語や表記の統一、改行・記号の扱いを確認します。問題箇所はファイル名、行番号、原文の引用、修正案とともに提示します。

  3. 指摘の照合と修正 担当：Muse

    指摘された文が実際のファイルに存在するかを確認し、英語原典と照合してから修正します。原典に合わない修正案や、根拠のない指摘はそのまま適用しません。

  4. 構造の検証 担当：Muse

    修正前後のコード、数式、リンク、画像、アンカーなどを機械的に比較し、翻訳によって教材の構造が壊れていないかを確認します。

  5. 再レビューと公開 担当：ChatGPT・Muse・霞ヶ関京

    指摘が解消したかを再確認し、必要なら修正を繰り返します。用語や文体の扱いなど、判断を要する事項は制作者が決定します。
