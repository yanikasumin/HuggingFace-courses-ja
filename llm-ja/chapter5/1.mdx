[Chapter 3](/course/chapter3) では、🤗 Datasets ライブラリに初めて触れ、モデルのファインチューニングには主に3つのステップがあることを見ました。

1. Hugging Face Hub からデータセットを読み込む。
2. `Dataset.map()` でデータを前処理する。
3. 指標を読み込んで計算する。

しかし、これは 🤗 Datasets ができることのほんの一部にすぎません。この章では、このライブラリを深く掘り下げていきます。その過程で、次のような疑問への答えを探っていきます。

* データセットが Hub にない場合はどうすればよいか？
* データセットをどうやって切り分けたり加工したりできるか？（どうしても Pandas を使いたい場合は？）
* データセットが巨大で、ノートパソコンの RAM を溶かしてしまいそうな場合はどうするか？
* 「メモリマッピング」や Apache Arrow とは一体何なのか？
* 自分のデータセットを作って Hub にプッシュするにはどうすればよいか？

ここで学ぶテクニックは、[Chapter 6](/course/chapter6) と [Chapter 7](/course/chapter7) で取り組む高度なトークナイズやファインチューニングの土台になります。コーヒーでも用意して、さっそく始めましょう！
