# 3D レンダラーを使った合成データの生成

訓練用の合成データとしてコンピュータで画像を生成する場合は、出来るだけ実物に近い画像を作るのが理想的です。
[Blender Cycles](https://www.blender.org) や [Unity](https://unity.com) のような物理ベースレンダラー（PBR）を使うと、見た目や質感が現実世界のものと殆ど変わらない、非常にリアルな画像を生成出来ます。

つやのあるリンゴの画像を作っていると想像してみてください。そのリンゴに色を付ける時、リアルに見せたいですよね？そこで登場するのが PBR と呼ばれるものです。

![リンゴ](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/apple.jpg)

では、分解して説明しましょう。

_色と光（Colors and Light）_

- 光が物体に当たると、その物体の性質によって様々な反応が起こります。PBR は、こうした光と物体の相互作用を理解し、コンピュータ上で再現しようとするものです。
- 光がリンゴにどう当たるか考えてみてください。光が直接当たる部分は明るくなり、光が遮られたり届きにくかったりする部分は暗くなります。

_素材（Materials）_

- 素材によって光への反応は異なります。例えば、つやのある金属の表面は、柔らかくマットな布よりも光を強く反射します。
- PBR は物体の素材を考慮します。その為、金属の花瓶をレンダリングすると、ふわふわのテディベアとは異なる光の反射が再現されます。

_テクスチャ（Textures）_

- PBR はテクスチャを使って、物体表面の凹凸、傷、小さな溝などの細部を加えます。現実世界では完全に滑らかなものは殆ど無い為、これによって物がよりリアルに見えます。

_リアリズム（Realism）_

- PBR は、物を可能な限り現実に近づけることを目指します。その為に、現実における光の振る舞い、素材ごとに異なる光との相互作用の仕方、表面の小さな不完全さを考慮します。

_光の層（Layers of Light）_

- コップの水を見ていると想像してみてください。PBR は、光が水をどのように通過し、見えるものをどのように歪めるかをシミュレーションしようとします。
- 光が物体の様々な部分と、複数の層を通じてどのように相互作用するかを考慮することで、レンダリングした画像をよりリアルにします。

PBR はワークフローも簡単にします。望む見た目にする為に多くのパラメータを手作業で調整する代わりに、標準化された素材とライティングモデルを使えます。これにより、作業がより直感的で分かり易くなります。

では、コンピュータビジョンで使われるような AI モデルの訓練について考えてみましょう。コンピュータに画像内の物体を認識させるには、実世界の様々な状況を忠実に再現した画像が有ると役立ちます。PBR を使えば、コンピュータビジョンモデルの訓練に効果的に利用出来る程リアルな合成データを生成出来ます。

PBR に利用出来る 3D レンダリングエンジンには、[Blender Cycles](https://www.blender.org) や [Unity](https://unity.com) などがあります。ここでは、オープンソースで参考資料も豊富な Blender を取り上げます。

## Blender

Blender は、アニメーション映画、視覚効果、アート、3D ゲームなどの制作に使われる、強力なオープンソースの 3D コンピュータグラフィックスソフトウェアです。幅広い機能を備えており、アーティスト、アニメーター、開発者にとって多用途なツールとなっています。まずは、象の合成画像をレンダリングする基本的な例を見ていきましょう。

必須の手順は次の通りです。

- 象のモデルを作成します。下に示したものは、フォトグラメトリを用いて [Metascan](https://metascan.ai) アプリで作成されました。
  フォトグラメトリは、通常の写真から 3D モデルを作る方法です。例えば、おもちゃを様々な角度から何枚も撮影し、その写真を使ってコンピュータ上におもちゃの 3D モデルを再現するようなものです。
- 背景を作成します。背景の作成には複数の手順が必要でした。詳しくは[こちら](https://github.com/kfahn22/Synthetic-Data-Creation-in-Blender/tree/main/BACKGROUND)を参照してください。
- ライティングとカメラの位置を調整します。
- 象がフレーム（つまりカメラの視界）に収まるよう、象の位置と回転を修正します。

Blender で生成された象の画像がこちらです。

![象の画像](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/synthetic-data-creation-PBR/rendered_elephant.png)

完全に実写のような画像ではありませんが、象の個体数を監視するモデルの訓練には十分なリアルさが有るでしょう。勿論、その為には象の合成画像を大量に集めたデータセットが必要です！

Blender の Python 環境である
[bpy](https://docs.blender.org/api/current/info_advanced_blender_as_bpy.html) を使えば、象の位置や回転をランダムに変えながら、大量の画像をレンダリング出来ます。セグメンテーション、深度、法線、姿勢推定に役立つスクリプトを使うことも出来ます。

素晴らしい！では、どうやって始めればよいでしょうか？

残念ながら、Blender を使いこなせるようになるには、かなりの学習が必要です。個々の手順はそれ程難しくありませんが、全ての手順を自分で調べなくてもデータセットをレンダリング出来たら便利ですよね？

幸い、BlenderProc というライブラリがあります。Blender を基盤としており、リアルな合成データとアノテーションを生成する為に必要なスクリプトが全て揃っています。

## BlenderProc

BlenderProc のパイプラインは、Denninger らによる [BlenderProc](https://arxiv.org/abs/1911.01911) で紹介されたもので、[Blender](https://www.blender.org/) の上に構築されたモジュール式パイプラインです。セグメンテーション、深度、法線、姿勢推定など、様々なユースケースの画像生成に使えます。

畳み込みニューラルネットワークの訓練に使うリアルな画像を生成出来るよう、専用に開発されています。  
合成データ生成に適した特長は次の通りです。

- 手続き型生成：手続き型の手法を使い、バリエーションの有る複雑な 3D シーンを自動生成出来ます。
- シミュレーション：物理シミュレーションなどを組み込むことで、よりリアルな画像を生成出来ます。
- 大規模生成：大規模なシーン生成を効率的に処理出来る設計で、様々な用途に適しています。
- 自動化と拡張性：
  - スクリプト：Python スクリプトで生成処理を自動化し、用途に合わせて BlenderProc の動作やパラメータを調整出来ます。
  - 並列処理：並列処理によって処理能力を拡張出来る為、大量のシーンを効率よく生成出来ます。

BlenderProc は pip でインストール出来ます。

```bash
pip install blenderProc
```

あるいは、公式の [BlenderProc リポジトリ](https://github.com/DLR-RM/BlenderProc) を Git でクローンすることも出来ます。

```bash
git clone https://github.com/DLR-RM/BlenderProc
```

BlenderProc は Blender の Python 環境（bpy）の中で実行しなければなりません。Blender API にアクセスする唯一の方法だからです。

```bash
blenderproc run <your_python_script>
```

Google Colab で実行するノートブックを使えば、[こちら](https://github.com/DLR-RM/BlenderProc/tree/main/examples/basics)に在る基本的なサンプルを試しながら BlenderProc を体験出来ます。基本例でレンダリングされた画像がこちらです。
