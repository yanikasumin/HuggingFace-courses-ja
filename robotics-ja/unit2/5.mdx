# 古典ロボティクスから学習ベースのロボティクスへ

この章では、これまでに学んだ古典的な手法を振り返り、なぜ学習ベースの手法が必要とされるのかを整理します。また、これから学ぶ内容を簡潔に紹介し、特に注目すべき点を示します。

> [!TIP]
> このページは少し内容が難しく感じられるかもしれませんが、心配はいりません。ここで紹介する内容は、続く数ユニットで一つずつ詳しく説明します。

## ここまでで学んだこと

まず、基礎ユニット全体で扱った重要な概念を簡単に振り返ります。

<!-- TODO: Small timeline diagram with milestones: Classical → Kinematics → Control → Limitations → Learning motivation. -->

**学習ベースのロボティクスを学ぶ理由:** ロボティクスの分野では、古典的なモデルベースの手法から、データを活用した学習ベースの手法へと大きな転換が進んでいます。これまでに、より高性能で汎化能力の高いロボットシステムを開発するうえで、ロボット学習が重要になっている理由を学びました。また、LeRobot のようなツールによって、より多くの研究者や実務者が高度なロボット学習技術を利用できるようになっていることも確認しました。

**LeRobot エコシステム:** LeRobot がロボティクスにどのように取り組んでいるか、その基本的な考え方を学びました。LeRobot は、ロボティクスのさまざまな要素を一体的に扱えるエンドツーエンドのライブラリを目指しています。また、複雑なマルチモーダルデータを扱うための LeRobotDataset 形式についても学びました。実際のロボティクスデータセットを読み込み、機械学習に利用できる形に処理する実践的な経験も積みました。

次は、データから自律的な制御動作を直接生成し、LeRobot を使って実際のロボットにデプロイする方法を学びます。

**古典ロボティクスの基礎:** 従来のロボティクス手法を詳しく学び、マニピュレーション、ロコモーション、モバイルマニピュレーションという運動の種類を確認しました。また、順運動学と逆運動学、微分運動学、フィードバック制御についても学びました。特に重要なのは、古典的な手法が数学的には厳密であっても、実世界の複雑で変化の多い環境に適用する際には限界があると理解したことです。

## 学習の革命

古典ロボティクスの探求を通じて、学習ベースのアプローチがこの分野における大きな前進である理由を明確に理解しました。

**古典的なアプローチには根本的な限界があります**。その限界は、複雑な現実世界の環境を扱うときに特に明らかになります。こうした手法では、ロボットを取り巻く環境やロボットとの相互作用を幅広く数理モデルで表す必要があります。しかし、複雑な状況になるほどモデルの構築は難しくなり、実用的な対応が困難になります。

また、視覚、触覚、プロプリオセプションなど、種類の異なるデータを一つのシステムで扱うことも容易ではありません。さらに重要なのは、タスクやロボットのエンボディメントが異なる場合に、同じ手法を幅広く適用しにくいことです。新しい用途に対応するたびに、大幅な再設計や高度な専門知識が必要になるのが一般的です。

**学習ベースのアプローチには、こうした限界を克服するうえで大きな利点があります**。専門家が問題のあらゆる側面を数理モデルで表す必要はなく、データから直接、適切な動作や特徴表現を学習できます。

このような複雑な入力を扱うために設計されたニューラルネットワークを利用すれば、複数のモダリティにまたがる高次元データを効果的に処理できます。また、異なるタスクやロボットのエンボディメントへの汎化も可能で、利用できるデータや計算資源が増えるほど、性能の向上も期待できます。

## 次の内容

ここまでに身に付けた基礎知識があれば、次のような発展的なテーマを学ぶ準備ができています。

**ロボティクスのための強化学習**では、ロボットが環境の中で試行錯誤を繰り返しながら、望ましい動作を学習する仕組みを扱います。ロボットのタスクに適した報酬信号の設計方法や、経験を積むことで性能を改善する強化学習手法について学びます。また、実世界で収集できるデータが限られていても効率よく学習するための「サンプル効率」という重要な課題も取り上げます。さらに、LeRobot における強化学習アルゴリズムの実装方法も紹介します。

**行動クローニングによる模倣学習**では、ロボットが熟練者の実演を観察して模倣することで、複雑な動作を習得する方法を学びます。この手法では報酬を明示的に設計する必要がなく、実際の人間の作業から学習できるため、強化学習を実環境で利用する際の難しさの一部を回避できます。また、学習時に経験していない状況に遭遇した際に発生する分布シフトへの対処方法や、基本的な行動クローニングを発展させた高度な模倣学習手法についても扱います。さらに、LeRobot のツールを使い、これらの手法を実際に実装する経験を積みます。

**ロボティクスのための基盤モデル**では、より汎用的で高性能なロボットを実現するための最新の研究動向を紹介します。マルチタスク学習によって異なるロボットやタスクの間で知識を共有する仕組み、自然言語による指示に従って動作する言語条件付き方策、そしてモデルやデータセットの規模が拡大したときの性能向上を説明するスケーリング則について学びます。これにより、汎用的なロボットシステムの開発を理解し、その研究開発に参加するための知識を身に付けます。

## 得た実践的スキル

このコースの基礎セクションを通じて、高度なトピックの土台となる技術的能力と概念的理解の両方を身に付けました。

**技術的スキル:** ロボティクスデータが従来の機械学習データセットとどう異なるのか、また専用のデータ形式が必要な理由を理解しました。LeRobotDataset API を使い、視覚、プロプリオセプション、行動情報などを含むマルチモーダルなロボティクスデータを読み込み、処理する実践経験も積みました。さらに、大規模なデータセットを効率的にストリーミングする方法も学びました。これは、現代のロボット学習システムを支える大量のデータを扱ううえで重要な技術です。

**概念的理解:** 特に重要なのは、現在のロボティクスがどのように発展しているかについて、全体像を理解できたことです。古典的な手法の歴史的背景や数学的基礎を学び、複雑な現実世界の問題に適用する際の根本的な限界も理解しました。また、学習ベースの手法がこうした限界にどのように対処するのか、そして大規模なロボティクスデータを利用できるようになったことで、この分野の可能性がどのように広がっているのかについても学びました。

## コースのまとめ
- ロボット学習は、モデルベースの手法からデータ駆動型の手法へのパラダイムシフトを表しています
- LeRobot は、最先端のロボット学習技術を誰もが利用しやすいものにします
- 古典ロボティクスは重要な基礎を提供しますが、根本的なスケーラビリティの限界があります
- 学習ベースの手法は、タスク、ロボット、環境をまたいで汎化できます
- 未来は、古典的な洞察と学習能力の組み合わせにあります
- 大規模データセットと基盤モデルが、ロボティクスで可能なことを変革しています
