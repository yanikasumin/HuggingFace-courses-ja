まとめ

2 つ目のユニットの LangGraph モジュールを修了しました。おめでとうございます！ 🥳

LangGraph を使って構造化されたワークフローを構築する基礎をマスターしました。これで、本番環境へ送り出せるようになります。

このモジュールは、LangGraph の旅の始まりにすぎません。より高度なトピックについては、次をおすすめします。

  • LangGraph の公式ドキュメント を読む
  • LangChain Academy の総合コース Introduction to LangGraph を受講する
  • 自分で何かを作ってみる！

次のユニットでは、実際のユースケースを探求します。理論から離れて、実際のアクションに移る時間です！
