画像セグメンテーション

画像セグメンテーションは、画像を意味のある領域に分割する処理です。画像内の各物体にスポットライトを当てるようなマスクを作ることがその本質です。 このタスクの直感的な捉え方は、画像のピクセルごとに分類を行う問題として見ることができるという点にあります。 セグメンテーションモデルは、さまざまな産業の中核を担うモデルです。農業や自動運転の分野で使われています。農業では、土地の区画を識別したり、作物の生育段階を評価したりするために使われます。自動運転車にとっても重要な役割を果たし、車線や歩道、その他の道路利用者を識別するために使われます。

文脈や目的に応じて、さまざまな種類のセグメンテーションが適用できます。 一般的に定義されるセグメンテーションは次のとおりです。 - セマンティックセグメンテーション（Semantic Segmentation）: 各ピクセルに最も可能性の高いクラスを割り当てます。たとえばセマンティックセグメンテーションでは、2匹の猫を個々に区別するのではなく、ピクセルのクラスに注目します。各ピクセルの分類がすべてです。 - インスタンスセグメンテーション（Instance Segmentation）: 物体の各インスタンスを固有のマスクで識別します。物体検出とセグメンテーションの要素を組み合わせ、同じクラスの個々の物体を区別します。 - パノプティックセグメンテーション（Panoptic Segmentation）: セマンティックセグメンテーションとインスタンスセグメンテーションの要素を組み合わせたハイブリッドな手法です。各ピクセルにクラスとインスタンスの両方を割り当て、画像の what（何が）と where（どこに）の両面を統合します。

どのセグメンテーション手法を選ぶかは、文脈と目的によって決まります。嬉しいことに、最近のモデルでは1つのモデルで3種類すべてのセグメンテーションを実現できます。こちらの記事をぜひご覧ください。パノプティックデータセットだけで3種類のセグメンテーションを達成する Meta の新しいモデル、Mask2former を紹介しています。

現代的なアプローチ: Vision Transformer ベースのセグメンテーション

画像セグメンテーションでよく使われるネットワーク、U-Net の名前を聞いたことがあるかもしれません。複数の畳み込み層で設計され、主に2つのフェーズで動作します。1つはダウンサンプリングフェーズで、画像を圧縮して特徴を理解します。もう1つはアップサンプリングフェーズで、画像を元のサイズに戻し、詳細なセグメンテーションを行います。

コンピュータビジョンはかつて畳み込みモデルが主流でしたが、最近では Vision Transformer のアプローチへ移行しつつあります。 例として、Segment Anything Model（SAM） があります。2023年4月に Meta AI Research（FAIR） が発表した、人気のプロンプトベースのモデルです。このモデルは Vision Transformer（ViT）をベースにしており、プロンプト可能（画像内でセグメントしたいものを言葉で指定できる）なセグメンテーションモデルを作ることに焦点を当てていて、新しい画像へのゼロショット転移が可能です。このモデルの強みは、1,100万枚の画像に10億を超えるマスクを含む、最大規模のデータセットで訓練されていることに由来します。いくつかの画像で Meta のデモを試してみることをおすすめします。さらに良いことに、Transformers のモデルでも試すことができます。

Transformers でこのモデルを使う例を紹介します。まず mask-generation パイプラインを初期化します。 次に、画像をパイプラインに渡して推論します。

from transformers import pipeline

pipe = pipeline("mask-generation", model="facebook/sam-vit-base", device=0)

raw_image = Image.open("path/to/image").convert("RGB")

masks = pipe(raw_image)

モデルの使い方の詳細はドキュメントをご覧ください。

セグメンテーションモデルはどう評価する？

セグメンテーションモデルの使い方は分かりました。では、どうやって評価すればよいのでしょうか。前のセクションで見たとおり、セグメンテーションは基本的に教師あり学習のタスクです。つまり、データセットは画像と、それに対応するマスク（正解データ）で構成されます。モデルの評価にはいくつかの指標が使えます。代表的なものは次のとおりです。

  • Intersection over Union（IoU）／Jaccard 指数は、予測マスクと正解データの共通部分と和集合の比です。 IoU は、セグメンテーションタスクでおそらく最もよく使われる指標です。クラス不均衡の影響を受けにくい点が利点で、モデリングを始めたばかりの段階でも良い選択肢になることが多いです。

  • ピクセル精度（Pixel accuracy）: 正しく分類されたピクセル数と総ピクセル数の比として計算されます。 直感的な指標ですが、クラス不均衡に敏感なため、誤解を招くことがあります。

  • Dice 係数: 共通部分の2倍と、予測マスクと正解データの合計の比です。 Dice 係数は、予測と正解データの重なりの割合そのものです。重なりの小さな差異に敏感である必要がある場合に適した指標です。
