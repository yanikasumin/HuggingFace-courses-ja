章末クイズ

この章では沢山の内容を扱いました！細部まで全部を把握出来ていなくても心配いりません。これからの章で、内部の仕組みがどのように動いているかを理解出来るようになります。

とはいえ、先に進む前に、この章で学んだことをテストしてみましょう。

1. 🤗 Datasets の load_dataset() 関数では、次のどの場所にあるデータセットを読み込めますか？（当てはまるものをすべて選んでください）

正解です！load_dataset() の data_files 引数にローカルファイルのパスを渡せば、ローカルデータセットを読み込めます。
正解です！データセット ID を指定すれば、Hub 上のデータセットを読み込めます。たとえば load_dataset('emotion') です。
正解です！load_dataset() の data_files 引数に URL を渡せば、リモートファイルを読み込めます。

2. 次のように GLUE タスクの1つを読み込んだとします。

from datasets import load_dataset

dataset = load_dataset("glue", "mrpc", split="train")

次のうち、dataset からランダムに50件のサンプルを取り出すコマンドはどれですか？

これは不正解です。Dataset.sample() というメソッドは存在しません。
正解です！この章で見たとおり、まずデータセットをシャッフルし、その後で50件のサンプルを選びます。
これは不正解です。コードは実行できますが、シャッフルされるのはデータセットの最初の50件だけです。

3. 家庭のペットに関する pets_dataset というデータセットがあり、各ペットの名前を示す name 列があるとします。次のうち、名前が「L」で始まるペットだけを抽出できる方法をすべて選んでください。

正解です！このような手早いフィルタには Python のラムダ関数を使うのがおすすめです。ほかにどんな解法が考えられますか？
これは不正解です。ラムダ関数は lambda *arguments* : *expression* という一般形を取るため、この場合は引数を指定する必要があります。
正解です！Dataset.map() と同じように、Dataset.filter() にも名前を付けて定義した関数を渡せます。短いラムダ関数では書きにくい複雑な処理がある場合に便利です。他の選択肢では、どれがうまくいきますか？

4. メモリマッピングとは何ですか？

違います。もう一度考えてみましょう！
正解です！🤗 Datasets は各データセットをメモリマップドファイルとして扱います。これにより、データセット全体をメモリに読み込まなくても、その要素にアクセスして操作できます。
これは正しくありません。もう一度考えてみましょう！

5. 次のうち、メモリマッピングの主な利点に当てはまるものをすべて選んでください。

正解です！おかげで 🤗 Datasets は非常に高速に動作します。但し、利点はそれだけではありません。
正解です！おかげで、ノートパソコン上でも CPU を爆発させることなく、数ギガバイト規模のデータセットを読み込めます。メモリマッピングには他にどんな利点がありますか？
これは正しくありません。もう一度考えてみましょう！

6. 次のコードが失敗するのはなぜですか？

from datasets import load_dataset

dataset = load_dataset("allocine", streaming=True, split="train")
dataset[0]
これは正しくありません。ストリーミングデータセットは必要に応じて解凍されます。また、ごくわずかな RAM でもテラバイト級のデータセットを処理できます！
正解です！IterableDataset はコンテナではなくジェネレータなので、その要素には next(iter(dataset)) を使ってアクセスする必要があります。
これは不正解です。Hub の [allocine データセットカード](https://huggingface.co/datasets/allocine) で、どの分割が含まれているか確認してみてください。

7. 次のうち、データセットカードを作成する主な利点に当てはまるものをすべて選んでください。

正解です！ドキュメントのないデータセットは、作成者の意図を反映しないモデルの訓練に使われるおそれがあります。また、プライバシーやライセンスの制限に反するデータでモデルを訓練すると、法的な扱いが不明確なモデルが生まれる可能性もあります。但し、利点はそれだけではありません！
正解です！ほぼすべてのデータセットには何らかのバイアスがあり、そのデータセットを使う後続のタスクに悪影響を及ぼす可能性があります。バイアスの存在を認識しておくことで、モデル開発者は内在するバイアスへの対処法を理解できます。データセットカードは他に何の役に立ちますか？
正解です！よく書かれたデータセットカードがあると、自分の大切なデータセットをより多くの人に使ってもらいやすくなります。他にどんな利点がありますか？

8. 次のうち、セマンティック検索について正しく説明しているものをすべて選んでください。

これは不正解です。この種の検索は *語彙検索（lexical search）* と呼ばれ、従来の検索エンジンで一般的に見られるものです。
正解です！セマンティック検索は埋め込みベクトルでクエリとドキュメントを表現し、類似度指標で両者の重なりの度合いを測ります。他にどう説明できますか？
正解です！セマンティック検索エンジンはキーワードマッチングよりもクエリの意図をよく捉えることができ、通常、関連性の高いドキュメントをより高い精度で取得できます。但し、正しい答えはそれだけではありません。セマンティック検索には他にどんな利点がありますか？

9. 非対称セマンティック検索では、通常どのようなクエリと段落の組み合わせを扱いますか？

正解です！
これは実際には対称セマンティック検索の例です。もう一度考えてみましょう！
これは不正解です。もう一度考えてみましょう！

10. 音声処理など、ほかの分野で利用するデータも 🤗 Datasets で読み込めますか？

これは不正解です。🤗 Datasets は現在、表形式データ、音声、コンピュータビジョンに対応しています。コンピュータビジョンの例として、Hub の MNIST データセット を見てみてください。
正解です！🤗 Transformers ライブラリでは、音声処理や画像処理の分野でも興味深い開発が進んでいます。これらの取り組みを調べ、🤗 Datasets がそれらの分野でどう使われているか確認してみてください。
