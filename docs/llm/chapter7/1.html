はじめに

Chapter 3 では、テキスト分類の為にモデルをファインチューニングする方法を見てきました。この章では、従来の NLP モデルと最新の LLM の両方を扱う上で欠かせない、次の一般的な言語タスクに取り組みます。

  • トークン分類
  • マスク言語モデリング（BERT など）
  • 要約
  • 翻訳
  • 因果言語モデリングによる事前学習（GPT-2 など）
  • 質問応答

これらの基本的なタスクは、大規模言語モデル（LLM）の仕組みの土台をなすものです。これらを理解することは、今日の最先端の言語モデルを効果的に扱う上で欠かせません。

{#if fw === 'pt'}

その為には、Chapter 3 で学んだ Trainer API と 🤗 Accelerate ライブラリ、Chapter 5 で学んだ Datasets ライブラリ、Chapter 6 で学んだ Tokenizers ライブラリの知識を総動員する必要があります。更に、Chapter 4 で行ったように、結果を Model Hub にアップロードします。まさに、全てが結実する章です！

各セクションは独立して読むことができ、Trainer API を使う方法と、Accelerate を使った独自の学習ループでモデルを学習する方法の両方を紹介します。どちらか片方を読み飛ばして、興味のある方に集中してもかまいません。

Trainer API は、裏側の仕組みを気にすることなくモデルをファインチューニングしたり学習したりするのに最適です。一方、Accelerate を使った学習ループなら、必要な部分をより簡単にカスタマイズ出来ます。
