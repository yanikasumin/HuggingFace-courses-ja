[Chapter 2](/course/chapter2) では、トークナイザと事前学習済みモデルを使って予測を行う方法を見てきました。では、特定のタスクを解くために事前学習済みモデルをファインチューニングしたい場合はどうすればよいでしょうか。それがこの章のテーマです。この章で学ぶのは次の内容です。

* 最新の 🤗 Datasets の機能を使って、Hub から大規模なデータセットを用意する方法
* 高レベルの `Trainer` API を使い、現代的なベストプラクティスでモデルをファインチューニングする方法
* 最適化のテクニックを取り入れた、カスタム学習ループの実装方法
* 🤗 Accelerate ライブラリを使って、あらゆる環境で分散学習を簡単に実行する方法
* 性能を最大限に引き出すための、現在のファインチューニングのベストプラクティスの適用方法

> [!TIP]
> 📚 **おすすめ資料**: 始める前に、データ処理について [🤗 Datasets ドキュメント](https://huggingface.co/docs/datasets/) を確認しておくとよいでしょう。

この章は、🤗 Transformers ライブラリ以外の Hugging Face ライブラリへの入門にもなります。🤗 Datasets、🤗 Tokenizers、🤗 Accelerate、🤗 Evaluate といったライブラリが、モデルの学習をより効率的かつ効果的に進める助けになる様子を見ていきます。

この章のメインセクションでは、それぞれ異なることを学びます。
- **セクション2**: 最新のデータ前処理テクニックと効率的なデータセットの扱い方
- **セクション3**: 強力な Trainer API とその最新機能の使いこなし方
- **セクション4**: 学習ループのゼロからの実装と、Accelerate による分散学習の理解

この章を終えるころには、高レベル API とカスタム学習ループの両方を使って、自分のデータセットでモデルをファインチューニングできるようになります。この分野の最新のベストプラクティスも適用できます。

> [!TIP]
> 🎯 **この章で作るもの**: この章を終えるころには、テキスト分類用に BERT モデルをファインチューニングし、そのテクニックを自分のデータセットやタスクに応用する方法を理解しているはずです。

この章では **PyTorch** のみに焦点を当てます。PyTorch は、現代の深層学習の研究と実務における標準フレームワークになっているためです。Hugging Face エコシステムの最新の API とベストプラクティスを使用します。

学習したモデルを Hugging Face Hub にアップロードするには、Hugging Face のアカウントが必要です。[アカウントを作成](https://huggingface.co/join)
