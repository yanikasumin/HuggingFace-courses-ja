はじめに

前章で扱った動画のほかに、よく使われる視覚データの形式として3次元のものがあります。 2D画像では通常、x と y という2つの次元を使いますが、3D画像では x、y、z の3つの次元を使います。

「待って、動画も3次元じゃないの？」と思ったかもしれません。そのとおりで、動画には空間方向の2次元 x と y に加えて、時間方向の次元 t があります。3Dデータとの違いは、3つの次元がすべて空間的な性質を持つことです。これにより、私たちの世界や知覚の仕組みをよりよくモデル化できます。そのため、現在3Dの応用が盛んな分野の1つが複合現実（Mixed Reality）です。デジタルな世界と現実の世界を融合させようとする試みです。

ユニットの概要

この導入の次の章では、3Dコンピュータビジョンの応用について学びます。その直後には、19世紀から現代までの3D応用の歴史的な発展をたどります。

こうした一般的な話題のあとは、用語と概念に踏み込み、カメラモデル、線形代数、さまざまな表現方法についての3つの章を扱います。

理論のあとは、3Dコンピュータビジョンの実際の応用分野を見ていきます。まず新規視点合成（Novel View Synthesis）から始め、ステレオビジョンを経て、最後は現在最も人気のある応用の1つである Neural Radiance Fields（NeRF）で締めくくります（今のところは）。
