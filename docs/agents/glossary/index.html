Agents コース

用語集

この用語集は日本語版独自の補足です。原典には含まれていません。本文を読む際の助けとして、平易な言葉で説明しています。

エージェント（AIエージェント）
LLM を頭脳として、ツールを使い、観測を受けて、複数ステップでタスクを進めるシステムです。
ツール
エージェントが外部の世界に働きかけるための関数。検索、計算、API呼び出しなどです。
Thought-Action-Observation サイクル
考えて（Thought）、行動し（Action）、結果を観察する（Observation）という、エージェントの基本ループです。
ReAct
推論（Reasoning）と行動（Action）を交互に行うエージェントの設計手法です。
smolagents
Hugging Face の軽量なエージェントライブラリ。行動をコードで書く CodeAgent が特徴です。
CodeAgent / ToolCallingAgent
行動をPythonコードで生成するエージェントと、ツール呼び出し形式で行動するエージェントです。
関数呼び出し（Function Calling）
モデルが、定義された関数の名前と引数を構造化して出力する仕組みです。
RAG（検索拡張生成）
外部の文書を検索し、その内容を根拠に回答を生成する手法です。
LlamaIndex
データへの接続と検索、エージェント構築のためのフレームワークです。
LangGraph
エージェントの処理をグラフ（ノードとエッジ）として組み立てるフレームワークです。
マルチエージェント
複数のエージェントが役割分担して協力する構成です。
可観測性（オブザーバビリティ）
エージェントの内部の動き（推論、ツール呼び出し、コスト）を記録し、後から追えるようにすることです。
GAIA
AIエージェントの実力を測るベンチマーク。実世界に近いタスクで構成されます。
チャットテンプレート
会話履歴を、モデルが想定する形式の文字列に変換するための型です。
特殊トークン
会話の区切りや役割を示すために予約されたトークンです。
関数呼び出し向けファインチューニング
モデルにツールの使い方を学習させ、関数呼び出しの精度を上げることです。
