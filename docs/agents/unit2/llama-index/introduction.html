LlamaIndex 入門

このモジュールへようこそ。ここでは、LlamaIndex ツールキットを使って、LLM を活用したエージェントを構築する方法を学びます。

LlamaIndex は、インデックスとワークフローを使って、自分のデータを活用する LLM エージェントを作成する為の包括的なツールキットです。このコースでは、LlamaIndex でエージェントを構築する上で中心となる 3 つの要素、Components、Agents and Tools、Workflows に焦点を当てます。

LlamaIndex の主要な要素と、それぞれがエージェントにどう役立つかを見ていきましょう。

  • Components：LlamaIndex で使う基本的な構成要素です。プロンプトやモデル、データベースなどが含まれます。Components は、LlamaIndex と他のツールやライブラリをつなぐ役割を果たすことも多くあります。
  • Tools：特定の機能を提供するコンポーネントです。検索や計算、外部サービスへのアクセスなどがその例です。エージェントがタスクを実行出来るようにする構成要素です。
  • Agents：ツールを使い、判断を下すことが出来る自律的なコンポーネントです。複雑な目標を達成する為に、ツールの使い方を調整します。
  • Workflows：処理を複数のステップに分け、ロジックを組み合わせて実行する仕組みです。Workflows（エージェンティックワークフロー）を使えば、エージェントを明示的に使わずに、エージェントのような振る舞いを段階的に組み立てられます。

LlamaIndex の特徴

LlamaIndex は、smolagents のような他のフレームワークと似たことも出来ますが、次のような特長が有ります。

  • 分かり易いワークフローシステム：Workflows では、イベント駆動型で非同期処理を前提とした構文を使い、エージェントの判断の流れをステップごとに分解出来ます。これにより、ロジックを明確に組み立て、整理出来ます。
  • LlamaParse による高度なドキュメント解析：LlamaParse は LlamaIndex 専用に開発されている為、LlamaIndex にスムーズに統合出来ます。但し、有料機能です。
  • 直ぐに使える豊富な Components：LlamaIndex は開発が長く続けられており、多くのフレームワークと連携出来ます。その為、LLM や検索器（retriever）、インデックスなど、動作検証が行われた信頼性の高いコンポーネントが数多くそろっています。
  • LlamaHub：LlamaIndex の中で使える、数百ものコンポーネントやエージェント、ツールを集めたレジストリです。

有用なエージェントを作るには、場面に応じてこれらの概念が全て必要になります。以降のセクションでは、これらの概念を一つずつ詳しく見ていきます。概念を身につけたあとは、学んだことを活かして、エージェントの Alfred を使った実践的な利用例を作ります！

LlamaIndex に実際に触れてみるのが楽しみになってきたのではないでしょうか。それでは早速、LlamaHub を使って、必要な統合を見つけてインストールすることから始めましょう！
