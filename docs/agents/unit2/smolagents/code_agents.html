コードを使うエージェントを作る

Code Agent は smolagents のデフォルトのエージェントタイプです。アクションを実行するために Python のツール呼び出しを生成し、効率的で表現力豊か、かつ正確なアクション表現を実現します。

その合理化されたアプローチにより、必要なアクションの数が減り、複雑な操作が簡単になり、既存のコード関数を再利用できます。smolagents は、約1,000行のコードで実装された、コードエージェントを構築するための軽量なフレームワークを提供します。

なぜ Code Agent なのか？

マルチステップエージェントのプロセスでは、LLM がアクションを書いて実行します。通常は外部のツール呼び出しを伴います。従来のアプローチは、ツール名と引数を文字列として指定する JSON 形式を使いますが、どのツールを実行するかを決めるために、システムがそれをパースしなければなりません。

しかし研究によれば、ツール呼び出しを行う LLM は、コードを直接扱うほうが効果的に働きます。これは smolagents の核となる原則であり、上記の論文 Executable Code Actions Elicit Better LLM Agents の図が示すとおりです。

アクションを JSON ではなくコードで書くことには、いくつかの重要な利点があります。

  • 合成可能性（Composability）: アクションを簡単に組み合わせ、再利用できる
  • オブジェクト管理: 画像のような複雑な構造を直接扱える
  • 汎用性: 計算可能なあらゆるタスクを表現できる
  • LLM にとって自然: 高品質なコードは、すでに LLM の訓練データに含まれている

Code Agent の仕組み

上の図は、CodeAgent.run() が Unit 1 で触れた ReAct フレームワークに従ってどう動作するかを示しています。smolagents におけるエージェントの主な抽象化は MultiStepAgent で、それが中核となる構成要素です。CodeAgent は MultiStepAgent の特殊な種類であり、以下の例で見ていきます。

CodeAgent はステップのサイクルを通じてアクションを実行します。既存の変数や知識はエージェントのコンテキストに取り込まれ、実行ログとして保持されます。

  1. システムプロンプトは SystemPromptStep に格納され、ユーザーのクエリは TaskStep に記録されます。

  2. 次に、以下の while ループが実行されます。

    2.1 メソッド agent.write_memory_to_messages() が、エージェントのログを LLM が読めるチャットメッセージのリストに書き出します。

    2.2 これらのメッセージが Model に送られ、補完が生成されます。

    2.3 補完がパースされ、アクションが抽出されます。CodeAgent を使っているので、この場合はコードスニペットのはずです。

    2.4 アクションが実行されます。

    2.5 結果が ActionStep としてメモリに記録されます。

各ステップの終わりに、エージェントに関数呼び出し（agent.step_callback 内）が含まれていれば、それらが実行されます。

smolagents を使ってパーティーのプレイリストを選ぶ

音楽はパーティーを成功させるうえで欠かせない要素です。アルフレッドはプレイリスト選びの手伝いが必要です。幸い、smolagents が助けてくれます。DuckDuckGo を使って Web を検索できるエージェントを構築できます。このツールへのアクセスをエージェントに与えるには、エージェント作成時にツールリストに含めます。

モデルには、Hugging Face の Serverless Inference API へのアクセスを提供する InferenceClientModel を使います。デフォルトのモデルは "Qwen/Qwen2.5-Coder-32B-Instruct" で、性能が高く高速な推論が可能ですが、Hub の互換性のあるモデルならどれでも選べます。

エージェントの実行はとても簡単です。

from smolagents import CodeAgent, DuckDuckGoSearchTool, InferenceClientModel

agent = CodeAgent(tools=[DuckDuckGoSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")

この例を実行すると、出力には実行されるワークフローのステップのトレースが表示されます。対応する Python コードも、次のメッセージとともに表示されます。

 ─ Executing parsed code: ──────────────────────────────────────────────────────────────────────────────────────── 
  results = web_search(query="best music for a Batman party")                                                      
  print(results)                                                                                                   
 ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────

数ステップののち、アルフレッドがパーティーで使えるプレイリストが生成されます！ 🎵

カスタムツールを使ってメニューを用意する

プレイリストが選べたので、次はゲスト向けのメニューを整える必要があります。ここでもアルフレッドは smolagents を活用できます。ここでは @tool デコレータを使って、ツールとして機能するカスタム関数を定義します。ツールの作り方は後ほど詳しく扱うので、ここではコードを実行するだけで構いません。

以下の例で分かるように、@tool デコレータでツールを作成し、tools リストに含めます。

from smolagents import CodeAgent, tool, InferenceClientModel

# 場面に応じたメニューを提案するツール
@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion (str): The type of occasion for the party. Allowed values are:
                        - "casual": Menu for casual party.
                        - "formal": Menu for formal party.
                        - "superhero": Menu for superhero party.
                        - "custom": Custom menu.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

# 執事のアルフレッドがパーティーのメニューを用意する
agent = CodeAgent(tools=[suggest_menu], model=InferenceClientModel())

# パーティーのメニューを用意する
agent.run("Prepare a formal menu for the party.")

エージェントは答えを見つけるまで数ステップ実行されます。docstring に許容値を明記しておくと、エージェントが実在する occasion 引数の値を使うよう誘導でき、ハルシネーションを抑えられます。

メニューの準備ができました！ 🥗

エージェントの中で Python のインポートを使う

プレイリストとメニューは準備できましたが、もうひとつ重要な詳細を確認する必要があります。それは準備にかかる時間です。

アルフレッドは、今から準備を始めた場合にすべてが何時に整うのかを計算する必要があります。他のスーパーヒーローの助けが必要になる場合に備えてです。

smolagents は、Python コードスニペットを書いて実行するエージェントに特化しており、セキュリティのためにサンドボックス実行を提供します。

コード実行には厳格なセキュリティ対策があります。事前に定義された安全なリストにないインポートは、デフォルトでブロックされます。ただし、additional_authorized_imports に文字列として渡すことで、追加のインポートを許可できます。 安全なコード実行の詳細については、公式のガイドをご覧ください。

エージェントを作成するとき、additional_authorized_imports を使って datetime モジュールのインポートを許可します。

from smolagents import CodeAgent, InferenceClientModel
import numpy as np
import time
import datetime

agent = CodeAgent(tools=[], model=InferenceClientModel(), additional_authorized_imports=['datetime'])

agent.run(
    """
    Alfred needs to prepare for the party. Here are the tasks:
    1. Prepare the drinks - 30 minutes
    2. Decorate the mansion - 60 minutes
    3. Set up the menu - 45 minutes
    4. Prepare the music and playlist - 45 minutes

    If we start right now, at what time will the party be ready?
    """
)

これらの例は、コードエージェントでできることのほんの始まりにすぎませんが、パーティーの準備における有用性はすでに見え始めています。 コードエージェントの作り方についてさらに学ぶには、smolagents のドキュメントをご覧ください。

まとめると、smolagents は Python コードスニペットを書いて実行するエージェントに特化し、セキュリティのためのサンドボックス実行を提供します。ローカルモデルと API ベースの言語モデルの両方をサポートしており、さまざまな開発環境に適応できます。

カスタムのパーティー準備エージェントを Hub に共有する

私たち自身のアルフレッドエージェントをコミュニティと共有できたら素晴らしいと思いませんか。共有すれば、誰でも Hub からエージェントを簡単にダウンロードして使え、ゴッサム究極のパーティープランナーを手元で活用できます。やってみましょう！ 🎉

smolagents ライブラリでは、完全なエージェントをコミュニティと共有したり、他の人のエージェントをダウンロードしてすぐに使ったりできます。次のように簡単です。

# 自分のユーザー名とリポジトリ名に変更してください
agent.push_to_hub('sergiopaniego/AlfredAgent')

エージェントを再びダウンロードするには、次のコードを使います。

# 自分のユーザー名とリポジトリ名に変更してください
alfred_agent = agent.from_hub('sergiopaniego/AlfredAgent', trust_remote_code=True)

alfred_agent.run("Give me the best playlist for a party at Wayne's mansion. The party idea is a 'villain masquerade' theme")

さらに素晴らしいことに、共有されたエージェントは Hugging Face Spaces として直接利用でき、リアルタイムにやり取りできます。他のエージェントはこちらで探索できます。

たとえば、AlfredAgent はこちらで利用できます。以下で直接試すことができます。

アルフレッドが smolagents を使ってどうやってこのようなエージェントを作ったのか、気になるかもしれません。いくつかのツールを統合することで、次のようにエージェントを生成できます。ツールについては心配いりません。この Unit の後半に、詳しく探る専用のセクションがあります。

from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, Tool, tool, VisitWebpageTool

@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion: The type of occasion for the party.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.

    Args:
        query: A search term for finding catering services.
    """
    # ケータリングサービスとその評価の例
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }

    # 最も評価の高いケータリングサービスを探す（検索クエリによるフィルタリングをシミュレーション）
    best_service = max(services, key=services.get)

    return best_service

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""

    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }

    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }

        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")


# 執事のアルフレッドがパーティーのメニューを用意する
agent = CodeAgent(
    tools=[
        DuckDuckGoSearchTool(), 
        VisitWebpageTool(),
        suggest_menu,
        catering_service_tool,
        SuperheroPartyThemeTool(),
    FinalAnswerTool()
    ], 
    model=InferenceClientModel(),
    max_steps=10,
    verbosity_level=2
)

agent.run("Give me the best playlist for a party at the Wayne's mansion. The party idea is a 'villain masquerade' theme")

このように、いくつかのツールでエージェントの機能を強化した CodeAgent を作成し、コミュニティと共有できる究極のパーティープランナーに仕上げました！ 🎉

OpenTelemetry と Langfuse でパーティー準備エージェントを検査する 📡

アルフレッドは Party Preparator Agent を微調整するなかで、その実行のデバッグに疲れてきています。エージェントは本質的に予測が難しく、検査も困難です。しかし、究極の Party Preparator Agent を構築して本番環境にデプロイすることを目指す以上、将来の監視と分析のために堅牢なトレーサビリティが必要です。

ここでも smolagents が助けてくれます。エージェントの実行を計測するための OpenTelemetry 標準を取り入れており、シームレスな検査とロギングが可能です。Langfuse と SmolagentsInstrumentor の助けを借りて、アルフレッドはエージェントの振る舞いを簡単に追跡・分析できます。

セットアップは簡単です！

まず、必要な依存関係をインストールします。

pip install opentelemetry-sdk opentelemetry-exporter-otlp openinference-instrumentation-smolagents langfuse

次に、アルフレッドはすでに Langfuse のアカウントを作成し、API キーの準備ができています。まだの場合は、Langfuse Cloud にこちらからサインアップするか、代替手段を探ってください。

API キーを取得したら、次のように適切に設定する必要があります。

import os

# プロジェクトのキーはプロジェクト設定ページから取得します: https://cloud.langfuse.com
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..." 
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..." 
os.environ["LANGFUSE_HOST"] = "https://cloud.langfuse.com" # 🇪🇺 EU リージョン
# os.environ["LANGFUSE_HOST"] = "https://us.cloud.langfuse.com" # 🇺🇸 US リージョン

環境変数を設定したら、Langfuse クライアントを初期化できます。get_client() は、環境変数に与えられた認証情報を使って Langfuse クライアントを初期化します。

from langfuse import get_client

langfuse = get_client()

# 接続を確認
if langfuse.auth_check():
    print("Langfuse client is authenticated and ready!")
else:
    print("Authentication failed. Please check your credentials and host.")

最後に、アルフレッドは SmolagentsInstrumentor を初期化し、エージェントのパフォーマンスの追跡を開始する準備が整いました。

from openinference.instrumentation.smolagents import SmolagentsInstrumentor

SmolagentsInstrumentor().instrument()

アルフレッドが接続できました 🔌！ smolagents の実行が Langfuse に記録され、エージェントの振る舞いを完全に把握できます。このセットアップにより、過去の実行を振り返って Party Preparator Agent をさらに改良する準備が整いました。
