Vision Transformer における知識蒸留

ここでは知識蒸留（Knowledge Distillation）について学びます。distilGPT や distilbert の背後にある手法です。この2つは、Hugging Face Hub で最もダウンロードされているモデルの一部です！

正解だけを教えて、あとは見たことの無い問題でテストする、そんな先生を思い浮かべてみてください。これは、ラベル付きデータセットを与えて訓練する、機械学習モデルの教師あり学習に似ています。

但し、モデルをラベルで訓練する代わりに、知識蒸留という別の道を選ぶことも出来ます。大きなモデルに匹敵する性能を持ちながら、はるかに小さく、しかも高速なモデルを得る為の方法です。

知識蒸留の直感的な理解

次のような選択式の問題を出されたとします。

「答えは Draco Malfoy です」とだけ言われても、各キャラクターと Harry Potter との関係については、あまり学べません。

一方で、「Ron Weasley ではないと強く確信しています。Neville Longbottom でもないと思いますが、こちらの確信度はそれほど高くありません。そして、Draco Malfoy である可能性は非常に高いと思います」と言われたらどうでしょうか。これなら、各キャラクターと Harry Potter との関係について、より多くの情報が得られます。知識蒸留では、まさにこのような情報を生徒モデルに伝えます。

ニューラルネットワークの知識を蒸留する

論文 ニューラルネットワークの知識を蒸留する（Distilling the Knowledge in a Neural Network） で、Hinton らは知識蒸留と呼ばれる訓練手法を提案しました。着想を得たのは、意外にも_昆虫_からです。昆虫が、異なるタスクに最適化された幼虫の姿から成虫の姿へ移行するように、大規模な機械学習モデルも、最初は幼虫のように扱い難い形でデータから構造を取り出す段階を経て、その知識を、デプロイ向けのより小さく効率的なモデルへ蒸留出来ます。

知識蒸留の本質は、教師ネットワークが予測した logits を使って、より小さく効率的な生徒モデルへ情報を伝えることです。その為に損失関数を書き換え、_蒸留損失（distillation loss）_を含めます。この損失により、生徒モデルの出力空間上の分布が、教師の分布に近づくよう促されます。

蒸留損失は次のように定式化されます。

KL 損失は、教師モデルと生徒モデルの出力分布の間のカルバック・ライブラー・ダイバージェンス（KL ダイバージェンス）を指します。生徒モデルの全体の損失は、この蒸留損失と、正解ラベルに対する通常の交差エントロピー損失の和として定式化されます。

エッジデバイス向けに知識蒸留を活用する

AI モデルをエッジデバイスで動かす機会が増えるにつれ、知識蒸留の重要性も高まっています。例えば、サイズが1 GBで応答に1秒掛かる大規模モデルは、計算能力やメモリへの要求が高い為、リアルタイム用途には適していません。こうした制約は主にモデルのサイズから生じます。その為、性能の低下を最小限に抑えながらモデルのパラメータ数を90%以上削減出来る知識蒸留が、この分野で広く使われるようになりました。

知識蒸留がもたらすもの（良い面と悪い面）

1. エントロピーの増加

情報理論におけるエントロピーは、物理学における対応概念と同様に、系の中の「混沌」や無秩序の度合いを測るものです。ここでの文脈では、分布が含む情報量を定量化します。次の例を考えてみてください。

  • [0, 1, 0, 0] と [0.2, 0.5, 0.2, 0.1] では、覚え難いのはどちらでしょうか？

最初のベクトル [0, 1, 0, 0] は、含む情報が少ない為、覚え易く、圧縮もし易いベクトルです。2番目の位置に「1」が在る、と表せます。一方、[0.2, 0.5, 0.2, 0.1] はより多くの情報を含んでいます。

これを踏まえて、例えばパラメータ数 80M のネットワークを ImageNet で訓練し、先ほど説明したようにパラメータ数 5M の生徒モデルへ蒸留したとします。この場合、教師モデルの出力に含まれるエントロピーは、生徒モデルの出力よりもはるかに低いことが分かります。つまり、生徒モデルの出力は、正しくても、教師の出力より混沌としているということです。これは単純な事実に帰着します。教師はパラメータが多い分、より多くの特徴を取り出せる為、クラス同士を見分け易いのです。

知識蒸留に対するこの見方は非常に興味深く、生徒のエントロピーを下げる研究が活発に行われています。エントロピーを損失関数として使う方法や、物理学に着想を得た類似の指標（エネルギーなど）を適用する方法が検討されています。

2. 一貫した勾配更新

モデルは、損失関数を最小化し、勾配降下法でパラメータを更新しながら、反復的に学習します。教師モデルにおいて、クラス A のサンプルを検出した時に活性化する役割を持つパラメータの集合 P = {w1, w2, w3, ..., wn} を考えてみてください。クラス A に似ているものの実際はクラス B に属する曖昧なサンプルが有ると、誤分類のあとでモデルの勾配更新は激しくなり、不安定さにつながります。これに対して蒸留のプロセスでは、教師モデルのソフトなターゲットにより、訓練中の勾配更新はより安定し、一貫したものになります。その結果、生徒モデルの学習プロセスはより滑らかになります。

3. ラベルなしデータで訓練出来る

教師モデルが有ることで、生徒モデルはラベルなしデータでも訓練出来ます。教師モデルがラベルなしサンプルに対して疑似ラベルを生成し、生徒モデルはそれを訓練に使えます。この方法により、使える訓練データの量を大きく増やせます。

4. 視点の転換

深層学習モデルは通常、十分なデータを与えれば、背後に在る現象を正確に表す関数 F を近似出来る、という前提で訓練されます。しかし現実には、データ不足の為にこの前提が成り立たない場合が多くあります。従来のアプローチでは、より大きなモデルを作り、最適な結果が得られるまで反復的にファインチューニングします。

これに対して知識蒸留は視点を転換します。既に十分に訓練された教師モデル F が有るなら、目標はより小さなモデル f で F を近似することになる、という考え方です。
