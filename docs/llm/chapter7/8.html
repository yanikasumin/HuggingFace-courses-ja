LLM を使いこなす

ここまでコースを進めてこられた皆さん、おめでとうございます。これで、🤗 Transformers と Hugging Face のエコシステムを使って、（ほぼ）あらゆる言語タスクに取り組む為の知識とツールが全て揃いました！

NLP から LLM へ

このコースでは従来の NLP タスクを数多く扱ってきましたが、この分野は大規模言語モデル（LLM）によって大きく変革されました。LLM は、言語処理で可能なことの範囲を劇的に広げました。

  • タスク固有のファインチューニングなしに、複数のタスクを処理出来る
  • 指示に従い、様々な文脈に適応するのが得意
  • 様々な用途に向けて、一貫性のある、文脈に適したテキストを生成出来る
  • chain-of-thought プロンプティングといった手法を通じて、推論を行い、複雑な問題を解ける

学んできた基礎的な NLP のスキルは、LLM を効果的に使う上で今でも欠かせません。トークン化、モデルアーキテクチャ、ファインチューニングのアプローチ、評価指標についての理解は、LLM の能力を最大限に引き出す為に必要な知識を与えてくれます。

これまで数多くのデータコレータを見てきました。そこで、タスクごとにどれを使えばよいか分かるよう、この小さな動画を用意しました。

主要な言語タスクを駆け足で巡るこのツアーを終えたら、次のことが出来るようになっているはずです。

  • 各タスクに最適なアーキテクチャ（エンコーダ、デコーダ、エンコーダ・デコーダ）を知っている
  • 言語モデルの事前学習とファインチューニングの違いを理解している
  • PyTorch と TensorFlow のどちらの学習経路を選んだかに応じて、Trainer API と Accelerate の分散学習機能を使う方法、又は TensorFlow と Keras を使って Transformer モデルを学習する方法を知っている
  • テキスト生成タスクにおける ROUGE や BLEU といった指標の意味と限界を理解している
  • ファインチューニングしたモデルを、Hub 上でも、Transformers の pipeline を使っても扱える
  • LLM が従来の NLP 技術の上に成り立ち、それを拡張したものであることが分かる

これだけの知識があっても、コード内の厄介なバグに遭遇したり、特定の言語処理の問題をどう解けばよいか疑問に思ったりするときが来るでしょう。幸い、Hugging Face コミュニティが助けてくれます！このパートの最終章では、Transformer モデルをデバッグし、効果的に助けを求める方法を探ります。
