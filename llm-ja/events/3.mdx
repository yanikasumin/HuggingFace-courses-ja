# Gradio Blocks パーティー[[gradio-blocks-party]]

コースの Gradio の章の公開に合わせて、Hugging Face は新しい Gradio Blocks 機能を使った、かっこいい機械学習デモを作成するコミュニティイベントを開催しました。

コミュニティが作成したデモはすべて、Hub 上の [`Gradio-Blocks`](https://huggingface.co/Gradio-Blocks) オーガニゼーションで見ることができます。受賞作品からいくつか例を紹介します。
