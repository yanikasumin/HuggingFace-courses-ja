Model Hub では適切なモデルを簡単に選べるので、下流のライブラリでも数行のコードで使えます。実際にモデルの使い方と、コミュニティへ貢献する方法を見ていきましょう。

フランス語のモデルでマスクの穴埋めができるものを探しているとします。

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/camembert.gif" alt="CamemBERT モデルを選択する様子。" width="80%"/>
</div>

`camembert-base` チェックポイントを選んで試してみます。使い始めるのに必要な識別子は `camembert-base` だけです。前の章で見たように、`pipeline()` 関数でインスタンス化できます。

```py
from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")
```

このように、パイプラインでモデルを読み込むのはとても簡単です。注意すべきは、選んだチェックポイントがこれから使うタスクに適しているかだけです。たとえば、ここでは `camembert-base` チェックポイントを `fill-mask` パイプラインで読み込んでおり、これはまったく問題ありません。しかし、このチェックポイントを `text-classification` パイプラインで読み込むと、`camembert-base` のヘッドがそのタスクに適していないため、結果は意味をなしません。適切なチェックポイントを選ぶには、Hugging Face Hub のインターフェースにあるタスクセレクタの利用をおすすめします。

<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/tasks.png" alt="Web インターフェースのタスクセレクタ。" width="80%"/>
</div>

チェックポイントは、モデルのアーキテクチャを直接使ってインスタンス化することもできます。

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")
```

ただし、代わりに [`Auto*` クラス](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) の利用をおすすめします。これらは設計上、アーキテクチャに依存しないためです。先ほどのコード例では、CamemBERT アーキテクチャで読み込めるチェックポイントに限られますが、`Auto*` クラスを使えばチェックポイントの切り替えが簡単になります。

```py
from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")
```
{:else}
```py
from transformers import CamembertTokenizer, TFCamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = TFCamembertForMaskedLM.from_pretrained("camembert-base")
```

ただし、代わりに [`TFAuto*` クラス](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) の利用をおすすめします。これらは設計上、アーキテクチャに依存しないためです。先ほどのコード例では、CamemBERT アーキテクチャで読み込めるチェックポイントに限られますが、`TFAuto*` クラスを使えばチェックポイントの切り替えが簡単になります。

```py
from transformers import AutoTokenizer, TFAutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = TFAutoModelForMaskedLM.from_pretrained("camembert-base")
```
{/if}

> [!TIP]
> 事前学習済みモデルを使うときは、そのモデルがどのように学習されたか、どのデータセットを使ったか、制限やバイアスを確認してください。これらの情報はすべてモデルカードに記載されているはずです。
