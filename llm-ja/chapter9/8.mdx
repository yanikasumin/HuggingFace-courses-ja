以上で、Gradio を使って ML デモを構築する章は終わりです。この章では、次の内容を学びました：

- 高レベルな `Interface` API を使って Gradio デモを作成する方法と、様々な入出力モダリティの設定方法
- 一時リンクによる共有と、[Hugging Face Spaces](https://huggingface.co/spaces) へのホスティングによる共有方法
- Gradio デモと、Hugging Face Hub 上のモデルや Spaces との連携方法
- デモへの状態の保存や認証といった高度な機能
- Gradio Blocks を使って、デモのデータフローとレイアウトを完全に制御する方法

この章で扱った概念の理解度は、次のセクションのクイズで確認出来ます。
