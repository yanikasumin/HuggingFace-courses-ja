🤗 Model Context Protocol（MCP）コースへようこそ

今、AI の世界で最も注目されているトピック、Model Context Protocol（MCP） へようこそ！

Anthropic と共同で制作したこの無料コースでは、MCP の理解から活用、アプリケーション構築までを、初級者から実践レベルまでステップアップしながら学べます。

この最初のユニットは、コースを始めるための準備編です。

  • コースのシラバスを確認します。
  • 認定プロセスとスケジュールについて詳しく説明します。
  • コース制作チームを紹介します。
  • アカウントを作成します。
  • Discord サーバーに参加して、受講生同士や私たちと交流しましょう。

さあ、始めましょう！

このコースで学べること

このコースでは、次のことを行います。

  • 📖 Model Context Protocol を理論・設計・実践の面から学ぶ
  • 🧑‍💻 既存の MCP SDK やフレームワークの使い方を学ぶ
  • 💾 自分のプロジェクトを共有し、コミュニティが作ったアプリケーションを探索する
  • 🏆 他の受講生の MCP 実装と競い合うチャレンジに参加する
  • 🎓 課題をこなして修了証を取得する

その他にも盛りだくさんです！

コース修了時には、MCP の仕組みを理解し、最新の MCP 標準を使って外部データやツールを活用する AI アプリケーションを自分で構築できるようになります。

コースへの登録も忘れずに！

コースの構成

コースは次の要素で構成されています。

  • 基礎ユニット: MCP の概念を理論的に学びます。
  • ハンズオン: 既存の MCP SDK の使い方を学び、アプリケーションを構築します。ハンズオンのセクションには、あらかじめ設定済みの環境が用意されています。
  • ユースケース課題: 学んだ概念を応用し、自分で選んだ実世界の課題を解決します。
  • コラボレーション: Hugging Face のパートナーと協力し、最新の MCP 実装やツールを紹介します。

このコースは、皆さんからのフィードバックや貢献によって進化し続ける生きたプロジェクトです！GitHub で Issue や PR を気軽に作成したり、Discord サーバーで議論したりしてください。

シラバス

こちらがコース全体のシラバスです。各ユニットの公開に合わせて、より詳しいトピック一覧も公開します。

Chapter Topic Description
0 オンボーディング 使用するツールやプラットフォームのセットアップを行います。
1 MCP の基礎、アーキテクチャ、コアコンセプト Model Context Protocol のコアコンセプト、アーキテクチャ、コンポーネントを解説します。MCP を使ったシンプルなユースケースも紹介します。
2 エンドツーエンドのユースケース: MCP の実践 コミュニティに共有できる、シンプルなエンドツーエンドの MCP アプリケーションを構築します。
3 デプロイ済みユースケース: MCP の実践 Hugging Face エコシステムとパートナーのサービスを使って、デプロイされた MCP アプリケーションを構築します。
4 ボーナスユニット パートナーのライブラリやサービスを活用し、コースをさらに楽しむためのボーナスユニットです。

前提条件

このコースを受講するには、次の知識があるとよいでしょう。

  • AI と LLM の概念に関する基礎的な理解
  • ソフトウェア開発の原則と API の概念への親しみ
  • 少なくとも1つのプログラミング言語の経験（Python または TypeScript の例を示します）

これらがなくても心配いりません！役立つリソースを紹介します。

  • LLM コース では、LLM の使い方と構築の基礎を学べます。
  • Agents コース では、LLM を使った AI エージェントの構築を学べます。

💡 ヒント

上記のコース自体は前提条件ではありません。LLM やエージェントの概念を理解していれば、今すぐコースを始められます！

必要なもの

必要なものは2つだけです。

  • インターネットに接続できる_コンピューター_
  • アカウント: コースのリソースにアクセスしたりプロジェクトを作成したりするために必要です。アカウントをお持ちでない場合は、こちらから作成できます（無料）。

認定プロセス

このコースは、_聴講モード_で受講することも、アクティビティをこなして_発行する2種類の修了証のうち1つを取得する_こともできます。聴講の場合でも、すべてのチャレンジに参加したり、希望すれば課題に取り組んだりできます。私たちへの連絡も不要です。

認定プロセスは完全に無料です。

  • 基礎の認定を取得するには: コースの Unit 1 を修了する必要があります。フルアプリケーションを構築することなく、MCP の最新動向を把握したい受講生向けです。
  • 修了証を取得するには: ユースケースのユニット（2 と 3）を修了する必要があります。フルアプリケーションを構築し、コミュニティに共有したい受講生向けです。

推奨ペース

このコースの各チャプターは、1週間、週に約3〜4時間の作業で修了できるよう設計されています。

締め切りがあるため、推奨ペースを紹介します。

コースを最大限に活用するには

コースを最大限に活用するためのアドバイスを紹介します。

  1. Discord の学習グループに参加する: グループで学ぶ方がいつも楽です。そのためには、Discord サーバーに参加し、アカウントを認証する必要があります。
  2. クイズと課題に取り組む: 学ぶための最良の方法は、実践と自己評価です。
  3. ペースを維持できるスケジュールを立てる: 下記の推奨ペースを使うか、自分用に作成してください。
