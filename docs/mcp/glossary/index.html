MCP コース

用語集

この用語集は日本語版独自の補足です。原典には含まれていません。本文を読む際の助けとして、平易な言葉で説明しています。

MCP（Model Context Protocol）
AIアプリケーションと外部のツールやデータを、決まった手順でつなぐためのオープンプロトコルです。
MCPサーバー
ツールやリソースを MCP の決まりで提供する側のプログラムです。
MCPクライアント
サーバーに接続してツールなどを呼び出す側。多くはAIアプリケーションの中にあります。
ホスト
ユーザーが直接使うAIアプリケーション全体（チャットアプリやIDEなど）を指す言葉です。
ツール（MCPのTool）
サーバーが公開する、モデルが呼び出せる機能。関数として定義されます。
リソース（Resource）
サーバーが提供する読み取り用のデータ。ファイルやデータベースの中身などです。
プロンプト（MCPのPrompt）
サーバーが提供する、再利用できる指示のテンプレートです。
JSON-RPC
MCP の通信で使う、JSON形式で遠隔の関数呼び出しを行う手順です。
トランスポート
通信路の方式。ローカルでは stdio、ネットワーク越しでは HTTP 系が使われます。
MCP SDK
各言語でサーバーやクライアントを作るための公式ライブラリです。
Gradio
Pythonで Web UI を簡単に作れるライブラリ。MCPサーバーとして公開する機能も持ちます。
プルリクエストエージェント
このコースの題材の一つ。コード変更の提案（プルリクエスト）を自動で作るエージェントです。
