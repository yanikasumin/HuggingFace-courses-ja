画像セグメンテーション

画像セグメンテーションは、画像を意味のある領域に分割する処理です。画像内のそれぞれの物体を浮かび上がらせるようなマスクを作ることが基本です。このタスクは、画像の各ピクセルを分類する問題と考えると分かり易いでしょう。

セグメンテーションモデルは、農業や自動運転など、様々な分野で重要な役割を担っています。農業では、土地の区画を識別したり、作物の生育段階を評価したりする為に使われます。自動運転では、車線や歩道、周囲の道路利用者を識別する為に使われます。

用途や目的によって、適したセグメンテーションの種類は異なります。代表的なものは次の通りです。 - セマンティックセグメンテーション（Semantic Segmentation）：各ピクセルに最も可能性の高いクラスを割り当てます。例えば、画像に猫が2匹写っていても、それぞれを別の個体として区別しません。あくまで各ピクセルがどのクラスに属するかを判定します。 - インスタンスセグメンテーション（Instance Segmentation）：物体の各インスタンスを固有のマスクで識別します。物体検出とセグメンテーションの要素を組み合わせ、同じクラスの個々の物体を区別します。 - パノプティックセグメンテーション（Panoptic Segmentation）：セマンティックセグメンテーションとインスタンスセグメンテーションを組み合わせた手法です。各ピクセルにクラスとインスタンスの両方を割り当て、画像内に何が有るか、そしてどこに在るかを一緒に扱います。

用途や目的に応じて、適切なセグメンテーション手法は異なります。

最近では、1つのモデルで3種類全てのセグメンテーションに対応出来るものも有ります。例えば、Meta が開発した新しいモデル Mask2Former は、パノプティックセグメンテーション用のデータセットだけを使って、3種類全てに対応出来ます。詳しくはこちらの記事をご覧ください。

現代的なアプローチ：Vision Transformer を使ったセグメンテーション

画像セグメンテーションでよく使われる U-Net というネットワークを聞いたことがあるかもしれません。U-Net は複数の畳み込み層から構成され、主に2つの段階で処理を行います。まず、ダウンサンプリングによって画像を圧縮し、特徴を抽出します。次に、アップサンプリングによって画像を元のサイズに戻し、細かな領域まで分割します。

コンピュータビジョンはかつて畳み込みモデルが主流でしたが、最近では Vision Transformer のアプローチへ移行しつつあります。例えば、Segment Anything Model（SAM） が有ります。これは、2023年4月に Meta AI Research（FAIR） が発表した、プロンプトを使ってセグメンテーションを行う人気のモデルです。Vision Transformer（ViT）を基盤としており、画像内で切り出したい対象を言葉で指定出来るような、プロンプト対応のセグメンテーションモデルを目指して開発されました。新しい画像に対してもゼロショット転移が可能です。

強みの1つは、1,100万枚の画像と10億を超えるマスクを含む、利用可能な中でも最大規模のデータセットで訓練されたことです。

まずは、いくつかの画像を使って Meta のデモを試してみてください。更に、Transformers のモデルでも試せます。

Transformers でこのモデルを使う例を紹介します。まず mask-generation パイプラインを初期化します。次に、画像をパイプラインに渡して推論します。

from transformers import pipeline

pipe = pipeline("mask-generation", model="facebook/sam-vit-base", device=0)

raw_image = Image.open("path/to/image").convert("RGB")

masks = pipe(raw_image)

モデルの使い方の詳細はドキュメントをご覧ください。

セグメンテーションモデルはどう評価する？

セグメンテーションモデルの使い方は分かりました。では、どうやって評価すればよいのでしょうか。前のセクションで見た通り、セグメンテーションは基本的に教師あり学習のタスクです。つまり、データセットは画像と、それに対応するマスク（正解データ）で構成されます。

モデルの評価にはいくつかの指標が使えます。代表的なものは次の通りです。

  • Intersection over Union（IoU）／Jaccard 指数は、予測マスクと正解データの共通部分と和集合の比です。 IoU は、セグメンテーションで最もよく使われる評価指標の1つです。クラスごとのデータ数に偏りがあっても影響を受け難い為、モデルの開発を始める際にも適しています。

  • ピクセル正解率（Pixel accuracy）：正しく分類されたピクセル数を、全ピクセル数で割って求めます。 直感的な指標ですが、クラス不均衡に敏感な為、誤解を招くことがあります。

  • Dice 係数：予測マスクと正解マスクが重なった部分の大きさを2倍し、両方のマスクの大きさの合計で割った値です。 Dice 係数は、予測マスクと正解マスクがどの程度重なっているかを表します。重なり具合のわずかな違いも捉えたい場合に適した指標です。
