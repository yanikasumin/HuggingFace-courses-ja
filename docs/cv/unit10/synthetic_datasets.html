Synthetic Datasets

Introduction

コンピュータビジョンにおける合成データセットの魅力的な世界へようこそ！古典的な教師なし手法から高度な深層学習技術へ移行するにつれ、広範で多様なデータセットへの需要は急増しました。合成データセットは、最先端モデルの訓練において極めて重要なリソースとして登場し、現実世界では収集が現実的でないか不可能なことが多い、豊富なデータを提供しています。このセクションでは、最も影響力のある合成データセットのいくつか、その応用、そしてそれらがコンピュータビジョンの未来をどう形作っているかを探ります。

Low-Level Computer Vision Problems

Optical Flow and Motion Analysis

光学フロー（Optical flow）とモーション分析は、画像のダイナミクスを理解するうえで重要です。この分野の進歩に大きく貢献したデータセットをいくつか紹介します。

データセット名 年 説明 論文 追加リンク
Middlebury 2021 (latest release) Middlebury Stereo データセットは、複雑な形状とピクセル精度の真値視差データを持つ高解像度ステレオシーケンスで構成されます。真値の視差は、構造化照明を用い、光プロジェクタのキャリブレーションを必要としない手法で取得されます。 A database and evaluation method for Optical Flow （執筆時点で3192件の引用） Papers with Code - Website
Playing for Benchmarks 2017 25万を超える高解像度ビデオフレーム。すべてに、高レベルタスク向けだけでなく、光学フロー推定や視覚オドメトリのような低レベルタスク向けの真値データもアノテーションされています。 Playing for benchmarks Website
MPI-Sintel 2012 光学フローのための合成データセット。MPI-Sintel の主な特徴は、品質と複雑さの異なるレンダリング設定で同じシーンを含んでいることです。このアプローチにより、さまざまな光学フローアルゴリズムがどこで破綻するかをより深く理解できます。（論文からの引用） A Naturalistic Open Source Movie for Optical Flow Evaluation （執筆時点で551件の引用） Website

High-Level Computer Vision Problems

Semantic Segmentation for Autonomous Driving

セマンティックセグメンテーションは、自動運転車が周囲を解釈し、安全に走行するために不可欠です。これらのデータセットは、この目的のための豊富なアノテーション付きデータを提供します。

名前 年 説明 論文 追加リンク
Virtual KITTI 2 2020 複数物体追跡分析の代理としての仮想世界 Virtual KITTI 2 Website
ApolloScape 2019 実シーンの既存の公開データセット、たとえば KITTI [2] や Cityscapes [3] と比べて、ApolloScape ははるかに大きく豊富なラベリングを含みます。各サイトの全体的なセマンティック密点群、ステレオ、ピクセル単位のセマンティックラベリング、レーンマークのラベリング、インスタンスセグメンテーション、3D の車インスタンス、複数のサイト・都市・時間帯のさまざまな運転動画の全フレームに対する高精度な位置情報などです。 The ApolloScape Open Dataset for Autonomous Driving and its Application Website
Driving in the Matrix 2017 「Driving in the Matrix」の核となる考え方は、シミュレーションエンジンによるフォトリアリスティックなコンピュータ生成画像を使い、アノテーション付きデータを素早く生成することです。 Driving in the Matrix: Can Virtual Worlds Replace Human-Generated Annotations for Real World Tasks? GitHub
CARLA 2017 CARLA（CAR Learning to Act）は都市運転のためのオープンなシミュレータで、Unreal Engine 4 の上にオープンソースの層として開発されました。技術的には、Unreal Engine 4 の上にオープンソースの層として動作するのと同様に機能し、センサーとして RGB カメラ（位置をカスタマイズ可能）、真値の深度マップ、運転向けに設計された12のセマンティッククラス（道路、レーンマーク、交通標識、歩道など）を持つ真値のセマンティックセグメンテーションマップ、環境内の動的物体のバウンディングボックス、エージェント自身の計測値（車両の位置と向き）を提供します。 CARLA: An Open Urban Driving Simulator Website
Synthia 2016 都市シーンのセマンティックセグメンテーションのための合成画像の大規模なコレクション。SYNTHIA は仮想都市からレンダリングされたフォトリアリスティックなフレームの集合で構成され、13クラス（misc、sky、building、road、sidewalk、fence、vegetation、pole、car、sign、pedestrian、cyclist、lane-marking）の正確なピクセル単位のセマンティックアノテーションを備えています。 The SYNTHIA Dataset: A Large Collection of Synthetic Images for Semantic Segmentation of Urban Scenes Website
GTA5 2016 GTA5 データセットは、ピクセル単位のセマンティックアノテーション付きの合成画像24966枚を含みます。画像はオープンワールドビデオゲーム Grand Theft Auto 5 を使ってレンダリングされ、すべてアメリカ風の仮想都市の路上で車の視点から撮影されています。19のセマンティッククラスは Cityscapes データセットのものと互換性があります。 Playing for Data: Ground Truth from Computer Games BitBucket
ProcSy セマンティックセグメンテーションのための合成データセット。現実世界の都市環境をモデル化し、天候やライティングなど、さまざまな変動影響要因を備えています。 ProcSy: Procedural Synthetic Dataset Generation Towards Influence Factor Studies Of Semantic Segmentation Networks Website

Conclusion

合成データセットの開発と活用は、コンピュータビジョンの分野におけるゲームチェンジャーとなりました。データ不足の問題に対する解決策を提供するだけでなく、実世界のデータだけでは達成が難しい水準の精度と多様性を保証します。技術が進歩するにつれ、コンピュータビジョンで可能なことの境界を押し広げ続ける、さらに洗練されリアルなデータセットが期待できます。
