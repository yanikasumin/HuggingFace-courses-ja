Transformer ベースの画像セグメンテーション

このセクションでは、画像セグメンテーションにおいて Vision Transformer と畳み込みニューラルネットワーク（CNN）がどう違うかを探ります。あわせて、Vision Transformer ベースのセグメンテーションモデルを例に、そのアーキテクチャを詳しく説明します。

このセクションでは、画像セグメンテーション、畳み込みニューラルネットワーク（CNN）、Vision Transformer の基礎を理解していることを前提としています。これらの概念にまだ慣れていない場合は、先にコース内の関連資料を確認することをおすすめします。

セグメンテーションにおける CNN と Transformer の比較

Vision Transformer が登場する前は、CNN（畳み込みニューラルネットワーク）が画像セグメンテーションの定番でした。U-Net や Mask R-CNN のようなモデルは、画像内の異なる物体を区別するために必要な詳細を捉え、セグメンテーションタスクで最先端の性能を達成しました。

過去10年間で優れた成果を上げてきた一方で、CNN ベースのモデルにはいくつかの限界があります。Transformer はその解決を目指しています。

  • 空間的な制約：CNN は、小さな受容野を通して局所的なパターンを学習します。この局所的な焦点のため、画像内で遠く離れているものの関連する特徴同士を「結びつける」ことが難しくなります。その結果、複雑なシーンや物体を正確にセグメンテーションする能力に影響します。CNN とは異なり、ViT はアテンション機構を活用し、画像内のグローバルな依存関係を捉えるよう設計されています。つまり、ViT ベースのモデルは画像全体を一度に考慮するため、画像の離れた部分同士の複雑な関係を理解できます。セグメンテーションにおいて、このグローバルな視点は、物体をより正確に切り分けることにつながります。
  • タスク固有のコンポーネント：Mask R-CNN のような手法は、セグメンテーションタスクに関する事前知識を符号化するために、手作業で設計されたコンポーネント（非最大値抑制や空間アンカーなど）を取り入れています。これらのコンポーネントは複雑さを増し、手作業での調整も必要になります。これに対して、ViT ベースのセグメンテーション手法は、手作業で設計されたコンポーネントを不要にすることでセグメンテーションのプロセスを簡素化し、最適化をより容易にします。
  • セグメンテーションタスクへの特化：CNN ベースのセグメンテーションモデルは、セマンティックセグメンテーション、インスタンスセグメンテーション、パノプティックセグメンテーションの各タスクに個別に取り組んできました。そのため、タスクごとに特化したアーキテクチャが生まれ、研究の取り組みも分かれていました。最近の ViT ベースのモデル、たとえば MaskFormer、SegFormer、SAM は、単一のフレームワークの中でセマンティック、インスタンス、パノプティックの各セグメンテーションタスクに取り組む統一的なアプローチを提供します。

MaskFormer に注目：画像セグメンテーションにおける ViT の例

MaskFormer（論文、Hugging Face Transformers ドキュメント）は、論文「MaskFormer: Per-Pixel Classification is Not All You Need for Semantic Segmentation」で発表されたモデルです。画像内に存在する各クラスについてセグメンテーションマスクを予測し、セマンティックセグメンテーションとインスタンスセグメンテーションを1つのアーキテクチャに統合します。

MaskFormer のアーキテクチャ

次の図は、論文から引用したアーキテクチャ図です。

このアーキテクチャは、3つのコンポーネントで構成されています。

ピクセルレベルモジュール：バックボーンを使って画像の特徴を抽出し、ピクセルデコーダでピクセルごとの埋め込みを生成します。

Transformer モジュール：標準的な Transformer デコーダを使い、画像の特徴と学習可能な位置埋め込み（クエリ）からセグメントごとの埋め込みを計算します。各セグメントに関するグローバルな情報を符号化します。

セグメンテーションモジュール：線形分類器と多層パーセプトロン（MLP）をそれぞれ使い、各セグメントについてクラスの確率予測とマスク埋め込みを生成します。マスク埋め込みは、ピクセルごとの埋め込みと組み合わせて使われ、各セグメントのバイナリマスクを予測します。

このモデルは、DETR と同じバイナリマスク損失と、予測されたセグメントごとの交差エントロピー分類損失で学習します。

Hugging Face Transformers を使ったパノプティックセグメンテーションの推論例

パノプティックセグメンテーションは、画像のすべてのピクセルにカテゴリのラベルを付け、それらのカテゴリの中で異なる物体を識別するタスクです。セマンティックセグメンテーションとインスタンスセグメンテーションを組み合わせたものです。

from transformers import pipeline
from PIL import Image
import requests

segmentation = pipeline("image-segmentation", "facebook/maskformer-swin-base-coco")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

results = segmentation(inputs=image, subtask="panoptic")
results

Vision Transformer ベースのセグメンテーションモデルのファインチューニング

事前学習済みのセグメンテーションモデルは数多く公開されています。そのため、特定のユースケースにこれらのモデルを適応させるために、転移学習とファインチューニングがよく使われます。特に、MaskFormer のような Transformer ベースのセグメンテーションモデルは大量のデータを必要とし、ゼロから学習するのは難しいためです。 これらの手法は、事前学習で得られた表現を活用し、新しいデータへ効率的にモデルを適応させます。通常、MaskFormer では、学習済みの汎用的な特徴を活用するために、バックボーン、ピクセルデコーダ、Transformer デコーダを凍結したままにします。一方で、Transformer モジュールはファインチューニングし、クラス予測とマスク生成の能力を新しいセグメンテーションタスクに適応させます。
