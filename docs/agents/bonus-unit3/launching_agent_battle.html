Pokémon バトルエージェントを起動しよう

いよいよバトルの時間です！⚡️

配信のエージェントとバトルしよう！

自分でエージェントを作る気分ではなく、ポケモンにおけるエージェントのバトルの実力に興味があるだけ、という方へ。私たちは twitch で自動ライブ配信を開催しています。

配信中のエージェントとバトルするには、次の手順を行います。

手順: 1. Pokémon Showdown Space に行く: こちら 2. 名前を選ぶ（右上）。 3. 現在のエージェントのユーザー名を見つける。確認先: * 配信画面: こちら 4. Showdown Space でそのユーザー名を検索し、バトルの招待を送信する。

注意: オンラインのエージェントは一度に 1 体だけです！名前が正しいか必ず確認してください。

Pokémon Battle Agent Challenger

前セクションで自分の Pokémon バトルエージェントを作った方は、他のエージェントとどう対戦させればいいのか気になっているでしょう。見ていきましょう！

この目的のための専用 Hugging Face Space を用意しています。

この Space は私たち自身の Pokémon Showdown サーバーに接続されており、あなたのエージェントが AI 駆動の壮大なバトルで他のエージェントと対戦できます。

エージェントを起動する方法

次の手順に従って、エージェントをアリーナに送り込みましょう。

  1. Space を複製する
    Space の右上メニューにある 3 つの点をクリックし、「Duplicate this Space」を選択します。

  2. エージェントのコードを agent.py に追加する
    ファイルを開き、エージェントの実装を貼り付けます。この例に従うか、プロジェクト構成を確認してください。

  3. エージェントを app.py に登録する
    エージェントの名前とロジックをドロップダウンメニューに追加します。参考にこのスニペットを見てください。

  4. エージェントを選択する
    追加すると、エージェントが「Select Agent」ドロップダウンメニューに表示されます。リストから選びましょう！✅

  5. Pokémon Showdown のユーザー名を入力する
    ユーザー名が、iframe の "Choose name" 入力欄に表示されるものと一致していることを確認してください。公式アカウントで接続することもできます。

  6. 「Send Battle Invitation」をクリックする
    エージェントが、選択した対戦相手に招待を送信します。画面に表示されるはずです！

  7. バトルを受けて、戦いを楽しむ！
    バトル開始です！最も賢いエージェントが勝ちますように

自分の作品が実際に動く様子を見る準備はできましたか？AI の頂上決戦、開始です！🥊
