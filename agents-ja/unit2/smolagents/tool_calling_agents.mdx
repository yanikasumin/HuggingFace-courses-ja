# アクションをコードスニペット又は JSON 形式で記述する

> [!TIP]
> コードは、Google Colab で実行できる<a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/tool_calling_agents.ipynb" target="_blank">このノートブック</a>で追うことができます。

Tool Calling Agents は、`smolagents` で使える2つ目のエージェントタイプです。Python スニペットを使う Code Agents とは異なり、これらのエージェントは **LLM プロバイダーの組み込みのツール呼び出し機能**を使って、ツール呼び出しを **JSON 構造**として生成します。これは OpenAI、Anthropic、その他多くのプロバイダーが採用する標準的なアプローチです。

例を見てみましょう。アルフレッドがケータリングサービスやパーティーのアイデアを検索したいとき、`CodeAgent` なら次のような Python コードを生成して実行します。

```python
for query in [
    "Best catering services in Gotham City", 
    "Party theme ideas for superheroes"
]:
    print(web_search(f"Search for: {query}"))
```

一方、`ToolCallingAgent` は JSON 構造を作ります。

```python
[
    {"name": "web_search", "arguments": "Best catering services in Gotham City"},
    {"name": "web_search", "arguments": "Party theme ideas for superheroes"}
]
```

この JSON 形式のデータを使ってツール呼び出しが実行されます。

`smolagents` は、[全体として性能が高い](https://huggingface.co/papers/2402.01030)ことから主に `CodeAgents` に焦点を当てていますが、`ToolCallingAgents` は、変数の扱いや複雑なツール呼び出しを必要としないシンプルなシステムでは効果的です。

![コードと JSON のアクション比較](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)  

## Tool Calling Agents の仕組み

Tool Calling Agents は、Code Agents と同じマルチステップのワークフローに従います（詳しくは[前のセクション](./code_agents)を参照してください）。

主な違いは、**アクションの構造化の方法**です。実行可能なコードの代わりに、**ツール名と引数を指定する JSON オブジェクトを生成**します。そしてシステムが**これらの指示をパース**して、適切なツールを実行します。

## 例：Tool Calling Agent を実行する

アルフレッドがパーティーの準備を始めた前回の例を、違いを際立たせるために今度は `ToolCallingAgent` を使って振り返りましょう。Code Agent の例と同じように、DuckDuckGo で Web を検索できるエージェントを構築します。違いはエージェントのタイプだけで、それ以外はすべてフレームワークが処理します。

```python
from smolagents import ToolCallingAgent, WebSearchTool, InferenceClientModel

agent = ToolCallingAgent(tools=[WebSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")
```

エージェントのトレースを見ると、`Executing parsed code:` の代わりに、次のような表示が見られます。

```text
╭─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ Calling tool: 'web_search' with arguments: {'query': "best music recommendations for a party at Wayne's         │
│ mansion"}                                                                                                       │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
```  

エージェントは構造化されたツール呼び出しを生成し、システムがそれを処理して出力を生みます。`CodeAgent` のようにコードを直接実行するわけではありません。

これで、2種類のエージェントの仕組みが分かりました。用途に応じて適切なものを選べます。アルフレッドのパーティーを成功させるために、引き続き `smolagents` の機能を学んでいきましょう！ 🎉
