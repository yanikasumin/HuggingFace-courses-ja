MCP クライアントとしての Gradio

前のセクションでは、Gradio を使って MCP サーバーを作成し、MCP クライアントを使って接続する方法を学びました。このセクションでは、MCP サーバーに接続するために、MCP クライアントとして Gradio を使う方法を学びます。

💡 ヒント

Gradio は UI クライアントと MCP サーバーの作成に最も適していますが、MCP クライアントとして使い、それを UI として公開することもできます。

前のセクションで作成したものと似た MCP サーバー（追加機能付き）に接続し、それを使って質問に答えます。

Gradio の MCP クライアント

サンプル MCP サーバーに接続する

Hugging Face 上ですでに動作しているサンプル MCP サーバーに接続しましょう。この例では この Space を使います。MCP ツールのコレクションを含む Space です。

from smolagents.mcp_client import MCPClient

with MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",}
) as tools:
    # リモートサーバーのツールが利用可能になる
    print("\n".join(f"{t.name}: {t.description}" for t in tools))
出力 

prime_factors: Compute the prime factorization of a positive integer.
generate_cheetah_image: Generate a cheetah image.
image_orientation: Returns whether image is portrait or landscape.
sepia: Apply a sepia filter to the input image.

Gradio から MCP サーバーに接続する

サンプル MCP サーバーに接続できました。次は、それをサンプルアプリケーションで使います。

まず、まだインストールしていない場合は、smolagents、Gradio、mcp-client ライブラリをインストールする必要があります。

pip install "smolagents[mcp]" "gradio[mcp]" mcp fastmcp

次に、必要なライブラリをインポートし、MCP クライアントを使って MCP サーバーに接続するシンプルな Gradio インターフェースを作成します。

import gradio as gr
import os

from mcp import StdioServerParameters
from smolagents import InferenceClientModel, CodeAgent, ToolCollection, MCPClient

次に、MCP サーバーに接続し、質問に答えるために使えるツールを取得します。

mcp_client = MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",} # これは前のセクションで作成した MCP クライアントです
)
tools = mcp_client.get_tools()

ツールが用意できたので、それらを使って質問に答えるシンプルなエージェントを作成できます。ここでは、シンプルな InferenceClientModel と smolagents のデフォルトモデルを使います。

InferenceClientModel に api_key を渡すことが重要です。トークンは Hugging Face アカウントから取得できます。こちらを確認してください。アクセストークンは環境変数 HF_TOKEN で設定します。

model = InferenceClientModel(token=os.getenv("HF_TOKEN"))
agent = CodeAgent(tools=[*tools], model=model)

これで、エージェントを使って質問に答えるシンプルな Gradio インターフェースを作成できます。

demo = gr.ChatInterface(
    fn=lambda message, history: str(agent.run(message)),
    type="messages",
    examples=["Prime factorization of 68"],
    title="MCP ツールを使うエージェント",
    description="MCP ツールを使って質問に答えるシンプルなエージェントです。"
)

demo.launch()

これで完成です！ MCP クライアントを使って MCP サーバーに接続し、質問に答えるシンプルな Gradio インターフェースを作成しました。

完全な例

Gradio で MCP クライアントを使う完全な例は次のとおりです。

import gradio as gr
import os

from smolagents import InferenceClientModel, CodeAgent, MCPClient


try:
    mcp_client = MCPClient(
        {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",}
    )
    tools = mcp_client.get_tools()

    model = InferenceClientModel(token=os.getenv("HUGGINGFACE_API_TOKEN"))
    agent = CodeAgent(tools=[*tools], model=model, additional_authorized_imports=["json", "ast", "urllib", "base64"])

    demo = gr.ChatInterface(
        fn=lambda message, history: str(agent.run(message)),
        type="messages",
        examples=["Analyze the sentiment of the following text 'This is awesome'"],
        title="MCP ツールを使うエージェント",
        description="MCP ツールを使って質問に答えるシンプルなエージェントです。",
    )

    demo.launch()
finally:
    mcp_client.disconnect()

finally ブロックで MCP クライアントを閉じていることに注目してください。MCP クライアントは長期間存続するオブジェクトであり、プログラム終了時に閉じる必要があるため、これは重要です。

Hugging Face Spaces へのデプロイ

サーバーを他の人が使えるようにするには、前のセクションと同様に、Hugging Face Spaces にデプロイできます。 Gradio MCP クライアントを Hugging Face Spaces にデプロイするには:

  1. Hugging Face で新しい Space を作成する: - huggingface.co/spaces にアクセスする - "Create new Space" をクリックする - SDK として "Gradio" を選択する - Space に名前を付ける（例: "mcp-client"）

  2. コード内の MCP サーバーの URL を更新する:

mcp_client = MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse"}
)
  1. requirements.txt ファイルを作成する:
gradio[mcp]
smolagents[mcp]
  1. コードを Space にプッシュする:
git init
git add app.py requirements.txt
git commit -m "Initial commit"
git remote add origin https://huggingface.co/spaces/YOUR_USERNAME/mcp-client
git push -u origin main

Note: remote origin を追加する際は、AccessToken を使った追加方法について password-git-deprecation を参照してください。
