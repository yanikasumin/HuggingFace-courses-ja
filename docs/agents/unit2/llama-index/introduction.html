LlamaIndex 入門

このモジュールへようこそ。ここでは、LlamaIndex ツールキットを使って、LLM を活用したエージェントを構築する方法を学びます。

LlamaIndex は、インデックスとワークフローを使って、自分のデータの上で動く LLM エージェントを作成するための包括的なツールキットです。このコースでは、LlamaIndex でエージェントを構築するうえで中心となる 3 つの要素、Components、Agents and Tools、Workflows に焦点を当てます。

LlamaIndex の主要な要素と、それぞれがエージェントにどう役立つかを見ていきましょう。

  • Components: LlamaIndex で使う基本的な構成要素です。プロンプトやモデル、データベースなどが含まれます。Components は、LlamaIndex と他のツールやライブラリをつなぐ役割を果たすことも多くあります。
  • Tools: 特定の機能を提供するコンポーネントです。検索や計算、外部サービスへのアクセスなどがその例です。エージェントがタスクを実行できるようにする構成要素です。
  • Agents: ツールを使い、判断を下すことができる自律的なコンポーネントです。複雑な目標を達成するために、ツールの使い方を調整します。
  • Workflows: ロジックをまとめて処理する、ステップごとのプロセスです。Workflows（エージェンティックワークフロー）は、エージェントを明示的に使わずに、エージェント的な振る舞いを構造化する方法です。

LlamaIndex の特徴

LlamaIndex は、smolagents のような他のフレームワークと似たこともできますが、次のような特長があります。

  • わかりやすいワークフローシステム: Workflows を使うと、イベント駆動で非同期を前提とした構文で、エージェントがどのように判断すべきかをステップごとに分解できます。これにより、ロジックを明確に組み立て、整理できます。
  • LlamaParse による高度なドキュメント解析: LlamaParse は LlamaIndex のために作られたものなので、統合はシームレスです。ただし、有料機能です。
  • すぐに使える豊富な Components: LlamaIndex は以前からあるため、他の多くのフレームワークと連携できます。そのため、LLM や retriever、インデックスなど、テストされ信頼性の高いコンポーネントが数多くそろっています。
  • LlamaHub: LlamaIndex の中で使える、数百ものコンポーネントやエージェント、ツールを集めたレジストリです。

有用なエージェントを作るには、場面に応じてこれらの概念がすべて必要になります。 以降のセクションでは、これらの概念を一つずつ詳しく見ていきます。 概念を身につけたあとは、学んだことを使って、エージェントの Alfred を使った実践的なユースケースを作成します！

LlamaIndex を実際に触ってみるのが楽しみになってきたのではないでしょうか。それではさっそく、LlamaHub を使って、必要な統合を見つけてインストールすることから始めましょう！ 🚀
