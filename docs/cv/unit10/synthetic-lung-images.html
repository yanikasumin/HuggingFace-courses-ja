DCGAN を使った合成データの生成

Unit 5 で学んだように、GAN は、生成器（Generator）と識別器（Discriminator）という2つのニューラルネットワークが絶えず対決する機械学習のフレームワークです。生成器は合成画像を作り、識別器は実画像と偽画像を区別しようとします。両者はこの敵対的なプロセスを通じて改善を続け、生成器はリアルな画像を作るのが上手くなり、識別器は偽物と本物の区別が上手くなります。

ここでは、GAN を使って医療画像を生成する方法を見ていきます。医療画像を扱う分野では、データセットの規模が小さいこと、プライバシーへの配慮が必要なこと、アノテーション付きのサンプルが少ないことなどが課題になっています。

研究者らは GAN を使って、肺の X 線画像、網膜画像、脳スキャン、肝臓画像などの合成画像を生成してきました。GAN を用いた合成脳 PET 画像の生成 では、著者らがアルツハイマー病の3つの異なる段階について脳の PET 画像を作成しました。肝病変分類における CNN 性能向上のための GAN ベースの医療画像拡張 は合成肝臓画像を生成しました。BrainGAN：GAN と CNN を用いた脳 MRI 画像の生成・分類フレームワーク は、複数の GAN アーキテクチャを使って脳 MRI 画像を生成するフレームワークを開発し、DCGAN と深層転移学習による新たな COVID-19 検出モデル は、COVID-19 の検出を支援する為に DCGAN を使って合成肺 X 線画像を生成しました。

DCGAN（深層畳み込み敵対的生成ネットワーク）

DCGAN は、Radford らによって 深層畳み込み敵対的生成ネットワークによる教師なし表現学習 で提案されたもので、多くの研究者が合成医療画像の生成に使ってきたモデルです。これを使って合成肺画像を生成していきます。

DCGAN を使ってモデルを訓練する前に、そのアーキテクチャを簡単に復習しましょう。生成器ネットワークはランダムノイズを入力として受け取り、合成肺画像を生成します。一方、識別器ネットワークは実画像と合成画像を区別しようとします。生成器と識別器の両方に畳み込み層を使い、空間的な特徴を効果的に捉えます。また DCGAN は、最大プーリングをストライド付き畳み込みに置き換え、空間次元をダウンサンプリングします。

生成器は次のモデルアーキテクチャを持ちます。

  • 入力は100個のランダムな数からなるベクトルで、出力はサイズ 1281283 の画像です。
  • モデルは4つの畳み込み層を持ちます。
  • Conv2D 層
  • Batch Normalization 層
  • ReLU 活性化
  • Tanh 活性化を伴う Conv2D 層。

識別器は次のモデルアーキテクチャを持ちます。

  • 入力は画像で、出力は画像が偽物か本物かを示す確率です。
  • モデルは1つの畳み込み層を持ちます。
  • Conv2D 層
  • Leaky ReLU 活性化
  • 次の構成を持つ3つの畳み込み層：
  • Conv2D 層
  • Batch Normalization 層
  • Leaky ReLU 活性化
  • Sigmoid を伴う Conv2D 層。

データの収集

まず、実際の肺画像のデータセットを取得する必要があります。Hugging Face Hub から Chest X-Ray Images (Pneumonia) データセットをダウンロードします。

このデータセットに関する情報は次の通りです。

* [画像ベースの深層学習による医学的診断と治療可能な疾患の特定](https://www.cell.com/cell/fulltext/S0092-8674(18)30154-5?_returnURL=https%3A%2F%2Flinkinghub.elsevier.com%2Fretrieve%2Fpii%2FS0092867418301545%3Fshowall%3Dtrue) より:

* このデータセットは3つのフォルダ（train、test、val）に整理されており、各画像カテゴリ（Pneumonia/Normal）のサブフォルダを含みます。5,863枚の X 線画像（JPEG）と2つのカテゴリ（Pneumonia/Normal）があります。

* 胸部 X 線画像（前後方向）は、広州婦女児童医療センター（Guangzhou Women and Children’s Medical Center, Guangzhou）の1歳から5歳の小児患者の後ろ向きコホートから選択されました。全ての胸部 X 線撮影は、患者の通常の臨床ケアの一環として行われました。

* 胸部 X 線画像の分析では、全ての胸部レントゲン写真は最初に品質管理の為にスクリーニングされ、低品質又は判読不能なスキャンは全て除去されました。画像の診断はその後、AI システムの訓練用に承認される前に、2人の専門医によって等級付けされました。等級付けの誤りを考慮する為、評価セットも3人目の専門家によってチェックされました。

まず、Hugging Face Hub にログインすることから始めます。

from huggingface_hub import notebook_login

notebook_login()

次に、データセットを読み込みます。

from datasets import load_dataset

dataset = load_dataset("hf-vision/chest-xray-pneumonia")

肺画像をリサイズし、ピクセル値を正規化して前処理します。

import torchvision.transforms as transforms
from torchvision.transforms import CenterCrop, Compose, Normalize, Resize, ToTensor

transform = Compose(

        transforms.Resize(image_size),
        transforms.CenterCrop(image_size),

訓練中、生成器は実画像と区別出来ない合成肺画像を生成することを目指し、識別器は画像を実物か合成か正しく分類することを学習します。生成器をランダムノイズで初期化することから始め、100エポック訓練します。

生成結果を確認する

識別器が「本物」と判定する確率を70%と評価した、「良い」合成画像64枚を以下に示します。

合成肺画像の中には良く見えるものもあれば、かすんでいるものもあることが分かります。

言及すべき重要な点がいくつかあります。第一に、合成医療画像を扱う研究者は通常、人間による評価（human in the middle）を取り入れます。この例では、専門の放射線科医が合成画像を確認します。そして、専門家でも本物と見分けられなかった画像だけを、実データと共にモデルの訓練に使用します。第二に、（少なくとも素人には）問題なさそうに見える生成画像は、互いに非常によく似ています。これは GAN のもう一つの既知の問題で、「モード崩壊（mode collapse）」を起こすことがあります。本質的には、生成器が同じ種類の出力を生成し始めることで起こります。

例えば、チョコレートチップクッキーを作って何度も褒められた人が、そのクッキーを作るのだけは_とても、とても_上手になったものの、他の種類のクッキーを作れなくなってしまうようなものです。

GAN を訓練して高品質な医療画像を生成する際には、いくつかの課題があります。その為、一部の研究者は肺画像の生成に拡散モデルを使う方法を検討してきました。

医療画像用の条件付き潜在 DDPM である Medfusion は、2D 医療画像では拡散確率モデルが GAN を上回る で提案されました。合成データによる改善：医用画像研究における合成データの可能性 において、Khosravi らは、拡散プロセスで生成された合成肺画像と実画像を混ぜて使うことで、モデルの性能が向上したことを見出しました。
