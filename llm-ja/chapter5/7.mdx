この章では、🤗 Datasets ライブラリを一通り解説しました。ここまで読み進めた皆さん、お疲れさまでした。この章で学んだ知識があれば、次のことが出来るようになっているはずです。

- Hugging Face Hub、自分のノートパソコン、会社のリモートサーバーなど、場所によらずデータセットを読み込めます。
- `Dataset.map()` と `Dataset.filter()` を組み合わせて、データを自在に扱えます。
- `Dataset.set_format()` を使って、Pandas や NumPy などの形式に素早く切り替え出来ます。
- 自分のデータセットを作って、Hugging Face Hub にプッシュ出来ます。
- Transformer モデルで文書を埋め込みベクトルに変換し、FAISS を使ってセマンティック検索エンジンを構築出来ます。

[Chapter 7](/course/chapter7) では、Transformer モデルが得意とする中核的な NLP タスクを扱い、この章で学んだことを活用します。その前に、短いクイズで Datasets の知識を試しておきましょう！
