[Hugging Face Hub](https://huggingface.co/) は Hugging Face のメインの Web サイトで、最新のモデルやデータセットを誰もが見つけて使い、貢献できる中心的なプラットフォームです。公開されているモデルは 10,000 を超え、多種多様なモデルが集まっています。この章ではモデルに焦点を当て、データセットは Chapter 5 で扱います。

Hub のモデルは 🤗 Transformers や NLP だけに限られません。NLP では [Flair](https://github.com/flairNLP/flair) や [AllenNLP](https://github.com/allenai/allennlp)、音声では [Asteroid](https://github.com/asteroid-team/asteroid) や [pyannote](https://github.com/pyannote/pyannote-audio)、画像では [timm](https://github.com/rwightman/pytorch-image-models) のモデルなど、さまざまなライブラリのものが公開されています。

これらのモデルはそれぞれ Git リポジトリとしてホストされており、バージョン管理や再現性が確保されています。Hub でモデルを共有すれば、コミュニティに開かれ、誰もが手軽に使えるようになります。利用者は自分でモデルを学習させる必要がなくなり、共有や利用が簡単になります。

さらに、Hub でモデルを共有すると、そのモデルのホスト型 Inference API が自動的にデプロイされます。コミュニティの誰もが、モデルのページ上でカスタム入力と適切なウィジェットを使って自由に試せます。

何より、Hub の公開モデルの共有も利用も完全に無料です。モデルを非公開で共有したい場合は [有料プラン](https://huggingface.co/pricing) もあります。
