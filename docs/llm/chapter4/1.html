Hugging Face Hub

Hugging Face Hub は Hugging Face のメインの Web サイトで、最新のモデルやデータセットを誰もが見つけて使い、貢献できる中心的なプラットフォームです。10,000 を超える多種多様なモデルが公開されています。この章ではモデルに焦点を当て、データセットは Chapter 5 で扱います。

Hub のモデルは 🤗 Transformers や NLP だけに限られません。NLP では Flair や AllenNLP、音声では Asteroid や pyannote、画像では timm のモデルなど、さまざまなライブラリのものが公開されています。

これらのモデルはそれぞれ Git リポジトリとしてホストされており、バージョン管理や再現性が確保されています。Hub でモデルを共有すれば、コミュニティに開かれ、誰もが手軽に使えるようになります。利用者は自分でモデルを学習させる必要がなくなり、公開する側も共有の手間が省けます。

さらに、Hub でモデルを共有すると、モデルをサーバー上で実行するための Inference API が自動的に用意されます。コミュニティの誰もが、モデルのページ上でカスタム入力と適切なウィジェットを使って自由に試せます。

何より、Hub の公開モデルの共有も利用も完全に無料です。モデルを非公開で共有したい場合は 有料プラン もあります。
