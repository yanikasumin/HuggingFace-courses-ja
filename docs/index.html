Hugging Face 学習コース日本語版

このサイトでは、Hugging Face が無料で公開しているAI・機械学習の学習コースを、日本語で読むことができます。文章を扱うAIや画像を認識するAIなどについて、仕組みを学び、実際にプログラムを動かしながら理解を深めるための教材です。

大規模言語モデル（LLM）、AI エージェント、MCP、コンピュータビジョン、ロボット工学の5コース、全316セクションを収録しています。教材は登録せずに読めます。原文を確認したい場合は、各ページから英語の公式サイトを開けます。

機械学習を初めて学ぶ方は、Hugging Face の説明を読んでから、学習の始め方へ進んでください。すでに学びたい分野が決まっている方は、収録コースから選べます。

Hugging Face とは

Hugging Face は、AI の開発に使うプログラムやデータを公開・共有できるサービスを運営している企業です。研究者や開発者が作ったAIを、ほかの人も利用できるようにしています。

例えば、商品のレビューが好意的か否定的かを判定するAIを作りたいとします。最初から自分でAIを学習させる方法もありますが、Hugging Face で公開されているものを使えば、すでに学習を終えたAIを試すことができます。

このような、データを使って学習したAIを「学習済みモデル」と呼びます。また、AIの学習や性能の確認に使う文章・画像などをまとめたものが「データセット」です。Hugging Face の「Hub」には、モデルとデータセットが多数公開されています。

公開されているモデルは、Python というプログラミング言語から利用できます。その際によく使われるのが、Hugging Face の「Transformers」というライブラリです。ライブラリとは、必要な処理をまとめて、ほかのプログラムから利用できるようにしたものです。

例：文章を判定するAIを試す場合

Hugging Face Hub でモデルを探す文章の内容を判定できる学習済みモデルを選ぶ
↓
Python からモデルを使うTransformers でモデルを読み込み、文章を入力する
↓
結果を確認する入力したレビューが好意的か否定的かなどを判定する

Hugging Face の学習コースでは、こうしたプログラムの使い方に加え、AIが文章を処理する仕組みや、モデルを追加学習させる方法まで学べます。

このサイトは、私自身が機械学習を独学する際、日本語で読める教材が欲しいと考えて制作しました。英語原典の内容を維持しながら、日本語として自然に読める文章になるよう翻訳しています。

学習の始め方

各コースには、説明文だけでなく、実際に動かせるプログラムやクイズもあります。AIの仕組みを理解するには、コードを動かして結果を確かめながら読むのがおすすめです。

多くの教材では Python（パイソン）というプログラミング言語を使用します。プログラミングを初めて学ぶ場合は、次の順番で準備してください。

  1. Python の基本を学ぶ

    変数、関数、繰り返し処理などの基本を覚えます。まだ分からない方は、無料の日本語教材である「ゼロからの Python 入門講座」から始められます。

  2. Google Colab を開く

    Google Colabは、ブラウザ上で Python を動かせるサービスです。Google アカウントでログインし、「新しいノートブック」を作成します。最初は自分のパソコンに Python をインストールする必要はありません。

  3. プログラムを実行する

    画面にある入力欄（コードセル）に次の1行を入力し、左側の実行ボタンを押してください。

print("こんにちは")

入力欄の下に「こんにちは」と表示されれば、Python が動いています。

次に、機械学習のモデルを扱うためのライブラリをインストールします。新しいコードセルに次の内容を入力して実行してください。

!pip install transformers datasets

import transformers
print(transformers.__version__)

最初の行は Transformers と Datasets をインストールする命令です。最後の行でバージョン番号が表示されれば、Transformers を読み込めています。

より詳しい設定方法は、LLM コース第0章「はじめに」で説明しています。パソコンに Python の実行環境を作る方法も掲載されています。演習によって必要なライブラリが異なる場合は、教材に書かれた手順に従ってください。

このサイトでの学習方法

収録コースの目次から章を選び、説明を読みながら進めてください。コードは Colab などにコピーして実行します。このサイトの画面上でコードを実行することはできませんが、クイズはその場で答え合わせができます。

各ページには前後の節へ進むリンクと英語原典へのリンクがあります。専門用語が分からない場合は、サイト内検索や各コースの用語集も利用できます。

教材を読むだけなら Hugging Face のアカウントは不要です。モデルの公開など一部の作業では登録が必要になります。Agents コースの準備ページにはアカウント作成やローカル実行の説明があり、Robotics コースの導入ページでは LeRobot のインストール方法を確認できます。

何から学べばよいか

機械学習を初めて学ぶ方には、Python の基本を覚えた後、LLM コースでモデルを動かし、興味のある専門分野へ進む方法をおすすめします。すべてのコースを決まった順番で終える必要はありません。

  1. Python の基本を学ぶ

    簡単なプログラムを読んだり書いたりできるようにします。Python Japan の無料教材や東京大学の Python 教材が参考になります。

  2. LLM コースでAIを動かす

    文章を分類したり、質問に答えたりする学習済みモデルを使ってみます。モデルが文章を処理する仕組みも学びます。

  3. 自分のデータでモデルを調整する

    既存のモデルを追加学習させる「ファインチューニング」などに取り組み、作成したモデルを公開する方法も学びます。

  4. 作りたいものに合わせて進む

    文章以外のデータを扱いたい場合や、AIに複数の作業をさせたい場合は、専門コースへ進みます。

翻訳方法と品質管理

本サイトは、翻訳作業を担当する Muse、訳文のレビューを担当する ChatGPT、翻訳方針と最終判断を担当する制作者の3者で制作しました。AIが出力した訳文をそのまま公開するのではなく、英語原典と照合し、日本語として不自然な箇所を修正しています。

翻訳対象は、各コースの英語原典を特定の Git コミット（更新履歴上の特定の時点）に固定しています。原典が更新されても、どの版を翻訳したのか確認できるようにするためです。

  1. 原典の取得と翻訳 担当：Muse

    章や節ごとに英語本文を翻訳します。プログラムのコード、数式、リンク先、見出しの識別子など、変更すべきでない部分はそのまま残します。

  2. 訳文のレビュー 担当：ChatGPT

    英語原典と同じ意味になっているか、日本語として自然か、専門用語の表記が統一されているか、改行や記号の位置が適切かを確認します。指摘にはファイル名、行番号、現在の文、問題点、修正案を添えます。

  3. 指摘の確認と修正 担当：Muse

    指摘された文章が実際のファイルにあるかを調べ、英語原典と照合してから修正します。誤った指摘や、原文の意味を変えてしまう修正案は採用しません。

  4. ファイルの機械検証 担当：Muse

    修正によってコード、数式、リンク、画像、見出しの識別子などが意図せず変更されていないかを、プログラムで確認します。

  5. 再レビュー 担当：ChatGPT

    修正後の訳文を再び確認します。問題が残っていれば前の工程に戻り、修正と確認を繰り返します。

  6. 最終判断と公開 担当：霞ヶ関京

    文体や用語の扱いなど、方針に関わる判断を行い、確認が済んだ翻訳をサイトに反映します。

再確認の流れ翻訳 → レビュー → 原典との照合・修正 → 機械検証 → 再レビュー問題が残っている場合は「照合・修正」に戻ります。

文章の参考にしているのは、『とほほのWWW入門』のような、初学者でも読みやすい日本語の技術解説です。英文の語順に引きずられず、意味が伝わるように文章を組み立てます。ただし、ライブラリ名や一般的な専門用語は、ほかの技術資料でも使われている表記を尊重しています。

原典自体に誤りや重複がある場合も、翻訳者の判断で黙って内容を変更することは避けています。翻訳に使用した原典の版はREADMEで、確認・修正の記録は進捗記録で確認できます。
