🤗 Model Context Protocol（MCP）コースへようこそ

今、AI の世界で最も盛り上がっている話題といえば、Model Context Protocol（MCP）です。MCP コースへようこそ！

Anthropic と共同で制作したこの無料コースでは、MCP の仕組みを理解し、活用し、MCP を使ったアプリケーションを構築するまでを、初心者が十分な知識を身につけられるよう段階的に学べます。

この最初のユニットは、コースを始める為の準備編です。

  • コースのシラバスを確認します。
  • 認定プロセスとスケジュールについて詳しく説明します。
  • コース制作チームを紹介します。
  • アカウントを作成します。
  • Discord サーバーに参加して、受講生同士や私たちと交流しましょう。

さあ、始めましょう！

このコースで学べること

このコースでは、次のことを行います。

  • Model Context Protocol を理論・設計・実践の面から学ぶ
  • 既存の MCP SDK やフレームワークの使い方を学ぶ
  • 自分のプロジェクトを共有し、コミュニティが作ったアプリケーションを探索する
  • 自分の MCP 実装を他の受講生の実装と比較・評価するチャレンジに参加する
  • 課題をこなして修了証を取得する

その他にも盛りだくさんです！

コース修了時には、MCP の仕組みを理解し、最新の MCP 標準を使って外部データやツールを活用する AI アプリケーションを自分で構築出来るようになります。

コースへの登録も忘れずに！

コースの構成

コースは次の要素で構成されています。

  • 基礎ユニット：MCP の概念を理論的に学びます。
  • ハンズオン：既存の MCP SDK の使い方を学び、アプリケーションを構築します。ハンズオンのセクションには、予め設定済みの環境が用意されています。
  • ユースケース課題：学んだ概念を応用して、自分で選んだ現実の課題を解決します。
  • コラボレーション：Hugging Face のパートナーと協力し、最新の MCP 実装やツールを紹介します。

このコースは、皆さんのフィードバックや貢献を受けて、更新され続けるプロジェクトです！GitHub で Issue や PR を気軽に作成したり、Discord サーバーでの議論に参加したりして下さい。

シラバス

以下はコースの大まかなシラバスです。各ユニットの公開に合わせて、より詳しいトピック一覧も公開します。

章 トピック 内容
0 オンボーディング 使用するツールやプラットフォームのセットアップを行います。
1 MCP の基礎、アーキテクチャ、コアコンセプト Model Context Protocol のコアコンセプト、アーキテクチャ、コンポーネントを解説します。MCP を使ったシンプルなユースケースも紹介します。
2 エンドツーエンドのユースケース：MCP の実践 コミュニティに共有出来る、シンプルなエンドツーエンドの MCP アプリケーションを構築します。
3 MCP の実践：アプリケーションのデプロイ Hugging Face エコシステムとパートナーのサービスを使って、MCP アプリケーションを構築し、デプロイします。
4 ボーナスユニット パートナーのライブラリやサービスを活用して、コースから更に多くのことを学ぶ為のボーナスユニットです。

前提条件

このコースを受講するには、次の知識が有るとよいでしょう。

  • AI と LLM の概念に関する基礎的な理解
  • ソフトウェア開発の基本的な考え方や API の概念を知っていること
  • 少なくとも1つのプログラミング言語を使った経験（コースでは Python 又は TypeScript を使った例を紹介します）

これらがなくても心配いりません！役立つリソースを紹介します。

  • LLM コースでは、LLM の使い方や、LLM を活用した開発の基礎を学べます。
  • Agents コースでは、LLM を使った AI エージェントの構築を学べます。

💡 ヒント

上記のコース自体は前提条件ではありません。LLM やエージェントの概念を理解していれば、今すぐコースを始められます！

必要なもの

必要なものは2つだけです。

  • インターネットに接続出来るコンピューター
  • アカウント：コースのリソースにアクセスしたり、プロジェクトを作成したりする為に必要です。まだお持ちでなければ、無料でアカウントを作成出来ます。

認定プロセス

このコースは、聴講モードで受講することも、課題に取り組んで発行予定の2種類の修了証の内1つを取得することも出来ます。聴講だけの場合も、全てのチャレンジに参加出来、希望すれば課題にも取り組めます。

私たちへの連絡も不要です。

認定プロセスは完全に無料です。

  • 基礎の認定を取得するには：コースの Unit 1 を修了する必要があります。完成したアプリケーションを構築せずに、MCP の最新動向を把握したい受講生向けです。
  • 修了証を取得するには：ユースケースを扱う Unit 2 と Unit 3 を修了する必要があります。完成したアプリケーションを構築し、コミュニティで共有したい受講生向けです。

推奨ペース

このコースの各チャプターは、週に約3〜4時間学習すれば、1週間で修了出来るように設計されています。

締め切りが有る為、推奨ペースを紹介します。

コースを最大限に活用するには

コースを最大限に活用する為のアドバイスを紹介します。

  1. Discord の学習グループに参加する：グループで学ぶと、より取り組みやすくなります。参加するには、Discord サーバーに参加し、アカウントを認証する必要があります。
  2. クイズと課題に取り組む：学ぶ為の最良の方法は、実践と自己評価です。
  3. ペースを維持出来るスケジュールを立てる：下記の推奨ペースを使うか、自分用に作成して下さい。
