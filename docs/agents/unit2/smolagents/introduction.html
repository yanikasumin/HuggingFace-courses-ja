smolagents 入門

このモジュールへようこそ。ここでは、優れた AI エージェントを作るための軽量なフレームワークを提供する smolagents ライブラリを使って、効果的なエージェントの作り方を学びます。

smolagents は Hugging Face のライブラリです。ぜひ smolagents のリポジトリにスターを付けて応援してください。

モジュールの概要

このモジュールでは、smolagents を使ってインテリジェントなエージェントを構築するための主要な概念と実践的な戦略を、幅広く解説します。

オープンソースのフレームワークは数多くあるため、smolagents が有用な選択肢となる構成要素や機能を理解し、あるいは別のソリューションのほうが適している場面を見極めることが大切です。

ソフトウェア開発タスク向けに設計されたコードエージェント、モジュール化された関数駆動のワークフローを作るツール呼び出しエージェント、情報にアクセスして統合する検索エージェントなど、重要なエージェントの種類を取り上げます。

さらに、複数のエージェントのオーケストレーションや、視覚機能と Web ブラウジングの統合についても扱います。これらによって、動的でコンテキストを意識したアプリケーションの新たな可能性が開けます。

この Unit では、Unit 1 に登場したエージェントのアルフレッドが再び登場します。今回は内部の仕組みに smolagents フレームワークを使っています。ウェイン家 🦇 が留守のあいだ、アルフレッドはウェイン邸でパーティーを開く準備をしていて、やることが山積みです。このフレームワークの背後にある主要な概念を、アルフレッドがさまざまなタスクに取り組む様子とともに見ていきましょう。

💡 ヒント

この Unit では、smolagents ライブラリで AI エージェントを作る方法を学びます。作ったエージェントは、データの検索、コードの実行、Web ページとのやり取りができるようになります。複数のエージェントを組み合わせて、より強力なシステムを作る方法も学びます。

目次

この smolagents の Unit では、次の内容を扱います。

1️⃣ smolagents を使う理由

smolagents は、アプリケーション開発に使える数多くのオープンソースのエージェントフレームワークのひとつです。このコースの他のモジュールで扱う LlamaIndex や LangGraph も代替候補です。smolagents には、特定のユースケースに適した優れた特徴がいくつかありますが、フレームワークを選ぶときは常にすべての選択肢を検討すべきです。ここでは smolagents を使う利点と欠点を探り、プロジェクトの要件に基づいて十分な情報を持って判断できるようにします。

2️⃣ CodeAgents

CodeAgents は smolagents の主要なエージェントタイプです。これらのエージェントは、JSON やテキストを生成する代わりに、アクションを実行するための Python コードを生成します。このモジュールでは、その目的、機能、仕組みを、能力を示す実践的な例とともに解説します。

3️⃣ ToolCallingAgents

ToolCallingAgents は smolagents がサポートする2つ目のエージェントタイプです。Python コードを生成する CodeAgents とは異なり、これらのエージェントは JSON/テキストの blob に依存し、システムがそれをパースして解釈することでアクションを実行します。このモジュールでは、その機能、CodeAgents との主な違いを扱い、使い方を示す例を紹介します。

4️⃣ ツール

Unit 1 で見たように、ツールは LLM が agentic システムの中で使える関数であり、エージェントの振る舞いを構成する不可欠な要素です。このモジュールでは、ツールの作り方、その構造、Tool クラスや @tool デコレータを使ったさまざまな実装方法を扱います。デフォルトのツールボックス、ツールをコミュニティと共有する方法、コミュニティが提供するツールを読み込んでエージェントで使う方法も学びます。

5️⃣ 検索エージェント

検索エージェントを使うと、モデルがナレッジベースにアクセスでき、複数のソースから情報を検索、統合、取得できます。効率的な検索のためにベクトルストアを活用し、Retrieval-Augmented Generation (RAG) のパターンを実装します。これらのエージェントは、メモリシステムで会話のコンテキストを維持しながら、Web 検索とカスタムのナレッジベースを統合するのに特に役立ちます。このモジュールでは、堅牢な情報検索のためのフォールバックの仕組みを含む実装戦略を探ります。

6️⃣ マルチエージェントシステム

複数のエージェントを効果的にオーケストレーションすることは、強力なマルチエージェントシステムを構築するうえで重要です。Web 検索エージェントとコード実行エージェントのように、異なる能力を持つエージェントを組み合わせることで、より高度なソリューションを作れます。このモジュールでは、効率と信頼性を最大化するためのマルチエージェントシステムの設計、実装、管理に焦点を当てます。

7️⃣ Vision エージェントとブラウザエージェント

Vision エージェントは、Vision-Language Models (VLMs) を取り入れることで従来のエージェントの能力を拡張し、視覚情報を処理・解釈できるようにします。このモジュールでは、VLM を活用したエージェントの設計と統合の方法を探り、画像ベースの推論、視覚データの分析、マルチモーダルなインタラクションといった高度な機能を実現します。また、Vision エージェントを使って、Web を閲覧して情報を抽出できるブラウザエージェントも構築します。
