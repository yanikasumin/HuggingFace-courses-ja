バイアスと限界

事前学習済みモデルやファインチューニング済みモデルを本番環境で使う場合は、その限界にも注意が必要です。とりわけ問題になるのが、事前学習に使うデータの集め方です。大量のデータを確保する為、研究者はインターネット上で見つかる情報を出来るだけ幅広く収集します。その結果、質の高い情報だけでなく、不適切な内容も学習データに混ざることがあります。

簡単な例として、BERT モデルを使った fill-mask パイプラインの例に戻りましょう。

from transformers import pipeline

unmasker = pipeline("fill-mask", model="bert-base-uncased")
result = unmasker("This man works as a [MASK].")
print([r["token_str"] for r in result])

result = unmasker("This woman works as a [MASK].")
print([r["token_str"] for r in result])

python out ['lawyer', 'carpenter', 'doctor', 'waiter', 'mechanic'] ['nurse', 'waitress', 'teacher', 'maid', 'prostitute']

（入力文の訳：「この男性は [MASK] として働いている」「この女性は [MASK] として働いている」。出力の職業は、男性の文では弁護士、大工、医師、ウェイター、整備士、女性の文では看護師、ウェイトレス、教師、メイド、売春婦の順です）

これら2つの文の空欄を埋めるよう求められた時、モデルが返す答えの内ジェンダーフリーなものは1つだけです（waiter/waitress）。それ以外は、通常はどちらか一方のジェンダーと結びつけられる職業です。実際に、"woman"（女性）と "work"（仕事）に対する上位5候補の中に、prostitute（売春婦）が入ってしまいました。

BERT は、インターネット中からデータを掻き集めて作られた訳ではない、数少ない Transformer モデルの1つです。一見中立的なデータ（英語版 Wikipediaと BookCorpus データセット）で学習されているにもかかわらず、こうした結果になってしまうのです。

従って、これらのツールを使う際は、元のモデルが性差別的・人種差別的・同性愛嫌悪的な内容を容易に生成してしまう可能性が有ることを忘れないでください。自分のデータでモデルをファインチューニングしても、この本質的なバイアスが消えることはありません。
