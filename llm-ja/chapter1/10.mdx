この章では、Transformer モデルと大規模言語モデル（LLM）の基礎、そしてそれらが AI をはじめとするさまざまな分野にどのような変革をもたらしているかを学びました。

## 扱った主な概念

### 自然言語処理と LLM

NLP とは何か、そして大規模言語モデルがこの分野をどう変えてきたか、具体的には次の点を学びました。
- NLP は分類から生成まで、幅広いタスクを包含している
- LLM は膨大なテキストデータで学習された強力なモデルである
- これらのモデルは、単一のアーキテクチャで複数のタスクを実行できる
- その能力にもかかわらず、LLM にはハルシネーションやバイアスといった限界がある

### Transformer の能力

🤗 Transformers の `pipeline()` 関数を使えば、事前学習済みモデルでさまざまなタスクを簡単に実行できることを学びました。
- テキスト分類、トークン分類、質問応答
- テキスト生成と要約
- 翻訳やその他のシーケンス・ツー・シーケンスのタスク
- 音声認識と画像分類

### Transformer のアーキテクチャ

Transformer モデルの大まかな仕組みも見てきました。ポイントは次のとおりです。
- アテンション機構の重要性
- 転移学習によってモデルが特定のタスクに適応できること
- 3つの主要なアーキテクチャのバリエーション：エンコーダのみ、デコーダのみ、エンコーダ・デコーダ

### モデルアーキテクチャとその応用
この章の重要なポイントの1つは、タスクに応じてどのアーキテクチャを使うかを理解することでした。

| モデル           | 例                                   | タスク                                                                            |
|-----------------|--------------------------------------------|----------------------------------------------------------------------------------|
| エンコーダのみ    | BERT, DistilBERT, ModernBERT               | 文の分類、固有表現抽出、抽出型質問応答 |
| デコーダのみ    | GPT, LLaMA, Gemma, SmolLM                  | テキスト生成、対話型 AI、クリエイティブな文章生成                             |
| エンコーダ・デコーダ | BART, T5, Marian, mBART                    | 要約、翻訳、生成型質問応答                        |

### 現代の LLM の発展
この分野の最近の発展についても学びました。
- LLM が時間とともに規模と能力を拡大してきたこと
- スケーリング則の概念と、それがモデル開発の指針になっていること
- より長いシーケンスの処理に役立つ、特殊なアテンション機構
- 事前学習とインストラクションチューニングという2フェーズの学習アプローチ

### 実践的な応用
この章を通して、これらのモデルが実世界の問題にどう応用できるかを見てきました。
- Hugging Face Hub を使って事前学習済みモデルを探し、使うこと
- Inference API を活用して、ブラウザ上で直接モデルを試すこと
- 特定のタスクにどのモデルが最も向いているかを理解すること
