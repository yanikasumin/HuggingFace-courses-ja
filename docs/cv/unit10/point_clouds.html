Introduction

What is a point cloud?

点群（point cloud）は個々の点の集合で、各点は [x, y, z] 座標で表される三次元空間内の表面のサンプルを表します。これらの点は、空間座標だけでなく、法線、RGB カラー、アルベド、双方向反射分布関数（BRDF）などの追加の属性を保持することがよくあります。

ここでアルベドとは、表面がどれだけ光を反射するかの尺度です。本質的には、表面に当たった入射光に対する反射光の比率です。簡単に言うと、入ってきた光がどれだけ跳ね返されるかを表します。アルベドが高いことは、雪のように多くの光を反射する表面を示し、アルベドが低いことは、アスファルトのように多くの光を吸収する表面を示唆します。

BRDF は、不透明な表面で光がどのように散乱または反射されるかを記述する関数です。入射光の方向と出射方向を考慮して、表面上の交点で光がどう反射されるかを詳述します。光沢、粗さ、さまざまな角度にわたる反射光の分布といった要因を含め、表面の反射特性を数学的に記述します。 これらの属性は、モデリング、レンダリング、シーン理解などのさまざまなアプリケーションで重要な役割を果たします。

点群データの概念自体は新しいものではなく、グラフィックスや物理シミュレーションなどの分野で長年欠かせないものでしたが、2つの重要なトレンドにより、その重要性は著しく高まっています。 第一に、コスト効率が良く使いやすい点群取得デバイスが広く普及したことで、アクセス性が大幅に向上しました。

拡張現実や自動運転車も、今日の技術的状況においてその関連性をさらに際立たせています。

点群とは何かが分かったところで、それで何ができるでしょうか？

3D ポイントデータは主に自動運転機能に使われますが、現在ではドローンやロボットのようなコンピュータビジョンを使う他の AI モデルも、より良い視覚認識のために LiDAR を使っています。LiDAR は、3D モデルや物体・環境の地図を作るために使われる計測値を収集するリモートセンシングのプロセスです。紫外線、可視光、近赤外光を使い、信号が物体に跳ね返ってスキャナに戻るまでの時間を計測することで、空間的な関係や形状を測ります。

Generation and Data Representation

Python ライブラリ point-cloud-utils と open-3d を使います。これらは次のようにインストールできます。

pip install point-cloud-utils

Python ライブラリ open-3d も使います。インストール方法は次のとおりです。

pip install open3d

または、より小さい CPU のみのバージョン:

pip install open3d-cpu

では、まずこれらの点群がどのような形式で保存されるのかを理解する必要があり、そのためにはメッシュクラウドを見る必要があります。

なぜでしょうか？

  • point-cloud-utils は一般的なメッシュ形式（PLY、STL、OFF、OBJ、3DS、VRML 2.0、X3D、COLLADA）の読み取りをサポートします。
  • MeshLab にインポートできるものであれば、読み取れます！（同ライブラリの readme より）

ファイルの種類は拡張子から推測されます。サポートされている拡張子の一部は次のとおりです。

** PLY (Polygon File Format) **

  • 単純な PLY オブジェクトは、オブジェクトを表現するための要素の集合で構成されます。頂点の (x,y,z) の三つ組のリストと、その頂点リストへのインデックスである面のリストで構成されます。
  • 頂点と面は要素の2つの例であり、PLY ファイルの大部分はこの2つの要素で構成されます。
  • 新しいプロパティを作成してオブジェクトの要素に付けることもできますが、こうした新しいプロパティに遭遇しても古いプログラムが壊れない方法で追加すべきです。

** STL (Standard Tessellation Language) **

  • この形式は、立体モデルの表面を三角形で近似します。
  • これらの三角形はファセットとも呼ばれ、各ファセットは垂直方向と、三角形の頂点を表す3つの点で記述されます。
  • ただし、これらのファイルには色やテクスチャの記述がありません。

** OFF (Object File Format) **

  • Object File Format（.OFF）ファイルは、モデルの表面のポリゴンを指定することで、モデルの形状を表現するために使われます。ポリゴンは任意の数の頂点を持つことができます。
  • 交換を目的としたオブジェクトの ASCII テキスト版と、読み書きの効率のためのバイナリ版をサポートします。
  • .obj 形式とも呼ばれます。

** 3DS (3D Studio) **

  • .3ds 拡張子のファイルは、Autodesk 3D Studio で使われる 3D Studio メッシュファイル形式を表します。
  • 3DS 形式はバイナリファイル構造を利用しており、テキストベースの形式と比べて処理が速く、ファイルサイズも小さくなります。データはファイル内のチャンクに整理されます。
  • これらのチャンクは、三次元シーンを構成する形状、ライティング、視聴情報を格納します。

** X3D (Extensible 3D Graphics) **

  • X3D は、3D 情報を表現するための XML ベースの 3D グラフィックスファイル形式です。モジュール式の標準であり、いくつかの ISO 仕様によって定義されています。
  • この形式は、ベクターグラフィックスとラスターグラフィックス、透明度、ライティング効果、回転、フェード、スイングを含むアニメーション設定をサポートします。
  • X3D には、カラー 3D プリンタでモデルを印刷する際に使われる色情報をエンコードできる利点があります（STL とは異なります）。

** DAE (Digital Asset Exchange) **

  • これは XML スキーマであり、オープン標準の XML スキーマで、DAE ファイルはこれをもとに構築されます。
  • このファイル形式は、グラフィックスソフトウェアアプリケーション間でデジタルアセットを交換するためのオープン標準 XML スキーマである COLLADA（COLLAborative Design Activity）XML スキーマに基づいています。
  • この形式の最大の売りは、複数のプラットフォームにわたる互換性です。
  • COLLADA ファイルは1つのプログラムやメーカーに限定されません。代わりに、3D アセットを保存する標準的な方法を提供します。
