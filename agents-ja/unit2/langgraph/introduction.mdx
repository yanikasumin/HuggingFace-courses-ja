# `LangGraph` 入門

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/LangGraph.png" alt="ユニット2.3のサムネイル"/>

次のパートへようこそ。ここでは、複雑な LLM ワークフローの構造を設計し、処理の流れを管理するためのフレームワーク [`LangGraph`](https://github.com/langchain-ai/langgraph) を使って、**アプリケーションを構築する方法** を学びます。

`LangGraph` は、エージェントの処理の流れを **制御** するためのツールを提供するフレームワークです。これにより、**本番環境に対応した** アプリケーションを構築できます。

## モジュールの概要

このユニットでは、次の内容を学びます。

### 2️⃣ [LangGraph の構成要素](./building_blocks)
### 3️⃣ [メール振り分け執事 Alfred](./first_graph)
### 4️⃣ [ドキュメント分析エージェント Alfred](./document_analysis_agent)
### 5️⃣ [クイズ](./quizz1)

> [!WARNING]
> このセクションの例を実行するには、高性能な LLM/VLM モデルへのアクセスが必要です。LangGraph との互換性が最も高いため、GPT-4o API を使って実行しました。

このユニットを終えるころには、堅牢で整理された、本番環境に対応したアプリケーションを構築できるようになります！

なお、このセクションは LangGraph の入門編です。より高度なトピックについては、LangChain Academy の無料コース [Introduction to LangGraph](https://academy.langchain.com/courses/intro-to-langgraph) で学べます。

さあ、始めましょう！
