## `Interface` の作り方[[how-to-create-an-interface]]

`Interface` クラスには、必須パラメータが3つあります。

`Interface(fn, inputs, outputs, ...)`

各パラメータは次の通りです:

  - `fn`：Gradio インターフェースでラップされる予測関数です。この関数は1つ以上のパラメータを取り、1つ以上の値を返すことが出来ます
  - `inputs`：入力コンポーネントの種類です。Gradio には `"image"` や `"mic"` 等、多くの組み込みコンポーネントが用意されています。
  - `outputs`：出力コンポーネントの種類です。こちらも `"image"` や `"label"` 等、多くの組み込みコンポーネントが用意されています。

コンポーネントの完全な一覧は、[Gradio のドキュメント](https://gradio.app/docs) を参照してください。各組み込みコンポーネントは、対応するクラスをインスタンス化してカスタマイズ出来ます。

例えば、[前のセクション](/course/chapter9/2) で見た様に、`inputs` パラメータに `"textbox"` を渡す代わりに、`Textbox(lines=7, label="Prompt")` コンポーネントを渡すと、7行のテキストボックスにラベルを付けられます。

別の例として、`Audio` コンポーネントを使った例を示します。

## 音声を使ったシンプルな例[[a-simple-example-with-audio]]

Gradio には様々な入出力が用意されています。ここでは、音声を扱う `Interface` を作ります。

この例では、音声ファイルを受け取って逆再生する関数を作ります。入力も出力も音声です。

入力には `Audio` コンポーネントを使います。`Audio` コンポーネントでは、音声の入力元を `source` で指定します。指定出来るのは、ユーザーがアップロードするファイルと、ユーザーが声を録音するマイクです。ここでは `"microphone"` に設定します。併せて、`Audio` には "Speak here..." というラベルを付けます。

音声は、逆再生の処理を行い易い様に numpy 配列として受け取ります。その為、`"type"` を `"numpy"` に設定します。これにより、入力データは (`sample_rate`, `data`) のタプルとして関数に渡されます。

出力にも `Audio` コンポーネントを使います。このコンポーネントは、サンプルレートと numpy 配列のタプルを、再生可能な音声ファイルとして自動的に表示します。今回はカスタマイズが不要な為、文字列ショートカットの `"audio"` を使います。


```py
import numpy as np
import gradio as gr


def reverse_audio(audio):
    sr, data = audio
    reversed_audio = (sr, np.flipud(data))
    return reversed_audio


mic = gr.Audio(source="microphone", type="numpy", label="Speak here...")
gr.Interface(reverse_audio, mic, "audio").launch()
```

上のコードを実行すると、下のようなインターフェースが生成されます（ブラウザがマイクの許可を求めてこない場合は、<a href="https://huggingface.co/spaces/course-demos/audio-reverse" target="_blank">デモを別のタブで開いてください</a>）。

## 複数の入出力を扱う[[handling-multiple-inputs-and-outputs]]

より複雑な関数では、入出力が複数になる場合があります。下の例の関数は、ドロップダウンのインデックスとスライダーの値と数値を受け取り、音階の音声サンプルを返します。

ポイントは、入力コンポーネントと出力コンポーネントをリストで渡す点です。

入出力コンポーネントのリストを渡す際は、次の対応関係が重要です。

* 入力コンポーネントのリストを渡すと、各コンポーネントが順番にパラメータに対応します。
* 出力コンポーネントのリストを渡すと、各コンポーネントが戻り値に対応します。

下のコードは、3つの入力コンポーネントが `generate_tone()` 関数の3つの引数にどの様に対応するかを示しています。

```py
import numpy as np
import gradio as gr

notes = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]


def generate_tone(note, octave, duration):
    sr = 48000
    a4_freq, tones_from_a4 = 440, 12 * (octave - 4) + (note - 9)
    frequency = a4_freq * 2 ** (tones_from_a4 / 12)
    duration = int(duration)
    audio = np.linspace(0, duration, duration * sr)
    audio = (20000 * np.sin(audio * (2 * np.pi * frequency))).astype(np.int16)
    return (sr, audio)


gr.Interface(
    generate_tone,
    [
        gr.Dropdown(notes, type="index"),
        gr.Slider(minimum=4, maximum=6, step=1),
        gr.Number(value=1, label="Duration in seconds"),
    ],
    "audio",
).launch()
```

### `launch()` メソッド[[the-launch-method]]

これまで `launch()` メソッドを使ってインターフェースを起動してきました。ここで、その役割を説明します。

デフォルトでは、`launch()` メソッドは、ローカルで動作する Web サーバー上でデモを起動します。Jupyter や Colab のノートブックでコードを実行している場合、Gradio はデモの GUI をノートブック内に埋め込みます。

`launch()` の動作は、様々なパラメータでカスタマイズ出来ます。

  - `inline` - Python ノートブック上にインターフェースをインライン表示するかどうか。
  - `inbrowser` - デフォルトブラウザの新しいタブでインターフェースを自動的に開くかどうか。
  - `share` - 自分のコンピュータからインターフェースへの公開可能な共有リンクを作成するかどうか。Google ドライブの共有リンクに似た仕組みです。

`share` パラメータについては、次のセクションで詳しく扱います。

## 試してみましょう[[lets-apply-it]]

**音声認識** モデルのデモ用インターフェースを作ります。入力は、マイクとアップロードされたファイルの *どちらでも* 受け付けられる様にします。

音声認識モデルは、🤗 Transformers の `pipeline()` 関数で読み込みます。復習が必要な場合は、[Chapter 1 の該当セクション](/course/chapter1/3) を参照してください。次に、音声を処理して文字起こしを返す `transcribe_audio()` 関数を実装します。最後に、入力に `Audio` コンポーネント、出力にテキストのみを指定した `Interface` で、この関数をラップします。

このアプリケーションのコード全体は次の通りです。

```py
from transformers import pipeline
import gradio as gr

model = pipeline("automatic-speech-recognition")


def transcribe_audio(audio):
    transcription = model(audio)["text"]
    return transcription


gr.Interface(
    fn=transcribe_audio,
    inputs=gr.Audio(type="filepath"),
    outputs="text",
).launch()
```
