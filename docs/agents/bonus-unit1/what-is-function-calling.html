Function Calling とは？

Function-calling は、LLM が環境に対して行動を起こすための仕組みです。GPT-4 で初めて導入され、その後、他のモデルにも再現されました。

エージェントの Tools と同じように、Function-calling はモデルに環境に対して行動を起こす能力を与えます。ただし、Function-calling の能力はモデルが学習によって身につけるもので、他のエージェント手法よりもプロンプトへの依存が小さいのが特徴です。

ユニット 1 の間、エージェントは Tools の使い方を学習したわけではありません。私たちは単に一覧を提供し、モデルがそれらの Tools を使った計画を立てられるよう汎化できることに頼っていました。

一方こちらでは、Function-calling によって、エージェントは Tools を使うようファインチューニング（訓練）されます。

モデルはどうやって行動を起こすことを「学ぶ」のか？

ユニット 1 では、エージェントの一般的なワークフローを探りました。ユーザーがエージェントにいくつかのツールを与え、クエリでプロンプトすると、モデルは次のサイクルを回します。

  1. Think（考える）: 目的を達成するために、どんなアクションを取る必要があるか。
  2. Act（行動する）: 正しいパラメータでアクションを整形し、生成を止める。
  3. Observe（観察する）: 実行結果を受け取る。

API 経由のモデルとの「典型的な」会話では、会話は次のようにユーザーとアシスタントのメッセージを交互に繰り返します。

conversation = [
    {"role": "user", "content": "I need help with my order"},
    {"role": "assistant", "content": "I'd be happy to help. Could you provide your order number?"},
    {"role": "user", "content": "It's ORDER-123"},
]

Function-calling は会話に新しいロールを持ち込みます！

  1. Action 用の新しいロール
  2. Observation 用の新しいロール

Mistral API を例に取ると、次のようになります。

conversation = [
    {
        "role": "user",
        "content": "What's the status of my transaction T1001?"
    },
    {
        "role": "assistant",
        "content": "",
        "function_call": {
            "name": "retrieve_payment_status",
            "arguments": "{\"transaction_id\": \"T1001\"}"
        }
    },
    {
        "role": "tool",
        "name": "retrieve_payment_status",
        "content": "{\"status\": \"Paid\"}"
    },
    {
        "role": "assistant",
        "content": "Your transaction T1001 has been successfully paid."
    }
]

…でも、関数呼び出し用の新しいロールがあると言いましたよね？

半分正解で半分違います。このケースや他の多くの API では、モデルは取るべきアクションを「assistant」メッセージとして整形します。その後、チャットテンプレートがこれを Function-calling 用の特殊トークンとして表現します。

  • [AVAILABLE_TOOLS] – 利用可能なツールの一覧の開始
  • [/AVAILABLE_TOOLS] – 利用可能なツールの一覧の終了
  • [TOOL_CALLS] – ツールへの呼び出しを行う（つまり「Action」を取る）
  • [TOOL_RESULTS] – アクションの結果を「Observe」する
  • [/TOOL_RESULTS] – 観測の終了（つまり、モデルは再びデコードできる）

このコースでは Function-calling について改めて取り上げますが、より深く知りたい場合はこの優れたドキュメントセクションを確認してください。

Function-calling とは何か、どう働くかを学んだところで、まだその能力を持っていないモデルに Function-calling の能力を追加しましょう。対象は google/gemma-2-2b-it で、新しい特殊トークンをモデルに追加します。

それを行うには、まずファインチューニングと LoRA を理解する必要があります。
