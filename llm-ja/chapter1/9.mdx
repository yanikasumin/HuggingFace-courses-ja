事前学習済みモデルやそのファインチューニング版を本番環境で使おうと考えているなら、これらのモデルは強力なツールである一方で、限界も伴うことを意識しておいてください。最大の限界は、大量のデータでの事前学習を可能にするために、研究者は見つけられるコンテンツをすべてかき集めることが多く、インターネット上にある最良のものも最悪のものも取り込んでしまうことです。

簡単な例として、BERT モデルを使った `fill-mask` パイプラインの例に戻りましょう。

```python
from transformers import pipeline

unmasker = pipeline("fill-mask", model="bert-base-uncased")
result = unmasker("This man works as a [MASK].")
print([r["token_str"] for r in result])

result = unmasker("This woman works as a [MASK].")
print([r["token_str"] for r in result])
```

```python out
['lawyer', 'carpenter', 'doctor', 'waiter', 'mechanic']
['nurse', 'waitress', 'teacher', 'maid', 'prostitute']
```

これら2つの文の空欄を埋めるよう求められたとき、モデルが返す答えのうちジェンダーフリーなものは1つだけです（waiter/waitress）。それ以外は、通常はどちらか一方のジェンダーと結びつけられる職業です。そして、はい、"woman"（女性）と "work"（仕事）に対してモデルが結びつける上位5つの候補の中に、prostitute（売春婦）が入ってしまいました。これは、BERT がインターネット中からデータをかき集めて作られたわけではない数少ない Transformer モデルの1つであり、一見中立的なデータ（[英語版 Wikipedia](https://huggingface.co/datasets/wikipedia)と [BookCorpus](https://huggingface.co/datasets/bookcorpus) データセット）で学習されているにもかかわらず起きていることです。

したがって、これらのツールを使うときは、使っている元のモデルが、性差別的、人種差別的、あるいは同性愛嫌悪的なコンテンツを非常にたやすく生成しうるということを、頭の片隅に置いておく必要があります。自分のデータでモデルをファインチューニングしても、この本質的なバイアスが消えることはありません。
