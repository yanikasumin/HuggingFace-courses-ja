# 制御システムとその限界

このセクションでは、運動学から制御へと話を進めます。まず、速度を使って運動を考える微分逆運動学（diff-IK）を説明します。次にフィードバック制御を取り入れ、最後に古典的な制御システムが実際の環境で直面する限界を整理します。

## 微分運動学: より賢いアプローチ

関節位置を直接解く代わりに、**速度** を使って考えることができます。

### 重要な洞察
関節速度とエンドエフェクタ速度の関係が分かれば、運動をより滑らかに制御できます。

$$\dot{p} = J(q) \dot{q}$$

ここで $J(q)$ は **ヤコビアン行列** で、関節空間とタスク空間の速度の関係を表します。

<!-- TODO: Micro-diagram: small vector at q in configuration space mapped by J(q) to a small vector at p in task space. -->

### 微分 IK の解
望ましいエンドエフェクタ速度 $\dot{p}^*$ が与えられたとき、関節速度を求めます。

$$\dot{q} = J(q)^+ \dot{p}^*$$

ここで $J(q)^+$ はヤコビアンの **擬似逆行列** です。

## フィードバック制御の追加

オープンループの追従は、モデリング誤差や外乱に対して脆弱です。追従誤差をフィードバックしてループを閉じます。

<img src="https://huggingface.co/robotics-course/images/resolve/main/ch2/ch2-planar-manipulator-floor-box.png" alt="動く障害物" style="width: 100%;" />

*動く障害物に対処するにはフィードバック制御が必要です。*

実際の環境は **動的で不確か** です。フィードバックが必要な理由は次のとおりです。
- **モデリング誤差** — 方程式は完全ではありません
- **外乱** — 予期しない力や障害物  
- **センサーノイズ** — 測定には不確かさがあります

### フィードバック制御の解

望ましい運動と誤差補正を組み合わせます。

$$\dot{q} = J(q)^+ (\dot{p}^* + k_p \Delta p)$$

ここで $\Delta p = p^* - p(q)$ は位置誤差です。


> [!TIP]
> $k_p$ は小さな値から始め、振動の有無を確認しながら徐々に大きくしてください。また、異常時に安全停止させるためのウォッチドッグを設け、指令値に上限・下限を設定することで、システムが安全な動作範囲を超えないようにします。

## 古典的な手法が直面する課題

微分運動学とフィードバック制御を使えば、多くの軌道追従タスクは理論上解決できます。しかし実際の環境はそれほど単純ではありません。以下に示すような理由から、システムがうまく動作しなくなることがあります。


<img src="https://huggingface.co/robotics-course/images/resolve/main/ch2/ch2-classical-limitations.png" alt="古典的手法の限界" style="width: 90%;" />

*動力学ベースのロボティクス手法の4つの重要な限界。*


### 1. **統合の課題**
古典的なパイプラインは **別々のモジュール** から構築されます。
- 知覚 → 状態推定 → 計画 → 制御 → 駆動

**問題点:**
- 誤差がパイプラインを通じて蓄積します
- どれか1つの構成要素が正常に動作しなくなるだけで、システム全体が不安定になりやすい
- 新しいタスクやロボットへの適応が難しい

### 2. **限られたスケーラビリティ**  
従来の手法では、次のような課題への対応が難しくなります。
- **高次元のセンサーデータ**（カメラ、LIDAR）
- **マルチタスクのシナリオ**（タスクごとにカスタムの計画が必要です）
- **マルチモーダルの統合**（視覚 + 触覚 + プロプリオセプション）

### 3. **モデリングの限界**
現実世界の物理は複雑です。
- **接触動力学** — 正確なモデリングが難しい
- **変形する物体** — 剛体近似では扱えません
- **摩擦とコンプライアンス** — 特性評価が難しい

### 4. **データトレンドの見落とし**
古典的な手法は次を活用しません。
- **増え続けるロボティクスデータセット** — 数百万のデモンストレーションが利用可能です
- **ロボットをまたいだ学習** — 他のプラットフォームからの知見
- **コミュニティの知識** — 分散したデータ収集

## 学習という代替手段

これらの限界に対処するため、古典的なモジュール型パイプラインとエンドツーエンドの学習方策を対比させます。

<hfoptions id="robotics-approaches">
<hfoption id="classical">

**古典ロボティクスのアプローチ:**

```
知覚 → 状態推定 → 計画 → 制御 → 駆動
```

**課題:**
- 各モジュールに専門的なチューニングが必要です
- 誤差がパイプラインを通して蓄積します  
- 新しいタスクやロボットへの適応が難しい
- 正確な世界モデルが必要です

</hfoption>
<hfoption id="learning">

**学習ベースのアプローチ:**

```
生センサー → ニューラルネットワーク → 行動
```

**利点:**
- データから学ぶ — デモンストレーションと経験を使います
- エンドツーエンド学習 — パイプライン全体を一括して最適化します  
- タスクをまたいで汎化 — 異なる目的の間で知識を共有します
- 新しいロボットへの適応 — プラットフォームをまたいで知見を転用します

</hfoption>
</hfoptions>

これが **ロボット学習** の可能性です！


> [!TIP]
> **両方の長所を組み合わせる:** 現代のロボット学習は、古典的な洞察と学習を組み合わせることがよくあります。例えば、制御理論の安全制約と学習を組み合わせることができます。
>
> 学習ベースの手法と古典的な手法を、どちらか一方だけ選ぶものと考える必要はありません。両者を組み合わせたハイブリッドアプローチも、すでに成果を上げています。

---

## 要点

- 古典ロボティクスは、明示的な数理モデルと専門知識に依存します
- 順運動学は計算自体は比較的簡単ですが、実用的に扱いやすいのはかなり単純な状況に限られます。逆運動学はより幅広い状況を扱えますが、実際に解法を構築するのが難しい場合があります  
- 微分運動学は、よりよい制御のために位置ではなく速度を扱います
- 古典的な手法には、システムの統合、拡張性、モデリングの精度、データの活用という課題があります
- 学習ベースの手法は、これらの根本的な限界への解決策を提供します
- 未来は、古典的な洞察と学習能力を組み合わせたハイブリッドなアプローチにあります

> [!TIP]
> 次は、強化学習や模倣学習といった学習ベースの手法が、データから直接最適化することで、こうした複雑な問題の一部にどのように対処できるのかを説明します。
