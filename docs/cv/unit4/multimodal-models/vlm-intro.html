視覚言語モデル入門

この章で学ぶこと: - マルチモダリティの簡単な紹介 - 視覚言語モデルの紹介 - さまざまな学習戦略 - VLM でよく使われるデータセット - 下流タスクと評価

私たちの世界はマルチモーダルである

人間は、視覚、聴覚、触覚、嗅覚といった多様な感覚を通して世界を探索します。周囲への完全な理解は、これら多様なモダリティからの洞察を調和させることで生まれます。 モダリティという概念は、もともと数学では異なるピークを指すものとして導入されましたが、ここでは詩的にこう考えます: 「モダリティごとに固有の役割があり、それらが一緒になって私たちの理解の配列を形作る。感覚の交響曲、調和の取れた融合、知覚の舞踏の中で、私たちの世界は超越する。」世界を理解できる AI の実現を追求して、機械学習の分野は、複数のモダリティにわたってデータを処理し統合できるモデルの開発を目指しています。しかし、表現（representation）と整合（alignment）など、いくつかの課題に対処する必要があります。表現とは、個々のモダリティ要素間の複雑なつながりを捉えながら、マルチモーダルデータを効果的に要約する手法を探ることです。整合とは、すべての要素にわたるつながりと相互作用を特定することに焦点を当てます。 さらに、マルチモダリティの取り扱いに固有の難しさを認識することも重要です: - あるモダリティが他のモダリティを支配してしまうことがある。 - モダリティを追加するとノイズが混入することがある。 - すべてのモダリティを完全にカバーできる保証はない。 - 異なるモダリティ同士が複雑な関係を持つことがある。

こうした課題にもかかわらず、機械学習コミュニティはこれらのシステムの開発で大きく前進してきました。この章では、視覚と言語の融合を掘り下げ、視覚言語モデル（VLM: Vision Language Model）の世界を見ていきます。マルチモダリティをより深く理解するには、このユニットの前セクションを参照してください。

はじめに

画像キャプション生成や視覚的質問応答のように、画像を処理してテキストを生成するタスクは、自動運転、リモートセンシングなども含め、長年研究されてきました。また、従来の機械学習／ディープラーニングのゼロからの学習から、事前学習、ファインチューニング、予測を含む新しい学習パラダイムへの移行も見られました。従来の方法では大量のデータを集める必要があるなど、このパラダイムは大きな利点を示しています。

ULMFIT の論文で初めて提案されたこのパラダイムは次の要素からなります: - 大規模な学習データでモデルを事前学習する。 - タスク固有のデータで事前学習済みモデルをファインチューニングする。 - 学習したモデルを分類などの下流タスクに利用する。

VLM では、このパラダイムを用い、視覚画像を組み合わせるよう拡張して、望ましい結果を得ます。例えば 2021 年に OpenAI が発表した画期的な論文 CLIP は、このアプローチの採用に大きな影響を与えました。CLIP は画像・テキストの対照目的関数を使い、ペアになった画像とテキストを埋め込み空間で近づけ、それ以外を遠ざけることで学習します。この事前学習方法により、VLM は豊かな視覚・言語の対応知識を獲得し、任意の画像とテキストの埋め込みを照合することでゼロショット予測ができるようになります。特に、CLIP は分布外（out-of-distribution）のタスクで ImageNet のモデルを上回りました。CLIP や類似モデルのさらなる探求は、この章の次セクションで扱います！

仕組み

視覚言語モデル（VLM）の機能を実現するには、共同学習のためにテキストと画像の意味のある組み合わせが不可欠です。どうすればよいのでしょうか？ 画像・テキストのペアが与えられた場合の単純で一般的な方法は次のとおりです: - テキストエンコーダと画像エンコーダを使って、画像とテキストの特徴を抽出する。画像については CNN または Transformer ベースのアーキテクチャが使える。 - 特定の事前学習目的で視覚・言語の相関を学習する。 - 事前学習目的は3つのグループに分けられる: - 対照（contrastive） 目的は、ペアのサンプルを近づけ、それ以外を埋め込み空間で遠ざけることで、VLM に識別的な表現を学習させる。 - 生成（generative） 目的は、画像／テキストデータを生成するようネットワークを学習させることで、VLM に意味的な特徴を学習させる。 - 整合（alignment） 目的は、埋め込み空間での全体的な画像・テキスト照合、または局所的な領域・単語の照合によって、画像・テキストのペアを整合させる。 - 学習した視覚・言語の相関を使って、任意の画像とテキストの埋め込みを照合することで、VLM を未知のデータに対してゼロショットで評価できる。

既存の研究は主に、次の3つの観点から VLM の改善に焦点を当てています: - 大規模で情報量の多い画像・テキストデータを収集すること。 - ビッグデータから学習するための効果的なモデルを設計すること。 - 効果的な視覚・言語の相関を学習するための新しい事前学習方法／目的を設計すること。

VLM の事前学習は、セグメンテーションや分類などの視覚認識タスクで効果的なゼロショット予測を目標に、画像・テキストの相関を学習するよう VLM を事前学習することです。

戦略

VLM は、2つの学習モードをどう活用するかによってグループ化できます。

  • 画像を、トークン埋め込みと共同で学習できる埋め込み特徴に変換する。

    • この方法では、画像を通常のテキストトークンとして扱うことで視覚情報を言語モデルに融合し、テキストと画像の両方の結合表現の列でモデルを学習する。具体的には、画像は複数の小さなパッチに分割され、各パッチが入力列の1つの「トークン」として扱われる。例: VisualBERT、SimVLM。

  • 凍結された事前学習済み言語モデルのプレフィックスとして機能する、良い画像埋め込みを学習する。

    • この方法では、視覚信号を扱えるように適応させる際に言語モデルのパラメータを変更しない。代わりに、言語モデルと互換性があるような画像の埋め込み空間を学習する。例: Frozen、ClipCap。

  • 特別に設計されたクロスアテンション機構を使って、視覚情報を言語モデルの層に融合する。

    • 言語モデルの層全体にわたる視覚情報の融合を強化するために、テキスト生成と視覚入力のバランスを取るよう調整されたクロスアテンション融合機構を用いる。例: VisualGPT など。
  • 学習なしに視覚モデルと言語モデルを組み合わせる。
    • MAGiC のような最近の手法は、ファインチューニングなしに、誘導付きデコーディングで次のトークンをサンプリングする。

VLM でよく使われるデータセット

以下は、HF dataset にある、VLM でよく使われるデータセットの一部です。

MSCOCO には 328K 枚の画像が含まれ、それぞれに5つの独立したキャプションがペアになっています。

NoCaps は、未知のクラスや概念への汎化を測るために設計されています。in-domain は COCO のクラスだけを描いた画像、near-domain は COCO のクラスと新規クラスの両方、out-of-domain は新規クラスだけから構成されます。

Conceptual Captions には、ウェブからマイニングされ後処理された、300万組の画像とキャプションのペアが含まれています。

ALIGN は、Conceptual Captions データセットのような高コストなフィルタリングや後処理のステップなしに得られた、10億組を超える画像と alt テキストのペアからなるノイズの多いデータセットです。

LAION データセットは画像・テキストのペアから構成されます。画像・テキストのペアは Common Crawl のウェブデータダンプから抽出されたもので、2014 年から 2021 年の間にクロールされたランダムなウェブページのものです。このデータセットは Stable Diffusion モデルの学習に使われました。

下流タスクと評価

VLM は、画像分類、物体検出、セマンティックセグメンテーション、画像・テキスト検索、行動認識など、多くの下流タスクで優れた性能を示し、従来の方法で学習されたモデルを上回っています。

一般に、VLM の評価に使われる設定はゼロショット予測と線形プローブ（linear probing）です。ゼロショット予測は VLM の最も一般的な評価方法で、タスク固有のファインチューニングなしに、事前学習済み VLM を下流タスクに直接適用します。

線形プローブでは、事前学習済み VLM を凍結し、VLM がエンコードした埋め込みを分類する線形分類器を学習させて、その表現を測ります。これらのモデルをどう評価すればよいのでしょうか？ データセットでの性能を調べることができます。例えば、画像と質問が与えられたとき、タスクは質問に正しく答えることです！ モデルが視覚データについての質問にどう推論して答えるかを調べることもできます。このために最もよく使われるデータセットは CLEVR です。

MSCOCO のような標準的なデータセットは、その分布ゆえにモデルにとって学習が容易かもしれません。そのため、より難しく多様なデータセットへの汎化能力を十分に示せない場合があります。これに対応して、Hateful Memes のようなデータセットが作られました。これは、データセットに難しい例（「benign confounders」）を加えて困難にすることでモデルの能力を極限まで試すことを目的とし、マルチモーダル事前学習がうまく機能せず、モデルと人間の性能の間に大きな差があることを示しました。

Winoground という別のデータセットは、CLIP が実際にどれだけ優れているかを明らかにするために設計されました。上の図 のとおり、このデータセットは、印象的な結果にもかかわらず、モデルが本当に人間のように構成的な関係を把握しているのか、それともデータを汎化しているだけなのかを考えるよう私たちに迫ります。例えば、初期の Stable Diffusion や他のテキストから画像へのモデルは、指の本数を正しく数えられませんでした。つまり、VLM を次の段階に進めるために、まだ素晴らしい仕事がたくさん残されているのです！

次のステップは？

コミュニティは速く動いており、対象とするすべてのモダリティを一度に扱う単一の「基盤」モデルを目指す FLAVA のような素晴らしい研究がすでにたくさん見られます。これは将来あり得るシナリオの1つ、つまり多くのモダリティを読み書きできる、モダリティに依存しない基盤モデルです！ しかし他の選択肢が発展する可能性もあります。確実に言えるのは、面白い未来が待っているということです。

こうした最近の進展をもっと知りたい方は、HF の Transformers ライブラリ と Diffusers ライブラリ をフォローしてください。最近の進展やモデルを可能な限り速く追加するよう努めています！ 重要なものが欠けていると感じたら、これらのライブラリに Issue を作成して、自分でコードを貢献することもできます。
