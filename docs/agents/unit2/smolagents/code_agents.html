コードを使うエージェントを作る

Code Agent は smolagents のデフォルトのエージェントタイプです。アクションを実行する為に Python のツール呼び出しを生成し、効率的で表現力豊か、且つ正確なアクション表現を実現します。

この効率的な方式を使うと、必要なアクションの数を減らし、複雑な操作を簡単に実行出来ます。また、既存の関数も再利用出来ます。smolagents は、約1,000行のコードで実装された、コードエージェントを構築する為の軽量なフレームワークを提供します。

図の出典：Executable Code Actions Elicit Better LLM Agents

💡 ヒント

コードエージェントが効果的な理由をもっと知りたい場合は、smolagents ドキュメントのこのガイドをご覧ください。

何故 Code Agent なのか？

マルチステップエージェントのプロセスでは、LLM がアクションを書いて実行します。通常は外部のツール呼び出しを伴います。従来のアプローチは、ツール名と引数を文字列として指定する JSON 形式を使いますが、どのツールを実行するかを決める為に、システムがそれをパースしなければなりません。

しかし研究によれば、ツール呼び出しを行う LLM は、コードを直接扱うほうが効果的に働きます。これは smolagents の核となる原則であり、上記の論文 Executable Code Actions Elicit Better LLM Agents の図が示す通りです。

アクションを JSON ではなくコードで書くことには、いくつかの重要な利点が有ります。

  • 合成可能性（Composability）：アクションを簡単に組み合わせ、再利用出来る
  • オブジェクト管理：画像のような複雑な構造を直接扱える
  • 汎用性：計算可能なあらゆるタスクを表現出来る
  • LLM にとって自然：高品質なコードは、既に LLM の訓練データに含まれている

Code Agent の仕組み

上の図は、CodeAgent.run() が Unit 1 で触れた ReAct フレームワークに従ってどう動作するかを示しています。smolagents では、エージェントの基本構造を表す MultiStepAgent が中核となっています。CodeAgent は MultiStepAgent の特殊な種類であり、以下の例で見ていきます。

CodeAgent はステップのサイクルを通じてアクションを実行します。既存の変数や知識はエージェントのコンテキストに取り込まれ、実行ログとして保持されます。

  1. システムプロンプトは SystemPromptStep に格納され、ユーザーのクエリは TaskStep に記録されます。

  2. 次に、以下の while ループが実行されます。

    2.1 メソッド agent.write_memory_to_messages() が、エージェントのログを LLM が読めるチャットメッセージのリストに書き出します。

    2.2 これらのメッセージが Model に送られ、補完が生成されます。

    2.3 補完がパースされ、アクションが抽出されます。CodeAgent を使っているので、この場合はコードスニペットのはずです。

    2.4 アクションが実行されます。

    2.5 結果が ActionStep としてメモリに記録されます。

各ステップの終わりには、agent.step_callback にコールバック関数が設定されていれば、その関数が実行されます。

smolagents を使ってパーティーのプレイリストを選ぶ

音楽はパーティーを成功させる上で欠かせない要素です。アルフレッドはプレイリスト選びの手伝いが必要です。幸い、smolagents が助けてくれます。

DuckDuckGo を使って Web を検索出来るエージェントを構築出来ます。このツールへのアクセスをエージェントに与えるには、エージェント作成時にツールリストに含めます。

モデルには、Hugging Face の Serverless Inference API へのアクセスを提供する InferenceClientModel を使います。デフォルトのモデルは "Qwen/Qwen2.5-Coder-32B-Instruct" で、性能が高く高速な推論が可能ですが、Hub の互換性の有るモデルならどれでも選べます。

エージェントの実行はとても簡単です。

from smolagents import CodeAgent, DuckDuckGoSearchTool, InferenceClientModel

agent = CodeAgent(tools=[DuckDuckGoSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")

（入力文の訳：Wayne 邸でのパーティーに最適な音楽のお勧めを検索してください）

この例を実行すると、ワークフローの各ステップの実行履歴（トレース）が表示されます。また、対応する Python コードも次のメッセージと共に表示されます。

（検索クエリの訳：バットマンのパーティーに最適な音楽）

カスタムツールを使ってメニューを用意する

プレイリストが選べたので、次はゲスト向けのメニューを整える必要があります。ここでもアルフレッドは smolagents を活用出来ます。

ここでは @tool デコレータを使って、ツールとして機能するカスタム関数を定義します。ツールの作り方は後ほど詳しく扱うので、ここではコードを実行するだけで構いません。

以下の例で分かるように、@tool デコレータでツールを作成し、tools リストに含めます。

from smolagents import CodeAgent, tool, InferenceClientModel

# 場面に応じたメニューを提案するツール
@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion (str): The type of occasion for the party. Allowed values are:
                        - "casual": Menu for casual party.
                        - "formal": Menu for formal party.
                        - "superhero": Menu for superhero party.
                        - "custom": Custom menu.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

# 執事のアルフレッドがパーティーのメニューを用意する
agent = CodeAgent(tools=[suggest_menu], model=InferenceClientModel())

# パーティーのメニューを用意する
agent.run("Prepare a formal menu for the party.")

（ツール説明・戻り値・入力文の訳：docstring は「場面に応じたメニューを提案します。引数 occasion はパーティーの場面の種類で、指定出来る値は casual（カジュアルなパーティーのメニュー）、formal（正式なパーティーのメニュー）、superhero（スーパーヒーローパーティーのメニュー）、custom（カスタムメニュー）です」です。戻り値は、casual が「ピザ、軽食、飲み物」、formal が「ワインとデザート付きの3コースディナー」、superhero が「高エネルギーで健康的な食べ物のビュッフェ」、その他が「執事の為のカスタムメニュー」です。入力文は「パーティーの正式なメニューを用意してください」です）

エージェントは、答えを見つけるまで数ステップにわたって処理を実行します。docstring に指定可能な値を明記しておくと、エージェントが occasion に有効な値を指定するよう誘導出来、ハルシネーションを抑えられます。

メニューの準備が出来ました！

エージェントの中で Python のインポートを使う

プレイリストとメニューは準備出来ましたが、もうひとつ重要な詳細を確認する必要があります。それは準備にかかる時間です。

アルフレッドは、今から準備を始めると何時に全ての準備が整うのかを計算する必要があります。これは、他のスーパーヒーローの助けが必要になった場合に備える為です。

smolagents は、Python コードスニペットを書いて実行するエージェントに特化しており、セキュリティの為にサンドボックス実行を提供します。

コード実行には厳格なセキュリティ対策があります。事前に定義された安全なリストに無いインポートは、デフォルトでブロックされます。但し、additional_authorized_imports に文字列として渡すことで、追加のインポートを許可出来ます。安全なコード実行の詳細については、公式のガイドをご覧ください。

エージェントを作成する時、additional_authorized_imports を使って datetime モジュールのインポートを許可します。

from smolagents import CodeAgent, InferenceClientModel
import numpy as np
import time
import datetime

agent = CodeAgent(tools=[], model=InferenceClientModel(), additional_authorized_imports=['datetime'])

agent.run(
    """
    Alfred needs to prepare for the party. Here are the tasks:
    1. Prepare the drinks - 30 minutes
    2. Decorate the mansion - 60 minutes
    3. Set up the menu - 45 minutes
    4. Prepare the music and playlist - 45 minutes

    If we start right now, at what time will the party be ready?
    """
)

（入力文の訳：Alfred はパーティーの準備をする必要があります。タスクは次の通りです。1. 飲み物の準備：30分、2. 邸宅の飾り付け：60分、3. メニューの準備：45分、4. 音楽とプレイリストの準備：45分。今すぐ始めたら、パーティーの準備が整うのは何時ですか）

これらの例は、コードエージェントで出来ることのほんの始まりに過ぎませんが、パーティーの準備における有用性は既に見え始めています。コードエージェントの作り方について更に学ぶには、smolagents のドキュメントをご覧ください。

まとめると、smolagents は Python コードスニペットを書いて実行するエージェントに特化し、セキュリティの為のサンドボックス実行を提供します。ローカルモデルと API ベースの言語モデルの両方をサポートしており、様々な開発環境に適応出来ます。

カスタムのパーティー準備エージェントを Hub に共有する

自分たちで作ったアルフレッドのエージェントを、コミュニティにも共有出来たら素晴らしいですよね。共有すれば、誰でも Hub からエージェントを簡単にダウンロードして使え、ゴッサム究極のパーティープランナーを手元で活用出来ます。やってみましょう！

smolagents ライブラリでは、完全なエージェントをコミュニティと共有したり、他の人のエージェントをダウンロードして直ぐに使ったり出来ます。次のように簡単です。

# 自分のユーザー名とリポジトリ名に変更してください
agent.push_to_hub('sergiopaniego/AlfredAgent')

エージェントを再びダウンロードするには、次のコードを使います。

# 自分のユーザー名とリポジトリ名に変更してください
alfred_agent = agent.from_hub('sergiopaniego/AlfredAgent', trust_remote_code=True)

alfred_agent.run("Give me the best playlist for a party at Wayne's mansion. The party idea is a 'villain masquerade' theme")

（入力文の訳：Wayne 邸でのパーティーに最適なプレイリストを教えてください。パーティーのアイデアは「悪役の仮面舞踏会」というテーマです）

アルフレッドが smolagents を使ってこのようなエージェントをどう作ったのか、気になるかもしれません。いくつかのツールを組み合わせれば、次のようにエージェントを作れます。今はツールの詳しい仕組みを理解していなくても大丈夫です。この Unit の後半で、ツールについて詳しく説明します。

from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, Tool, tool, VisitWebpageTool

@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion: The type of occasion for the party.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.

    Args:
        query: A search term for finding catering services.
    """
    # ケータリングサービスとその評価の例
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }

    # 最も評価の高いケータリングサービスを探す（検索クエリによるフィルタリングをシミュレーション）
    best_service = max(services, key=services.get)

    return best_service

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""

    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }

    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }

        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")


# 執事のアルフレッドがパーティーのメニューを用意する
agent = CodeAgent(
    tools=[
        DuckDuckGoSearchTool(), 
        VisitWebpageTool(),
        suggest_menu,
        catering_service_tool,
        SuperheroPartyThemeTool(),
    FinalAnswerTool()
    ], 
    model=InferenceClientModel(),
    max_steps=10,
    verbosity_level=2
)

agent.run("Give me the best playlist for a party at the Wayne's mansion. The party idea is a 'villain masquerade' theme")

（ツール説明とデータの訳：catering_service_tool の docstring は「このツールは、ゴッサムシティで最も評価の高いケータリングサービスを返します。引数 query は、ケータリングサービスを探す為の検索語です」です。SuperheroPartyThemeTool の説明は「カテゴリに基づいて、創造的なスーパーヒーローをテーマにしたパーティーのアイデアを提案するツールで、独自のパーティーテーマのアイデアを返します」です。テーマの候補データは、classic heroes が「ジャスティスリーグ・ガラ：ゲストはお気に入りの DC ヒーローの衣装で来場し、『クリプトナイト・パンチ』のようなテーマカクテルを楽しみます」、villain masquerade が「ゴッサム・ローグズ・ボール：ゲストが古典的なバットマンの悪役の衣装で来場する、神秘的な仮面舞踏会です」、futuristic Gotham が「ネオ・ゴッサム・ナイト：バットマン・ビヨンドに着想を得たサイバーパンク風のパーティーで、ネオンの装飾と未来的なガジェットを使います」で、該当しない場合は「テーマのパーティーのアイデアが見つかりません。'classic heroes'、'villain masquerade'、'futuristic Gotham' を試してください」という文が返ります。入力文の訳は、前のプレイリストの例と同じです）

このように、いくつかのツールでエージェントの機能を強化した CodeAgent を作成し、コミュニティと共有出来る究極のパーティープランナーに仕上げました！

OpenTelemetry と Langfuse でパーティー準備エージェントを検査する

アルフレッドは Party Preparator Agent を微調整するなかで、その実行のデバッグに疲れてきています。エージェントは本質的に予測が難しく、検査も困難です。しかし、究極の Party Preparator Agent を構築して本番環境にデプロイすることを目指す以上、将来の監視と分析の為に堅牢なトレーサビリティが必要です。

ここでも smolagents が助けてくれます。エージェントの実行を計測する為の OpenTelemetry 標準を取り入れており、シームレスな検査とロギングが可能です。Langfuse と SmolagentsInstrumentor の助けを借りて、アルフレッドはエージェントの振る舞いを簡単に追跡・分析出来ます。

セットアップは簡単です！

まず、必要な依存関係をインストールします。

pip install opentelemetry-sdk opentelemetry-exporter-otlp openinference-instrumentation-smolagents langfuse

次に、アルフレッドは既に Langfuse のアカウントを作成し、API キーの準備が出来ています。まだの場合は、Langfuse Cloud にこちらからサインアップするか、代替手段を探ってください。

API キーを取得したら、次のように適切に設定する必要があります。

import os

# プロジェクトのキーはプロジェクト設定ページから取得します: https://cloud.langfuse.com
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..." 
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..." 
os.environ["LANGFUSE_HOST"] = "https://cloud.langfuse.com" # 🇪🇺 EU リージョン
# os.environ["LANGFUSE_HOST"] = "https://us.cloud.langfuse.com" # 🇺🇸 US リージョン

環境変数を設定したら、Langfuse クライアントを初期化出来ます。get_client() は、環境変数に設定された認証情報を使って Langfuse クライアントを初期化します。

from langfuse import get_client

langfuse = get_client()

# 接続を確認
if langfuse.auth_check():
    print("Langfuse クライアントの認証が完了し、利用可能になりました！")
else:
    print("認証に失敗しました。認証情報とホストの設定を確認してください。")

最後に、アルフレッドは SmolagentsInstrumentor を初期化し、エージェントのパフォーマンスの追跡を開始する準備が整いました。

from openinference.instrumentation.smolagents import SmolagentsInstrumentor

SmolagentsInstrumentor().instrument()

アルフレッドが接続出来ました！ smolagents の実行が Langfuse に記録され、エージェントの振る舞いを完全に把握出来ます。このセットアップにより、過去の実行を振り返って Party Preparator Agent を更に改良する準備が整いました。

💡 ヒント

エージェントのトレース方法や、収集したデータでパフォーマンスを評価する方法については、Bonus Unit 2 をご覧ください。

from smolagents import CodeAgent, InferenceClientModel

agent = CodeAgent(tools=[], model=InferenceClientModel())
alfred_agent = agent.from_hub('sergiopaniego/AlfredAgent', trust_remote_code=True)
alfred_agent.run("Give me the best playlist for a party at Wayne's mansion. The party idea is a 'villain masquerade' theme")

（入力文の訳は、前のプレイリストの例と同じです）

アルフレッドはこちらのログにアクセスして、確認と分析を行えます。

💡 ヒント

実は、実行中に小さなエラーが発生しました。ログの中で見つけられますか？ エージェントがそれをどのように処理し、それでも有効な答えを返すかを追ってみてください。答え合わせをしたい場合は、エラーへの直接リンクがこちらです。勿論、そのエラーは既に修正されています。詳細はこちらの issue をご覧ください。

一方、おすすめのプレイリストが、パーティーの準備にぴったりの雰囲気を作ってくれます。素敵ですよね？
