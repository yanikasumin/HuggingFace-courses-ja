Hugging Face の学習コースを、日本語で学ぶ

このサイトは、AI 開発プラットフォーム Hugging Face が公開している無料の学習コース（英語）の日本語訳です。LLM（大規模言語モデル）、AI エージェント、コンピュータビジョンなど、5つのコース・全 316 セクションを日本語で読めます。

Hugging Face の公式コースは、世界中の開発者や研究者が機械学習を学ぶために使っている教材ですが、これまで日本語版がありませんでした。英語のままでは読み進めにくいという人のために、公式コースの内容をそのまま日本語で学べる形にして公開しています。各ページには英語の公式ページへのリンクがあるので、原文と照らし合わせながら読むこともできます。

学べるコース

コースは5つあります。いずれも無料で、登録なしで読めます。多くのセクションには理解度を確認するクイズと、実際に動かせるコード例が含まれています。

LLM コース

LLM Course

大規模言語モデル（LLM）の仕組みを基礎から学ぶ中心コース。Transformer の動作原理、Hugging Face Transformers の使い方、ファインチューニング、データセットとトークナイザの扱い、音声処理や独自モデルの構築までを扱います。

  • Transformer の仕組みと、モデルにできること
  • Transformers ライブラリの実践的な使い方
  • 事前学習モデルのファインチューニングと共有
  • データセットとトークナイザの扱い
  • LLM のファインチューニングと思考モデルの構築

全 104 セクション（無料）

Robotics コース

Robotics Course

ロボット学習の入門コース。古典的なロボティクスの基礎（運動学・制御）から、オープンソースライブラリ LeRobot を使ったロボット学習とデータセットの扱いまでを学びます。

  • 古典ロボティクスの基礎（運動の種類・運動学・制御）
  • 学習ベースのロボティクスへの移行
  • LeRobot と LeRobotDataset の使い方

Agents コース

Agents Course

AI エージェントの仕組みと作り方を学ぶコース。LLM とツールの連携、思考・行動・観察のサイクルを理解し、smolagents や LangGraph を使って実際にエージェントを構築し、評価する方法までを扱います。

  • エージェントの基礎（LLM・ツール・思考と行動のサイクル）
  • smolagents、LlamaIndex、LangGraph の3つのフレームワーク実践
  • Agentic RAG のユースケース
  • 最終課題でのエージェント構築と認定

全 74 セクション（無料）

MCP コース

MCP Course（Model Context Protocol）

Model Context Protocol（MCP）の入門コース。MCP の概念・アーキテクチャ・通信の仕組みを学び、Gradio などと連携する MCP アプリケーションを実際に構築します。

  • MCP の概念・アーキテクチャ・通信プロトコル
  • MCP SDK とクライアントの実装
  • Gradio と連携する MCP アプリケーションの構築
  • カスタムワークフローサーバーとプルリクエストエージェントの実践

Community Computer Vision Course

どのコースから始めるか

  • 機械学習や LLM を基礎から学びたい → LLM コース。第1章から順に読むのが基本の進め方です。
  • AI エージェントを作りたい → Agents コース。LLM コースの第1〜2章程度の知識があると進めやすくなります。
  • 画像認識や画像生成に興味がある → Community CV コース。基礎の Unit 1 から始めてください。
  • LLM に外部ツールをつなぐ仕組みを知りたい → MCP コース。短めのコースなので、他のコースと並行しても進められます。
  • ロボットを学習させたい → Robotics コース。全11セクションの短い入門編です。

学び方

  1. 目次から読む：各コースは章・ユニットの順番どおりに進む構成です。前後のセクションへは、ページ上下のナビゲーションで移動できます。
  2. クイズで確認する：多くのセクションにクイズがあり、その場で答え合わせができます。
  3. コードを動かす：コード例はコピーしてそのまま試せます。ブラウザ上で実行できるノートブックへのリンクが付いている節もあります。
  4. 原文と比べる：各ページ上部のボタンから、Hugging Face 公式の英語ページをすぐ開けます。専門用語の英語表現を確認したいときに便利です。
  5. 分からない言葉は用語集で：コースごとに、日本語版独自の用語集を用意しています。本文の検索も、ページ上部の検索窓からできます。
