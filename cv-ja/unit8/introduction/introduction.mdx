# はじめに

前章では動画を扱いました。今回は、もう1つの代表的な視覚データである3次元データを紹介します。2D画像では通常、_x_ と _y_ という2つの次元を使いますが、3D画像では _x_、_y_、_z_ の3つの次元を使います。

「でも、動画も3次元では？」と思うかもしれません。確かに、動画には空間を表す2つの次元 _x_ と _y_ に加えて、時間を表す次元 _t_ が有ります。一方、ここで扱う3Dデータでは、_x_、_y_、_z_ の3つが全て空間の次元です。

3つの空間次元を使うことで、現実世界の形や構造、私たちが物体を知覚する仕組みを、より詳しくモデル化出来ます。こうした3D技術が活用される代表的な分野が、複合現実（Mixed Reality）です。複合現実では、デジタル情報と物理的な現実世界を組み合わせた体験を実現します。

## ユニットの概要

この導入に続く章では、まず3Dコンピュータビジョンの応用例を紹介します。その次の章では、19世紀から現代まで、3D技術がどのように発展してきたかを振り返ります。

全体像をつかんだあとは、基本的な用語や概念を学びます。カメラモデル、線形代数、3Dデータの様々な表現方法を、それぞれ1章ずつ説明します。

基礎を学んだあとは、3Dコンピュータビジョンの具体的な技術とその応用を見ていきます。まず新規視点合成（Novel View Synthesis）を学び、続いてステレオビジョンを扱います。そして最後に、現在特に注目されている手法の1つである Neural Radiance Fields（NeRF）を紹介します。ひとまず、このユニットはそこで終了です。
