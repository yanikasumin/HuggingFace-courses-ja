# MobileNet を更に深く掘り下げる
## Vision Transformer を MobileNet と一緒に使えるか？
### そのまま一体化はできませんが、組み合わせて利用できます
MobileNet は、画像処理タスクを強化する為に、様々な方法で Transformer モデルと統合出来ます。

1つのアプローチは、MobileNet を特徴抽出器として使う方法です。その畳み込み層が画像を処理し、得られた特徴が更なる解析の為に Transformer モデルへ送られます。

別のアプローチは、MobileNet と Vision Transformer を別々に訓練し、アンサンブル手法によってそれらの予測を組み合わせる方法です。各モデルがデータの異なる側面を捉える可能性がある為、性能が高まる可能性があります。この多面的な統合は、画像処理における畳み込みアーキテクチャと Transformer アーキテクチャを組み合わせる柔軟性と可能性を示しています。

このコンセプトの実装として、Mobile-Former が有ります。

### Mobile-Former
Mobile-Former は、MobileNet と Transformer を組み合わせ、画像処理タスクを効率よく実行することを目指したニューラルネットワークアーキテクチャです。局所的な特徴抽出には MobileNet を、文脈の理解には Transformer を活用するよう設計されています。

![Mobile-Former のアーキテクチャ](https://www.researchgate.net/publication/370058769/figure/fig1/AS:11431281148324026@1681702186116/The-overall-architecture-of-Dynamic-Mobile-FormerDMF-and-details-of-DMF-block.png)

詳しい説明は [Mobile-Former の論文](https://arxiv.org/abs/2108.05895)で確認出来ます。

## timm を使った MobileNet
### timm とは？
`timm`（Py**T**orch **Im**age **M**odels）は、主にコンピュータビジョンタスクに焦点を当てた事前学習済み深層学習モデルのコレクションと、訓練、ファインチューニング、推論の為のユーティリティを提供する Python ライブラリです。

PyTorch では、`timm` ライブラリを使うと、MobileNet の様々なバージョンを初め、幅広い事前学習済みモデルを簡単に利用出来ます。以下は `timm` で MobileNet を使う基本的な実装です。

先ず `pip` で `timm` をインストールする必要があります。
```bash
pip install timm
```
基本的なコードはこちらです。
```python
import timm
import torch

# 事前学習済みの MobileNet モデルを読み込む
model_name = "mobilenetv3_large_100"

model = timm.create_model(model_name, pretrained=True)

# 推論にモデルを使いたい場合
model.eval()

# ダミー入力での順伝播
# バッチサイズ1、カラーチャンネル3、224x224 の画像
input_tensor = torch.rand(1, 3, 224, 224)

output = model(input_tensor)
print(output)
```
[timm の Hugging Face ページ](https://huggingface.co/timm)では、様々なタスク向けの他の事前学習済みモデルやデータセットが見つかります。
