LlamaIndex でエージェントを使う

先ほど登場した、頼れる執事エージェントの Alfred を覚えていますか？ 彼はこれからアップグレードされます！ LlamaIndex で使えるツールを理解したので、Alfred に新しい能力を与えて、よりよくサポートしてもらえるようにできます。

その前に、Alfred のようなエージェントがどう成り立っているかを思い出しておきましょう。 Unit 1 では、次のことを学びました。

エージェントとは、AI モデルを活用して環境と対話し、ユーザーが定義した目標を達成するシステムです。推論、計画、アクションの実行（多くの場合は外部ツールを介します）を組み合わせて、タスクを遂行します。

LlamaIndex は、推論を行うエージェントとして主に次の 3 種類をサポートしています。

  1. Function Calling Agents - 特定の関数を呼び出すことができる AI モデルと連携して動作します。
  2. ReAct Agents - チャットやテキストのエンドポイントを持つあらゆる AI と連携でき、複雑な推論タスクを扱えます。
  3. Advanced Custom Agents - より複雑なタスクやワークフローを扱うために、より高度な手法を使います。

エージェントを初期化する

💡 ヒント

コードは Google Colab で実行できる このノートブック で確認できます。

エージェントを作成するには、まずその能力を定義する関数／ツールのセットを与えます。 基本的なツールを使ったエージェントの作成方法を見ていきましょう。この記事の執筆時点では、エージェントは（利用できる場合は）function calling API を自動的に使うか、標準的な ReAct エージェントのループを使います。

ツール／関数の API をサポートする LLM は比較的新しいものですが、特定のプロンプトを避け、提供されたスキーマに基づいて LLM にツール呼び出しを作成させることで、ツールを呼び出す強力な方法を提供します。

ReAct エージェントも複雑な推論タスクが得意で、チャットやテキスト補完の能力を持つあらゆる LLM と連携できます。より冗長ではありますが、特定のアクションを取る理由も示してくれます。

from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
from llama_index.core.agent.workflow import AgentWorkflow
from llama_index.core.tools import FunctionTool

# サンプルの Tool を定義します -- 型アノテーション、関数名、docstring はすべて、解析されるスキーマに含まれます！
def multiply(a: int, b: int) -> int:
    """Multiplies two integers and returns the resulting integer"""
    return a * b

# LLM を初期化します
llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")

# エージェントを初期化します
agent = AgentWorkflow.from_tools_or_functions(
    [FunctionTool.from_defaults(multiply)],
    llm=llm
)

エージェントはデフォルトではステートレスですが、Context オブジェクトを使うことで過去のやり取りを記憶できます。 複数のメッセージにわたって文脈を保持するチャットボットや、時間をかけて進捗を追跡する必要があるタスクマネージャーのように、過去のやり取りを覚えておく必要があるエージェントを使いたい場合に役立ちます。

# ステートレス
response = await agent.run("What is 2 times 2?")

# 状態を記憶します
from llama_index.core.workflow import Context

ctx = Context(agent)

response = await agent.run("My name is Bob.", ctx=ctx)
response = await agent.run("What was my name again?", ctx=ctx)

LlamaIndex のエージェントが非同期であることにお気づきでしょうか。これは Python の await 演算子を使っているためです。Python の非同期コードに慣れていない場合や、復習したい場合は、優れた非同期ガイドがあります。

基本を押さえたので、次はエージェントでより複雑なツールを使う方法を見ていきましょう。

QueryEngineTools を使って RAG エージェントを作成する

Agentic RAG は、エージェントを使って自分のデータに関する質問に答える強力な方法です。 Alfred にさまざまなツールを渡して、質問への回答を助けてもらうことができます。 ただし、ドキュメントに基づいて自動的に質問に答えるのではなく、Alfred は質問に答えるために他のツールやフローを使うかどうかを判断できます。

QueryEngine をエージェントのツールとしてラップするのは簡単です。 その際には、名前と説明を定義する必要があります。LLM はこの情報を使って、ツールを正しく使います。 コンポーネントのセクションで作成した QueryEngine を使って、QueryEngineTool を読み込む方法を見ていきましょう。

from llama_index.core.tools import QueryEngineTool

query_engine = index.as_query_engine(llm=llm, similarity_top_k=3) # LlamaIndex のコンポーネントのセクションで示したもの

query_engine_tool = QueryEngineTool.from_defaults(
    query_engine=query_engine,
    name="name",
    description="a specific description",
    return_direct=False,
)
query_engine_agent = AgentWorkflow.from_tools_or_functions(
    [query_engine_tool],
    llm=llm,
    system_prompt="You are a helpful assistant that has access to a database containing persona descriptions. "
)

マルチエージェントシステムを作成する

AgentWorkflow クラスは、マルチエージェントシステムも直接サポートしています。各エージェントに名前と説明を与えることで、システムはアクティブな発言者を 1 つに保ち、各エージェントが別のエージェントへ引き継げるようにします。

各エージェントの範囲を絞ることで、ユーザーのメッセージに応答する際の全体的な精度を高めることができます。

LlamaIndex のエージェントは、他のエージェントのツールとして直接使うこともできます。これにより、より複雑でカスタムなシナリオに対応できます。

from llama_index.core.agent.workflow import (
    AgentWorkflow,
    FunctionAgent,
    ReActAgent,
)

# ツールをいくつか定義します
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b


def subtract(a: int, b: int) -> int:
    """Subtract two numbers."""
    return a - b


# エージェントの設定を作成します
# NOTE: ここでは FunctionAgent または ReActAgent を使えます。
# FunctionAgent は function calling API を持つ LLM で動作します。
# ReActAgent はあらゆる LLM で動作します。
calculator_agent = ReActAgent(
    name="calculator",
    description="Performs basic arithmetic operations",
    system_prompt="You are a calculator assistant. Use your tools for any math operation.",
    tools=[add, subtract],
    llm=llm,
)

query_agent = ReActAgent(
    name="info_lookup",
    description="Looks up information about XYZ",
    system_prompt="Use your tool to query a RAG system to answer information about XYZ",
    tools=[query_engine_tool],
    llm=llm
)

# ワークフローを作成して実行します
agent = AgentWorkflow(
    agents=[calculator_agent, query_agent], root_agent="calculator"
)

# システムを実行します
response = await agent.run(user_msg="Can you add 5 and 3?")
