イントロダクション

最初のボーナスユニットへようこそ。ここでは、Function-calling（関数呼び出し）のために大規模言語モデル（LLM）をファインチューニングする方法を学びます。

LLM の文脈では、Function-calling は急速に必須のテクニックになりつつあります。

考え方はこうです。ユニット 1 で行ったようなプロンプトベースのアプローチだけに頼るのではなく、Function-calling では訓練フェーズのうちに、行動を起こし、観測を解釈できるようモデルを訓練し、AI をより堅牢にします。

このボーナスユニットはいつやるべきですか？

このセクションは任意で、ユニット 1 より高度な内容です。今すぐ取り組んでもよいし、このコースで知識が深まってから戻ってきても構いません。

ただし心配はいりません。このボーナスユニットには必要な情報がすべてそろっているので、ファインチューニングの内部の仕組みをまだ学んでいなくても、Function-calling 用にモデルをファインチューニングする核心的な概念を一つずつ案内します。

このボーナスユニットを進めるうえで最適なのは、次の状態でいることです。

  1. Transformers を使った LLM のファインチューニング方法を知っていること。分からない場合はこちらを確認してください。

  2. モデルのファインチューニングに SFTTrainer を使う方法を知っていること。詳しくはこちらのドキュメントを確認してください。

学ぶこと

  1. Function Calling
    最新の LLM が会話を効果的に構造化し、Tools を発動できるようにする仕組み。

  2. LoRA（Low-Rank Adaptation）
    計算とストレージのオーバーヘッドを抑える、軽量で効率的なファインチューニング手法。LoRA により、大規模モデルの訓練がより速く、より安く、よりデプロイしやすくなります。

  3. Function Calling モデルにおける Thought → Act → Observe サイクル
    モデルがいつ（そしてどうやって）関数を呼び出すかを決め、中間ステップを追跡し、外部の Tools や API からの結果を解釈する仕組みを構造化する、シンプルながら強力なアプローチ。

  4. 新しい特殊トークン
    モデルが次のものを区別するのに役立つ特殊なマーカーを紹介します。 - 内部の「chain-of-thought」推論 - 外部への関数呼び出し - 外部ツールから返ってくる応答

このボーナスユニットを終える頃には、次のことができるようになります。

  • Tools に関わる API の内部の仕組みを理解する。
  • LoRA の手法を使ってモデルをファインチューニングする。
  • Thought → Act → Observe サイクルを実装・変更して、堅牢で保守しやすい Function-calling のワークフローを作る。
  • 特殊トークンを設計・活用して、モデルの内部推論と外部アクションをシームレスに分離する。

そして、Function-calling ができるよう自分のモデルをファインチューニングし終えているはずです。🔥

さあ、Function-callingに飛び込みましょう！
