はじめに

第2章 では、トークナイザと事前学習済みモデルを使って予測する方法を見てきました。では、事前学習済みモデルを特定のタスク向けにファインチューニングするには、どうすればよいのでしょうか。この章のテーマは、そのファインチューニングです。学ぶ内容は次の通りです。

  • 🤗 Datasets の最新機能を使って、Hub から大規模なデータセットを用意する方法
  • 高レベル API の Trainer を使い、最新の推奨手法に沿ってモデルをファインチューニングする方法
  • 最適化手法を取り入れたカスタム学習ループの実装方法
  • Accelerate ライブラリを使って、あらゆる環境で分散学習を簡単に実行する方法
  • ファインチューニングの最新の推奨手法を取り入れ、モデルの性能を最大限に引き出す方法

💡 ヒント

📚 お勧め資料：この章を始める前に、Datasets のドキュメント でデータ処理について復習しておくとよいでしょう。

この章は、Transformers 以外の Hugging Face ライブラリへの入門にもなります。Datasets、Tokenizers、Accelerate、Evaluate を使うと、モデルの学習をどう効率化し、効果を高められるのかを見ていきます。

この章の主なセクションでは、次の内容を扱います。

  • セクション2：最新のデータ前処理の手法と、データセットを効率よく扱う方法
  • セクション3：強力な Trainer API を使いこなし、最新機能を活用する方法
  • セクション4：学習ループを一から実装する方法と、Accelerate を使った分散学習の仕組み

この章を終えるころには、自分のデータセットでモデルをファインチューニング出来るようになります。高レベル API でもカスタム学習ループでも対応でき、この分野の最新の推奨手法を実践できるようになります。

💡 ヒント

🎯 この章で作るもの：この章を終えるころには、BERT モデルをテキスト分類向けにファインチューニングし、その手法を自分のデータセットやタスクに応用する方法を理解しているはずです。

この章で扱うのは PyTorch のみです。PyTorch は、深層学習の研究でも本番運用でも標準的なフレームワークになっている為です。使用する API や手法も、Hugging Face エコシステムの最新のものに沿います。

学習したモデルを Hugging Face Hub にアップロードするには、Hugging Face のアカウントが必要です。アカウントを作成
