[Chapter 3](/course/chapter3) では、モデルをテキスト分類向けにファインチューニングする方法を扱いました。この章では、代表的な言語タスクを取り上げます。いずれも、従来の NLP モデルでも最新の LLM でも欠かせない基本のタスクです。

- トークン分類
- マスク言語モデリング（BERT など）
- 要約
- 翻訳
- 因果言語モデリングによる事前学習（GPT-2 など）
- 質問応答

これらのタスクは、大規模言語モデル（LLM）の仕組みの土台です。最先端の言語モデルを扱うには、まずこの土台を理解する必要があります。

{#if fw === 'pt'}

この章では、これまでに学んだ内容を組み合わせます。[Chapter 3](/course/chapter3) の `Trainer` API と 🤗 Accelerate ライブラリ、[Chapter 5](/course/chapter5) の Datasets ライブラリ、[Chapter 6](/course/chapter6) の Tokenizers ライブラリです。結果は、[Chapter 4](/course/chapter4) と同様に Model Hub へアップロードします。これまでの章の内容が、ここでつながります。

各セクションは独立しています。`Trainer` API で学習する方法と、Accelerate で独自の学習ループを書く方法の両方を示すので、関心のある方だけを読んでもかまいません。

`Trainer` API は、内部の処理を意識せずにファインチューニングや学習を行いたい場合に向きます。学習ループを自分で書けば、必要な部分を細かく調整出来ます。
