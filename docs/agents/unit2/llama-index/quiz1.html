小さなクイズ（採点なし）

ここまで、LlamaIndex で使う主要なコンポーネントとツールについて学んできました。短いクイズに挑戦してみましょう。

自分の理解度を確かめることは学習する上で最も効果的な方法であり、分かったつもりになるのを防ぐ ことにもつながります。このクイズを通して、知識を補強する必要がある部分を確認出来ます。

このクイズは任意で、採点はされません。

Q1：QueryEngine とは何ですか？

QueryEngine コンポーネントを最もよく説明しているのは、次の内どれですか？

QueryEngine には、関連する情報を検索して処理出来ることが求められます。
これが QueryEngine コンポーネントの中心的な役割を表しています。
QueryEngine は埋め込みを保存するだけではありません。情報を能動的に検索して取得します。
評価は、QueryEngine の主な役割である検索とは別のものです。

Q2：FunctionTools の目的は何ですか？

FunctionTools は、エージェントにとって何故重要ですか？

FunctionTools の主な目的はデータの保存ではありません。
FunctionTools は Python 関数をラップして、エージェントが利用出来るようにします。
FunctionTools は、関数をエージェントが利用出来るようにするという明確な目的を持っています。
FunctionTools はテキスト処理に限らず、様々な種類の関数で使えます。

Q3：LlamaIndex の Toolspecs とは何ですか？

Toolspecs の主な目的は何ですか？

Toolspecs は LlamaIndex のエコシステムで重要な役割を果たしています。
Toolspecs によって、コミュニティでツールを共有し、再利用出来ます。
Toolspecs はメモリを管理するものではなく、ツールを提供する為のものです。
Toolspecs にはテキスト処理に限らず、様々な種類のツールを含めることが出来ます。

Q4：ツールを作成する為に必要なものは何ですか？

ツールを作成する時に含めなければならない情報は何ですか？

これらは全てツールを構成する要素ですが、名前と説明は関数と docstring から読み取ることが出来ます。
ツールを適切にドキュメント化するには、関数と、説明（又は docstring）も必要です。
エージェントがツールを選択した時に実行するコードが必要な為、関数が必須です。
名前と説明は、渡された関数の名前と docstring がデフォルトとして使われます。
