## NLP と LLM について[[understanding-nlp-and-llms]]

このコースはもともと NLP（Natural Language Processing）を中心にしていましたが、その後、この分野における最新の進歩である大規模言語モデル（LLM）を重視する内容へと発展してきました。

**両者の違いは？**
- **NLP（Natural Language Processing：自然言語処理）** は、コンピュータが人間の言語を理解し、解釈し、生成できるようにすることに焦点を当てた、より広い分野です。NLP には、感情分析、固有表現認識、機械翻訳など、さまざまな技術やタスクが含まれます。
- **LLM（Large Language Models：大規模言語モデル）** は NLP モデルの強力なサブセットで、巨大な規模、膨大な訓練データ、そしてタスク固有の訓練を最小限に抑えながら幅広い言語タスクを実行できる能力が特徴です。Llama、GPT、Claude といったモデルシリーズは、NLP で可能なことを一変させた LLM の例です。

このコースを通して、従来の NLP の概念と最先端の LLM の技術の両方を学びます。NLP の基礎を理解することは、LLM を効果的に活用するうえで欠かせません。

コースの概要を簡単に紹介します。

- Chapter 1 から 4 では、🤗 Transformers ライブラリの主要な概念を紹介します。このパートを終えるころには、Transformer モデルの仕組みに慣れ、[Hugging Face Hub](https://huggingface.co/models) からモデルを使う方法、データセットでファインチューニングする方法、そして結果を Hub で共有する方法が分かるようになります。
- Chapter 5 から 8 では、🤗 Datasets と 🤗 Tokenizers の基礎を学んでから、古典的な NLP タスクや LLM の技術に進みます。このパートを終えるころには、最も一般的な言語処理の課題に自分で取り組めるようになります。
- Chapter 9 では NLP の範囲を超えて、自分のモデルのデモを 🤗 Hub で構築・共有する方法を扱います。このパートを終えるころには、自分の 🤗 Transformers アプリケーションを世界に披露する準備が整います。
- Chapter 10 から 12 では、ファインチューニング、高品質なデータセットのキュレーション、推論モデルの構築といった、LLM の高度なトピックを深掘りします。

このコースは：

* Python について十分な知識が必要です
* [fast.ai](https://www.fast.ai/) の [Practical Deep Learning for Coders](https://course.fast.ai/) や、[DeepLearning.AI](https://www.deeplearning.ai/) が開発したプログラムなど、深層学習の入門コースを先に受けておくと、よりスムーズに学べます
* [PyTorch](https://pytorch.org/) や [TensorFlow](https://www.tensorflow.org/) の事前知識は前提としていませんが、どちらかに慣れていると理解の助けになります

このコースを終えたら、DeepLearning.AI の [Natural Language Processing Specialization](https://www.coursera.org/specializations/natural-language-processing?utm_source=deeplearning-ai&utm_medium=institutions&utm_campaign=20211011-nlp-2-hugging_face-page-nlp-refresh) をチェックしてみることをおすすめします。ナイーブベイズや LSTM など、知っておく価値のある従来の NLP モデルを幅広く扱っています。
