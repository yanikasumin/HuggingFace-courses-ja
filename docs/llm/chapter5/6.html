セクション 5 では、🤗 Datasets の GitHub リポジトリの issue とコメントからデータセットを作成しました。このセクションでは、そのデータを使って検索エンジンを作ります。目的は、ライブラリについて特に気になることへの答えを探せるようにすることです。

埋め込みを用いたセマンティック検索

第1章 で見たように、Transformer ベースの言語モデルは、テキストの各トークンを 埋め込みベクトル で表します。個々の埋め込みをプーリング（集約）すると、文や段落を1つのベクトルで表せます。場合によっては、ドキュメント全体も同様に表せます。類似したドキュメントの検索は、この埋め込みを使います。クエリの埋め込みとコーパス内の各ドキュメントの埋め込みについて、内積による類似度（又は別の類似度指標）を計算し、値の大きいドキュメントを返します。

このセクションで作るのは、埋め込みを使うセマンティック検索エンジンです。セマンティック検索には、従来の方法に比べていくつかの利点があります。従来の方法は、クエリに含まれるキーワードとドキュメントを照合する方式です。

テキスト埋め込みの作成

第2章 で見たように、トークン埋め込みは AutoModel クラスで取得出来ます。必要なのは、モデルの読み込みに使う適切なチェックポイントの選択だけです。

埋め込みの作成に特化したライブラリとして、sentence-transformers があります。このライブラリのドキュメントによると、短いクエリの答えを issue のコメントのような比較的長いドキュメントから探す処理は、非対称セマンティック検索 に当たります。チェックポイントは、ドキュメント内のモデル概要表でセマンティック検索の性能が最も高いとされる multi-qa-mpnet-base-dot-v1 を使います。トークナイザも、同じチェックポイントから読み込みます。

{#if fw === 'pt'}

from transformers import AutoTokenizer, AutoModel

model_ckpt = "sentence-transformers/multi-qa-mpnet-base-dot-v1"
tokenizer = AutoTokenizer.from_pretrained(model_ckpt)
model = AutoModel.from_pretrained(model_ckpt)

埋め込みの計算を高速化する為、モデルと入力を GPU に置きます。ここで準備しておきます。

import torch

{:else}

前に述べた通り、GitHub の issue から作ったコーパスの各エントリは、1つのベクトルで表す必要があります。その為には、トークン埋め込みを何らかの方法でプーリングします。平均化も方法の1つです。よく使われる方法の1つが、モデルの出力に対する CLS プーリング です。これは、特殊トークン [CLS] に対応する最終隠れ状態を取り出す方法です。次の関数で実装出来ます。

def cls_pooling(model_output):
    return model_output.last_hidden_state[:, 0]

次に、ヘルパー関数を作成します。この関数は、ドキュメントのリストをトークナイズし、テンソルを GPU に配置してモデルに入力し、最後に出力へ CLS プーリングを適用します。

{#if fw === 'pt'}

def get_embeddings(text_list):
    encoded_input = tokenizer(
        text_list, padding=True, truncation=True, return_tensors="pt"
    )
    encoded_input = {k: v.to(device) for k, v in encoded_input.items()}
    model_output = model(**encoded_input)
    return cls_pooling(model_output)

FAISS による効率的な類似検索

埋め込みベクトルのデータセットが出来ました。次に必要なのは、その中から似たベクトルを探す仕組みです。ここでは、Datasets で利用出来る FAISS インデックス というデータ構造を使います。FAISS（Facebook AI Similarity Search の略）は、埋め込みベクトルの高速な検索とクラスタリングの為のアルゴリズムを提供するライブラリです。

FAISS の基本的な考え方は、インデックスと呼ばれる特殊なデータ構造を作ることです。インデックスがあれば、入力した埋め込みに類似する埋め込みを探せます。Datasets での作成は簡単です。Dataset.add_faiss_index() 関数を使い、インデックス化する列を指定します。

embeddings_dataset.add_faiss_index(column="embeddings")

これで、Dataset.get_nearest_examples() 関数による最近傍検索が出来るようになりました。インデックスから近いベクトルを探す検索です。まず、質問文を埋め込みベクトルに変換して試します。
