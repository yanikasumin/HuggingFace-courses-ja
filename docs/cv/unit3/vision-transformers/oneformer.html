OneFormer：1つの Transformer で画像セグメンテーションを統合する

はじめに

OneFormer は、画像セグメンテーションに対する画期的なアプローチです。画像セグメンテーションは、画像を意味の有る領域に分割するコンピュータビジョンのタスクです。従来の手法では、個々の物体を識別するインスタンスセグメンテーション（instance segmentation）や、領域にカテゴリのラベルを付けるセマンティックセグメンテーション（semantic segmentation）など、タスクごとに別々のモデルとアーキテクチャを使っていました。より最近の試みでは、アーキテクチャを共有してこれらのタスクを統一しようとしましたが、それでもタスクごとに別々の訓練が必要でした。

ここに登場する OneFormer は、こうした課題を克服する為に設計された汎用画像セグメンテーションのフレームワークです。独自のマルチタスク手法を導入し、セマンティック、インスタンス、パノプティックの各セグメンテーションタスクを、タスクごとに別々に訓練することなく、1つのモデルで処理出来ます。中核となる工夫は、タスク条件付き共同訓練です。モデルはタスク入力によって誘導され、訓練時も推論時も、異なるタスクに動的に対応出来ます。

この進歩により、訓練プロセスがシンプルになるだけでなく、様々なデータセットで既存のモデルを上回る性能が得られます。OneFormer は、全てのタスクに必要な正解情報を統一するパノプティックアノテーションを使うことでこれを実現しています。更に、このフレームワークは query-text 対照学習を導入し、タスク同士の区別をより明確にして、全体の性能を高めています。

OneFormer の背景

OneFormer 論文から引用した画像

OneFormer の重要性を理解する為に、画像セグメンテーションの背景を見ていきます。画像処理において、セグメンテーションは画像を異なる部分に分割する処理で、物体の認識やシーンの内容理解といったタスクに欠かせません。従来、セグメンテーションの主なタスクは2種類でした。1つはセマンティックセグメンテーション（semantic segmentation）で、ピクセルに「道路」や「空」のようなカテゴリのラベルを付けます。もう1つはインスタンスセグメンテーション（instance segmentation）で、明確な境界を持つ個々の物体を識別します。

その後、研究者らはセマンティックセグメンテーションとインスタンスセグメンテーションを統一する方法として、パノプティックセグメンテーション（panoptic segmentation）を提案しました。しかし、こうした進歩があっても課題は残りました。パノプティックセグメンテーション向けに設計された既存のモデルでも、タスクごとに別々の訓練が必要で、せいぜい半汎用にとどまっていたのです。

ここで OneFormer が状況を変えます。新しいアプローチとして、マルチタスクの汎用アーキテクチャを導入しました。考え方はシンプルです。このフレームワークを、1つの汎用アーキテクチャ、1つのモデル、1つのデータセットだけで、1回だけ訓練します。すると OneFormer は、セマンティック、インスタンス、パノプティックの各セグメンテーションタスクで、特化したフレームワークを上回ります。

この進歩は、単に精度が上がるという話ではありません。画像セグメンテーションをより汎用的で効率的なものにする点に意味があります。OneFormer があれば、タスクごとに大量のリソースを使って別々に訓練する必要は過去のものになります。

OneFormer の中核となる概念

OneFormer を際立たせている主な特徴を分解して見ていきます。

Task-Dynamic Mask

OneFormer は「Task-Dynamic Mask」という仕組みを使い、様々な画像セグメンテーションタスクに対応します。モデルに画像を入力すると、この仕組みによって、シーン全体に注目するのか、境界の明確な個々の物体を識別するのか、あるいは両方を組み合わせるのかを判断します。

Task-Conditioned Joint Training

OneFormer の大きな特徴の1つが、タスク条件付き共同訓練です。セマンティック、インスタンス、パノプティックの各セグメンテーションを別々に訓練するのではなく、訓練中に各タスクを一様にサンプリングします。この方法により、モデルは異なるセグメンテーションタスクをまとめて学習し、それらのタスクに対して汎化出来ます。タスクトークンを通じてモデルに処理対象のタスクを伝えることで、訓練の手順を統一し、タスクごとに専用のアーキテクチャやモデル、データセットを用意する必要性を減らします。その結果、訓練パイプラインを簡素化し、必要な計算資源も削減出来ます。

Query-Text Contrastive Loss

最後に、「Query-Text Contrastive Loss」について説明します。OneFormer がタスクやクラス同士の違いを自ら学ぶ為の方法、と考えて下さい。訓練プロセスでは、モデルは画像から取り出した特徴（クエリ）と、対応するテキスト記述（「車が写った写真」のようなもの）を比較します。これにより、モデルは各タスクの固有の特徴を理解し、異なるクラス同士の混同を減らせます。

OneFormer の「Task-Dynamic Mask」は、マルチタスクのアシスタントのように汎用的に振る舞えるようにするものです。そして「Query-Text Contrastive Loss」は、視覚的な特徴とテキスト記述を比べることで、各タスクの具体的な内容を学ぶ助けになります。

これらの中核となる概念を組み合わせることで、OneFormer は画像セグメンテーションの為の賢く効率的なツールになり、プロセスをより汎用的で身近なものにします。

まとめ

OneFormer 論文から引用した画像

まとめると、OneFormer フレームワークは画像セグメンテーション分野における画期的なアプローチです。様々な領域にわたってこのタスクをシンプルにし、統一することを目指しています。セグメンテーションタスクごとに特化したアーキテクチャに頼る従来の手法とは異なり、OneFormer は新しいマルチタスクの汎用アーキテクチャを導入しました。汎用データセットで1回だけ訓練した1つのモデルで、既存のフレームワークを上回ります。更に、訓練時に query-text 対照損失を取り入れることで、モデルがタスク間及びクラス間の違いを学習する能力が高まります。OneFormer は、コンピュータビジョンにおける最近の成功に着想を得た Transformer ベースのアーキテクチャを使い、タスクへの感度を高める為にタスク誘導クエリを導入しています。

結果は目覚ましく、OneFormer は ADE20k、Cityscapes、COCO といったベンチマークデータセットで、セマンティック、インスタンス、パノプティックの各セグメンテーションタスクにおいて最先端のモデルを上回ります。このフレームワークの性能は、新しい ConvNeXt 及び DiNAT バックボーンによって更に高まります。

要するに、OneFormer は汎用的で身近な画像セグメンテーションに向けた大きな一歩です。多様なセグメンテーションタスクを処理出来る1つのモデルを導入することで、このフレームワークはセグメンテーションプロセスを効率化し、必要なリソースを減らします。

モデルの使用例

モデルの使用例を見ていきます。DiNAT バックボーンには NATTEN ライブラリが必要で、インストールに時間が掛かる場合があります。

セグメンテーションの種類に応じた推論コードを次に示します。

from transformers import OneFormerProcessor, OneFormerForUniversalSegmentation
from PIL import Image
import requests
import matplotlib.pyplot as plt


def run_segmentation(image, task_type):
    """Performs image segmentation based on the given task type.

    Args:
        image (PIL.Image): The input image.
        task_type (str): The type of segmentation to perform ('semantic', 'instance', or 'panoptic').

    Returns:
        PIL.Image: The segmented image.

    Raises:
        ValueError: If the task type is invalid.
    """

    processor = OneFormerProcessor.from_pretrained(
        "shi-labs/oneformer_ade20k_dinat_large"
    )  # ここで1回だけ読み込みます
    model = OneFormerForUniversalSegmentation.from_pretrained(
        "shi-labs/oneformer_ade20k_dinat_large"
    )

    if task_type == "semantic":
        inputs = processor(images=image, task_inputs=["semantic"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_semantic_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]

    elif task_type == "instance":
        inputs = processor(images=image, task_inputs=["instance"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_instance_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]["segmentation"]

    elif task_type == "panoptic":
        inputs = processor(images=image, task_inputs=["panoptic"], return_tensors="pt")
        outputs = model(**inputs)
        predicted_map = processor.post_process_panoptic_segmentation(
            outputs, target_sizes=[image.size[::-1]]
        )[0]["segmentation"]

    else:
        raise ValueError(
            "無効なタスクの種類です。'semantic'、'instance'、'panoptic' のいずれかを指定してください"
        )

    return predicted_map


def show_image_comparison(image, predicted_map, segmentation_title):
    """Displays the original image and the segmented image side-by-side.

    Args:
        image (PIL.Image): The original image.
        predicted_map (PIL.Image): The segmented image.
        segmentation_title (str): The title for the segmented image.
    """

    plt.figure(figsize=(12, 6))
    plt.subplot(1, 2, 1)
    plt.imshow(image)
    plt.title("元の画像")
    plt.axis("off")
    plt.subplot(1, 2, 2)
    plt.imshow(predicted_map)
    plt.title(segmentation_title + " セグメンテーション")
    plt.axis("off")
    plt.show()


url = "https://huggingface.co/datasets/shi-labs/oneformer_demo/resolve/main/ade20k.jpeg"
response = requests.get(url, stream=True)
response.raise_for_status()  # HTTP エラーを確認します
image = Image.open(response.raw)

task_to_run = "semantic"
predicted_map = run_segmentation(image, task_to_run)
show_image_comparison(image, predicted_map, task_to_run)
