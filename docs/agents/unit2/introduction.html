Agentic フレームワーク入門

Unit 2 へようこそ。この Unit では、高度なエージェント型アプリケーションを構築する為に役立つ、様々なエージェントフレームワークを学びます。

学ぶ内容は次の通りです。

  • Unit 2.1: smolagents
  • Unit 2.2: LlamaIndex
  • Unit 2.3: LangGraph

早速始めましょう！

エージェントフレームワークを使うべき時

LLM を中心にしたアプリケーションを作る時、エージェントフレームワークが常に必要とは限りません。フレームワークを使うと、特定のタスクを効率よく解決出来るよう、ワークフローを柔軟に組み立てられます。但し、必ずしもフレームワークが必要な訳ではありません。

ユーザーのリクエストに応えるには、事前に決められたワークフローで十分なこともあり、エージェントフレームワークが本当に必要とは限りません。プロンプトを順につなぐ程度の単純な仕組みでエージェントを作るなら、フレームワークを使わず、通常のコードだけで十分な場合も有ります。その利点は、抽象化に頼らず、開発者がシステムを完全に制御し、理解出来ることです。

一方で、LLM に関数を呼び出させたり、複数のエージェントを使ったりしてワークフローが複雑になってくると、こうした抽象化が役に立ち始めます。

これらを踏まえると、必要になる機能が見えてきます。

  • システムを動かす LLM エンジン
  • エージェントがアクセス出来るツールのリスト
  • LLM の出力からツール呼び出しを抽出するパーサー
  • パーサーと同期したシステムプロンプト
  • メモリシステム
  • LLM のミスを制御する為のエラーログとリトライの仕組み

これらのテーマが、smolagents、LlamaIndex、LangGraph などの各種フレームワークでどう解決されているかを見ていきます。
