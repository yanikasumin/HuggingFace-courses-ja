拡散モデルの制御

DreamBooth

拡散モデルや GAN は多くのユニークな画像を生成できますが、常に正確に必要なものを生成できるとは限りません。そのため、モデルをファインチューニングする必要がありますが、通常は大量のデータと計算を必要とします。しかし、わずかな例だけでモデルをパーソナライズできる技術も存在します。

1つの例が Google Research の DreamBooth です。これは、被写体やスタイルの数枚の画像だけで学習して拡散モデル全体を更新する学習技術です。プロンプト中の特殊な単語を例の画像と関連付けることで動作します。DreamBooth の詳細は論文と Hugging Face の DreamBooth 学習ドキュメントにあります。

以下では、犬の4枚の画像で学習した DreamBooth の結果と、推論の例を見ることができます。 上の Hugging Face ドキュメントに従えば、この結果を再現できます。

この例から、モデルがその特定の犬について学習し、多様なポーズや背景でその犬の新しい画像を生成できることが明らかです。計算、データ、時間の面では改善されたものの、他の人々はモデルをカスタマイズするもっと効率的な方法を見つけました。

そこで登場するのが、現在この目的でもっとも人気のある方法、Low Rank Adaptation（LoRA）です。この方法はもともと、大規模言語モデルを効率的にファインチューニングするために Microsoft がこの論文で開発したものです。主なアイデアは、重みの更新行列を2つの低ランク行列に因数分解し、モデルの残りを凍結したまま、学習中にこれらを最適化するというものです。Hugging Face のドキュメントには、LoRA の仕組みについての優れた概念ガイドがあります。

では、これらのアイデアを組み合わせると、DreamBooth を使って少数の例で拡散モデルを LoRA によって効率的にファインチューニングできます。その方法を示した Google Colab ノートブックのチュートリアルがこちらにあります。

この方法の品質と効率のため、多くの人が独自の LoRA パラメータを作成しており、その多くは Civitai というウェブサイトや Hugging Face で見つけることができます。 Civitai では LoRA の重みをダウンロードでき、通常は 50〜500MB の範囲です。Hugging Face 版の場合は、モデルハブからモデルを直接読み込むことができます。 以下は、両方のケースで LoRA の重みを読み込み、モデルと融合する例です。

まず diffusers ライブラリをインストールすることから始めます。

pip install diffusers
````
`StableDiffusionXLPipeline` を初期化し、LoRA アダプタの重みを読み込みます。
```python
from diffusers import StableDiffusionXLPipeline
import torch

model = "stabilityai/stable-diffusion-xl-base-1.0"
pipe = StableDiffusionXLPipeline.from_pretrained(model, torch_dtype=torch.float16)
pipe.load_lora_weights(
    "lora_weights.safetensors"
)  # 重みファイルからインストールする場合
pipe.load_lora_weights(
    "ostris/crayon_style_lora_sdxl"
)  # リポジトリから直接 LoRA をインストールする場合
pipe.fuse_lora(lora_scale=0.8)

これにより、特に選択肢の多いモデルの中から、カスタマイズされた拡散モデルを素早く読み込んで推論に使うことができます。次に、LoRA の重みを取り除きたい場合は、pipe.unfuse_lora() を呼ぶとモデルは元の状態に戻ります。lora_scale パラメータについては、これは推論時に LoRA の重みをどれだけ使うかを制御するハイパーパラメータです。1.0 の値は LoRA の重みが完全に使われることを意味し、0.0 の値は LoRA の重みが全く使われないことを意味します。最良の値は多くの場合 0.7 から 1.0 の間ですが、ユースケースに最適な値を見つけるために異なる値を試してみる価値があります。

Hugging Face の LoRA モデルのいくつかは、この Gradio デモで試すことができます。

ControlNet によるガイド付き拡散

拡散モデルには、プロンプト、ネガティブプロンプト、ガイダンススケール、インペインティングなど、望ましい出力の生成をガイドする方法が数多くあります。ここでは、多くのバリエーションがあり、他のすべての方法と組み合わせることができる ControlNet と呼ばれる方法に焦点を当てます。これはスタンフォード大学のこの論文で導入されました。この方法を使うと、通常は深度、ポーズ、エッジなど非常に具体的な情報を保持する画像で拡散モデルをガイドできます。これにより、生成画像の一貫性が高まりますが、これは拡散モデルでしばしば問題となる点です。

ControlNet はテキストから画像への生成と、画像から画像への生成の両方で使えます。以下は、エッジ検出の条件付けで学習された ControlNet を使った text-to-image の例で、左上の画像が入力として使われています。 生成された画像すべてが非常に似た形をしていて、色だけが異なることが分かります。これは、ControlNet が入力画像と同じ形の画像を作るよう拡散モデルをガイドしているためです。

Stable Diffusion XL で ControlNet を実行するコードについては公式ドキュメントのこちらを参照してください。単に例を試してみたいだけなら、さまざまな種類の ControlNet を試せるこの Gradio デモを見てみてください。
