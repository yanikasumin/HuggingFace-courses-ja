はじめに

Chapter 3 では、テキスト分類のためにモデルをファインチューニングする方法を見てきました。この章では、従来の NLP モデルと最新の LLM の両方を扱ううえで欠かせない、次の一般的な言語タスクに取り組みます。

  • トークン分類
  • マスク言語モデリング（BERT など）
  • 要約
  • 翻訳
  • 因果言語モデリングによる事前学習（GPT-2 など）
  • 質問応答

これらの基本的なタスクは、大規模言語モデル（LLM）の仕組みの土台をなすものです。これらを理解することは、今日の最先端の言語モデルを効果的に扱ううえで欠かせません。
