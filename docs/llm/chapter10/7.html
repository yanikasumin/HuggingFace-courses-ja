章末クイズ

この章で学んだことをテストしましょう！

1. Argilla は何に使えますか？

Argilla を使ってデータセットにアノテーションを追加し、NLP タスクに利用できます。
これは Argilla の機能ではありません。ただし、公開ウェブサイトをスクレイピングし、Python SDK を使ってアノテーション用の Argilla データセットに変換することはできます。
以前のアノテーションを提案として使い、それを修正することでデータセットの質を向上させられます。
Argilla のさまざまな質問タイプを使って、既存のデータセットを自分の用途に合わせて調整できます。
Argilla の中で直接モデルを学習させることはできませんが、Argilla で整備したデータを使って自分のモデルを学習させることはできます。
合成データセットの生成には distilabel パッケージを使用し、生成したデータの確認や整備には Argilla を利用できます。

2. Argilla は Hugging Face Spaces と Hugging Face Datasets でのみ動作します。

Argilla は Docker を使ってローカルにデプロイすることもできますし、Python SDK を使えば Hugging Face Datasets を含むあらゆる種類のデータをアップロードできます。
Argilla は Docker を使ってローカルにデプロイすることもできますし、Python SDK を使えば Hugging Face Datasets を含むあらゆる種類のデータをアップロードできます。

3. Python SDK を Argilla サーバーに接続するには、Hugging Face のトークンが必要です。

これは、Argilla Space が非公開（プライベート）の場合にのみ必要です！
公開されている Argilla Space や、Docker によるローカルデプロイを使っている場合は、トークンは不要です。

4. Argilla における fields（フィールド） とは何ですか？フィールドはいくつ使えますか？

必要に応じて、情報を複数のフィールドに分けることができます。
はい、複数のフィールドを持つことができ、アノテーションするデータの種類に応じて、異なるタイプ（text、chat、image など）のフィールドも使えます。
データセットにはフィールドとメタデータの両方を持てますが、それぞれ目的が異なります。メタデータは追加情報としてフィルタリングや並べ替えに使われ、フィールドはアノテーション対象のデータを表示します。

5. トークン分類タスクに最適な質問タイプはどれですか？

SpanQuestion では、テキストの一部をハイライトしてラベルを付けることができます。トークン分類タスクに最適なタイプです。
このタイプの質問では、レコード全体に適用されるラベルを選択できます。テキスト分類タスクに最適なタイプです。
このタイプの質問では、テキストを記述できます。トークン分類タスクには適していません。
SpanQuestion では、テキストの一部をハイライトしてラベルを付けることができます。トークン分類タスクに最適なタイプです。

6. 「Save as draft」ボタンの目的は何ですか？

このボタンはレスポンスを保存しますが、送信はしません。
これは、Hub から Hugging Face モデルを読み込むための正しい方法です。
もう一度考えてみましょう。'demos' プレフィックスを使ってもモデルは読み込めません。

7. Argilla は提案ラベルを自動では提供しません。そのデータは自分で用意する必要があります。

プロジェクトのどの時点でも、レコードに提案を追加（または更新）できます。
提案ラベルを表示したい場合は、レコード作成時か、それ以降の時点で自分で登録する必要があります。

8. Argilla データセット全体を Hub にエクスポートするために必要なステップをすべて選んでください。

はい、サーバーを操作するには、まずインスタンス化する必要があります。
いいえ。これは、Hub から自分の Argilla インスタンスにデータセットをインポートするためのものです。
はい、その後の操作にはこれが必要です。
データセット全体をエクスポートする場合は、これは不要です。Argilla が代わりに処理してくれます。ただし、レコードの一部だけを扱う場合は必要になるかもしれません。
これにより、指定したリポジトリ ID にデータセットがプッシュされます。リポジトリが存在しない場合は新規に作成されます。
