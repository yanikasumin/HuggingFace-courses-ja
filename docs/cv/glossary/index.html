用語集

この用語集は日本語版独自の補足です。原典には含まれていません。本文を読む際の助けとして、平易な言葉で説明しています。

コンピュータビジョン
画像や動画から情報を読み取る技術分野。分類、検出、分割などが中心タスクです。
畳み込み（コンボリューション）
画像に小さなフィルタを滑らせて特徴を取り出す演算。CNNの核です。
CNN（畳み込みニューラルネットワーク）
畳み込み層を中心とした、画像処理向けのニューラルネットワークです。
特徴量
画像の中の角や模様など、識別に役立つ情報。古典手法では人が設計し、深層学習では自動で学びます。
転移学習
大規模データで学習済みのモデルを、別のタスクに流用して追加学習することです。
物体検出
画像の中の物体の位置（枠）と種類を同時に当てるタスクです。
セグメンテーション
画像のすべてのピクセルに意味のラベルを付けるタスクです。
Vision Transformer（ViT）
画像をパッチに分割し、Transformer で処理するモデルです。
パッチ
ViT が画像を切り分ける小さな正方形の断片。トークンのように並べて処理します。
CLIP
画像とテキストを同じ空間に埋め込み、対応関係を学習したマルチモーダルモデルです。
マルチモーダル
テキスト、画像、音声など、複数の種類のデータを扱うことです。
拡散モデル（ディフュージョン）
ノイズから少しずつ画像を復元する過程を学習した生成モデルです。
GAN（敵対的生成ネットワーク）
生成器と識別器を競わせて学習する生成モデルです。
VAE（変分オートエンコーダ）
データを潜在空間に圧縮し、そこから生成もできるモデルです。
NeRF
様々な角度の画像から3D空間の見え方を学習し、新しい視点の画像を作る技術です。
ゼロショット学習
学習時に見たことのないクラスを、テキストの説明などをもとに識別することです。
合成データ
実データの代わりに、CGや生成モデルで人工的に作った学習データです。
デプロイ向けのモデル最適化
量子化や枝刈りなどで、モデルを小さく速くして実環境で動かす工夫です。
