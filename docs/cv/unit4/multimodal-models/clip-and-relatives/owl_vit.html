マルチモーダル物体検出（OWL-ViT）

はじめに

物体検出はコンピュータービジョンの重要なタスクであり、YOLO のようなモデル（原論文、最新のコード版）によって大きな進歩を遂げてきました。しかし、YOLO のような従来のモデルには、学習データセットの外にある物体を検出するうえで限界があります。これに対処するため、AI コミュニティは、より広い範囲の物体を特定できるモデルの開発へと移行し、物体検出のための CLIP のようなモデルの創出につながりました。

OWL-ViT: 強化点と能力

OWL-ViT は、オープンボキャブラリ物体検出における飛躍的な進歩を表しています。CLIP と同様の学習段階から始まり、対照損失を使った視覚エンコーダと言語エンコーダに焦点を当てます。この基礎段階により、モデルは視覚データとテキストデータの共有表現空間を学習できます。

物体検出のためのファインチューニング

OWL-ViT の革新は、物体検出のためのファインチューニング段階で現れます。ここでは、CLIP で使われるトークンのプーリングと最終投影層の代わりに、OWL-VIT は各出力トークンの線形投影を用いて、物体ごとの画像埋め込みを取得します。これらの埋め込みは分類に使われ、ボックス座標はトークン表現から小さな MLP を通じて導かれます。このアプローチにより、OWL-ViT は画像内の物体とその空間位置を検出でき、従来の物体検出モデルに対する大きな進歩となっています。

オープンボキャブラリ検出

ファインチューニング後、OWL-ViT はオープンボキャブラリ物体検出に優れた性能を示します。視覚エンコーダとテキストエンコーダの共有埋め込み空間のおかげで、学習データセットに明示的に存在しない物体も特定できます。この能力により、物体検出に画像とテキストクエリの両方を使うことが可能になり、多用途性が高まります。

使用例

実際の応用では、通常、テキストをクエリとして使い、画像を文脈として使います。次の Python の例は、OWL-ViT で推論を実行するために transformers ライブラリを使う方法を示しています。

import requests
from PIL import Image, ImageDraw
import torch
from transformers import OwlViTProcessor, OwlViTForObjectDetection

processor = OwlViTProcessor.from_pretrained("google/owlvit-base-patch32")
model = OwlViTForObjectDetection.from_pretrained("google/owlvit-base-patch32")

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)
texts = [["a photo of a cat", "a photo of a dog", "remote control", "cat tail"]]
inputs = processor(text=texts, images=image, return_tensors="pt")
outputs = model(**inputs)

target_sizes = torch.Tensor([image.size[::-1]])
results = processor.post_process_object_detection(
    outputs=outputs, target_sizes=target_sizes, threshold=0.1
)
i = 0  # 対応するテキストクエリについて、最初の画像の予測を取得する
text = texts[i]
boxes, scores, labels = results[i]["boxes"], results[i]["scores"], results[i]["labels"]

# 描画オブジェクトを作成する
draw = ImageDraw.Draw(image)

# 各バウンディングボックスを描画する
for box, score, label in zip(boxes, scores, labels):
    box = [round(i, 2) for i in box.tolist()]
    print(
        f"Detected {text[label]} with confidence {round(score.item(), 3)} at location {box}"
    )
    # 画像にバウンディングボックスを描画する
    draw.rectangle(box, outline="red")

まとめ

物体検出に対する OWL-ViT のアプローチは、AI モデルが視覚世界を理解し、やり取りする方法における注目すべき転換を表しています。言語理解と視覚知覚を統合することで、物体検出の境界を押し広げ、より広い範囲の物体を特定できる、より正確で多用途なモデルを可能にします。モデル能力のこの進化は、特に動的で実世界の環境において、視覚シーンへの微妙な理解を必要とする応用にとって重要です。

より詳しい情報と技術的な詳細は、OWL-VIT 論文 を参照してください。OWL-ViT 2 モデル についての情報も Hugging Face ドキュメントで確認できます。
