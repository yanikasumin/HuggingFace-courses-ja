# Gradio Blocks パーティー[[gradio-blocks-party]]

コースで Gradio を扱う章の公開に合わせて、Hugging Face は、新しい Gradio Blocks 機能を使って魅力的な機械学習デモを制作するコミュニティイベントを開催しました。

コミュニティが作成したデモはすべて、Hub 上の [`Gradio-Blocks`](https://huggingface.co/Gradio-Blocks) オーガニゼーションで見ることができます。受賞作品の中から、いくつかをご紹介します。
