Zero-shot Learning

入門の章に続いて、次にゼロショット学習（ZSL）をより詳しく説明します。この章では次を扱います。 - さまざまな種類の ZSL の定義と、それらの違い。
- 意味埋め込み（semantic embeddings）を用いる ZSL の詳しい例 [1]。

Zero-shot Learning vs. Generalized Zero-shot Learning

ゼロショット学習と一般化ゼロショット学習（GZSL）は、画像分類モデルが訓練に含まれていないラベルを分類しなければならない機械学習アルゴリズムの種類に属します。ZSL と GZSL は非常によく似ており、主な違いはモデルの評価方法にあります [2]。

ZSL では、モデルは未知のクラスの画像を分類する能力についてのみ評価されます。ZSL のテストデータセットには、未知のクラスの観測のみが含まれます。GZSL では、モデルは既知のクラスと未知のクラスの両方で評価されます。これは現実世界のユースケースにより近いと考えられます。全体として、GZSL は、観測が新しいクラスに属するのか既知のクラスに属するのかをモデルが判断しなければならない分、より困難です。

Inductive Zero-shot Learning vs. Transductive Zero-shot Learning

訓練データの種類に基づいて、ゼロショット学習には2つの種類があります。

帰納的（inductive）ZSL では、モデルは既知のクラスのみを含むデータセットだけで訓練され、未知のクラスのデータには一切アクセスしません。学習プロセスは、訓練データからパターンを抽出して汎化することに焦点を当て、それを未知のクラスのインスタンスの分類に適用します。このアプローチは、訓練時に既知データと未知データが明確に分離されていることを前提とし、訓練データから未知のクラスへ汎化するモデルの能力を重視します。

伝達的（transductive）ZSL は、訓練時にモデルが未知のクラスに関する何らかの情報にアクセスできる点が異なります。通常は未知のクラスの属性やラベルなしの例ですが、ラベルは含まれません。このアプローチは、未知データの構造に関する追加の情報を活用して、より汎化可能なモデルを訓練します。

次のセクションでは、Google の古典的な研究論文 [1] の主概念に沿って、帰納的 ZSL の例を取り上げます。

Zero-shot Learning Example with Semantic Embeddings

前の章で述べたように、成功する ZSL モデルを開発するには、画像とクラスラベルだけでは不十分です。画像だけに基づいて未知のクラスを分類することは、ほぼ不可能です。ZSL は、意味属性や埋め込みのような補助情報を利用して、未知のクラスの画像の分類を助けます。詳細に入る前に、この用語に不慣れな読者のために、意味埋め込みについて短く紹介します。

What are Semantic Embeddings?

意味埋め込み（Semantic embeddings）は、データの意味と解釈を担う意味情報のベクトル表現です。たとえば、話し言葉で伝えられる情報は、意味情報の一種です。意味情報には、単語や文の直接的な意味だけでなく、文脈的・文化的な含意も含まれます。

埋め込みとは、意味情報を実数のベクトルへ写像するプロセスを指します。意味埋め込みは、Word2Vec [3] や GloVe [4] のような教師なし機械学習モデルで学習されることがよくあります。単語、句、文など、あらゆる種類のテキスト情報は、定められた手順に基づいて数値ベクトルに変換できます。意味埋め込みは、単語間の距離と方向がその意味関係を反映する高次元空間で単語を記述します。これにより、機械は単語埋め込みに対する数学的演算によって、各単語の用法、同義語、文脈を理解できます。

Enable Zero-shot Learning with Semantic Embeddings

訓練中、ZSL モデルは、既知のクラスの画像の視覚的特徴を、対応する意味埋め込みと結びつけることを学習します。目的は、画像の射影された視覚的特徴と、そのクラスの意味埋め込みとの間の距離を最小化することです。このプロセスは、モデルが画像と意味情報の対応関係を学習する助けとなります。

モデルは画像の特徴を意味空間へ射影することを学習しているため、未知のクラスの画像の特徴を同じ空間へ射影し、未知のクラスの埋め込みと比較することで、未知のクラスの画像の分類を試みることができます。未知のクラスの画像については、モデルはその射影された埋め込みを計算し、未知のクラスの中から最も近い意味埋め込みを探索します。埋め込みが最も近い未知のクラスが、その画像の予測ラベルとなります。

まとめると、意味埋め込みは ZSL の中心にあり、モデルがその分類能力を拡張できるようにします。このアプローチにより、ラベル付きデータセットを必要とせずに、膨大な量の現実世界のカテゴリを分類する、より柔軟でスケーラブルな方法が可能になります。

Comparison to CLIP

ZSL と CLIP（Contrastive Language–Image Pre-training）[5] の関係は、訓練データに存在しなかったカテゴリの画像を認識・分類できるようにするという共通の目標に由来します。しかし、CLIP は ZSL の基礎にある原則の大きな進歩であり、より広い応用でもあります。新規な学習と汎化のアプローチを活用しています。

ZSL と CLIP の関係は次のように説明できます。

  • ZSL と CLIP はどちらも、訓練時に見ていないクラスへ画像を分類することを目指します。しかし、従来の ZSL アプローチが、既知と未知のクラスの間のギャップを埋めるために事前に定義された意味埋め込みや属性に依存するかもしれないのに対し、CLIP は自然言語の記述から直接学習し、タスク固有の埋め込みを必要とせずに、はるかに広い範囲のタスクへ汎化できます。

  • CLIP は、モデルがテキストデータと視覚データの両方から学習するマルチモーダル学習の代表例です。このアプローチは、分類性能を改善するために補助情報を使う ZSL と一致します。CLIP は、生のテキストと画像から直接学習することでこの概念をさらに進め、視覚コンテンツと記述言語の間の関係を理解し表現できるようにします。

Zero-shot Learning Evaluation Datasets

新しい ZSL の手法は毎年提案されており、評価方法が異なるため、優れたアプローチを特定するのは困難です。さまざまな ZSL 手法を評価するには、標準化された評価フレームワークとデータセットが好まれます。古典的な ZSL 手法の比較研究は [6] に示されています。ZSL の評価によく使われるデータセットには次のものがあります。

  • Animal with Attributes (AwA)

転移学習アルゴリズム、特に属性ベースの分類をベンチマークするためのデータセット [7]。50の動物クラスの画像30475枚で構成され、各画像に6種類の特徴表現が付いています。

  • Caltech-UCSD-Birds-200-2011（CUB）

きめ細かい視覚分類タスクのためのデータセット。200の鳥のサブカテゴリの画像11788枚を含みます。各画像には、1つのサブカテゴリラベル、15の部位位置、312のバイナリ属性、1つのバウンディングボックスがあります。また、各画像について10文の記述が、Amazon の Mechanical Turk を通じて収集されており、その記述はサブカテゴリ情報を含まないよう注意深く構成されています。

  • Sun database（SUN）

最初の大規模なシーン属性データベース。このデータセットは、899カテゴリの画像130519枚で構成され、高レベルのシーン理解ときめ細かいシーン認識に使えます。

  • Attribute Pascal and Yahoo dataset（aPY）

3つの大まかなカテゴリ（動物、物体、乗り物）から構成され、合計32のサブカテゴリにさらに分割された、粗い粒度のデータセットで、15339枚の画像からなります。

  • ILSVRC2012/ILSVRC2010（ImNet-2）

ImageNet Large Scale Visual Recognition Challenge（ILSVRC）は、大規模な物体検出と画像分類のアルゴリズムを評価します [8]。
