# 🤗 Model Context Protocol（MCP）コースへようこそ

![MCP コースのサムネイル](https://huggingface.co/datasets/mcp-course/images/resolve/main/unit0/1.png)

今、AI の世界で最も盛り上がっている話題といえば、**Model Context Protocol（MCP）**です。MCP コースへようこそ！

[Anthropic](https://www.anthropic.com) と共同で制作したこの無料コースでは、MCP の仕組みを理解し、活用し、MCP を使ったアプリケーションを構築するまでを、**初心者が十分な知識を身につけられるよう**段階的に学べます。

この最初のユニットは、コースを始めるための準備編です。

* **コースのシラバス**を確認します。
* **認定プロセスとスケジュールについて詳しく**説明します。
* コース制作チームを紹介します。
* **アカウント**を作成します。
* **Discord サーバーに参加して**、受講生同士や私たちと交流しましょう。

さあ、始めましょう！

## このコースで学べること

このコースでは、次のことを行います。

* 📖 Model Context Protocol を**理論・設計・実践**の面から学ぶ
* 🧑‍💻 **既存の MCP SDK やフレームワークの使い方**を学ぶ
* 💾 **自分のプロジェクトを共有し**、コミュニティが作ったアプリケーションを探索する
* 🏆 **自分の MCP 実装を他の受講生の実装と比較・評価する**チャレンジに参加する
* 🎓 課題をこなして**修了証を取得する**

その他にも盛りだくさんです！

コース修了時には、**MCP の仕組みを理解し、最新の MCP 標準を使って外部データやツールを活用する AI アプリケーションを自分で構築できる**ようになります。

[**コースへの登録**](https://huggingface.co/mcp-course)も忘れずに！

## コースの構成

コースは次の要素で構成されています。

* _基礎ユニット_：MCP の**概念を理論的に**学びます。
* _ハンズオン_：**既存の MCP SDK の使い方**を学び、アプリケーションを構築します。ハンズオンのセクションには、あらかじめ設定済みの環境が用意されています。
* _ユースケース課題_：学んだ概念を応用して、自分で選んだ現実の課題を解決します。
* _コラボレーション_：Hugging Face のパートナーと協力し、最新の MCP 実装やツールを紹介します。

この**コースは、皆さんのフィードバックや貢献を受けて、更新され続けるプロジェクト**です！GitHub で Issue や PR を気軽に作成したり、Discord サーバーでの議論に参加したりしてください。

## シラバス

以下は**コースの大まかなシラバス**です。各ユニットの公開に合わせて、より詳しいトピック一覧も公開します。

| 章 | トピック | 内容 |
| ------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 0       | オンボーディング                                  | 使用するツールやプラットフォームのセットアップを行います。                                                             |
| 1       | MCP の基礎、アーキテクチャ、コアコンセプト | Model Context Protocol のコアコンセプト、アーキテクチャ、コンポーネントを解説します。MCP を使ったシンプルなユースケースも紹介します。       |
| 2 | エンドツーエンドのユースケース：MCP の実践 | コミュニティに共有できる、シンプルなエンドツーエンドの MCP アプリケーションを構築します。 |
| 3 | MCP の実践：アプリケーションのデプロイ | Hugging Face エコシステムとパートナーのサービスを使って、MCP アプリケーションを構築し、デプロイします。 |

## 前提条件

このコースを受講するには、次の知識があるとよいでしょう。

* AI と LLM の概念に関する基礎的な理解
* ソフトウェア開発の基本的な考え方や API の概念を知っていること
* 少なくとも1つのプログラミング言語を使った経験（コースでは Python または TypeScript を使った例を紹介します）

これらがなくても心配いりません！役立つリソースを紹介します。

* [LLM コース](https://huggingface.co/learn/llm-course/)では、LLM の使い方や、LLM を活用した開発の基礎を学べます。
* [Agents コース](https://huggingface.co/learn/agents-course/)では、LLM を使った AI エージェントの構築を学べます。

> [!TIP]
> 上記のコース自体は前提条件ではありません。LLM やエージェントの概念を理解していれば、今すぐコースを始められます！

## 必要なもの

必要なものは2つだけです。

* インターネットに接続できる*コンピューター*
* _アカウント_：コースのリソースにアクセスしたり、プロジェクトを作成したりするために必要です。まだお持ちでなければ、[無料でアカウントを作成](https://huggingface.co/join)できます。

## 認定プロセス

このコースは、*聴講モード*で受講することも、課題に取り組んで*発行予定の2種類の修了証のうち1つを取得する*こともできます。聴講だけの場合も、すべてのチャレンジに参加でき、希望すれば課題にも取り組めます。**私たちへの連絡も不要です**。

認定プロセスは**完全に無料**です。

* _基礎の認定を取得するには_：コースの Unit 1 を修了する必要があります。完成したアプリケーションを構築せずに、MCP の最新動向を把握したい受講生向けです。
* _修了証を取得するには_：ユースケースを扱う Unit 2 と Unit 3 を修了する必要があります。完成したアプリケーションを構築し、コミュニティで共有したい受講生向けです。
