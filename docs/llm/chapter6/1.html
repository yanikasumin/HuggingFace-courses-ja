はじめに

Chapter 3 では、モデルを特定のタスク向けにファインチューニングする方法を見ました。その際は、モデルが事前学習で使ったのと同じトークナイザを使いました。では、モデルをゼロから学習させたい場合はどうすればよいのでしょうか。この場合、別のドメインや言語のコーパスで事前学習されたトークナイザを使うのは、たいてい最適ではありません。たとえば、英語コーパスで学習したトークナイザは、空白や句読点の使い方が大きく異なる日本語のテキストコーパスでは、うまく機能しません。

この章では、テキストのコーパスでまったく新しいトークナイザを学習し、それを使って言語モデルを事前学習できるようにする方法を学びます。これらの作業には、🤗 Transformers ライブラリの「高速」トークナイザを支える 🤗 Tokenizers ライブラリを使用します。このライブラリが提供する機能を詳しく見て、高速トークナイザが「低速」版とどう違うのかを探ります。

この章で扱うトピックは次のとおりです。

  • あるチェックポイントで使われているトークナイザと似た新しいトークナイザを、新しいテキストコーパスで学習する方法
  • 高速トークナイザの特別な機能
  • 現在 NLP で使われている3つの主要なサブワードトークン化アルゴリズムの違い
  • 🤗 Tokenizers ライブラリを使ってトークナイザをゼロから構築し、データで学習する方法

この章で学ぶ手法は、Chapter 7 で Python ソースコード向けの言語モデルを構築する際の基礎になります。まず、トークナイザを「学習する」とはそもそもどういうことかを見ていきましょう。
