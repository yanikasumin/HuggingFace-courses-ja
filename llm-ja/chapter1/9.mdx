事前学習済みモデルやそのファインチューニング版を本番環境で使おうと考えているなら、これらのモデルは強力なツールである一方で、限界も伴うことを意識しておいてください。最大の限界は、事前学習の進め方にあります。大量のデータで事前学習できるようにするため、研究者は見つけられるコンテンツをすべてかき集めることが多く、インターネット上にある最良のものも最悪のものも取り込んでしまうのです。

簡単な例として、BERT モデルを使った `fill-mask` パイプラインの例に戻りましょう。

```python
from transformers import pipeline

unmasker = pipeline("fill-mask", model="bert-base-uncased")
result = unmasker("This man works as a [MASK].")
print([r["token_str"] for r in result])

result = unmasker("This woman works as a [MASK].")
print([r["token_str"] for r in result])
```

```python out
['lawyer', 'carpenter', 'doctor', 'waiter', 'mechanic']
['nurse', 'waitress', 'teacher', 'maid', 'prostitute']
```

これら2つの文の空欄を埋めるよう求められたとき、モデルが返す答えのうちジェンダーフリーなものは1つだけです（waiter/waitress）。それ以外は、通常はどちらか一方のジェンダーと結びつけられる職業です。実際に、"woman"（女性）と "work"（仕事）に対する上位5候補の中に、prostitute（売春婦）が入ってしまいました。BERT は、インターネット中からデータをかき集めて作られたわけではない、数少ない Transformer モデルの1つです。一見中立的なデータ（[英語版 Wikipedia](https://huggingface.co/datasets/wikipedia)と [BookCorpus](https://huggingface.co/datasets/bookcorpus) データセット）で学習されているにもかかわらず、こうした結果になってしまうのです。

したがって、これらのツールを使うときは、使っている元のモデルが、性差別的、人種差別的、あるいは同性愛嫌悪的なコンテンツを非常にたやすく生成しうるということを、念頭に置いておく必要があります。自分のデータでモデルをファインチューニングしても、この本質的なバイアスが消えることはありません。
