（任意）Discord 101

このガイドは、ゲームや ML のコミュニティで人気の無料チャットサービス「Discord」を初めて使う人の為の入門ガイドです。

こちらをクリックして、メンバーが100,000人を超える Hugging Face コミュニティの Discord サーバーに参加しましょう。他の人とつながるのに最適な場所です！

Hugging Face の Discord コミュニティに在る Agents コースのチャンネル

Discord を初めて使うと、少し戸惑うかもしれません。そこで、迷わず利用出来るように簡単なガイドを用意しました。

HF コミュニティサーバーには、様々な分野に興味を持つ人々が集まっています。論文について議論したり、イベントに参加したりしながら学ぶことが出来ます。

登録したら、#introduce-yourself チャンネルで自己紹介してください。

Agents コース用に4つのチャンネルを用意しました。

  • agents-course-announcements：コースの最新情報用。
  • 🎓-agents-course-general：一般的な議論や雑談用。
  • agents-course-questions：質問したり、クラスメイトを助けたりする為のもの。
  • agents-course-showcase：自信作のエージェントを披露する為のもの。

あわせて、次もチェック出来ます。

  • smolagents：ライブラリに関する議論とサポート用。

Discord を効果的に使う為のヒント

サーバーへの参加方法

Discord にあまり慣れていない場合は、サーバーへの参加方法についてのガイドを確認するとよいでしょう。

手順の概要は次の通りです。

  1. 招待リンクをクリックする。
  2. Discord アカウントでサインインする（アカウントがなければ作成する）。
  3. AIエージェントではないことを確認する！
  4. ニックネームとアバターを設定する。
  5. 「Join Server」をクリックする。

Discord の効果的な使い方

Discord を効果的に使う為のヒントをいくつか紹介します。

  • ボイスチャンネルも使えますが、テキストチャットのほうが一般的です。
  • Markdown 形式でテキストを装飾出来、特にコードを書く時に便利です。但し、Markdown はリンクにはあまり向いていません。
  • 長い会話ではスレッドを開くと、議論が整理されて便利です。

このガイドが役立てば幸いです！質問があれば、Discord で気軽に聞いてください。
