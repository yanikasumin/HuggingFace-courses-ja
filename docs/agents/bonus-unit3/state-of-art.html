ゲームにおける LLM 活用の最先端

この分野でどれほどの進歩があったか分かるように、ゲームへの LLM 統合を紹介する 3 つの技術デモと、実際に発売された 1 つのゲームを検証します。

🕵️‍♂️ NVIDIA と Inworld AI による Covert Protocol

GDC 2024 で発表された Covert Protocol は、私立探偵になりきってプレイする技術デモです。

このデモで興味深いのは、AI を搭載した NPC がプレイヤーの問いかけにリアルタイムで応答し、そのやり取りに応じて物語に影響を与える点です。

このデモは Unreal Engine 5 上に構築され、NVIDIA の Avatar Cloud Engine (ACE) と Inworld の AI を活用して、生き生きとしたキャラクターとのやり取りを実現しています。

詳しくはこちら 👉 Inworld AI Blog

🤖 Ubisoft の NEO NPCs

同じく GDC 2024 で、Ubisoft が生成 AI を搭載した NPC を紹介するプロトタイプ NEO NPCs を発表しました。

これらのキャラクターは、周囲の環境を知覚し、過去のやり取りを記憶し、プレイヤーと有意義な会話を交わせます。

ここでの狙いは、プレイヤーが NPC と真に交流できる、より没入感のある応答性の高いゲーム世界を作ることです。

詳しくはこちら 👉 Inworld AI Blog

⚔️ NVIDIA の ACE を搭載した Mecha BREAK

マルチプレイヤーのメカバトルゲーム Mecha BREAK は、NVIDIA の ACE テクノロジーを統合し、AI を搭載した NPC に命を吹き込んでいます。

プレイヤーは自然言語でこれらのキャラクターと交流でき、NPC は GPT-4o との統合により、ウェブカメラを通してプレイヤーや物体を認識できます。この革新により、より没入感のある、インタラクティブなゲーム体験が期待できます。

詳しくはこちら 👉 NVIDIA Blog

🧛‍♂️ Proxima Enterprises の Suck Up!

最後に紹介する Suck Up! は、発売済みのゲームです。プレイヤーはヴァンパイアとなり、AI を搭載した NPC を説得して家に招き入れてもらうことを目指します。

各キャラクターは生成 AI によって駆動されており、ダイナミックで予測不能なやり取りが楽しめます。

詳しくはこちら 👉 Suck Up! Official Website
