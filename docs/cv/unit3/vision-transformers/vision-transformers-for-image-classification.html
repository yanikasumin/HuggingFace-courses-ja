画像分類の為の Vision Transformer の転移学習とファインチューニング

はじめに

Transformer アーキテクチャは、自然言語処理の分野で大規模化しても良好な性能を示しました。そこで、同じアーキテクチャを画像にも適用する試みが生まれました。画像を小さなパッチに分割し、それぞれをトークンとして扱う方法です。こうして生まれたのが Vision Transformer（ViT）です。転移学習とファインチューニングについて学ぶ前に、畳み込みニューラルネットワーク（CNN）と Vision Transformer を比較してみましょう。

Vision Transformer（VT）の概要

Vision Transformer では、画像を小さなパッチに分割し、それらを2次元の格子状に並んだ要素として扱います。モデルは、こうして分割したパッチから特徴を学習します。

但し、落とし穴があります。CNN は、VT には無い前提を基に設計されています。その前提は、人間が画像の中の物体をどのように知覚するかに関わるものです。次のセクションで説明します。

CNN と Vision Transformer の違いは何ですか？

帰納バイアス

帰納バイアスは機械学習の用語です。学習アルゴリズムが予測を行う為に使う前提の集合を指します。簡単に言えば、帰納バイアスは近道のようなものです。これまでに見た情報を基に、機械学習モデルが根拠の有る推測を行う助けになります。

CNN で見られる帰納バイアスには、次のようなものがあります。

  • 並進同変性：物体は画像のどこに現れてもよく、CNN はその特徴を検出出来ます。
  • 局所性：画像のピクセルは、主に周辺のピクセルと相互作用して特徴を形成します。

CNN は、この2つの帰納バイアスを構造として備えています。一方、ViT には同じ前提がありません。その為、学習データが一定の規模に達するまでは、CNN の方が ViT より高い性能を示します。

しかし、ViT には別の強みがあります。Transformer アーキテクチャは（主に）異なる種類の線形関数で構成されています。その為、ViT は拡張性が非常に高くなります。そしてその拡張性によって、膨大な量のデータを使えば、上記の2つの帰納バイアスを持たないという問題を克服出来ます。

では、誰もが大規模なデータセットを利用出来るのでしょうか？

優れた性能を得る為に何百万枚もの画像で Vision Transformer を学習させることは、誰にでも出来ることではありません。代わりに、Hugging Face Hub のような場所で公開されているモデルの重みを利用出来ます。

事前学習済みモデルをどう使うのでしょうか。転移学習を適用してファインチューニングします。

画像分類の為の転移学習とファインチューニング

転移学習の考え方はシンプルです。非常に大規模なデータセットで学習した Vision Transformer が獲得した特徴を活用し、その特徴を自分のデータセットに適用します。これにより、モデルの性能が大きく向上することがあります。特に、学習に使えるデータが限られているデータセットでは効果的です。

学習済みの特徴を活用する為、モデル全体を更新する必要もありません。重みの大部分を凍結し、一部の層だけを学習すれば、学習時間や GPU の使用量を抑えながら、優れた性能を得られます。
