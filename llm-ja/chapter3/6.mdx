# ファインチューニング、チェック！[[fine-tuning-check]]

<CourseFloatingBanner
    chapter={3}
    classNames="absolute z-10 right-0 top-0"
/>

盛りだくさんの内容でした！最初の2章ではモデルとトークナイザについて学びました。この章では、最新のベストプラクティスに沿って、自分のデータでそれらをファインチューニングする方法を身につけました。この章で学んだことを振り返りましょう。

* [Hub](https://huggingface.co/datasets) 上のデータセットと、最新のデータ処理手法について学びました
* 動的パディングやデータコレータの使い方を含め、データセットを効率よく読み込んで前処理する方法を学びました
* 最新機能を備えた高レベルな `Trainer` API を使って、ファインチューニングと評価を実装しました
* PyTorch で完全なカスタムトレーニングループを一から実装しました
* 🤗 Accelerate を使って、トレーニングコードが複数の GPU や TPU でそのまま動作するようにしました
* 混合精度トレーニングや勾配累積といった最新の最適化手法を適用しました

> [!TIP]
> 🎉 **おめでとうございます！** Transformer モデルをファインチューニングする基礎を習得しました。これで実践的な ML プロジェクトに取り組む準備が整いました！
>
> 📖 **さらに学ぶには**: 知識を深めるためのリソースを紹介します。
> - 具体的な NLP タスクについては [🤗 Transformers のタスクガイド](https://huggingface.co/docs/transformers/main/en/tasks/sequence_classification)
> - 充実したノートブック集については [🤗 Transformers のサンプル](https://huggingface.co/docs/transformers/main/en/notebooks)
>
> 🚀 **次のステップ**: 
> - 学んだ手法を使って、自分のデータセットでファインチューニングに挑戦してみましょう
> - [Hugging Face Hub](https://huggingface.co/models) にあるさまざまなモデルアーキテクチャを試してみましょう
> - [Hugging Face コミュニティ](https://discuss.huggingface.co/) に参加して、プロジェクトを共有したり、助けを得たりしましょう

🤗 Transformers を使う旅は、まだ始まったばかりです。次の章では、モデルとトークナイザをコミュニティと共有し、広がり続ける事前学習済みモデルのエコシステムに貢献する方法を見ていきます。

ここで身につけたスキル、つまりデータの前処理、トレーニングの設定、評価、最適化は、あらゆる機械学習プロジェクトの基礎となります。テキスト分類、固有表現認識、質問応答、そのほかどんな NLP タスクに取り組む場合でも、これらの手法が役に立つはずです。
