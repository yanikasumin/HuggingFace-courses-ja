AMD NPU と iGPU アクセラレーションによるローカル Tiny Agents

このセクションでは、AMD のニューラルプロセッシングユニット（NPU）と統合 GPU（iGPU）を使い、エンドツーエンドの Tiny Agents アプリケーションを高速化する方法を紹介します。更に、ローカルファイルを操作し、機密情報をデバイス内で処理出来るアシスタントを作成します。これにより、アプリケーションの機能を広げながら、プライバシーを最大限に保護します。

その為に、NPU と iGPU による高速化に対応し、モデルをローカルで実行出来る Lemonade Server を使います。

セットアップ

Lemonade Server のセットアップ

Lemonade Server は Windows と Linux の両方にインストール出来ます。追加のドキュメントは lemonade-server.ai で確認出来ます。

windows

Windows に Lemonade Server をインストールするには、最新のインストーラーを[ダウンロード](https://github.com/lemonade-sdk/lemonade/releases/latest/download/Lemonade_Server_Installer.exe)して実行するだけです。 Lemonade Server は、Windows の x86/x64 環境で、全ての実行エンジンによる CPU 推論に対応しています。GPU による高速化には、Vulkan を利用する llamacpp エンジンを使用し、主に AMD Ryzen™ AI 7000/8000/300 シリーズと AMD Radeon™ 7000/9000 シリーズを対象としています。NPU による高速化では、ONNX Runtime GenAI（OGA）エンジンを使い、AMD Ryzen™ AI 300 シリーズのデバイスに対応します。 Lemonade Server をインストールしたら、デスクトップに追加された `Lemonade` アイコンをクリックして起動出来ます。

linux

Linux に Lemonade をインストールするには、まず venv を作成して有効化します。

💡 ヒント

`uv` がインストールされていない場合は、[こちら](https://docs.astral.sh/uv/getting-started/installation/) の手順に従ってインストール出来ます。 
uv venv --python 3.11
source .venv/bin/activate
次に、`lemonade-sdk` パッケージをインストールします。 
uv pip install lemonade-sdk==8.0.3
あるいは、リポジトリをクローンしてパッケージをビルドすることで、ソースからインストールすることも出来ます。 
git clone https://github.com/lemonade-sdk/lemonade-sdk.git
cd lemonade-sdk
pip install -e .
インストールが完了したら、次のコマンドを実行して Lemonade を起動出来ます。 
lemonade-server-dev serve
Lemonade Server は、Windows x86/x64 上の全てのプラットフォームとエンジンで CPU 推論をサポートします。GPU アクセラレーションは llamacpp エンジン（Vulkan）を通じて有効化され、AMD Ryzen™ AI 7000/8000/300 シリーズと Radeon™ 7000/9000 シリーズに重点が置かれています。

💡 ヒント

*NPU アクセラレーションは、Windows 上の AMD Ryzen™ AI 300 シリーズでのみ利用出来ます。*

Tiny Agents と npx のセットアップ

このセクションでは、npx と Tiny Agents が既にインストールされていることを前提とします。未だインストールしていない場合は、このコースの Tiny Agents のセクションを参照してください。また、huggingface_hub[mcp]==0.33.2 を使用してください。

AMD NPU と iGPU で Tiny Agents アプリケーションを実行する

AMD NPU と iGPU で Tiny Agents アプリケーションを実行するには、前のセクション で作成した MCP サーバーを、次に示すように Lemonade Server に向けるだけです。

windows

{
  "model": "Qwen3-8B-GGUF",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "mcp-remote",
        "http://localhost:7860/gradio_api/mcp/sse"
      ]
    }
  ]
}

linux

{
  "model": "Qwen3-8B-GGUF",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "npx",
      "args": [
        "mcp-remote",
        "http://localhost:7860/gradio_api/mcp/sse"
      ]
    }
  ]
}

続いて、ローカルで実行するモデルを選びます。利用出来るモデルには様々な種類がありますが、ここでは Vulkan を使って AMD GPU 上で効率よく動作する Qwen3-8B-GGUF を使用しました。対応モデルの一覧を確認したり、自分のモデルを追加したりするには、http://localhost:8000/#model-management にアクセスしてください。

機密情報をローカルで処理するアシスタントを作成する

次は、ローカルファイルにアクセス出来、機密情報を総てデバイス内で処理するアシスタントを追加して、アプリケーションの機能を広げましょう。このアシスタントは、採用候補者の履歴書を評価し、採用時の意思決定を支援します。データを外部に送らず、プライバシーと安全性を保ちながら処理することを目指します。

その為に、Desktop Commander MCP サーバーを使います。Desktop Commander を使うと、ローカルマシン上でコマンドを実行出来るほか、ファイルシステムの幅広い操作、ターミナルの制御、コードの編集も行えます。

基本的な Tiny Agent を使ったプロジェクトをセットアップしましょう。

mkdir file-assistant
cd file-assistant

次に、file-assistant フォルダ内に新しい agent.json ファイルを作成します。

windows

{
  "model": "user.jan-nano",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "-y",
        "@wonderwhy-er/desktop-commander"
      ]
    }
  ]
}

linux

{
  "model": "user.jan-nano",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@wonderwhy-er/desktop-commander"
      ]
    }
  ]
}

最後に、Jan Nano モデルをダウンロードします。http://localhost:8000/#model-management にアクセスしてモデル管理ページを開き、「Add a Model」をクリックしてください。次の情報を入力すると、モデルを追加出来ます。

Model Name: user.jan-nano
Checkpoint: Menlo/Jan-nano-gguf:jan-nano-4b-Q4_0.gguf
Recipe: llamacpp

これで準備完了です！ では、試してみましょう。

他のモデルとアクセラレーションオプションを探る

上記の例では、Jan-Nano モデルが Vulkan アクセラレーションを活用し、AMD GPU 上で効率的なローカル LLM 推論を行いました。http://localhost:8000/#model-management にアクセスするか、モデルのドキュメント を確認することで、他のモデルやアクセラレーションオプションも試せます。

比較的短いコンテキストで動作し、NPU と iGPU による高速化を活用出来る Windows アプリケーションには、Lemonade Server の Hybrid モデルを試せます。これらのモデルは AMD Ryzen AI 300 シリーズの PC 向けに最適化されています。例えば、Llama-xLAM-2-8b-fc-r-Hybrid はツール呼び出し用に特別にファインチューニングされており、高速で応答性のよい動作が期待出来ます。

まとめ

このユニットでは、AMD NPU と iGPU を使ってエンドツーエンドの Tiny Agents アプリケーションを高速化する方法を紹介しました。また、機密情報をローカルで処理するアシスタントを作成する方法も紹介しました。

Lemonade Server をローカルモデルの高速化やプライバシー重視のアプリケーションに活用する方法を学んだので、Lemonade の GitHub リポジトリ で更に多くの例や機能を探ることが出来ます。このリポジトリには追加のドキュメントや実装例が含まれており、コミュニティによって活発にメンテナンスされています。
