# ファインチューニング、チェック[[fine-tuning-check]]

<CourseFloatingBanner
    chapter={3}
    classNames="absolute z-10 right-0 top-0"
/>

ここまで、沢山のことを学びました！最初の2章ではモデルとトークナイザについて学び、この章では、現在推奨されている手法を使って、それらを自分のデータでファインチューニングする方法を身につけました。学んだ内容を振り返ってみましょう。

* [Hub](https://huggingface.co/datasets) 上のデータセットと、現在使われているデータ処理手法について学びました
* 動的パディングやデータコレータの使い方を含め、データセットを効率よく読み込んで前処理する方法を学びました
* 最新機能を備えた高レベルの `Trainer` API を使って、ファインチューニングと評価を実装しました
* PyTorch で完全なカスタム学習ループを一から実装しました
* 🤗 Accelerate を使って、学習コードが複数の GPU や TPU でそのまま動作するようにしました
* 混合精度学習や勾配累積といった、現在よく使われている最適化手法を適用しました

> [!TIP]
> 🎉 **おめでとうございます！** Transformer モデルをファインチューニングする為の基礎を身につけました。これで実践的な ML プロジェクトに取り組む準備が整いました。
>
> 📖 **更に学ぶには**：知識を深める為の参考資料を紹介します。
> - 具体的な NLP タスクを学ぶには、[Transformers のタスクガイド](https://huggingface.co/docs/transformers/main/en/tasks/sequence_classification) を参照してください
> - 内容の充実したノートブックを探すには、[Transformers のサンプル](https://huggingface.co/docs/transformers/main/en/notebooks) を参照してください
>
> 🚀 **次のステップ**：
> - 学んだ手法を使って、自分のデータセットでファインチューニングに挑戦してみましょう
> - [Hugging Face Hub](https://huggingface.co/models) に在る様々なモデルアーキテクチャを試してみましょう
> - [Hugging Face コミュニティ](https://discuss.huggingface.co/) に参加して、プロジェクトを共有したり、助けを得たりしましょう

Transformers の学習は、まだ始まったばかりです。次の章では、モデルとトークナイザをコミュニティと共有し、広がり続ける事前学習済みモデルのエコシステムに貢献する方法を見ていきます。

この章で身につけたデータの前処理、学習の設定、評価、最適化のスキルは、あらゆる機械学習プロジェクトの基礎になります。テキスト分類、固有表現認識、質問応答など、どのような NLP タスクに取り組む時も、これらの手法は役立ちます。

> [!TIP]
> 💡 **実践に役立つヒント**：
> - カスタム学習ループを実装する前に、`Trainer` API を使って、比較の基準となる十分な性能のベースラインを作っておきましょう
> - Hub で自分のタスクに近い事前学習済みモデルを探すと、より適したモデルから学習を始められます
> - 適切な評価指標を使って学習の状況を確認し、チェックポイントの保存も忘れないようにしましょう
> - コミュニティを活用しましょう。モデルやデータセットを共有すれば、他の人の助けになると共に、自分の取り組みへのフィードバックも得られます
