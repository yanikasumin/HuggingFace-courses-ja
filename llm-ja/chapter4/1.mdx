[Hugging Face Hub](https://huggingface.co/) は、Hugging Face の中心となる Web サイトです。最先端のモデルとデータセットを誰でも探して使うことが出来ます。新しいモデルやデータセットを公開して、コミュニティに貢献することも出来ます。公開されているモデルは 10,000 を超え、多種多様です。この章ではモデルを取り上げます。データセットは Chapter 5 で取り上げます。

Hub のモデルは、🤗 Transformers や NLP だけに限られません。例えば、NLP では [Flair](https://github.com/flairNLP/flair) と [AllenNLP](https://github.com/allenai/allennlp)、音声では [Asteroid](https://github.com/asteroid-team/asteroid) と [pyannote](https://github.com/pyannote/pyannote-audio)、画像では [timm](https://github.com/rwightman/pytorch-image-models) のモデルが公開されています。

各モデルは Git リポジトリとして公開されています。その為、バージョン管理が出来、結果を再現出来ます。Hub でモデルを共有すれば、誰でも簡単に使えるようになります。自分でモデルを学習させる必要はなくなり、共有と利用の手間も減ります。

更に、Hub でモデルを共有すると、サーバー上で実行出来る Inference API が自動で用意されます。コミュニティの誰でも、モデルのページで入力を自由に指定し、用途に合ったウィジェットを使って直接試すことが出来ます。

何より、Hub の公開モデルは、共有も利用も完全に無料です。モデルを非公開で共有したい場合の為に、[有料プラン](https://huggingface.co/pricing) も用意されています。
