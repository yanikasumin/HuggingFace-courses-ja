Swin Transformer

2021年の論文 Swin Transformer: Hierarchical Vision Transformer using Shifted Windows で提案された Swin Transformer は、シフトウィンドウ（sliding window ではなく shifted window）を使うことで必要な演算量を減らし、レイテンシと性能を最適化したアーキテクチャです。Swin はコンピュータビジョンにおける 階層型バックボーン（hierarchical backbone） とみなされています。画像分類などのタスクに使えます。

深層学習でいうバックボーンとは、ニューラルネットワークのうち特徴抽出を担う部分のことです。バックボーンにレイヤーを追加すれば、さまざまなビジョンタスクに対応できます。階層型バックボーンは段階的な構造を持ち、解像度が途中で変わることもあります。これに対して、VitDet モデルの非階層型の plain backbone があります。

主な特徴

シフトウィンドウ

元の ViT では、各パッチが他のすべてのパッチとの間で attention を計算するため、計算量が大きくなります。Swin はこの処理を最適化し、通常は2次（quadratic）になる ViT の計算量を、画像サイズに対して線形（linear）にまで減らします。その仕組みは CNN に似ています。パッチは他のすべてのパッチではなく、同じウィンドウ内のパッチだけに attend し、その後、隣接するパッチと段階的にマージされていきます。この構造が、Swin を階層型モデルにしています。

Swin Transformer の論文から取った画像

利点

計算効率

Swin は、ViT のような完全にパッチベースのアプローチよりも高い性能を示します。

大規模データセット

SwinV2 は、初期の 3B パラメータモデルの1つです。学習規模が大きくなるにつれて、Swin は CNN を上回るようになります。パラメータ数が多いため、学習できる容量が増え、より複雑な表現を扱えます。

Swin Transformer V2 (paper)

Swin Transformer V2 は、最大で 3B パラメータまで対応し、高解像度画像で学習できる大規模なビジョンモデルです。元の Swin Transformer から、学習の安定化、低解像度画像で事前学習したモデルの高解像度タスクへの転移、そして学習に必要なラベル付き画像の数を減らす自己教師あり学習手法 SimMIM の導入によって改善されています。

画像復元への応用

SwinIR (paper)

SwinIR は、Swin Transformer をベースに、低解像度画像を高解像度画像に変換するモデルです。

Swin2SR (paper)

Swin2SR も画像復元のモデルです。Swin Transformer V2 を取り入れて SwinIR を改良したもので、学習の安定性や、より高い画像解像度に対応できる能力といった Swin V2 の利点を活かしています。

Swin の PyTorch 実装の概要

元の論文の Swin の実装 の主要部分を、以下で概説します。

Swin Transformer クラス

  1. パラメータの初期化。さまざまな dropout や正規化のパラメータに加えて、次のパラメータがあります。

    • window_size: ローカル self-attention 用のウィンドウのサイズ。
    • ape (bool): True の場合、パッチ埋め込みに絶対位置埋め込みを追加します。
    • fused_window_process: ハードウェア向けの任意の最適化。

  2. パッチ埋め込みの適用: ViT と同様に、画像を重ならないパッチに分割し、Conv2D を使って線形に埋め込みます。

  3. 位置埋め込みの適用: SwinTransformer では、パッチ埋め込みに加える絶対位置埋め込み（ape）を任意で使います。絶対位置埋め込みがあると、各パッチの位置情報をモデルが活用できるようになり、より情報に基づいた予測に役立つことがよくあります。

  4. Depth decay の適用: Depth decay は、正則化と過学習の防止に役立ちます。通常は学習中にレイヤーをスキップすることで行います。この Swin の実装では stochastic（確率的） な depth decay が使われており、レイヤーが深いほどスキップされる確率が高くなります。

  5. レイヤーの構築:

    • モデルは SwinTransformerBlock の複数のレイヤー（BasicLayer）で構成され、各レイヤーは PatchMerging を使って特徴マップをダウンサンプリングし、階層的に処理します。
    • 特徴の次元と特徴マップの解像度は、レイヤーごとに変わります。

  6. 分類ヘッド: ViT と同様に、最後のステップとして、self.head で定義される Multi-Layer Perceptron（MLP）ヘッドを分類タスクに使います。

class SwinTransformer(nn.Module):
    def __init__(
        self,
        img_size=224,
        patch_size=4,
        in_chans=3,
        num_classes=1000,
        embed_dim=96,
        depths=[2, 2, 6, 2],
        num_heads=[3, 6, 12, 24],
        window_size=7,
        mlp_ratio=4.0,
        qkv_bias=True,
        qk_scale=None,
        drop_rate=0.0,
        attn_drop_rate=0.0,
        drop_path_rate=0.1,
        norm_layer=nn.LayerNorm,
        ape=False,
        patch_norm=True,
        use_checkpoint=False,
        fused_window_process=False,
        **kwargs,
    ):
        super().__init__()

        self.num_classes = num_classes
        self.num_layers = len(depths)
        self.embed_dim = embed_dim
        self.ape = ape
        self.patch_norm = patch_norm
        self.num_features = int(embed_dim * 2 ** (self.num_layers - 1))
        self.mlp_ratio = mlp_ratio

        # 画像を重ならないパッチに分割
        self.patch_embed = PatchEmbed(
            img_size=img_size,
            patch_size=patch_size,
            in_chans=in_chans,
            embed_dim=embed_dim,
            norm_layer=norm_layer if self.patch_norm else None,
        )
        num_patches = self.patch_embed.num_patches
        patches_resolution = self.patch_embed.patches_resolution
        self.patches_resolution = patches_resolution

        # 絶対位置埋め込み
        if self.ape:
            self.absolute_pos_embed = nn.Parameter(torch.zeros(1, num_patches, embed_dim))
            trunc_normal_(self.absolute_pos_embed, std=0.02)

        self.pos_drop = nn.Dropout(p=drop_rate)

        # 確率的深さ（stochastic depth）
        dpr = [
            x.item() for x in torch.linspace(0, drop_path_rate, sum(depths))
        ]  # 確率的深さの減衰ルール

        # レイヤーを構築
        self.layers = nn.ModuleList()
        for i_layer in range(self.num_layers):
            layer = BasicLayer(
                dim=int(embed_dim * 2**i_layer),
                input_resolution=(
                    patches_resolution[0] // (2**i_layer),
                    patches_resolution[1] // (2**i_layer),
                ),
                depth=depths[i_layer],
                num_heads=num_heads[i_layer],
                window_size=window_size,
                mlp_ratio=self.mlp_ratio,
                qkv_bias=qkv_bias,
                qk_scale=qk_scale,
                drop=drop_rate,
                attn_drop=attn_drop_rate,
                drop_path=dpr[sum(depths[:i_layer]) : sum(depths[: i_layer + 1])],
                norm_layer=norm_layer,
                downsample=PatchMerging if (i_layer < self.num_layers - 1) else None,
                use_checkpoint=use_checkpoint,
                fused_window_process=fused_window_process,
            )
            self.layers.append(layer)

        self.norm = norm_layer(self.num_features)
        self.avgpool = nn.AdaptiveAvgPool1d(1)
        self.head = (
            nn.Linear(self.num_features, num_classes)
            if num_classes > 0
            else nn.Identity()
        )

        self.apply(self._init_weights)

    def _init_weights(self, m):
        if isinstance(m, nn.Linear):
            trunc_normal_(m.weight, std=0.02)
            if isinstance(m, nn.Linear) and m.bias is not None:
                nn.init.constant_(m.bias, 0)
        elif isinstance(m, nn.LayerNorm):
            nn.init.constant_(m.bias, 0)
            nn.init.constant_(m.weight, 1.0)

    @torch.jit.ignore
    def no_weight_decay(self):
        return {"absolute_pos_embed"}

    @torch.jit.ignore
    def no_weight_decay_keywords(self):
        return {"relative_position_bias_table"}

    def forward_features(self, x):
        x = self.patch_embed(x)
        if self.ape:
            x = x + self.absolute_pos_embed
        x = self.pos_drop(x)

        for layer in self.layers:
            x = layer(x)

        x = self.norm(x)  # B L C
        x = self.avgpool(x.transpose(1, 2))  # B C 1
        x = torch.flatten(x, 1)
        return x

    def forward(self, x):
        x = self.forward_features(x)
        x = self.head(x)
        return x

Swin Transformer Block

SwinTransformerBlock は、Swin Transformer の中核となる処理、つまりローカルなウィンドウ attention と、その後の MLP 処理をカプセル化したものです。ローカルなパッチに注目しながらグローバルな表現も学習できる能力を保つことで、Swin Transformer が大きな画像を効率的に扱えるようにするうえで、重要な役割を果たします。

レイヤーの構成要素: - 正規化レイヤー1（self.norm1）: attention 機構の前に適用されます。 - Window Attention（self.attn）: ローカルウィンドウ内で self-attention を計算します。 - Drop Path（self.drop_path）: 正則化のための stochastic depth を実装します。 - 正規化レイヤー2（self.norm2）: MLP レイヤーの前に適用されます。 - MLP（mlp）: attention の後の特徴を処理する multi-layer perceptron です。 - Attention Mask（self.register_buffer）: attention mask は self-attention の計算時に使われ、ウィンドウ化した入力のどの要素同士が相互作用（つまり互いに attend）できるかを制御します。シフトウィンドウの手法ではウィンドウをまたいだ相互作用も一部可能になるため、モデルはより広い文脈情報を捉えられます。

Swin Transformer Block の初期化

class SwinTransformerBlock(nn.Module):
    r"""Swin Transformer Block.

    Args:
        dim (int): Number of input channels.
        input_resolution (tuple[int]): Input resulotion.
        num_heads (int): Number of attention heads.
        window_size (int): Window size.
        shift_size (int): Shift size for SW-MSA.
        mlp_ratio (float): Ratio of mlp hidden dim to embedding dim.
        qkv_bias (bool, optional): If True, add a learnable bias to query, key, value. Default: True
        qk_scale (float | None, optional): Override default qk scale of head_dim ** -0.5 if set.
        drop (float, optional): Dropout rate. Default: 0.0
        attn_drop (float, optional): Attention dropout rate. Default: 0.0
        drop_path (float, optional): Stochastic depth rate. Default: 0.0
        act_layer (nn.Module, optional): Activation layer. Default: nn.GELU
        norm_layer (nn.Module, optional): Normalization layer.  Default: nn.LayerNorm
        fused_window_process (bool, optional): If True, use one kernel to fused window shift & window partition for acceleration, similar for the reversed part. Default: False
    """

    def __init__(
        self,
        dim,
        input_resolution,
        num_heads,
        window_size=7,
        shift_size=0,
        mlp_ratio=4.0,
        qkv_bias=True,
        qk_scale=None,
        drop=0.0,
        attn_drop=0.0,
        drop_path=0.0,
        act_layer=nn.GELU,
        norm_layer=nn.LayerNorm,
        fused_window_process=False,
    ):
        super().__init__()
        self.dim = dim
        self.input_resolution = input_resolution
        self.num_heads = num_heads
        self.window_size = window_size
        self.shift_size = shift_size
        self.mlp_ratio = mlp_ratio
        if min(self.input_resolution) <= self.window_size:
            # ウィンドウサイズが入力解像度より大きい場合は、ウィンドウに分割しない
            self.shift_size = 0
            self.window_size = min(self.input_resolution)
        assert 0 <= self.shift_size < self.window_size, "shift_size must in 0-window_size"

        self.norm1 = norm_layer(dim)
        self.attn = WindowAttention(
            dim,
            window_size=to_2tuple(self.window_size),
            num_heads=num_heads,
            qkv_bias=qkv_bias,
            qk_scale=qk_scale,
            attn_drop=attn_drop,
            proj_drop=drop,
        )

        self.drop_path = DropPath(drop_path) if drop_path > 0.0 else nn.Identity()
        self.norm2 = norm_layer(dim)
        mlp_hidden_dim = int(dim * mlp_ratio)
        self.mlp = Mlp(
            in_features=dim,
            hidden_features=mlp_hidden_dim,
            act_layer=act_layer,
            drop=drop,
        )

        if self.shift_size > 0:
            # SW-MSA 用の attention mask を計算
            H, W = self.input_resolution
            img_mask = torch.zeros((1, H, W, 1))  # 1 H W 1
            h_slices = (
                slice(0, -self.window_size),
                slice(-self.window_size, -self.shift_size),
                slice(-self.shift_size, None),
            )
            w_slices = (
                slice(0, -self.window_size),
                slice(-self.window_size, -self.shift_size),
                slice(-self.shift_size, None),
            )
            cnt = 0
            for h in h_slices:
                for w in w_slices:
                    img_mask[:, h, w, :] = cnt
                    cnt += 1

            mask_windows = window_partition(
                img_mask, self.window_size
            )  # nW, window_size, window_size, 1
            mask_windows = mask_windows.view(-1, self.window_size * self.window_size)
            attn_mask = mask_windows.unsqueeze(1) - mask_windows.unsqueeze(2)
            attn_mask = attn_mask.masked_fill(attn_mask != 0, float(-100.0)).masked_fill(
                attn_mask == 0, float(0.0)
            )
        else:
            attn_mask = None

        self.register_buffer("attn_mask", attn_mask)
        self.fused_window_process = fused_window_process

    ### New cell ###
    def forward(self, x):
        H, W = self.input_resolution
        B, L, C = x.shape
        assert L == H * W, "input feature has wrong size"

        shortcut = x
        x = self.norm1(x)
        x = x.view(B, H, W, C)

        # 循環シフト（cyclic shift）
        if self.shift_size > 0:
            if not self.fused_window_process:
                shifted_x = torch.roll(
                    x, shifts=(-self.shift_size, -self.shift_size), dims=(1, 2)
                )
                # ウィンドウに分割
                x_windows = window_partition(
                    shifted_x, self.window_size
                )  # nW*B, window_size, window_size, C
            else:
                x_windows = WindowProcess.apply(
                    x, B, H, W, C, -self.shift_size, self.window_size
                )
        else:
            shifted_x = x
            # ウィンドウに分割
            x_windows = window_partition(
                shifted_x, self.window_size
            )  # nW*B, window_size, window_size, C

        x_windows = x_windows.view(
            -1, self.window_size * self.window_size, C
        )  # nW*B, window_size*window_size, C

        # W-MSA/SW-MSA
        attn_windows = self.attn(
            x_windows, mask=self.attn_mask
        )  # nW*B, window_size*window_size, C

        # ウィンドウをマージ
        attn_windows = attn_windows.view(-1, self.window_size, self.window_size, C)

        # 循環シフトを元に戻す
        if self.shift_size > 0:
            if not self.fused_window_process:
                shifted_x = window_reverse(
                    attn_windows, self.window_size, H, W
                )  # B H' W' C
                x = torch.roll(
                    shifted_x, shifts=(self.shift_size, self.shift_size), dims=(1, 2)
                )
            else:
                x = WindowProcessReverse.apply(
                    attn_windows, B, H, W, C, self.shift_size, self.window_size
                )
        else:
            shifted_x = window_reverse(attn_windows, self.window_size, H, W)  # B H' W' C
            x = shifted_x
        x = x.view(B, H * W, C)
        x = shortcut + self.drop_path(x)

        # フィードフォワードネットワーク（FFN）
        x = x + self.drop_path(self.mlp(self.norm2(x)))

        return x

Swin Transformer Block のフォワードパス

重要なステップは4つです。

  1. 循環シフト（cyclic shift）: 特徴マップは window_partition でウィンドウに分割されます。その区画に cyclic shift が適用されます。cyclic shift とは、列の中の要素（ここでは区画）を左または右へずらし、一端からはみ出した要素を反対側に回り込ませる操作です。要素同士の相対的な位置は変わりますが、列そのものはそのまま保たれます。たとえば、列 A, B, C, D を右へ1つ cyclic shift すると D, A, B, C になります。

cyclic shift により、モデルは隣接するウィンドウ同士の関係を捉えられるようになり、個々のウィンドウのローカルな範囲を超えた空間的文脈を学習する能力が高まります。

  1. ウィンドウ attention: ウィンドウベースの multi-head self attention（W-MSA）モジュールを使って attention を実行します。

  2. パッチのマージ: PatchMerging でパッチをマージします。

  3. 循環シフトを元に戻す: attention が終わったら、reverse_window でウィンドウ分割を元に戻し、cyclic shift の操作も逆向きに実行して、特徴マップを元の形に戻します。

class WindowAttention(nn.Module):
    """
    Args:
        dim (int): Number of input channels.
        window_size (tuple[int]): The height and width of the window.
        num_heads (int): Number of attention heads.
        qkv_bias (bool, optional):  If True, add a learnable bias to query, key, value. Default: True
        qk_scale (float | None, optional): Override default qk scale of head_dim ** -0.5 if set
        attn_drop (float, optional): Dropout ratio of attention weight. Default: 0.0
        proj_drop (float, optional): Dropout ratio of output. Default: 0.0
    """

    def __init__(
        self,
        dim,
        window_size,
        num_heads,
        qkv_bias=True,
        qk_scale=None,
        attn_drop=0.0,
        proj_drop=0.0,
    ):

        super().__init__()
        self.dim = dim
        self.window_size = window_size  # Wh, Ww
        self.num_heads = num_heads
        head_dim = dim // num_heads
        self.scale = qk_scale or head_dim**-0.5

        # 相対位置バイアスのパラメータテーブルを定義
        self.relative_position_bias_table = nn.Parameter(
            torch.zeros((2 * window_size[0] - 1) * (2 * window_size[1] - 1), num_heads)
        )  # 2*Wh-1 * 2*Ww-1, nH

        # ウィンドウ内の各トークンについて、ペアごとの相対位置インデックスを取得
        coords_h = torch.arange(self.window_size[0])
        coords_w = torch.arange(self.window_size[1])
        coords = torch.stack(torch.meshgrid([coords_h, coords_w]))  # 2, Wh, Ww
        coords_flatten = torch.flatten(coords, 1)  # 2, Wh*Ww
        relative_coords = (
            coords_flatten[:, :, None] - coords_flatten[:, None, :]
        )  # 2, Wh*Ww, Wh*Ww
        relative_coords = relative_coords.permute(1, 2, 0).contiguous()  # Wh*Ww, Wh*Ww, 2
        relative_coords[:, :, 0] += self.window_size[0] - 1  # 0 から始まるようにシフト
        relative_coords[:, :, 1] += self.window_size[1] - 1
        relative_coords[:, :, 0] *= 2 * self.window_size[1] - 1
        relative_position_index = relative_coords.sum(-1)  # Wh*Ww, Wh*Ww
        self.register_buffer("relative_position_index", relative_position_index)

        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

        trunc_normal_(self.relative_position_bias_table, std=0.02)
        self.softmax = nn.Softmax(dim=-1)

    def forward(self, x, mask=None):
        """
        Args:
            x: input features with shape of (num_windows*B, N, C)
            mask: (0/-inf) mask with shape of (num_windows, Wh*Ww, Wh*Ww) or None
        """
        B_, N, C = x.shape
        qkv = (
            self.qkv(x)
            .reshape(B_, N, 3, self.num_heads, C // self.num_heads)
            .permute(2, 0, 3, 1, 4)
        )
        q, k, v = (
            qkv[0],
            qkv[1],
            qkv[2],
        )  # torchscript の都合に合わせる（テンソルをタプルとしては使えないため）

        q = q * self.scale
        attn = q @ k.transpose(-2, -1)

        relative_position_bias = self.relative_position_bias_table[
            self.relative_position_index.view(-1)
        ].view(
            self.window_size[0] * self.window_size[1],
            self.window_size[0] * self.window_size[1],
            -1,
        )  # Wh*Ww,Wh*Ww,nH
        relative_position_bias = relative_position_bias.permute(
            2, 0, 1
        ).contiguous()  # nH, Wh*Ww, Wh*Ww
        attn = attn + relative_position_bias.unsqueeze(0)

        if mask is not None:
            nW = mask.shape[0]
            attn = attn.view(B_ // nW, nW, self.num_heads, N, N) + mask.unsqueeze(
                1
            ).unsqueeze(0)
            attn = attn.view(-1, self.num_heads, N, N)
            attn = self.softmax(attn)
        else:
            attn = self.softmax(attn)

        attn = self.attn_drop(attn)

        x = (attn @ v).transpose(1, 2).reshape(B_, N, C)
        x = self.proj(x)
        x = self.proj_drop(x)
        return x

Window Attention

WindowAttention は、相対位置バイアスを持つウィンドウベースの multi-head self attention（W-MSA）モジュールです。シフトありとシフトなしのどちらのウィンドウにも使えます。

class PatchMerging(nn.Module):
    r"""Patch Merging Layer.

    Args:
        input_resolution (tuple[int]): Resolution of input feature.
        dim (int): Number of input channels.
        norm_layer (nn.Module, optional): Normalization layer.  Default: nn.LayerNorm
    """

    def __init__(self, input_resolution, dim, norm_layer=nn.LayerNorm):
        super().__init__()
        self.input_resolution = input_resolution
        self.dim = dim
        self.reduction = nn.Linear(4 * dim, 2 * dim, bias=False)
        self.norm = norm_layer(4 * dim)

    def forward(self, x):
        """
        x: B, H*W, C
        """
        H, W = self.input_resolution
        B, L, C = x.shape
        assert L == H * W, "input feature has wrong size"
        assert H % 2 == 0 and W % 2 == 0, f"x size ({H}*{W}) are not even."

        x = x.view(B, H, W, C)

        x0 = x[:, 0::2, 0::2, :]  # B H/2 W/2 C
        x1 = x[:, 1::2, 0::2, :]  # B H/2 W/2 C
        x2 = x[:, 0::2, 1::2, :]  # B H/2 W/2 C
        x3 = x[:, 1::2, 1::2, :]  # B H/2 W/2 C
        x = torch.cat([x0, x1, x2, x3], -1)  # B H/2 W/2 4*C
        x = x.view(B, -1, 4 * C)  # B H/2*W/2 4*C

        x = self.norm(x)
        x = self.reduction(x)

        return x

Patch Merging レイヤー

パッチマージはダウンサンプリングに使われる手法です。従来の畳み込みニューラルネットワーク（CNN）の pooling と同様に、特徴マップの空間次元を削減します。受容野を段階的に広げ、空間解像度を下げながら、階層的な特徴表現を構築するのに役立ちます。

from datasets import load_dataset
from transformers import AutoImageProcessor, SwinForImageClassification
import torch

model = SwinForImageClassification.from_pretrained(
    "microsoft/swin-tiny-patch4-window7-224"
)
image_processor = AutoImageProcessor.from_pretrained(
    "microsoft/swin-tiny-patch4-window7-224"
)

dataset = load_dataset("huggingface/cats-image")
image = dataset["test"]["image"][0]

inputs = image_processor(image, return_tensors="pt")

with torch.no_grad():
    logits = model(**inputs).logits

predicted_label_id = logits.argmax(-1).item()
predicted_label_text = model.config.id2label[predicted_label_id]

print(predicted_label_text)
