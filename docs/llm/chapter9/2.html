最初のデモを作る

Gradio は Python パッケージです。インストールは次のコマンドで行います。

$ pip install gradio

Gradio は、Python が動作する環境であればどこでも実行出来ます。普段使っている Python IDE、Jupyter ノートブック、Google Colab のいずれでも利用出来ます 🤯。

次に、Gradio の構文を確認する為に、シンプルな「Hello World」の例を示します。

import gradio as gr


def greet(name):
    return "Hello " + name


demo = gr.Interface(fn=greet, inputs="text", outputs="text")

demo.launch()

上のコードを順に見ていきましょう:

  • まず、greet() という関数を定義します。この例では名前の前に "Hello" を付けるだけの単純な関数ですが、対象は任意の Python 関数です。例えば、機械学習の応用では、入力を受け取って モデルを呼び出して予測を行い、その出力を返す関数になります。
  • 次に、fn、inputs、outputs の3つの引数で Gradio の Interface を作成します。これらの引数は、予測関数と、使いたい入出力コンポーネントの 種類 を定義します。今回の例では、どちらのコンポーネントもシンプルなテキストボックスです。
  • 最後に、作成した Interface に対して launch() メソッドを呼びます。

このコードを実行すると、Jupyter/Colab のノートブックでは下のインターフェースが自動的に表示されます。スクリプトから実行した場合は、ブラウザで http://localhost:7860 が開きます。

この GUI は、名前などを入力してそのまま試せます。

この GUI では、Gradio が入力パラメータの名前（name）を自動で推測し、テキストボックスの上のラベルとして適用しています。ラベルを変更する場合や、テキストボックスを他の方法でカスタマイズする場合は、入力コンポーネントに対応するクラスのインスタンスを作成します。

下の例を示します。

import gradio as gr


def greet(name):
    return "Hello " + name


# Textbox クラスをインスタンス化します
textbox = gr.Textbox(label="Type your name here:", placeholder="John Doe", lines=2)

gr.Interface(fn=greet, inputs=textbox, outputs="text").launch()

（入力欄のラベルの訳：ここに名前を入力してください：。プレースホルダの John Doe は人名の例です）

この例では、ラベルとプレースホルダと行数を指定して、入力テキストボックスを作成しています。出力テキストボックスも同じ方法で作成出来ますが、ここでは扱いません。

この様に、わずか数行のコードで、任意の入出力を持つ関数にシンプルなインターフェースを付けられます。このセクションではテキストボックスを扱いました。次のセクションでは、他の種類の入出力を扱います。続いて、Gradio アプリケーションに NLP を取り入れる例を示します。

🤖 モデルの予測を取り入れる

ここでは、GPT-2 の様な テキスト生成 モデルをデモにする、シンプルなインターフェースを作ります。

モデルは 🤗 Transformers の pipeline() 関数を使って読み込みます。手早く復習したい場合は、Chapter 1 の該当セクション に戻ってください。

まず、テキストプロンプトを受け取り、補完されたテキストを返す予測関数を定義します:

from transformers import pipeline

model = pipeline("text-generation")


def predict(prompt):
    completion = model(prompt)[0]["generated_text"]
    return completion

この関数は、与えたプロンプトの続きを生成します。動作は、任意のプロンプトを入力して確認出来ます。実行例は次の通りです（補完結果は異なる場合があります）。

predict("My favorite programming language is")

>> My favorite programming language is Haskell. I really enjoyed the Haskell language, but it doesn't have all the features that can be applied to any other language. For example, all it does is compile to a byte array.

予測を生成する関数が出来たら、先ほどと同じ方法で Interface を作成して起動出来ます。

import gradio as gr

gr.Interface(fn=predict, inputs="text", outputs="text").launch()

以上で準備は完了です。下のインターフェースで、GPT-2 モデルによるテキスト生成を試せます 🤯。
