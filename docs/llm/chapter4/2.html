Model Hub では適切なモデルを簡単に選べるので、さまざまなライブラリからわずか数行のコードで利用できます。実際にモデルの使い方と、コミュニティへ貢献する方法を見ていきましょう。

フランス語の文章中で、マスクされた単語を予測できるモデルを探しているとしましょう。

camembert-base チェックポイントを選んで試してみます。このモデルを読み込むには、モデル識別子の camembert-base を指定するだけです。前の章で見たように、pipeline() 関数を使っても読み込めます。

from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")

```python out [ {'sequence': 'Le camembert est délicieux :)', 'score': 0.49091005325317383, 'token': 7200, 'token_str': 'délicieux'}, {'sequence': 'Le camembert est excellent :)', 'score': 0.1055697426199913, 'token': 2183, 'token_str': 'excellent'}, {'sequence': 'Le camembert est succulent :)', 'score': 0.03453313186764717, 'token': 26202, 'token_str': 'succulent'}, {'sequence': 'Le camembert est meilleur :)', 'score': 0.0330314114689827, 'token': 528, 'token_str': 'meilleur'}, {'sequence': 'Le camembert est parfait :)', 'score': 0.03007650189101696, 'token': 1654, 'token_str': 'parfait'} ]

このように、パイプラインでモデルを読み込むのはとても簡単です。注意すべきは、選んだチェックポイントがこれから使うタスクに適しているかだけです。たとえば、ここでは `camembert-base` チェックポイントを `fill-mask` パイプラインで読み込んでおり、これはまったく問題ありません。しかし、このチェックポイントを `text-classification` パイプラインで読み込むと、`camembert-base` のヘッドがそのタスクに適していないため、結果は意味をなしません。適切なチェックポイントを選ぶには、Hugging Face Hub のインターフェースにあるタスクセレクタの利用をおすすめします。

チェックポイントは、モデルのアーキテクチャを直接使ってインスタンス化することもできます。

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")

ただし、代わりに Auto* クラス の利用をおすすめします。これらのクラスは、チェックポイントに応じて適切なアーキテクチャのクラスを自動で選択してくれるためです。先ほどのコード例では、CamemBERT アーキテクチャで読み込めるチェックポイントに限られますが、Auto* クラスを使えばチェックポイントの切り替えが簡単になります。

from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")

{:else}

from transformers import CamembertTokenizer, TFCamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = TFCamembertForMaskedLM.from_pretrained("camembert-base")

ただし、代わりに TFAuto* クラス の利用をおすすめします。これらのクラスは、チェックポイントに応じて適切なアーキテクチャのクラスを自動で選択してくれるためです。先ほどのコード例では、CamemBERT アーキテクチャで読み込めるチェックポイントに限られますが、TFAuto* クラスを使えばチェックポイントの切り替えが簡単になります。

from transformers import AutoTokenizer, TFAutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = TFAutoModelForMaskedLM.from_pretrained("camembert-base")
