# 補足資料と参考リソース 🤗

マルチモーダルモデルのユニットは楽しんでいただけたでしょうか。マルチモーダル学習とモデルについてさらに詳しく学びたい方のために、参考リソースをまとめました：

- [**Hugging Face Tasks**](https://huggingface.co/tasks) では、コンピュータービジョン、音声、NLP、マルチモーダル学習、強化学習などの領域のさまざまなタスクの概要を見られます。各タスクにはデモ、ユースケース、モデル、データセットなどが含まれています。
- [**11-777 MMML**](https://cmu-multicomp-lab.github.io/mmml-course/fall2022/) は CMU によるマルチモーダル機械学習のコースです。ビデオ講義は[**こちら**](https://www.youtube.com/@LPMorency/playlists)で見られます。
- [**Chip Huyen によるマルチモダリティと LLM についてのブログ**](https://huyenchip.com/2023/10/10/multimodal.html) では、マルチモダリティ、大規模マルチモーダルモデル、BLIP、CLIP などのシステムの包括的な概要が得られます。
- [**Awesome Multimodal ML**](https://github.com/pliang279/awesome-multimodal-ml) は、論文、コース、アーキテクチャ、ワークショップ、チュートリアルなどを集めた GitHub リポジトリです。
- [**Awesome Multimodal Large Language Models**](https://github.com/BradyFU/Awesome-Multimodal-Large-Language-Models) は、マルチモーダル LLM に関する論文とデータセットを集めた GitHub リポジトリです。
- [**EE/CS 148, Caltech**](https://gkioxari.github.io/teaching/cs148/) は、大規模な言語・視覚モデルに関するコースです。

次のユニットでは、近年マルチモダリティによって大きく発展した、もう1種類のニューラルネットワークモデル、**生成ニューラルネットワーク**について学びます。
絵筆を用意して、コンピュータービジョンの世界での新たな冒険に一緒に参加しましょう 🤠
