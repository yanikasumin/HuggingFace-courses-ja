LangGraph 入門

次のパートへようこそ。ここでは、複雑な LLM ワークフローの構造化とオーケストレーションを支援するフレームワーク LangGraph を使って、アプリケーションを構築する方法 を学びます。

LangGraph は、エージェントのフローに対する 制御 のためのツールを提供することで、本番環境に対応した アプリケーションを構築できるようにするフレームワークです。

モジュールの概要

このユニットでは、次の内容を学びます。

1️⃣ LangGraph とは何か、いつ使うのか

2️⃣ LangGraph の構成要素

3️⃣ メール仕分け執事 Alfred

4️⃣ ドキュメント分析エージェント Alfred

5️⃣ クイズ

⚠️ 注意

このセクションの例を実行するには、高性能な LLM/VLM モデルへのアクセスが必要です。LangGraph との互換性が最も高いため、GPT-4o API を使って実行しました。

このユニットを終えるころには、堅牢で整理された、本番環境に対応したアプリケーションを構築できるようになります！

なお、このセクションは LangGraph の入門編です。より高度なトピックについては、LangChain Academy の無料コース Introduction to LangGraph で学べます。

さあ、始めましょう！
