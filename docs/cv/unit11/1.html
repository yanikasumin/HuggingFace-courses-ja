はじめに

基礎知識に加え、このユニットでは転移学習とマルチモーダル学習の概念を理解していることを前提としています。コースを最初から順に学んでいない場合は、少なくともユニット2の転移学習のセクションと、ユニット4の全体に目を通しておくことをお勧めします。

汎化について

試験前に一夜漬けで勉強する学生のように、モデルの訓練を全エポックにわたって終えました。ここからが本当のテストです！訓練中に学んだ知識を、学習に使った写真（例えば猫の写真）以外にも活かし、Alice や Ted の飼い猫のような、見たことのない猫も認識出来ることを期待します。訓練中に見た猫の顔を丸暗記するのではなく、「猫らしさ」の本質を学んでほしいのです。

学んだ知識を新しい状況に応用する能力を汎化（generalization）と呼びます。これが、猫を認識出来る優れたモデルと、猫の写真を暗記しただけのモデルとの違いです。

汎化が存在しない世界を想像出来るでしょうか？実は簡単です。世界中の猫が地球上にしか存在しないと仮定して、Alice や Ted の飼い猫も含め、あらゆる猫の画像でモデルを訓練します。あとは、今いる猫が繁殖しないようにする方法を見つけるだけです。そう、大したことではありませんね。

但し、モデルが見たことのない猫の写真なら何でも認識出来る、という訳ではありません。認識出来ると期待されるのは、訓練に使った画像データと同じ分布に属する猫の写真です。

例えば、猫の自撮り写真で訓練したモデルに漫画の猫の絵を見せても、おそらく認識出来ないでしょう。この2種類の画像は、まったく異なる分布、つまりドメインに属しているからです。

猫の自撮り写真で訓練したモデルに漫画の猫を認識させることを、ドメイン適応（domain adaptation）と呼びます（詳しくは後で簡単に触れます）。実在する猫について学んだ知識を応用して、アニメに登場する猫も認識出来るようにする訳です。

ここまで、見たことのない Alice や Ted の猫の写真を認識する「汎化」と、アニメの猫を認識する「ドメイン適応」を見てきました。しかし、私たちが目指すのはその先です。自分の猫や Alice と Ted の猫、更には漫画の猫を認識するだけでは満足出来ません。猫の写真で訓練したモデルに、リャマやハヤブサの写真まで認識してほしいのです。

さあ、ここからがゼロショット学習（zero-shot learning、略称 ZSL）の領域です。

ゼロショット学習とは？

定義でウォームアップしましょう。ゼロショット学習は、テスト時に、訓練中に触れたことのないクラスに属する画像だけがモデルに提示される設定です。言い換えれば、訓練セットとテストセットは互いに素（disjoint）です。

ここで1つ注意が有ります。従来の ZSL では、テストセットに含まれるのは、訓練時にモデルが見たことのないクラスの画像だけです。訓練時に扱ったクラスの画像は1枚も含まれません。これは少し非現実的に感じるかもしれません。学生に、習ったことのない内容だけを出題する試験で高得点を取るよう求めるようなものです。

幸い、ZSL には、この厳しい制約を緩めた、より実用的な方式が有ります。一般化ゼロショット学習（generalized zero-shot learning、GZSL）です。GZSL では、テストセットに既知のクラスと未知のクラスの両方を含められます。その為、実際の利用場面により近い条件でモデルを評価出来ます。

ゼロショット学習の歴史

明示的に訓練していないタスクでも優れた性能を発揮するモデルを作れるのか。この問いは、深層学習が現実的な手法として注目され始めたころに生まれました。

2008年には、米国人工知能学会（AAAI）の会議で発表された2本の独立した論文が、ZSL 研究の始まりにつながりました。1本目の論文は Dataless Classification という題名で、自然言語処理（NLP）の分野におけるゼロショット学習の概念を探究しています。2本目の Zero-Data Learning は、ZSL をコンピュータビジョンのタスクに応用することを扱っています。そして「ゼロショット学習」という用語が初めて登場したのは、2009年の NeurIPS で発表された論文です。その共著者の1人は、なんと Geoffrey Hinton でした！

ZSL の歴史における主な出来事を、以下の年表にまとめます。
2008 ゼロショット学習につながる最初の問題提起
2009 ゼロショット学習という用語が生まれた
2013 一般化ゼロショット学習（GZSL）の概念が導入された
2017 エンコーダ・デコーダパラダイムの ZSL への最初の応用
2020 OpenAI の GPT-3 がゼロショット NLP で目覚ましい性能を達成
2021 OpenAI の CLIP がゼロショットコンピュータビジョンをまったく新しい水準に引き上げた

CLIP はゼロショットコンピュータビジョンの研究に大きな影響を与え、新しい時代を切り開きました。その汎用性と高い性能によって、新たな可能性が広がったのです。ゼロショットコンピュータビジョンの歴史は、CLIP 以前と CLIP 以後の2つの時代に分けられると言ってもよいでしょう。

コンピュータビジョンではゼロショット学習はどのように機能するのか？

ゼロショット学習が何か分かった所で、次はコンピュータビジョンでどのように使われるのかを見てみましょう。詳しい仕組みは後の章で説明しますが、ここでは先ず全体像をつかんでおきます。

NLP におけるゼロショット学習は、今では比較的簡単に実現出来ますが、以前からそうだった訳ではありません。多くの言語モデルは、大規模なテキストデータセットを使い、与えられた単語列の次に来る単語を予測するように訓練されます。これにより、言語のパターンや意味的な関係を学習し、明示的に訓練していないタスクでも驚く程高い性能を発揮出来るようになります。例えば GPT-2 は、プロンプトに TL;DR を追加するだけで文章を要約出来ます。

一方、ゼロショットコンピュータビジョンでは事情が異なります。

先ずは簡単な質問から始めましょう。私たち人間は、見たことのない物体をどうやって認識しているのでしょうか？

そうです、まったくその通りです！その物体に関する他の情報が必要です。ライオンがどんな姿かを知っていれば、トラを見たことがなくても、トラを簡単に識別出来ます。トラは、縞模様が有り、たてがみの無いライオンです。シマウマは、白黒の縞模様の馬です。デッドプールは、赤と黒のスパイダーマンです。

このように、視覚以外の情報も使う為、ゼロショットコンピュータビジョンは本質的にマルチモーダルな手法です。汎化を、本を読んだり人と話したりしながら言語を学ぶことにたとえるなら、ゼロショットコンピュータビジョンは、辞書を読んだり、誰かにその言語がどんな音に聞こえるのかを説明してもらったりして、言語を学ぶようなものです。

ゼロショット学習は、教師なし学習の一種なのでしょうか？いいえ、ゼロショット学習も教師あり学習です。教師なし学習では、モデルはラベルの付いていないデータから学習します。一方、ゼロショット学習では、ラベルのないデータではなく、対応するデータの無いラベルから学習します。初期の研究で「Dataless Classification」と呼ばれていたことを思い出して下さい。

ほかにどのような情報が必要なのか？

ゼロショットコンピュータビジョンを実現するには、訓練時に画像の視覚的特徴だけでなく、別の情報もモデルに与える必要があります。この情報を意味情報又は補助情報（Semantic or Auxiliary Information）と呼びます。意味情報は、画像の視覚的特徴と未知のクラスを意味の面で結びつける役割を果たします。テキストと画像を組み合わせたこうしたマルチモーダルな情報を使うことで、モデルは、実際の画像を見たことがない物体でも認識出来るようになります。つまり、意味情報を使って、既知のクラスと未知のクラスの両方を高次元のベクトル空間に埋め込むのです。

意味情報には、次のような種類が有ります。

  1. 属性ベクトル（Attribute vectors）：物体が持つ様々な特徴を、表形式でまとめたものです。
  2. テキスト記述（Textual Descriptions）：画像キャプションに似た、画像に含まれる物体を記述するテキストです。
  3. クラスラベルベクトル（Class label vectors）：クラスラベル自体の埋め込みです。

この意味情報を使い、画像の特徴と意味的特徴を対応づける関数を学習するようにモデルを訓練します。推論時には、例えば k近傍法を使って意味空間で最も近いラベルを探し、画像のクラスを予測します。つまり、意味情報を利用して、既知のクラスから得た知識を未知のクラスに転移しているのです。

ゼロショットコンピュータビジョンの手法ごとに、使用する意味情報と、推論時に利用する埋め込み空間が異なります。

転移学習とは何が違うのか？

良い質問です！ゼロショット学習（ZSL）は転移学習の一種であり、特に異種転移学習（heterogeneous transfer learning）に分類されます。つまり、ソースドメイン（既知のクラス）で得た知識を、異なるターゲットドメイン（未知のクラス）へ転移することで学習します。

ソースドメインとターゲットドメインには違いが有る為、ZSL には転移学習特有の課題があります。例えば、データの分布が大きく異なる「ドメインシフト」への対処や、ターゲットドメインにラベル付きデータが無いという問題です。こうした課題については後で詳しく説明するので、今は心配しなくても大丈夫です。先ずは、ゼロショットコンピュータビジョンの様々な手法を見ていきましょう。

ゼロショットコンピュータビジョンの手法

ゼロショットコンピュータビジョンには様々な手法が提案されており、その分類方法も複数有ります。その中でも私が分かり易いと感じるのは、手法を大きく埋め込みベースの手法（Embedding-based methods）と生成ベースの手法（Generative-based methods）に分ける方法です。この分類を使うと、様々なゼロショットコンピュータビジョンの手法を理解し、比較し易くなります。

  • 埋め込みベースの手法（Embedding-based methods）：モデルは、画像とその意味的特徴・表現の両方が射影される共通の埋め込み空間を学習します。新しい未知のクラスは、その空間における類似度の尺度を使って予測されます。例えば CLIP です。
  • 生成ベースの手法（Generative-based methods）：生成モデルを使い、既知のクラスのサンプルと、既知・未知の両方のクラスの意味表現をもとに、未知のクラスの合成画像や視覚的特徴を生成します。これにより、未知のクラスの実データがなくても、生成したデータを使ってモデルを訓練出来ます。つまり、少し工夫をして、ゼロショット学習の問題を教師あり学習の問題に変えてしまう訳です。例えば CVAE[^6] が挙げられます。

埋め込みベースと生成ベースのどちらを選ぶかは、機械学習における他の選択と同じく、取り組むタスクの内容と利用出来るリソースに依存します。埋め込みベースの手法は効率とスケーラビリティに優れる為、よく選ばれます。

一方、生成ベースの手法は柔軟性が高く、複雑なデータにも対応出来る可能性があります。

なお、このユニットで扱うのは埋め込みベースの手法のみです。これには、アテンション機構を利用した埋め込みベースの手法も含まれます。ゼロショット学習は幅広い分野なので、全てを説明するには独立したコースが必要になるかもしれません。更に学びたい方は、紹介している追加資料も是非読んでみて下さい。

似ている手法との比較：ゼロショット学習は何が違うのか？

ここまで長い道のりでしたね！ゼロショット学習とは何か、その歴史、コンピュータビジョンへの応用、基本的な仕組みについて、大凡の理解が出来たと思います。最後に、一見するとゼロショット学習に似ている、他の手法との違いを見ていきましょう。

  • ドメイン適応（Domain Adaptation, DA）：こちらはもうおなじみですね。ゼロショット学習は、ドメイン適応を更に突き詰めたものと考えることが出来ます。少し欲張りな話ですが、未知のクラスのデータがまったくなくても、そのクラスを認識出来るようにすることを目指します。一方、ドメイン適応は、データの分布が異なる2つの関連したドメイン（データセット）の違いを埋めることに重点を置き、ラベル付きデータを必要とします。
  • オープンセット認識（Open Set Recognition, OSR）：ゼロショット学習を、真か偽かの二択で判定するようなものだと考えて下さい。ZSL と同様に、OSR でもモデルは既知のクラスと未知のクラスの両方を扱います。但し ZSL とは異なり、テスト時には、入力データが既知のクラスに属するかどうかを判定するだけで済みます。具体的なクラス名まで答える必要はありません。それでも、これは大きな課題です。
  • 分布外（Out of Distribution, OOD）検出：オープンセット認識を、二択ではなく連続的な尺度で考える手法と捉えて下さい。ここでは、訓練時に登場しなかったデータを全て検出するのではなく、訓練データの分布から大きく外れたデータを検出します。予期しないデータを適切に検出して扱えるようになれば、予測出来ない環境にも対応出来る、より信頼性が高く頑健な AI システムの実現につながります。
  • オープンボキャブラリ学習（Open Vocabulary Learning, OVL）：ゼロショット学習が目指す方向性を、更に発展させたものです。いわば、ZSL を大幅にパワーアップさせたような手法です。OVL は ZSL の拡張と考えることが出来、未知のクラスの限られたデータから学習する能力に加えて、既知のクラスや、理論上は無数に存在し得る新しいクラスとタスクにも対応出来るようにします。
