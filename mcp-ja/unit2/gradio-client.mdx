# MCP クライアントとしての Gradio

前のセクションでは、Gradio で MCP サーバーを作成し、クライアントから接続する方法を学びました。ここでは、Gradio 自体を MCP クライアントとして使い、MCP サーバーに接続する方法を説明します。

> [!TIP]
> Gradio は UI クライアントや MCP サーバーの作成に特に適していますが、Gradio 自体を MCP クライアントとして使い、その機能を UI から利用出来るようにすることも出来ます。

前のセクションで作成したサーバーに似ていますが、更に機能を備えた MCP サーバーに接続し、そのツールを使って質問に答えます。

## Gradio の MCP クライアント

### サンプル MCP サーバーに接続する

Hugging Face 上で既に動作しているサンプルの MCP サーバーに接続しましょう。今回は、複数の MCP ツールを提供している [この Space](https://huggingface.co/spaces/abidlabs/mcp-tool-http) を使います。

```python
from smolagents.mcp_client import MCPClient

with MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",}
) as tools:
    # リモートサーバーのツールが利用可能になる
    print("\n".join(f"{t.name}: {t.description}" for t in tools))

```

### Gradio から MCP サーバーに接続する

サンプル MCP サーバーに接続出来ました。次は、それをサンプルアプリケーションで使います。

まず、未だインストールしていない場合は、`smolagents`、Gradio、mcp-client ライブラリをインストールする必要があります。

```bash
pip install "smolagents[mcp]" "gradio[mcp]" mcp fastmcp
```

次に、必要なライブラリをインポートし、MCP クライアントを使って MCP サーバーに接続するシンプルな Gradio インターフェースを作成します。


```python
import gradio as gr
import os

from mcp import StdioServerParameters
from smolagents import InferenceClientModel, CodeAgent, ToolCollection, MCPClient
```

次に、MCP サーバーに接続し、質問に答える為に使えるツールを取得します。

```python
mcp_client = MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",} # これは前のセクションで作成した MCP クライアントです
)
tools = mcp_client.get_tools()
```

ツールが用意出来たので、それらを使って質問に答えるシンプルなエージェントを作成出来ます。ここでは、シンプルな `InferenceClientModel` と `smolagents` のデフォルトモデルを使います。

InferenceClientModel に api_key を渡すことが重要です。トークンは Hugging Face アカウントから取得出来ます。詳しくは [Hugging Face のアクセストークンに関する説明](https://huggingface.co/docs/hub/en/security-tokens) を参照してください。

アクセストークンは環境変数 `HF_TOKEN` で設定します。

```python
model = InferenceClientModel(token=os.getenv("HF_TOKEN"))
agent = CodeAgent(tools=[*tools], model=model)
```

これで、エージェントを使って質問に答えるシンプルな Gradio インターフェースを作成出来ます。

```python
demo = gr.ChatInterface(
    fn=lambda message, history: str(agent.run(message)),
    type="messages",
    examples=["Prime factorization of 68"],
    title="MCP ツールを使うエージェント",
    description="MCP ツールを使って質問に答えるシンプルなエージェントです。"
)

demo.launch()
```

これで完成です！ MCP クライアントを使って MCP サーバーに接続し、質問に答えるシンプルな Gradio インターフェースを作成しました。

## 完全な例

Gradio で MCP クライアントを使う完全な例は次の通りです。

```python
import gradio as gr
import os

from smolagents import InferenceClientModel, CodeAgent, MCPClient


try:
    mcp_client = MCPClient(
        {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse",}
    )
    tools = mcp_client.get_tools()

    model = InferenceClientModel(token=os.getenv("HUGGINGFACE_API_TOKEN"))
    agent = CodeAgent(tools=[*tools], model=model, additional_authorized_imports=["json", "ast", "urllib", "base64"])

    demo = gr.ChatInterface(
        fn=lambda message, history: str(agent.run(message)),
        type="messages",
        examples=["Analyze the sentiment of the following text 'This is awesome'"],
        title="MCP ツールを使うエージェント",
        description="MCP ツールを使って質問に答えるシンプルなエージェントです。",
    )

    demo.launch()
finally:
    mcp_client.disconnect()
```

`finally` ブロックで MCP クライアントを閉じていることに注目してください。MCP クライアントはプログラム内で長く使い続けるオブジェクトなので、プログラムの終了時には必ず閉じる必要があります。

## Hugging Face Spaces へのデプロイ

サーバーを他の人が使えるようにするには、前のセクションと同様に、Hugging Face Spaces にデプロイ出来ます。Gradio MCP クライアントを Hugging Face Spaces にデプロイするには、次の操作を行います。

1. Hugging Face で新しい Space を作成する
   - huggingface.co/spaces にアクセスする
   - 「Create new Space」をクリックする
   - SDK として「Gradio」を選択する
   - Space に名前を付ける（例：「mcp-client」）

2. コード内の MCP サーバーの URL を更新する

```python
mcp_client = MCPClient(
    {"url": "https://abidlabs-mcp-tool-http.hf.space/gradio_api/mcp/sse", "transport": "sse"}
)
```

3. `requirements.txt` ファイルを作成する
```txt
gradio[mcp]
smolagents[mcp]
```

4. コードを Space にプッシュする
```bash
git init
git add app.py requirements.txt
git commit -m "Initial commit"
git remote add origin https://huggingface.co/spaces/YOUR_USERNAME/mcp-client
git push -u origin main
```

注：Git のリモートリポジトリ（`origin`）を追加する時は、アクセストークンを使う方法について、[Git のパスワード認証廃止に関する記事](https://huggingface.co/blog/password-git-deprecation) を参照してください。
