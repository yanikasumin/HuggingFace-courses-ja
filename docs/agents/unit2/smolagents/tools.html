ツール

Unit 1で探ったように、エージェントはさまざまなアクションを実行するためにツールを使います。smolagents では、ツールはエージェントシステムの中で LLM が呼び出せる関数として扱われます。

ツールとやり取りするために、LLM には次の主要な構成要素を持つインターフェースの説明が必要です。

  • 名前: ツールの呼び名
  • ツールの説明: ツールが何をするか
  • 入力の型と説明: ツールが受け取る引数
  • 出力の型: ツールが返すもの

たとえば、ウェイン邸でのパーティーの準備をしながら、アルフレッドはケータリングサービスの検索からパーティーテーマのアイデア探しまで、情報を集めるためのさまざまなツールを必要とします。シンプルな検索ツールのインターフェースは、次のようになります。

  • 名前: web_search
  • ツールの説明: 特定のクエリで Web を検索する
  • 入力: query（文字列）- 検索する語句
  • 出力: 検索結果を含む文字列

これらのツールを使うことで、アルフレッドは情報に基づいた判断を下し、完璧なパーティーの計画に必要な情報をすべて集めることができます。

以下では、ツール呼び出しがどう管理されるかを示すアニメーションが見られます。

ツールの作成方法

smolagents では、ツールは2つの方法で定義できます。 1. シンプルな関数ベースのツールには @tool デコレータを使う 2. より複雑な機能には Tool のサブクラスを作成する

@tool デコレータ

@tool デコレータは、シンプルなツールを定義する推奨の方法です。内部では、smolagents が Python から関数に関する基本情報をパースします。そのため、関数の名前を分かりやすくし、良い docstring を書けば、LLM が使いやすくなります。

このアプローチでは、次の要素を持つ関数を定義します。

  • LLM が目的を理解しやすい、明確で説明的な関数名
  • 適切な使用を保証するための、入力と出力の両方に対する型ヒント
  • 各引数を明示的に説明する Args: セクションを含む、詳細な説明。これらの説明は LLM に貴重なコンテキストを提供するので、丁寧に書くことが重要です

最高評価のケータリングを取得するツールを生成する

💡 ヒント

コードは、Google Colab で実行できるこのノートブックで追うことができます。

アルフレッドはすでにパーティーのメニューを決めましたが、今度は大勢のゲストのために料理を用意する手助けが必要です。そのためにケータリングサービスを雇いたいと考えており、利用可能な中で最高評価の選択肢を特定する必要があります。アルフレッドは、自分の地域で最高のケータリングサービスを検索するツールを活用できます。

以下は、アルフレッドが @tool デコレータを使ってこれを実現する例です。

from smolagents import CodeAgent, InferenceClientModel, tool

# 最高評価のケータリングサービスを取得する関数があると仮定します
@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.

    Args:
        query: A search term for finding catering services.
    """
    # ケータリングサービスとその評価の例
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }

    # 最も評価の高いケータリングサービスを探す（検索クエリによるフィルタリングをシミュレーション）
    best_service = max(services, key=services.get)

    return best_service


agent = CodeAgent(tools=[catering_service_tool], model=InferenceClientModel())

# 最高のケータリングサービスを見つけるためにエージェントを実行する
result = agent.run(
    "Can you give me the name of the highest-rated catering service in Gotham City?"
)

print(result)   # 出力: Gotham Catering Co.

ツールを Python クラスとして定義する

このアプローチでは、Tool のサブクラスを作成します。複雑なツールについては、Python 関数の代わりにクラスを実装できます。このクラスは、LLM が効果的に使えるよう助けるメタデータで関数をラップします。このクラスでは次を定義します。

  • name: ツールの名前。
  • description: エージェントのシステムプロンプトに組み込まれる説明。
  • inputs: type と description をキーに持つ辞書で、Python インタープリターが入力を処理するための情報を提供します。
  • output_type: 期待される出力の型を指定します。
  • forward: 実行する推論ロジックを含むメソッド。

以下では、Tool を使って構築したツールの例と、それを CodeAgent に統合する方法が見られます。

スーパーヒーローをテーマにしたパーティーのアイデアを生成するツールを作る

邸宅でのアルフレッドのパーティーはスーパーヒーローがテーマのイベントですが、本当に特別なものにするには独創的なアイデアが必要です。素晴らしいホストとして、彼はユニークなテーマでゲストを驚かせたいと考えています。

そのために、与えられたカテゴリに基づいてスーパーヒーローをテーマにしたパーティーのアイデアを生成するエージェントを使えます。こうすれば、アルフレッドはゲストを感動させる完璧なパーティーテーマを見つけられます。

from smolagents import Tool, CodeAgent, InferenceClientModel

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""

    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }

    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic Gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }

        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")

# ツールをインスタンス化する
party_theme_tool = SuperheroPartyThemeTool()
agent = CodeAgent(tools=[party_theme_tool], model=InferenceClientModel())

# パーティーテーマのアイデアを生成するためにエージェントを実行する
result = agent.run(
    "What would be a good superhero party idea for a 'villain masquerade' theme?"
)

print(result)  # 出力: "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains."

このツールがあれば、アルフレッドは究極のスーパーホストとなり、忘れられないスーパーヒーローをテーマにしたパーティーでゲストを感動させるでしょう！ 🦸‍♂️🦸‍♀️

デフォルトのツールボックス

smolagents には、エージェントに直接注入できる事前に構築されたツール一式が付属しています。デフォルトのツールボックスには次のものが含まれます。

  • PythonInterpreterTool
  • FinalAnswerTool
  • UserInputTool
  • DuckDuckGoSearchTool
  • GoogleSearchTool
  • VisitWebpageTool

アルフレッドは、ウェイン邸での完璧なパーティーのためにさまざまなツールを使えます。

  • まず、DuckDuckGoSearchTool を使って、独創的なスーパーヒーローをテーマにしたパーティーのアイデアを探せます。

  • ケータリングについては、GoogleSearchTool を頼りにゴッサムで最高評価のサービスを探せます。

  • 座席の配置を管理するために、アルフレッドは PythonInterpreterTool で計算を実行できます。

  • すべてが集まったら、FinalAnswerTool を使って計画をまとめます。

これらのツールにより、アルフレッドはパーティーが格別で、かつ滞りないものになることを保証します。🦇💡

ツールの共有とインポート

smolagents の最も強力な機能のひとつは、カスタムツールを Hub で共有し、コミュニティが作成したツールをシームレスに統合できることです。これには HF Spaces や LangChain ツール との接続も含まれ、ウェイン邸で忘れられないパーティーを演出するアルフレッドの能力を大きく高めます。🎭

これらの統合により、アルフレッドは高度なイベント企画ツールを利用できます。完璧な雰囲気のための照明の調整、パーティーに理想的なプレイリストの選定、ゴッサム最高のケータリング業者との調整などです。

ここでは、これらの機能がパーティー体験をどう引き上げるかを示す例を紹介します。

ツールを Hub に共有する

カスタムツールをコミュニティと共有するのは簡単です。push_to_hub() メソッドを使って、自分の Hugging Face アカウントにアップロードするだけです。

たとえば、アルフレッドは party_theme_tool を共有して、他の人がゴッサムで最高のケータリングサービスを見つけられるよう支援できます。方法は次のとおりです。

party_theme_tool.push_to_hub("{your_username}/party_theme_tool", token="<YOUR_HUGGINGFACEHUB_API_TOKEN>")

ツールを Hub からインポートする

load_tool() 関数を使えば、他のユーザーが作成したツールを簡単にインポートできます。たとえば、アルフレッドが AI を使ってパーティーの宣伝画像を生成したいとします。ツールをゼロから構築する代わりに、コミュニティの事前定義されたツールを利用できます。

from smolagents import load_tool, CodeAgent, InferenceClientModel

image_generation_tool = load_tool(
    "m-ric/text-to-image",
    trust_remote_code=True
)

agent = CodeAgent(
    tools=[image_generation_tool],
    model=InferenceClientModel()
)

agent.run("Generate an image of a luxurious superhero-themed party at Wayne Manor with made-up superheros.")

Hugging Face Space をツールとしてインポートする

Tool.from_space() を使って、HF Space をツールとしてインポートすることもできます。これにより、画像生成からデータ分析まで、さまざまなタスクのためにコミュニティの何千もの Space と連携できる可能性が開けます。

このツールは gradio_client を使って Space の Gradio バックエンドに接続するので、まだインストールしていない場合は pip でインストールしてください。

パーティーのために、アルフレッドは既存の HF Space を使って、告知に使う AI 生成画像を生成できます（前に触れた事前構築ツールを使う代わりに）。作ってみましょう！

from smolagents import CodeAgent, InferenceClientModel, Tool

image_generation_tool = Tool.from_space(
    "black-forest-labs/FLUX.1-schnell",
    name="image_generator",
    description="Generate an image from a prompt"
)

model = InferenceClientModel("Qwen/Qwen2.5-Coder-32B-Instruct")

agent = CodeAgent(tools=[image_generation_tool], model=model)

agent.run(
    "Improve this prompt, then generate an image of it.",
    additional_args={'user_prompt': 'A grand superhero-themed party at Wayne Manor, with Alfred overseeing a luxurious gala'}
)

LangChain ツールをインポートする

LangChain フレームワークについては、今後のセクションで取り上げます。ここでは、smolagents のワークフローで LangChain ツールを再利用できることだけ述べておきます！

Tool.from_langchain() メソッドを使えば、LangChain ツールを簡単に読み込めます。完璧主義者のアルフレッドは、ウェイン家が留守のあいだウェイン邸で壮大なスーパーヒーローの夜を用意しています。すべての細部が期待を超えるよう、彼は LangChain ツールを利用して一流のエンターテイメントのアイデアを探します。

Tool.from_langchain() を使うことで、アルフレッドは高度な検索機能を自分の smolagent に手軽に追加でき、数個のコマンドだけで限定のパーティーのアイデアやサービスを見つけられます。

方法は次のとおりです。

まず、smolagents 用の langchain 統合をインストールする必要があります。

pip install -U langchain-community

langchain 統合をインストールしたあと、SerpAPI キーを設定してください。 これは SerpAPITool のような検索ベースのツールに必要です。

os.environ['SERPAPI_API_KEY'] = '...'

SerpAPI キーはこちらで作成できます。

from langchain.agents import load_tools
from smolagents import CodeAgent, InferenceClientModel, Tool

search_tool = Tool.from_langchain(load_tools(["serpapi"])[0])

agent = CodeAgent(tools=[search_tool], model=model)

agent.run("Search for luxury entertainment ideas for a superhero-themed event, such as live performances and interactive experiences.")

あらゆる MCP サーバーからツールコレクションをインポートする

smolagents では、glama.ai や smithery.ai で利用できる何百もの MCP サーバーからツールをインポートすることもできます。MCP についてもっと深く知りたい場合は、無料の MCP コースをご覧ください。

MCP クライアントをインストールする まず、`smolagents` 用の `mcp` 統合をインストールする必要があります。 
pip install "smolagents[mcp]"

MCP サーバーのツールは、次のように ToolCollection オブジェクトに読み込めます。

import os
from smolagents import ToolCollection, CodeAgent
from mcp import StdioServerParameters
from smolagents import InferenceClientModel


model = InferenceClientModel("Qwen/Qwen2.5-Coder-32B-Instruct")


server_parameters = StdioServerParameters(
    command="uvx",
    args=["--quiet", "pubmedmcp@0.1.3"],
    env={"UV_PYTHON": "3.12", **os.environ},
)

with ToolCollection.from_mcp(server_parameters, trust_remote_code=True) as tool_collection:
    agent = CodeAgent(tools=[*tool_collection.tools], model=model, add_base_tools=True)
    agent.run("Please find a remedy for hangover.")

このセットアップにより、アルフレッドは豪華なエンターテイメントの選択肢を素早く見つけることができ、ゴッサムの上流階級のゲストに忘れられない体験を保証します。このツールは、ウェイン邸での完璧なスーパーヒーローをテーマにしたイベントの企画を助けてくれます！ 🎉
