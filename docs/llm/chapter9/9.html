1. Gradio を使うと何ができますか？

正解です！数行の Python コードで、組み込みコンポーネントのライブラリを使って ML モデルのデモを生成できます。
正解です！launch メソッドの share=True パラメータを使えば、誰にでも送れる共有リンクを生成できます。
正解です！Gradio デモの利点の1つは、実データでモデルをテストし、データを変更しながらモデルの予測がリアルタイムに変わる様子を観察できることです。これがモデルのデバッグに役立ちます。
不正解です。Gradio は、モデルの学習が終わった後の、モデル推論に使うよう設計されています。

2. Gradio は PyTorch モデルでしか動作しない

不正解です。Gradio は PyTorch に限らず、さまざまな機械学習モデルに対応しています！
正解です！Gradio はモデルに依存しないため、あらゆる種類の機械学習モデルのデモを作成できます。

3. Gradio デモはどこから起動できますか？

正解です！Gradio はお気に入りの IDE で問題なく動作します。
正解です！Google Colab ノートブック内でデモを作成して起動できます。
正解です！Jupyter ノートブック内でデモを作成し、起動できます。

4. Gradio は主に NLP モデル向けに設計されている

不正解です。Gradio は NLP だけでなく、ほぼあらゆるデータ型で動作します。
正解です！Gradio は、ほぼすべてのデータ型に対応した組み込みコンポーネントのライブラリを開発者に提供しています。

5. 次のうち、Gradio がサポートしている機能はどれですか？

正解です！Gradio では複数の入出力が可能です。対応するパラメータに入力と出力のリストを渡すだけです。
正解です！Gradio ではインターフェースに状態を追加できます。
正解です！launch メソッドにユーザー名/パスワードのタプルのリストを渡すことで、認証を追加できます。
不正解です。Gradio は、デモの利用者に関する分析を開発者に提供していません。
正解です！gr.Interface.load() メソッドを使えば、あらゆる Hugging Face モデルを読み込めます。

6. 次のうち、Hugging Face モデルを Hub または Spaces から読み込む正しい方法はどれですか？

正解です！これは Hub から Hugging Face モデルを読み込む正しい方法です。

7. Gradio インターフェースに状態を追加するために必要なステップをすべて選んでください

正解です！インターフェースの履歴や状態を保存する追加のパラメータが必要です。
正解です！この履歴や状態の値を関数から返す必要があります。
正解です！Gradio には、データを保持するための状態入力・出力コンポーネントが用意されています。

8. 次のうち、Gradio ライブラリに含まれるコンポーネントはどれですか？

正解です！Textbox コンポーネントでテキストボックスを作成できます。

9. Gradio の Blocks を使うと何ができますか？

正解です！`with gradio.Tabs():` を使えば、複数のデモ用のタブを追加できます。
正解です！イベントを割り当てる際は、3つのパラメータを渡します: fn（呼び出す関数）、inputs（入力コンポーネント。複数の場合はリストで指定）、outputs（出力コンポーネント。複数の場合はリストで指定）です。
正解です！定義したイベントトリガーに基づいて、Blocks はコンポーネントがユーザーの入力を受け付けるべきかどうかを自動で判断します。
正解です！1つのコンポーネントを、あるイベントトリガーの入力でありながら、別のイベントトリガーの出力にできます。
