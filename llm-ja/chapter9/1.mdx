この章では、機械学習モデルを **インタラクティブなデモ** として見せる方法を学びます。

そもそも、なぜモデルのデモや GUI を作るのでしょうか。デモがあれば:

- **機械学習の開発者** は、技術に詳しくないチームや顧客を含む幅広い相手に、自分の成果を分かりやすく見せられます
- **研究者** は、機械学習モデルとその挙動を再現しやすくなります
- **品質テスター** や **エンドユーザー** は、モデルの失敗ポイントを見つけてデバッグしやすくなります
- **多様なユーザー** が、モデルに潜むアルゴリズムのバイアスを発見できます

モデルのデモ作りには Gradio というライブラリを使います。Gradio を使うと、あらゆる機械学習モデルに対応した Web ベースのデモを、すべて Python で構築・カスタマイズ・共有できます。

この章は、_概念_ と _応用_ の両方を含むセクションで構成されています。各セクションで概念を学んだら、それを応用して、画像分類から音声認識まで、さまざまな種類のデモを作ります。この章を終えるころには、わずか数行の Python コードでこれらのデモ（そしてもっと多くのデモ！）を作れるようになるはずです。
