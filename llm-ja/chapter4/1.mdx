[Hugging Face Hub](https://huggingface.co/) は Hugging Face のメインの Web サイトです。誰でも最先端のモデルやデータセットを見つけて利用したり、新しいモデルやデータセットを公開してコミュニティに貢献したりできます。10,000 を超える多種多様なモデルが公開されています。この章ではモデルを取り上げ、データセットについては Chapter 5 で説明します。

Hub で公開されているのは、🤗 Transformers のモデルや NLP 向けのモデルだけではありません。NLP 向けには [Flair](https://github.com/flairNLP/flair) や [AllenNLP](https://github.com/allenai/allennlp)、音声処理向けには [Asteroid](https://github.com/asteroid-team/asteroid) や [pyannote](https://github.com/pyannote/pyannote-audio)、画像処理向けには [timm](https://github.com/rwightman/pytorch-image-models) など、様々なライブラリのモデルが公開されています。

これらのモデルはそれぞれ Git リポジトリとして公開されているため、バージョンを管理でき、結果の再現もしやすくなっています。Hub でモデルを共有すると、コミュニティの誰もが簡単に利用できるようになります。利用者は自分でモデルを学習させる必要がなくなり、モデルを共有したり利用したりする手間も減らせます。

更に、Hub でモデルを共有すると、そのモデルをサーバー上で実行できる Inference API が自動的に用意されます。コミュニティの誰でも、モデルのページで好きな入力を指定し、用途に合ったウィジェットを使って直接試せます。

何より、Hub の公開モデルの共有も利用も完全に無料です。モデルを非公開で共有したい場合は [有料プラン](https://huggingface.co/pricing) もあります。
