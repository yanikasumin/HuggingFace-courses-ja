🤗 Datasets ライブラリを巡る、なかなかの旅でした。ここまでたどり着いた皆さん、お疲れさまでした！この章で得た知識があれば、次のことができるようになっているはずです。

- Hugging Face Hub、自分のノートパソコン、会社のリモートサーバーなど、場所を問わずデータセットを読み込める。
- `Dataset.map()` と `Dataset.filter()` 関数を組み合わせて、データを自在に扱える。
- `Dataset.set_format()` を使って、Pandas や NumPy に対応した出力形式へすばやく切り替えられる。
- 自分だけのデータセットを作って、Hugging Face Hub にプッシュできる。
- Transformer モデルでドキュメントを埋め込み、FAISS を使ったセマンティック検索エンジンを構築できる。

[Chapter 7](/course/chapter7) では、Transformer モデルが得意とする中核的な NLP タスクを深く掘り下げ、ここで学んだことを存分に活用します。その前に、短いクイズで 🤗 Datasets の知識を試しておきましょう！
