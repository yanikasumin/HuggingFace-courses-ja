最初のユニット、お疲れさまでした！ここまでに学んだ重要な概念を、どれくらい理解できているか確認しましょう。

クイズに合格したら、次のセクションに進んで認定証を取得してください。

頑張ってください！

クイズ

以下にインタラクティブなクイズを用意しました。このクイズは Hugging Face Hub の Space で公開されています。選択式の問題に答えながら、このユニットで学んだ重要な概念への理解を確認できます。クイズを完了すると、スコアと正解の内訳が確認できます。

重要：クイズに合格したら、必ず「Submit」をクリックしてください。クリックしないと試験のスコアが保存されません！

クイズには 👉 こちら からもアクセスできます。

認定証

クイズに合格したので、認定証 🎓 を取得できます。

クイズを完了すると、このユニットの修了認定証にアクセスできるようになります。認定証をダウンロードして共有し、コースの進捗をアピールしましょう。

認定証を受け取ったら、LinkedIn 🧑‍💼 のプロフィールに追加したり、X や Bluesky などで共有したりできます。@huggingface をタグ付けしてくれたら、私たちも誇らしく思いますし、お祝いしたいと思います！ 🤗
