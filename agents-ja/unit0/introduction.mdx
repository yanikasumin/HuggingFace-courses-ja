今、AI 分野で最も注目されているテーマ、**Agents（エージェント）**の世界へようこそ！

この無料コースでは、**初歩から専門的な内容まで**段階的に学びながら、AIエージェントの仕組みを理解し、活用し、自分で構築する方法を身に付けられます。

この最初のユニットは、コースを始める為の準備編です。

- **コースのシラバス**を確認します。
- 受講の**進め方を選びます**（聴講のみか、認定プロセスか）。
- **認定プロセスについて詳しく**知ることが出来ます。
- コースの運営チームを紹介します。
- **Hugging Face アカウント**を作成します。
- **Discord サーバーに参加して**、クラスメイトや運営チームと交流します。

さあ、始めましょう！

## このコースで得られること [[expect]]

このコースでは、次のようなことに取り組みます。

- AIエージェントを**理論・設計・実践**の面から学ぶ
- [smolagents](https://huggingface.co/docs/smolagents/en/index)、[LlamaIndex](https://www.llamaindex.ai/)、[LangGraph](https://langchain-ai.github.io/langgraph/) といった**実績の有るAIエージェント用ライブラリの使い方**を学ぶ
- 自分のエージェントを Hugging Face Hub で**共有し**、コミュニティが作ったエージェントを探索する
- **自分のエージェントを他の受講生のエージェントと競わせる**チャレンジに参加する
- 課題をこなして**修了証を取得する**

ほかにも盛り沢山です。

コースを終える頃には、**エージェントの仕組みや、最新のライブラリ・ツールを使って独自のエージェントを構築する方法**が分かるようになります。

忘れずに**<a href="https://bit.ly/hf-learn-agents">コースに登録してください！</a>**

（プライバシーは尊重します。メールアドレスは、**各ユニットの公開時にリンクを送ったり、チャレンジや更新情報を案内したりする**為にのみ収集します）

## コースの構成 [[course-look-like]]

このコースは次の要素で構成されています。

- *基礎ユニット*：エージェントの**基本概念や理論**を学びます。
- *ハンズオン*：**実績の有るAIエージェント用ライブラリ**を使い、それぞれに特色のある環境でエージェントを訓練する方法を学びます。実習には、予め環境が設定された **Hugging Face Spaces** を使用します。
- *ユースケース課題*：学んだ概念を応用して、自分で選んだ現実の問題を解きます。
- *チャレンジ*：自分のエージェントを他の受講生のエージェントと競わせます。エージェントの性能を比較出来る[リーダーボード](https://huggingface.co/spaces/agents-course/Students_leaderboard)も用意されています。

この**コースは、受講生のフィードバックと貢献で進化し続ける生きたプロジェクトです！** [GitHub で Issue や PR を開いたり](https://github.com/huggingface/agents-course)、Discord サーバーで議論したりして、気軽に参加してください。

コースを終えた後は、[👉 こちらのフォーム](https://docs.google.com/forms/d/e/1FAIpQLSe9VaONn0eglax0uTwi29rIn4tM7H2sYmmybmG5jJNlE5v0xA/viewform?usp=dialog)からフィードバックも送れます。

## シラバス [[syllabus]]

**コース全体のシラバス**は次の通りです。各ユニットの公開に合わせて、より詳しいトピック一覧も公開します。

| 章 | トピック | 説明 |
| :---- | :---- | :---- |
| 0 | オンボーディング | 使用するツールやプラットフォームの準備をします。 |
| 1 | エージェントの基礎 | Tools、Thoughts、Actions、Observations とその形式を説明します。LLM、メッセージ、特殊トークン、チャットテンプレートも扱います。Python 関数をツールとして使うシンプルなユースケースも紹介します。 |
| 2 | フレームワーク | エージェントの基本概念が、人気ライブラリ（smolagents、LangGraph、LLamaIndex）でどのように実装されているかを学びます。 |
| 3 | ユースケース | 実生活の課題を題材に、いくつかのユースケースを実装します（経験豊富なエージェント開発者からの PR も歓迎です） |
| 4 | 最終課題 | 選定されたベンチマークに対応するエージェントを構築し、受講生リーダーボードで学習成果を示します |

本編のシラバスに加えて、ボーナスユニットが3つ有ります。
- *ボーナスユニット 1*：Function-calling の為の LLM ファインチューニング
- *ボーナスユニット 2*：エージェントの可観測性と評価
- *ボーナスユニット 3*：ポケモンで遊ぶエージェント

例えばボーナスユニット 3 では、ポケモンバトルをプレイするエージェントの作り方を学びます。

## 認定プロセス [[certification-process]]

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit0/three-paths.jpg" alt="2つの進路" width="100%"/>

このコースは*聴講のみ*で受講することも、課題に取り組んで*運営が発行する2種類の証明書のいずれかを取得する*ことも出来ます。

聴講の場合でも、全てのチャレンジに参加出来、希望すれば課題にも取り組めます。**運営への連絡は不要です**。

認定プロセスは**完全無料**です。

- *基礎認定を取得するには*：コースのユニット 1 を修了する必要が有ります。エージェントの最新トレンドを押さえたい受講生向けです。
- *修了証を得るには*：ユニット 1 の修了に加えて、コース内で提示されるユースケース課題の内1つと、最終チャレンジを修了する必要が有ります。

認定プロセスに**締め切りはありません**。
