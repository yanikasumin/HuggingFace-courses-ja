Gradio、チェック！

これで、Gradio を使って素敵な ML デモを構築する章は終わりです。楽しんでいただけたでしょうか！振り返ると、この章では次のことを学びました:

  • 高レベルな Interface API を使って Gradio デモを作成し、さまざまな入出力モダリティを設定する方法。
  • 一時リンクと Hugging Face Spaces へのホスティングによる、Gradio デモの共有方法。
  • Gradio デモを Hugging Face Hub 上のモデルや Spaces と連携させる方法。
  • デモに状態を保存したり、認証を提供したりといった高度な機能。
  • Gradio Blocks を使って、デモのデータフローとレイアウトを完全に制御する方法。

この章で扱った概念の理解度をテストしたい場合は、次のセクションのクイズに挑戦してください！

次に進むには

Gradio についてもっと学びたい場合は、次の方法があります： - リポジトリの Demos を見てみましょう。たくさんの例があります。 - Guides ページでは、便利で高度な機能についてのガイドが見つかります。 - 詳細は Docs ページで確認してください。
