LLM Course — 原典: huggingface/course

大規模言語モデル（LLM）の仕組みを基礎から学ぶコースです。Transformer の動作原理から、Hugging Face Transformers の使い方、ファインチューニング、データセットやトークナイザの扱い、音声処理、独自モデルの構築まで学べます。
