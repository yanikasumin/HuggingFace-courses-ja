クイズ 1: MCP の基礎

Model Context Protocol のコアコンセプトに関する知識をテストしましょう。

Q1: Model Context Protocol（MCP）の主な目的は何ですか？

MCP は、AI モデルがアクセスできるコンテキストを制限するのではなく、拡張することを目指しています。
正解！MCP の主な目標は相互運用性を促進することです。
MCP はプロンプティングを強化するプロトコルであり、それを置き換えるものではありません。
MCP はプロトコルであり、プログラミング言語ではありません。

Q2: MCP が主に解決を目指す問題は何ですか？

MCP が対処するのは統合の課題であり、AI モデル自体の可用性ではありません。
MCP は効率を改善し得ますが、その主な焦点は学習コストの直接的な削減ではありません。
正解！MCP は接続を標準化し、M×N 通りのカスタム統合を避けられるようにします。
MCP は既存のアルゴリズムやツールを使うことを促進するもので、新しいものをゼロから作るためのものではありません。

Q3: 次のうち、MCP の主な利点はどれですか？

MCP は AI の能力を強化することを目指しているため、理想的には精度の向上や維持につながるべきであり、低下はしません。
MCP は統合を簡素化し、それによって複雑さを減らすことを目指しています。
正解！これは MCP の主な目標であり利点です。
MCP が促進するのは接続とやり取りであり、隔離ではありません。

Q4: MCP の用語で「ホスト」とは何ですか？

これは MCP サーバーを表しています。
正解！ホストはユーザーが操作するアプリケーションです。
これは MCP の機能（リソース）の一種を表しています。
これは MCP の機能（プロンプト）の一種を表しています。

Q5: AI アプリケーションの文脈で「M×N 統合問題」とは何を指しますか？

これはモデルの学習に関するもので、MCP が対処する統合問題ではありません。
正解！MCP はこの M*N の複雑さを解決するための標準を提供します。
