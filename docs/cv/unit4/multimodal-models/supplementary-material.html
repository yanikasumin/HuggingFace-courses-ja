補足資料と参考リソース 🤗

マルチモーダルモデルのユニットは楽しんでいただけたでしょうか。マルチモーダル学習とモデルについてさらに詳しく学びたい方のために、参考リソースをまとめました:

  • Hugging Face Tasks では、コンピュータービジョン、音声、NLP、マルチモーダル学習、強化学習などの領域のさまざまなタスクの概要を見られます。各タスクにはデモ、ユースケース、モデル、データセットなどが含まれています。
  • 11-777 MMML は CMU によるマルチモーダル機械学習のコースです。ビデオ講義はこちらで見られます。
  • Chip Huyen によるマルチモダリティと LLM についてのブログ では、マルチモダリティ、大規模マルチモーダルモデル、BLIP、CLIP などのシステムの包括的な概要が得られます。
  • Awesome Multimodal ML は、論文、コース、アーキテクチャ、ワークショップ、チュートリアルなどを集めた GitHub リポジトリです。
  • Awesome Multimodal Large Language Models は、マルチモーダル LLM に関する論文とデータセットを集めた GitHub リポジトリです。
  • EE/CS 148, Caltech は、大規模な言語・視覚モデルに関するコースです。

次ユニットでは、近年マルチモダリティによって革命が起きた、もう1種類のニューラルネットワークモデルを見ていきます: 生成ニューラルネットワークです。 絵筆を用意して、コンピュータービジョンの世界での新たな冒険に一緒に参加しましょう 🤠
