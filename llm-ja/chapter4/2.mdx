Model Hub を使えば、目的に合ったモデルを簡単に選べます。選んだモデルは、数行のコードで様々なライブラリから使うことが出来ます。この節では、モデルの使い方と、コミュニティへの貢献の方法を説明します。

フランス語に対応し、文中のマスクされた部分を予測出来るモデルを探している場合を考えます。

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/camembert.gif" alt="CamemBERT モデルを選択する様子。" width="80%"/>
</div>

試しに `camembert-base` チェックポイントを選びます。使い始める為に必要な識別子は `camembert-base` だけです。前の章で見たとおり、`pipeline()` 関数でインスタンス化出来ます。

```py
from transformers import pipeline

camembert_fill_mask = pipeline("fill-mask", model="camembert-base")
results = camembert_fill_mask("Le camembert est <mask> :)")
```


（入力文の訳：カマンベールは <mask> です :)。出力の訳：補完された文は「カマンベールは美味しいです :)」「カマンベールは素晴らしいです :)」「カマンベールはとても美味しいです :)」「カマンベールはより良いです :)」「カマンベールは完璧です :)」です）

パイプラインでモデルを読み込む手順は、このように非常に簡単です。注意点は一つだけです。選んだチェックポイントが、使うタスクに適しているかを確認してください。

例えば、`camembert-base` は `fill-mask` パイプラインで問題なく使えます。一方、`text-classification` パイプラインで使うと、意味の有る結果は得られません。`camembert-base` のヘッドがテキスト分類に適していない為です。

タスクに合ったチェックポイントを選ぶには、Hugging Face Hub の画面に在るタスクセレクタの利用をお勧めします。

<div class="flex justify-center">
<img src="https://huggingface.co/datasets/huggingface-course/documentation-images/resolve/main/en/chapter4/tasks.png" alt="Web インターフェースのタスクセレクタ。" width="80%"/>
</div>

モデルのアーキテクチャを直接使って、チェックポイントをインスタンス化することも出来ます。

{#if fw === 'pt'}
```py
from transformers import CamembertTokenizer, CamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = CamembertForMaskedLM.from_pretrained("camembert-base")
```

但し、お勧めは、特定のアーキテクチャに依存しない [`Auto*` クラス](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) です。先程のコードで読み込めるのは CamemBERT アーキテクチャのチェックポイントだけです。`Auto*` クラスを使えば、チェックポイントの切り替えが簡単になります。

```py
from transformers import AutoTokenizer, AutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = AutoModelForMaskedLM.from_pretrained("camembert-base")
```
{:else}
```py
from transformers import CamembertTokenizer, TFCamembertForMaskedLM

tokenizer = CamembertTokenizer.from_pretrained("camembert-base")
model = TFCamembertForMaskedLM.from_pretrained("camembert-base")
```

但し、お勧めは、特定のアーキテクチャに依存しない [`TFAuto*` クラス](https://huggingface.co/transformers/model_doc/auto?highlight=auto#auto-classes) です。先程のコードで読み込めるのは CamemBERT アーキテクチャのチェックポイントだけです。`TFAuto*` クラスを使えば、チェックポイントの切り替えが簡単になります。

```py
from transformers import AutoTokenizer, TFAutoModelForMaskedLM

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
model = TFAutoModelForMaskedLM.from_pretrained("camembert-base")
```
{/if}

> [!TIP]
> 事前学習済みモデルを使う際は、学習方法、学習に使ったデータセット、制限、バイアスを確認してください。これらの情報は、モデルカードに記載されているはずです。
