Hugging Face の学習コースを、日本語で学ぶ

このサイトは、AI 開発プラットフォーム Hugging Face が公開している無料の学習コース（英語）の日本語訳です。LLM（大規模言語モデル）、AI エージェント、コンピュータビジョンなど、5つのコース・全 316 セクションを日本語で読めます。

Hugging Face の公式コースは、世界中の開発者や研究者が機械学習を学ぶために使っている教材ですが、これまで日本語版がありませんでした。英語のままでは読み進めにくいという人のために、公式コースの内容をそのまま日本語で学べる形にして公開しています。各ページには英語の公式ページへのリンクがあるので、原文と照らし合わせながら読むこともできます。

このサイトの目的

Hugging Face の公式コースは優れた教材ですが、英語のみで公開されているため、日本語話者にとっては最初の一歩の負担が大きいものでした。このサイトの目的は、その入口の負担を取り除き、機械学習を日本語で、順序立てて学べる場所を用意することです。

日本語で全体像をつかんだうえで、各ページから公式の英語ページへ進んで原文に当たる、という使い方も想定しています。翻訳は学習の代わりではなく、学習への入口です。

学べるコース

コースは5つあります。いずれも無料で、登録なしで読めます。多くのセクションには理解度を確認するクイズと、実際に動かせるコード例が含まれています。

  • データセットとトークナイザの扱い

どのコースから始めるか

  • 機械学習や LLM を基礎から学びたい → LLM コース。第1章から順に読むのが基本の進め方です。
  • AI エージェントを作りたい → Agents コース。LLM コースの第1〜2章程度の知識があると進めやすくなります。
  • 画像認識や画像生成に興味がある → Community CV コース。基礎の Unit 1 から始めてください。
  • LLM に外部ツールをつなぐ仕組みを知りたい → MCP コース。短めのコースなので、他のコースと並行しても進められます。
  • ロボットを学習させたい → Robotics コース。全11セクションの短い入門編です。

使い方と学び方

  1. 目次から読む：各コースは章・ユニットの順番どおりに進む構成です。前後のセクションへは、ページ上下のナビゲーションで移動できます。
  2. クイズで確認する：多くのセクションにクイズがあり、その場で答え合わせができます。
  3. コードを動かす：コードは実際に動かしながら読むのが基本です。本文のコードを Google Colab や自分のパソコンなどの実行環境にコピーして実行してください（このサイト自体にはコードの実行機能はありません）。ブラウザ上で実行できるノートブックへのリンクが付いている節もあります。
  4. 原文と比べる：各ページ上部のボタンから、Hugging Face 公式の英語ページをすぐ開けます。専門用語の英語表現を確認したいときに便利です。
  5. 分からない言葉は用語集で：コースごとに、日本語版独自の用語集を用意しています。本文の検索も、ページ上部の検索窓からできます。

翻訳方法

この翻訳は、翻訳エージェント（Muse）、審査役（ChatGPT）、翻訳者（霞ヶ関京）の3者で工程を分担し、単元ごとに「翻訳 → レビュー → 照合と修正 → 再チェック」を繰り返して作りました。機械翻訳の出力をそのまま載せるのではなく、指摘と照合の往復で一文ずつ確定していく方法です。

工程の詳細

  1. 原典の固定（Muse）：各コースの英語版リポジトリを特定のコミットに固定し、翻訳対象の版を確定しました。固定したコミットは、コースごとにリポジトリの README に記載しています。原典が後から更新されても、翻訳の基準がぶれないようにするためです。
  2. 翻訳（Muse）：全316セクションを翻訳しました。見出しのアンカー、コード、数式、数値、URL、データは原文のまま保持し、本文と画面表示のラベルを訳します。モデルへの入力文のように「データ」として扱うべき英文は訳しません。
  3. レビュー（ChatGPT）：翻訳文を単元ごとにまとめ、ChatGPT の思考モードで審査しました。審査基準は、(1) 日本語の自然さ（『とほほのWWW入門』のような平易な解説文が手本）、(2) 意味の誤り、(3) 用語と表記、(4) 改行や記号の配置など日本語読者向けの組版、の4点です。指摘は、対象ファイルと行番号、現在の文の正確な引用、問題点、修正案の全文をセットで出させました。
  4. 照合と修正（Muse）：レビューの指摘は、そのままでは適用しません。1件ずつ実ファイルで引用が実在するかを確認し、原典と突き合わせてから修正しました。引用が実在しない指摘や、原典の内容と合わない修正案は、根拠がないものとして適用せず、審査側に再提示を求めました。
  5. 機械検証（Muse）：修正のたびに、コード・リンク・アンカー・画像が原典と一致しているかを自動で照合し、翻訳の過程で文書の構造が壊れていないことを確認しました。
  6. 再チェック（ChatGPT）：修正後の文を再び審査し、指摘が解消したかを判定しました。合格にならない場合は「照合と修正」に戻り、解消するまで繰り返しました。意図的に原文どおり残した箇所（原典由来の表現など）は、その理由を添えて再チェックにかけています。
  7. 公開（霞ヶ関京）：合格した文をサイトに反映して公開しました。文体の方針、用語の採否、原典自体に誤りがある場合の扱い（勝手に直さず原文に忠実に訳す）など、判断が要る点は翻訳者が決めています。

役割分担

  • Muse：翻訳の実務。翻訳、指摘の照合と修正、構造の機械検証、サイトの構築と公開作業を担当しました。
  • ChatGPT：第三者としての審査。翻訳者とは別の立場から、自然さと正確さを単元ごとにチェックしました。
  • 霞ヶ関京：翻訳者。文体の方針（平易な解説文）、用語の採否、原典の誤りの扱いなど、工程全体の方針と最終判断を担当しました。

公開後も、漢字と仮名の使い分けや改行の位置といった表記の整備を続けています。
