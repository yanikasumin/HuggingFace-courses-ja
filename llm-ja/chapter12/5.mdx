## データセットを読み込む

データセットを読み込みます。この演習では、短い物語を集めた [`mlabonne/smoltldr`](https://huggingface.co/datasets/mlabonne/smoltldr) データセットを使います。

```python
dataset = load_dataset("mlabonne/smoltldr")
```

## モデルを読み込む

次に、モデルを読み込みます。

この演習では、[`SmolLM2-135M`](https://huggingface.co/HuggingFaceTB/SmolLM2-135M) モデルを使います。

このモデルは、パラメータ数135Mの小さなモデルです。限られたハードウェアでも動作するため、学習の練習には向いています。但し、最も高性能なモデルではありません。より強力なハードウェアを使える場合は、[`SmolLM2-1.7B`](https://huggingface.co/HuggingFaceTB/SmolLM2-1.7B) のような大きなモデルのファインチューニングも試せます。

```python
model_id = "HuggingFaceTB/SmolLM-135M-Instruct"
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    torch_dtype="auto",
    device_map="auto",
    attn_implementation="flash_attention_2",
)
tokenizer = AutoTokenizer.from_pretrained(model_id)
```

## LoRA を読み込む

次に、LoRA の設定を読み込みます。LoRA を使うと、学習するパラメータの数が減ります。その分、ファインチューニングに必要なメモリ使用量も減ります。

LoRA に馴染みがない方は、[第11章](https://huggingface.co/learn/course/en/chapter11/3)で詳しく説明しています。

```python
# LoRA を読み込む
lora_config = LoraConfig(
    task_type="CAUSAL_LM",
    r=16,
    lora_alpha=32,
    target_modules="all-linear",
)
model = get_peft_model(model, lora_config)
print(model.print_trainable_parameters())
```

```sh
Total trainable parameters: 135M
```

## 報酬関数を定義する

前のセクションで述べた通り、GRPO では任意の報酬関数を使ってモデルを改善できます。この演習では、長さ50トークンのテキストを生成するようモデルを促す、簡単な報酬関数を使います。

```python
# 報酬関数
ideal_length = 50


def reward_len(completions, **kwargs):
    return [-abs(ideal_length - len(completion)) for completion in completions]
```

## 学習引数を定義する

学習引数を定義します。学習引数の定義には `GRPOConfig` クラスを使い、典型的な `transformers` の形式で書きます。

学習引数を定義するのが初めての方は、[TrainingArguments](https://huggingface.co/docs/transformers/en/main_classes/trainer#trainingarguments) クラスで詳細を確認してください。詳しい紹介は [第2章](https://huggingface.co/learn/course/en/chapter2/1)にもあります。

```python
# 学習引数
training_args = GRPOConfig(
    output_dir="GRPO",
    learning_rate=2e-5,
    per_device_train_batch_size=8,
    gradient_accumulation_steps=2,
    max_prompt_length=512,
    max_completion_length=96,
    num_generations=8,
    optim="adamw_8bit",
    num_train_epochs=1,
    bf16=True,
    report_to=["wandb"],
    remove_unused_columns=False,
    logging_steps=1,
)
```

これで、モデルとデータセットと学習引数を使ってトレーナーを初期化し、学習を開始できます。

```python
# トレーナー
trainer = GRPOTrainer(
    model=model,
    reward_funcs=[reward_len],
    args=training_args,
    train_dataset=dataset["train"],
)

# モデルを学習する
wandb.init(project="GRPO")
trainer.train()
```

学習には、Google Colab や Hugging Face Spaces で利用できる単一の A10G GPU で約1時間かかります。

## 学習中にモデルを Hub にプッシュする

`push_to_hub` 引数を `True` に設定し、`model_id` 引数に有効なモデル名を指定すると、学習中のモデルが Hugging Face Hub にプッシュされます。学習の途中からモデルを試し、どのような応答を生成するか確かめたい場合に便利です。

## 学習結果を解釈する

`GRPOTrainer` は、報酬関数からの報酬と損失、その他の様々なメトリクスを記録します。

ここでは、報酬関数からの報酬と損失に焦点を当てます。

ご覧の通り、モデルが学習するにつれて、報酬関数からの報酬は0に近づいていきます。これは、モデルが正しい長さのテキストを生成できるようになってきたことを示す、良い兆候です。

![報酬関数からの報酬](https://huggingface.co/reasoning-course/images/resolve/main/grpo/13.png)

損失は0から始まり、学習中に増加することに気づくかもしれません。直感に反するように思えますが、この振る舞いは GRPO では想定内のものです。アルゴリズムの数学的な定式化に直接関係しています。GRPO の損失は、KL ダイバージェンス（元の方策からの乖離を抑えるための尺度）に比例します。

学習が進むと、モデルは報酬関数によりよく合うテキストを生成するようになります。その分、当初の方策からは乖離していきます。この乖離の増大が損失値の上昇として現れます。損失の上昇は、モデルが報酬関数への最適化に適応できていることを示しています。

![損失](https://huggingface.co/reasoning-course/images/resolve/main/grpo/14.png)

## テキストを生成する

🎉 GRPO でモデルのファインチューニングができました。次に、このモデルでテキストを生成してみましょう。

まず、とても長い文書を定義します。

```python
prompt = """
# A long document about the Cat

The cat (Felis catus), also referred to as the domestic cat or house cat, is a small 
domesticated carnivorous mammal. It is the only domesticated species of the family Felidae.
Advances in archaeology and genetics have shown that the domestication of the cat occurred
in the Near East around 7500 BC. It is commonly kept as a pet and farm cat, but also ranges
freely as a feral cat avoiding human contact. It is valued by humans for companionship and
its ability to kill vermin. Its retractable claws are adapted to killing small prey species
such as mice and rats. It has a strong, flexible body, quick reflexes, and sharp teeth,
and its night vision and sense of smell are well developed. It is a social species,
but a solitary hunter and a crepuscular predator. Cat communication includes
vocalizations—including meowing, purring, trilling, hissing, growling, and grunting—as
well as body language. It can hear sounds too faint or too high in frequency for human ears,
such as those made by small mammals. It secretes and perceives pheromones.
"""

messages = [
    {"role": "user", "content": prompt},
]
```

（入力文の訳）

猫についての長い文書

猫（Felis catus）は、家猫とも呼ばれ、小型の家畜化された肉食哺乳類です。ネコ科の中で唯一家畜化された種です。考古学と遺伝学の進歩により、猫の家畜化は紀元前7500年頃に近東で起きたことが示されています。一般にはペットや農場の猫として飼われていますが、人との接触を避ける野良猫として自由に行動することもあります。人間からは、伴侶であることと、害獣を殺す能力のために重んじられています。格納できる爪は、ネズミやラットのような小さな獲物の種を殺すのに適しています。強く柔軟な体、素早い反射神経、鋭い歯を持ち、暗視能力と嗅覚がよく発達しています。社会性のある種ですが、単独で狩りをする、薄明薄暮性の捕食者です。猫のコミュニケーションには、ニャーと鳴くこと、喉をゴロゴロ鳴らすこと、震える声で鳴くこと、シューッと鳴くこと、うなること、うめくことといった発声と、体の動きによる表現が含まれます。人間の耳にはかすか過ぎたり、周波数が高過ぎたりする音、例えば小さな哺乳類が出すような音も聞くことができます。フェロモンを分泌し、感知します。

では、モデルを使ってテキストを生成します。

```python
# テキストを生成する
from transformers import pipeline

generator = pipeline("text-generation", model="SmolGRPO-135M")

## または、先に定義したモデルとトークナイザを使う
# generator = pipeline("text-generation", model=model, tokenizer=tokenizer)

generate_kwargs = {
    "max_new_tokens": 256,
    "do_sample": True,
    "temperature": 0.5,
    "min_p": 0.1,
}

generated_text = generator(messages, generate_kwargs=generate_kwargs)

print(generated_text)
```
