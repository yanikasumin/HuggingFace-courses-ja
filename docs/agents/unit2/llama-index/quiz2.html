えっ、またクイズですか？ その気持ちは分かります…… 😅 でも、この短い採点なしのクイズは、今学んだばかりの重要な概念を定着させるためのものです。

このクイズでは、効果的な AI エージェントを構築するうえで欠かせない、エージェントのワークフローとインタラクションを扱います。

Q1: LlamaIndex の AgentWorkflow の目的は何ですか？

はい。AgentWorkflow は、1つ以上のエージェントからなるシステムを手早く作成するための主な方法です。
いいえ。AgentWorkflow にはそれ以上のことができます。データに対する単純なクエリには QueryEngine を使います。
AgentWorkflow がツールを構築することはありません。ツールの構築は開発者の仕事です。
メモリと状態の管理は、AgentWorkflow の主な目的ではありません。

Q2: ワークフローの状態を追跡するために使うオブジェクトはどれですか？

State は、ワークフローの状態管理に使う正しいオブジェクトではありません。
Context が、ワークフローの状態を追跡するために使う正しいオブジェクトです。
WorkflowState は正しいオブジェクトではありません。
Management は、ワークフローの状態に使える有効なオブジェクトではありません。

Q3: エージェントに過去のインタラクションを記憶させたい場合、どのメソッドを使うべきですか？

.run(query_str) では会話履歴は保持されません。
chat() はワークフローで使える有効なメソッドではありません。
interact() は、エージェントとのインタラクションに使える有効なメソッドではありません。
コンテキストを渡して維持することで、状態を保持できます。

Q4: Agentic RAG の主な特徴は何ですか？

Agentic RAG は、ドキュメントベースのツールを含む、さまざまなツールを使うことができます。
Agentic RAG は、質問に答えるためにツールを使います。
Agentic RAG には、さまざまなツールを使って質問に答えられる柔軟さがあります。
Agentic RAG は Function Calling Agents に限定されません。
