# イントロダクション

![ボーナスユニット 1 のサムネイル](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/bonus-unit1/thumbnail.jpg)

最初の**ボーナスユニット**へようこそ。ここでは、**Function-calling（関数呼び出し）のために大規模言語モデル（LLM）をファインチューニングする**方法を学びます。

LLM を扱ううえで、Function-calling は急速に*知っておくべき*技術になりつつあります。

考え方はこうです。ユニット 1 で行ったようなプロンプトベースの方法だけに頼るのではなく、Function-calling では**モデルが行動を起こし、その結果を解釈できるよう、訓練の段階から学習させます**。これにより、AI をより堅牢にできます。

> **このボーナスユニットはいつやるべきですか？**
>
> このセクションは**任意**で、ユニット 1 より高度な内容です。今すぐ取り組んでもよいし、このコースで知識が深まってから戻ってきても構いません。
>  
> 但し心配はいりません。このボーナスユニットでは、必要な情報をひととおり説明します。ファインチューニングの詳しい仕組みをまだ知らなくても、Function-calling のためのファインチューニングに必要な基本概念を一つずつ学べるように説明します。

このボーナスユニットをスムーズに進めるには、次の知識があると役立ちます。

1. Transformers を使った LLM のファインチューニング方法を知っていること。分からない場合は[こちらを確認してください](https://huggingface.co/learn/nlp-course/chapter3/1?fw=pt)。

2. モデルのファインチューニングに `SFTTrainer` を使う方法を知っていること。詳しくは[こちらのドキュメント](https://huggingface.co/learn/nlp-course/en/chapter11/1)を確認してください。

---

## 学ぶこと

1. **Function-calling**  
   現在の LLM が会話を適切に構成し、**ツール**を呼び出せるようにする仕組み。

2. **LoRA（Low-Rank Adaptation）**  
   計算とストレージのオーバーヘッドを抑える、**軽量で効率的な**ファインチューニング手法。LoRA を使うと、大規模モデルを*より速く、低コストで訓練でき、デプロイもしやすく*なります。

3. Function-calling モデルにおける **Thought → Act → Observe サイクル**  
   モデルが関数を呼び出すタイミングと方法を判断し、中間ステップを追跡して、外部のツールや API から返された結果を解釈できるようにするための、シンプルで強力な方法。

4. **新しい特殊トークン**  
   モデルが次のものを区別するのに役立つ**特殊なマーカー**を紹介します。
   - 内部で行う「思考の連鎖（chain-of-thought）」による推論
   - 外部への関数呼び出し
   - 外部ツールから返ってくる応答

---

このボーナスユニットを終える頃には、次のことができるようになります。

- ツールを扱う API が内部でどのように動くのかを**理解する**。
- LoRA の手法を使ってモデルを**ファインチューニングする**。
- Thought → Act → Observe サイクルを**実装**・**変更**して、堅牢で保守しやすい Function-calling のワークフローを作る。
- 特殊トークンを**設計・活用**して、モデルの内部推論と外部アクションをシームレスに分離する。

そして、**自分のモデルを Function-calling に対応させるためのファインチューニングも完了しているはずです**。🔥

さあ、**Function-calling** を学んでいきましょう！
