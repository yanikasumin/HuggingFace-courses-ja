合成データの利用に伴う課題と可能性

機械学習モデルの訓練には大量のデータが必要です。合成データは、プライバシー問題への対処、限られたデータの拡張、実データの不均衡の是正によって、その助けとなります。私たちは、合成データを生成するいくつかの異なる方法を学んできました。しかし、合成データをモデルの訓練に使う前に、考慮すべき重要な点がいくつかあります。

モデルの過学習

過学習（Overfitting）とは、機械学習モデルが訓練データに過度に適合し、初めて見るデータに対して十分な性能を発揮出来なくなる現象です。これは、或る問題の特定の解き方を覚えたものの、その方法が通用しない新しい状況に遭遇するようなものです。合成データの生成方法が単純過ぎたり、データに同じようなパターンが繰り返し現れたりすると、モデルが合成データの限られたパターンばかりを学習して、過学習を起こす可能性があります。

とても単純な例として、赤い円25個と青い四角25個からなる合成データセットでモデルを訓練したとしましょう。モデルはおそらく、円は赤色、四角は青色と結びつけて学習するでしょう。このモデルは、赤い四角を見せられた時に失敗する可能性が高いです。

データセットに次のような種類のパターンが含まれていないことを、必ず再確認してください！

一貫し過ぎた色（Overly Consistent Color）

一貫し過ぎたサイズ（Overly Consistent Size）

一貫し過ぎた背景（Overly Consistent Background）

一貫し過ぎた位置（Overly Consistent Location）

合成データにはバイアスがあるのか？

合成データの生成過程にバイアスや不正確な部分があると、モデルが知らず知らずのうちにそのバイアスを学習し、再生産してしまう可能性があります。次のような問題に注意してください。

多様性の不足（Limited Diversity）

一つの課題は、合成データが実データの複雑さと多様性を十分に表現出来ない場合が有るということです。図形の例は些細なものに思えるかもしれませんが、人、場所、動物、物体などの幅広いバリエーションを考慮しないと、モデルの性能が上がらない状況は沢山あります。

例えば、アイアイ（aye-aye）キツネザルのような絶滅危惧種の個体数をモニタリングするモデルを訓練したいとしましょう。データセットにワオキツネザルの画像しか含まれていなければ、モデルは野生のアイアイキツネザルを正確に識別するのに苦労するかもしれません。この制約は、個体数評価の誤りにつながる可能性があります。

一方、元のデータセットの不均衡を把握していれば、サンプル数の少ないクラスの合成データを追加し、実データに含まれるバイアスを軽減出来る可能性があります。

データセットが現実世界に見られる多様性を反映するよう心がけてください！

良いバリエーション（Nice Variety）

既存のバイアスの複製（Copying Existing Biases）

合成画像を作る為に使ったデータ自体に既にバイアスがあった場合、モデルは意図せずにそのバイアスを学習し、再現してしまうかもしれません。友達のノートを、間違いがあることに気づかず写すようなものです。コンピュータが同じ誤りを抱えてしまう可能性があります。

合成データの利点は計算コストに見合うのか？

高品質な合成データの生成には計算コストがかかる場合があります。これは、特に複雑なモデルや大規模なデータセットでは、時間とリソースの両面で課題となりえます。一般的な目安として、合成データセットの生成と利用が意味を持つのは、最終的にリソース（費用、時間など）を節約出来る場合だけです。

合成画像の見た目の品質はどうか？

DCGAN を使って生成した肺の画像を考えてみましょう。一部の画像はかなりリアルに見えましたが、そうでないものもありました。

低品質な画像で訓練されたモデルは、実画像には存在しないノイズが含まれている為に、肺炎を検出出来ないかもしれません。また、モデルが合成データに含まれるパターンを非常にうまく認識出来るようになっても、現実世界にはそのパターンが存在しなかったり、実際とは異なっていたりする可能性があります。

良い実践方法は、Frechet Inception Distance（FID）、Inception Score（IS）、Classification Accuracy Score（CAS）のような指標を使ってデータセットを評価することです。

FID

FID では、Inception など、画像内の物体認識が得意な事前学習済みニューラルネットワークを使います。このネットワークで実画像と生成画像の特徴をそれぞれ抽出します。FID は、こうして得られた2つの特徴分布がどれだけ離れているかを、分布の平均と共分散を使って測る指標です。

FID が低いことは、実画像と生成画像の特徴分布が似ており、生成画像がよりリアルである可能性が高いことを示唆します。

IS

IS は、生成モデル（特に GAN）によって生成された画像の品質を評価する為に、事前に訓練された Inception モデルを使用します。生成画像ごとに、Inception モデルは、その画像内の物体をどれだけ確信を持って認識できるかに基づいてスコアを割り当てます。スコアが高い程良く、Inception モデルが画像の内容に確信を持っていることを示します。

CAS

分類精度は、モデルが合成データでどれだけうまく機能しているかを示すもう一つの指標です。精度が高い程、モデルが実画像の特徴やパターンを効果的に捉えていることを示します。特定のクラスの精度スコアが低い場合は、非現実的な背景、不正確なテクスチャ、一貫しない照明条件など、生成プロセスの問題を示している可能性があります。CIS を使えば、こうした問題を特定して対処し、合成データセット全体の品質を向上させることが出来ます。

まとめ

モデルを訓練した後でも、現実世界のシナリオでその性能を継続的にモニタリングすることが重要です。モデルが、合成データには存在しなかった新しい状況やトレンドに遭遇すると、適応に苦労するかもしれません。

こうした課題に対処するには、合成データの生成方法を慎重に設計し、実データに対するモデルの性能を評価する必要があります。これらを実践することで、合成データの可能性を十分に生かせるでしょう！
