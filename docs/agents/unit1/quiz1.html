Q1: エージェントとは何か？

AI エージェントを最もよく表しているのは次のうちどれですか？

この定義は、エージェントの本質的な特徴を捉えています。
エージェントは、アクションを取り、環境とやり取りできなければなりません。
このようなチャットボットはアクションを取る能力を欠いており、エージェントとは異なります。
エージェントは、静的な情報を提供するだけでなく、環境と積極的にやり取りします。

Q2: エージェントにおける計画の役割は何か？

エージェントはなぜアクションを取る前に計画する必要があるのですか？

計画とは、過去のやり取りを保存することではなく、将来のアクションを決定することです。
計画は、エージェントがタスクを完了するための最良のステップとツールを決定するのに役立ちます。
計画により、エージェントのアクションが意図的でランダムでないことが保証されます。
計画とは、単にテキストを変換することではなく、アクションを構造化することです。

Q3: ツールはエージェントの能力をどう高めるのか？

ツールはなぜエージェントに不可欠なのですか？

ツールは、テキスト生成を超えたアクションを実行できるようにすることで、エージェントの能力を拡張します。
ツールは主にアクションを実行するためのものであり、データを保存するためだけのものではありません。
逆に、ツールによりエージェントはテキストベースの応答を超えたことができるようになります。
ツールにより、エージェントは現実世界とやり取りし、タスクを完了できます。

Q4: アクションはツールとどう違うのか？

アクションとツールの主な違いは何ですか？

アクションはより高レベルの目的であり、ツールはエージェントが呼び出せる特定の関数です。
いいえ、アクションは目標やタスクであり、ツールはエージェントがそれらを達成するために使う特定のユーティリティです。
必ずしもそうではありません。アクションにはデジタルなタスクも物理的なタスクも含まれます。
LLM はアクションの決定を助けますが、アクション自体が LLM に依存しているわけではありません。

Q5: 大規模言語モデル（LLM）はエージェントでどんな役割を果たすのか？

LLM はエージェントの機能にどう貢献しますか？

LLM は、単に情報を保存するのではなく、テキスト入力を積極的に処理し、応答を生成します。
LLM により、エージェントは解釈し、計画し、次のステップを決定できます。
LLM は主にテキストを扱いますが、マルチモーダル入力とやり取りすることもあります。
LLM は現代の AI エージェントの中核コンポーネントです。

Q6: AI エージェントを最もよく示しているのはどれか？

AI エージェントの働きを最もよく示す実世界の例はどれですか？

静的な FAQ ページは、ユーザーと動的にやり取りしたりアクションを取ったりしません。
計算機は推論や計画なしに固定されたルールに従うため、エージェントではありません。
この例には、推論、計画、環境とのやり取りが含まれます。
NPC が推論、計画、ツールの使用ができない限り、AI エージェントとしては機能しません。
