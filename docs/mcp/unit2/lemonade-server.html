AMD NPU と iGPU アクセラレーションによるローカル Tiny Agents

このセクションでは、AMD Neural Processing Unit (NPU) と統合 GPU (iGPU) を使って、エンドツーエンドの Tiny Agents アプリケーションを高速化する方法を紹介します。次に、ローカルファイルへのアクセスを可能にし、機密情報をローカルで処理するアシスタントを作成することで、エンドツーエンドアプリケーションを強化し、最大限のプライバシーを確保します。

これを可能にするために、NPU と iGPU アクセラレーションでモデルをローカル実行するツールである Lemonade Server を使います。

セットアップ

Lemonade Server のセットアップ

Lemonade Server は Windows と Linux の両方にインストールできます。追加のドキュメントは lemonade-server.ai で確認できます。

windows

Windows に Lemonade Server をインストールするには、最新のインストーラーを[こちら](https://github.com/lemonade-sdk/lemonade/releases/latest/download/Lemonade_Server_Installer.exe)からダウンロードして実行するだけです。 Lemonade Server は、Windows x86/x64 上のすべてのプラットフォームとエンジンで CPU 推論をサポートします。GPU アクセラレーションは Vulkan を使う llamacpp エンジンで有効化され、AMD Ryzen™ AI 7000/8000/300 シリーズと AMD Radeon™ 7000/9000 シリーズに重点が置かれています。NPU アクセラレーションについては、ONNX Runtime GenAI (OGA) エンジンにより AMD Ryzen™ AI 300 シリーズデバイスがサポートされます。 Lemonade Server をインストールしたら、デスクトップに追加された `Lemonade` アイコンをクリックして起動できます。

linux

Linux に Lemonade をインストールするには、まず venv を作成して有効化します。

💡 ヒント

`uv` がインストールされていない場合は、[こちら](https://docs.astral.sh/uv/getting-started/installation/) の手順に従ってインストールできます。 
uv venv --python 3.11
source .venv/bin/activate
次に、`lemonade-sdk` パッケージをインストールします。 
uv pip install lemonade-sdk==8.0.3
あるいは、リポジトリをクローンしてパッケージをビルドすることで、ソースからインストールすることもできます。 
git clone https://github.com/lemonade-sdk/lemonade-sdk.git
cd lemonade-sdk
pip install -e .
インストールが完了したら、次のコマンドを実行して Lemonade を起動できます。 
lemonade-server-dev serve
Lemonade Server は、Windows x86/x64 上のすべてのプラットフォームとエンジンで CPU 推論をサポートします。GPU アクセラレーションは llamacpp エンジン（Vulkan）を通じて有効化され、AMD Ryzen™ AI 7000/8000/300 シリーズと Radeon™ 7000/9000 シリーズに重点が置かれています。

💡 ヒント

*NPU アクセラレーションは、Windows 上の AMD Ryzen™ AI 300 シリーズでのみ利用できます。*

Tiny Agents と NPX のセットアップ

このコースのこのセクションでは、npx と Tiny Agents がすでにインストールされていることを前提とします。まだの場合は、コースの Tiny Agents セクションを参照してください。huggingface_hub[mcp]==0.33.2 を使うようにしてください。

AMD NPU と iGPU で Tiny Agents アプリケーションを実行する

AMD NPU と iGPU で Tiny Agents アプリケーションを実行するには、前のセクション で作成した MCP サーバーを、次に示すように Lemonade Server に向けるだけです。

windows

{
  "model": "Qwen3-8B-GGUF",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "mcp-remote",
        "http://localhost:7860/gradio_api/mcp/sse"
      ]
    }
  ]
}

linux

{
  "model": "Qwen3-8B-GGUF",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "npx",
      "args": [
        "mcp-remote",
        "http://localhost:7860/gradio_api/mcp/sse"
      ]
    }
  ]
}

その後、ローカルマシンで実行するモデルをさまざまな選択肢から選べます。この例では、Vulkan アクセラレーションにより AMD GPU 上で効率的に動作する Qwen3-8B-GGUF モデルを使いました。サポートされるモデルのリストの確認や、独自モデルのインポートは、http://localhost:8000/#model-management にアクセスして行えます。

機密情報をローカルで処理するアシスタントを作成する

では、ローカルファイルへのアクセスを可能にし、機密情報をすべてデバイス上で処理するアシスタントを導入して、エンドツーエンドアプリケーションを強化しましょう。具体的には、このアシスタントは候補者の履歴書の評価を支援し、採用プロセスにおける意思決定をサポートします。その間、データはプライベートかつ安全に保たれます。

そのために、Desktop Commander MCP サーバーを使います。これにより、ローカルマシン上でコマンドを実行でき、包括的なファイルシステムアクセス、ターミナル制御、コード編集機能が得られます。

基本的な Tiny Agent を使ったプロジェクトをセットアップしましょう。

mkdir file-assistant
cd file-assistant

次に、file-assistant フォルダ内に新しい agent.json ファイルを作成します。

windows

{
  "model": "user.jan-nano",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "-y",
        "@wonderwhy-er/desktop-commander"
      ]
    }
  ]
}

linux

{
  "model": "user.jan-nano",
  "endpointUrl": "http://localhost:8000/api/",
  "servers": [
    {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@wonderwhy-er/desktop-commander"
      ]
    }
  ]
}

最後に、Jan Nano モデルをダウンロードする必要があります。これは http://localhost:8000/#model-management, つまりモデル管理ページにアクセスし、Add a Model をクリックして、次の情報を入力することで行えます。

Model Name: user.jan-nano
Checkpoint: Menlo/Jan-nano-gguf:jan-nano-4b-Q4_0.gguf
Recipe: llamacpp

これで準備完了です！ では、試してみましょう。

他のモデルとアクセラレーションオプションを探る

上記の例では、Jan-Nano モデルが Vulkan アクセラレーションを活用し、AMD GPU 上で効率的なローカル LLM 推論を行いました。http://localhost:8000/#model-management にアクセスするか、モデルのドキュメント を確認することで、他のモデルやアクセラレーションオプションも試せます。

簡潔なコンテキストが必要で、NPU + iGPU アクセラレーションの恩恵を受けられる Windows アプリケーションには、Lemonade Server で利用できる Hybrid モデル（AMD Ryzen AI 300 シリーズ PC 向けに最適化）を試せます。Llama-xLAM-2-8b-fc-r-Hybrid のようなモデルは、ツール呼び出し向けに特別にファインチューニングされており、高速で応答性の高いパフォーマンスを発揮します！

まとめ

このユニットでは、AMD NPU と iGPU を使ってエンドツーエンドの Tiny Agents アプリケーションを高速化する方法を紹介しました。また、機密情報をローカルで処理するアシスタントを作成する方法も紹介しました。
