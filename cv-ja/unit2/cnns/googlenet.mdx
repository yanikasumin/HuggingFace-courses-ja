# GoogLeNet

この章では、GoogLeNet と呼ばれる畳み込みアーキテクチャを見ていきます。

## 概要

Inception アーキテクチャは、分類や検出などのコンピュータビジョンのタスクの為に設計された畳み込みニューラルネットワーク（CNN）であり、その効率性で際立っています。パラメータ数は700万未満で、従来のモデルよりも大幅にコンパクトです。パラメータ数で比べると、AlexNet の約9分の1、VGG16 の約22分の1です。このアーキテクチャは ImageNet 2014 チャレンジで注目を集め、Google による適応版である GoogLeNet（LeNet へのオマージュとして名付けられました）が、従来の主要手法よりも少ないパラメータを使いながら性能の新たな基準を打ち立てました。


### アーキテクチャの革新

Inception アーキテクチャの登場以前は、AlexNet や VGG などのモデルが、より深いネットワーク構造の利点を示していました。しかし、深いネットワークは通常、計算ステップが増え、過学習や勾配消失問題などの課題につながります。Inception アーキテクチャはその解決策を提供し、浮動小数点パラメータの数を減らしながら複雑な CNN の訓練を可能にします。

#### Inception の「Network In Network」モジュール

AlexNet や VGG のような従来のネットワークでは、基本ブロックは畳み込み層そのものでした。しかし、Lin ら（2013年）は Network In Network という概念を提案し、畳み込み層を1つ使うだけでは、基本的な構成ブロックとして必ずしも十分ではなく、もっと複雑な構造にすべきだと主張しました。そこで Inception モデルの著者たちは、それに着想を得て、有名な映画「インセプション」（夢の中の夢）にちなんで名付けられた Inception モジュールという、より複雑な構成ブロックを採用することにしました。

Inception モジュールでは、異なるカーネルサイズの畳み込みフィルタを使い、複数のスケールで特徴を抽出します。任意の入力特徴マップに対して、\\(1 \times 1\\) 畳み込み、3×3 畳み込み、5×5 畳み込みを並列に適用します。畳み込みに加えて、最大プーリング演算も適用されます。4つの演算全てに、空間次元が同じになるようなパディングとストライドが設定されます。これらの特徴が連結され、次のステージへの入力となります。図1をご覧下さい。


![素朴な Inception モジュール](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/inception_naive.png)

図1：素朴な Inception モジュール

図のように、5×5 のような大きなカーネルサイズで複数のスケールの畳み込みを適用すると、パラメータ数が大幅に増える可能性があります。この問題は、入力特徴のサイズ（チャンネル数）が大きくなる程顕著になります。その為、こうした「Inception モジュール」をネットワークの深くに積み重ねていくと、計算量が大幅に増大します。

簡単な解決策は、計算量が増え易い箇所で特徴の数を減らすことです。計算量の多さの主な原因は畳み込み層です。計算量の安い \\(1 \times 1\\) 畳み込みを 3×3 や 5×5 の畳み込みの直前に置くことで、特徴の次元を削減します。例で見てみましょう。

\\( S \times S \times 128 \\) の特徴マップを、5×5 畳み込みで \\( S \times S \times 256 \\) に変換したいとします。パラメータ数（バイアスを除く）は 5\*5\*128\*256 = 819,200 です。しかし、先ず \\(1 \times 1\\) 畳み込みで特徴の次元を64まで削減すると、パラメータ数（バイアスを除く）は \\( 1\times 1\times 128\times 64 + 5\times 5\times 64\times 256 = 8,192 + 409,600 = 417,792 \\) となります。つまり、パラメータ数がほぼ半分に減りました！

また、出力特徴マップと連結する前に、最大プーリングの出力特徴も削減したい所です。そこで、最大プーリング層の後にもう1つ \\( 1\times 1 \\) 畳み込みを追加します。各 \\( 1\times 1 \\) 畳み込みの後には ReLU 活性化も追加し、モジュールの非線形性と複雑さを高めます。図2をご覧下さい。

![次元削減した Inception モジュール](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/inception_reduced.png)

図2：Inception モジュール

また、複数のスケールでの畳み込みを並列に実行することで、ネットワークを深くすることなく演算を増やせる為、本質的に勾配消失問題が緩和されます。

#### 平均プーリング

AlexNet や VGG のような従来のネットワークでは、最終層はいくつかの全結合層でした。これらの全結合層はユニット数が多い為、ネットワークのパラメータの大部分を占めます。例えば、VGG16 のパラメータの89%は最後の3つの全結合層に在ります。AlexNet のパラメータの95%は最後の全結合層に在ります。これ程多くの全結合層が必要とされていたのは、畳み込み層だけでは十分に複雑な処理が出来ないと考えられていた為でしょう。


しかし、Inception ブロックを使えば、全結合層を使わなくても、空間方向に単純な平均プーリングを行うだけで十分なはずです。これも Network in Network 論文から導かれたものでした。但し、GoogLeNet には全結合層が1つ含まれています。著者たちは top-1 精度が 0.6% 向上したと報告しています。


GoogLeNet では、全結合層に在るパラメータは全体の15%だけです。


#### 補助分類器

計算量の少ない \\( 1 \times 1 \\) 畳み込みを導入し、複数の全結合層を平均プーリングに置き換えたことで、ネットワークのパラメータ数は大幅に減りました。その分、更に多くの層を追加し、ネットワークを深く出来ます。しかし、層を積み重ねると勾配消失の問題が生じ得ます。勾配が入力側の層へ逆伝播するうちに小さくなり、ゼロに近づいてしまうのです。

論文では補助分類器（auxiliary classifier）が導入されています。中間層からいくつかの小さな分類器を分岐させ、各分類器の損失に小さな重みを付けて、ネットワーク全体の損失に加えます。これにより、入力に近い層も適度な大きさの勾配を受け取れるようになります。

補助分類器は以下から構成されます。
- フィルタサイズ \\( 5 \times 5 \\)、ストライド3の平均プーリング層。
- 次元削減の為の128個のフィルタを持つ \\( 1 \times 1 \\) 畳み込みと、整流線形活性化（ReLU）。
- 1024個のユニットと整流線形活性化を持つ全結合層。
- 出力の70%を無効化するドロップアウト層。
- 分類器として softmax 損失を持つ線形層。

これらの補助分類器は推論時には取り除かれます。なお、補助分類器の使用による利得はわずかです（0.5%）。

### GoogLeNet のアーキテクチャ

GoogLeNet の完全なアーキテクチャを下の図に示します。Inception ブロック内部を含む全ての畳み込みは ReLU 活性化を使います。最初に、畳み込み層と最大プーリング層からなる2つのブロックが有ります。続いて、2つの Inception モジュール（3a と 3b）と最大プーリング層が配置されます。その後、5つの Inception ブロック（4a、4b、4c、4d、4e）と最大プーリング層が続きます。

補助分類器は 4a と 4d の出力から取り出されます。次に2つの Inception ブロック（5a と 5b）が続きます。その後、平均プーリングと128ユニットの全結合層が使われます。

![GoogLeNet の全体アーキテクチャ](https://huggingface.co/datasets/hf-vision/course-assets/resolve/main/googlenet_architecture.png)
図4：GoogLeNet の完全なアーキテクチャ

### コード


```python
import torch
import torch.nn as nn


class BaseConv2d(nn.Module):
    def __init__(self, in_channels, out_channels, **kwargs):
        super(BaseConv2d, self).__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, **kwargs)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.conv(x)
        x = self.relu(x)
        return x


class InceptionModule(nn.Module):
    def __init__(self, in_channels, n1x1, n3x3red, n3x3, n5x5red, n5x5, pool_proj):
        super(InceptionModule, self).__init__()

        self.b1 = nn.Sequential(
            nn.Conv2d(in_channels, n1x1, kernel_size=1),
            nn.ReLU(True),
        )

        self.b2 = nn.Sequential(
            BaseConv2d(in_channels, n3x3red, kernel_size=1),
            BaseConv2d(n3x3red, n3x3, kernel_size=3, padding=1),
        )

        self.b3 = nn.Sequential(
            BaseConv2d(in_channels, n5x5red, kernel_size=1),
            BaseConv2d(n5x5red, n5x5, kernel_size=5, padding=2),
        )

        self.b4 = nn.Sequential(
            nn.MaxPool2d(3, stride=1, padding=1),
            BaseConv2d(in_channels, pool_proj, kernel_size=1),
        )

    def forward(self, x):
        y1 = self.b1(x)
        y2 = self.b2(x)
        y3 = self.b3(x)
        y4 = self.b4(x)
        return torch.cat([y1, y2, y3, y4], 1)


class AuxiliaryClassifier(nn.Module):
    def __init__(self, in_channels, num_classes, dropout=0.7):
        super(AuxiliaryClassifier, self).__init__()
        self.pool = nn.AvgPool2d(5, stride=3)
        self.conv = BaseConv2d(in_channels, 128, kernel_size=1)
        self.relu = nn.ReLU(True)
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(2048, 1024)
        self.dropout = nn.Dropout(dropout)
        self.fc2 = nn.Linear(1024, num_classes)

    def forward(self, x):
        x = self.pool(x)
        x = self.conv(x)
        x = self.flatten(x)
        x = self.fc1(x)
        x = self.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)
        return x


class GoogLeNet(nn.Module):
    def __init__(self, use_aux=True):
        super(GoogLeNet, self).__init__()

        self.use_aux = use_aux
        ## ブロック 1
        self.conv1 = BaseConv2d(3, 64, kernel_size=7, stride=2, padding=3)
        self.lrn1 = nn.LocalResponseNorm(5, alpha=0.0001, beta=0.75)
        self.maxpool1 = nn.MaxPool2d(3, stride=2, padding=1)

        ## ブロック 2
        self.conv2 = BaseConv2d(64, 64, kernel_size=1)
        self.conv3 = BaseConv2d(64, 192, kernel_size=3, padding=1)
        self.lrn2 = nn.LocalResponseNorm(5, alpha=0.0001, beta=0.75)
        self.maxpool2 = nn.MaxPool2d(3, stride=2, padding=1)

        ## ブロック 3
        self.inception3a = InceptionModule(192, 64, 96, 128, 16, 32, 32)
        self.inception3b = InceptionModule(256, 128, 128, 192, 32, 96, 64)
        self.maxpool3 = nn.MaxPool2d(3, stride=2, padding=1)

        ## ブロック 4
        self.inception4a = InceptionModule(480, 192, 96, 208, 16, 48, 64)
        self.inception4b = InceptionModule(512, 160, 112, 224, 24, 64, 64)
        self.inception4c = InceptionModule(512, 128, 128, 256, 24, 64, 64)
        self.inception4d = InceptionModule(512, 112, 144, 288, 32, 64, 64)
        self.inception4e = InceptionModule(528, 256, 160, 320, 32, 128, 128)
        self.maxpool4 = nn.MaxPool2d(3, stride=2, padding=1)

        ## ブロック 5
        self.inception5a = InceptionModule(832, 256, 160, 320, 32, 128, 128)
        self.inception5b = InceptionModule(832, 384, 192, 384, 48, 128, 128)

        ## 補助分類器
        if self.use_aux:
            self.aux1 = AuxiliaryClassifier(512, 1000)
            self.aux2 = AuxiliaryClassifier(528, 1000)

        ## ブロック 6
        self.avgpool = nn.AvgPool2d(7, stride=1)
        self.dropout = nn.Dropout(0.4)
        self.fc = nn.Linear(1024, 1000)

    def forward(self, x):
        ## ブロック 1
        x = self.conv1(x)
        x = self.maxpool1(x)
        x = self.lrn1(x)

        ## ブロック 2
        x = self.conv2(x)
        x = self.conv3(x)
        x = self.lrn2(x)
        x = self.maxpool2(x)

        ## ブロック 3
        x = self.inception3a(x)
        x = self.inception3b(x)
        x = self.maxpool3(x)

        ## ブロック 4
        x = self.inception4a(x)
        if self.use_aux:
            aux1 = self.aux1(x)
        x = self.inception4b(x)
        x = self.inception4c(x)
        x = self.inception4d(x)
        if self.use_aux:
            aux2 = self.aux2(x)
        x = self.inception4e(x)
        x = self.maxpool4(x)

        ## ブロック 5
        x = self.inception5a(x)
        x = self.inception5b(x)

        ## ブロック 6
        x = self.avgpool(x)
        x = torch.flatten(x, 1)
        x = self.dropout(x)
        x = self.fc(x)

        if self.use_aux:
            return x, aux1, aux2
        else:
            return x
```
