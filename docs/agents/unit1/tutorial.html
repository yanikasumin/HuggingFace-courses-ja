smolagents を使って初めてのエージェントを作成しましょう

前回のセクションでは、Python コードを使ってゼロからエージェントを作成する方法を学び、そのプロセスがいかに面倒かも分かりました。幸いなことに、多くのエージェントライブラリは、大変な作業の多くを代わりに処理して この作業を簡素化してくれます。

このチュートリアルでは、画像生成、Web 検索、タイムゾーンの確認など、さまざまなアクションを実行できる 初めてのエージェントを作成します！

さらに、エージェントを Hugging Face Space に公開し、友人や同僚と共有できるように もします。

さあ、始めましょう！

smolagents とは何か？

このエージェントを作るために、smolagents を使います。これは、エージェントを簡単に開発するためのフレームワークを提供する ライブラリです。

この軽量ライブラリはシンプルさのために設計されていますが、エージェント構築の複雑さの多くを抽象化してくれるため、エージェントの振る舞いの設計に集中できます。

smolagents については、次のユニットでさらに深く掘り下げます。その間、こちらの ブログ記事 や、ライブラリの GitHub リポジトリ もご覧ください。

要するに、smolagents は codeAgent に焦点を当てたライブラリです。codeAgent は、コードブロックを通じて 「アクション（Actions）」 を実行し、コードを実行することで結果を 「観察（Observes）」 するタイプのエージェントです。

smolagents 内のエージェントは、以前に構築したカスタムエージェントと同じ振る舞い をします。最終回答に到達するまで、サイクルで考え、行動し、観察します。

エージェントを構築しましょう！

まず、この Space を複製してください: https://huggingface.co/spaces/agents-course/First_agent_template

このテンプレートを提供してくれた Aymeric に感謝します！ 🙌

この Space を複製することは、自分のプロフィール上にローカルコピーを作成する ことを意味します。

Space を複製したあとは、エージェントがモデル API にアクセスできるよう、Hugging Face API トークンを追加する必要があります。

  1. まず、まだ持っていない場合は、https://hf.co/settings/tokens から推論の権限を持つ Hugging Face トークンを取得します
  2. 複製した Space に移動し、Settings タブをクリックします
  3. Variables and Secrets セクションまでスクロールし、New Secret をクリックします
  4. 名前が HF_TOKEN のシークレットを作成し、値をとしてトークンを貼り付けます
  5. Save をクリックして、トークンを安全に保存します

このレッスンを通じて、変更する必要があるファイルは（現在は不完全な）"app.py" だけです。テンプレート内の 元のファイル がこちらで確認できます。自分のファイルを見つけるには、Space のコピーに移動し、Files タブをクリックして、ディレクトリ一覧の app.py をクリックします。

コードを一緒に分解していきましょう。

  • ファイルは、シンプルですが必要なライブラリのインポートから始まります
from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, load_tool, tool
import datetime
import requests
import pytz
import yaml

先に概説したように、smolagents の CodeAgent クラスを直接使います。

ツール

では、ツールに入りましょう！ツールについて復習したい場合は、遠慮なくコースの ツール セクションに戻ってください。

@tool
def my_custom_tool(arg1:str, arg2:int)-> str: # 戻り値の型を指定することが重要です
    # ツールの説明/引数の説明にはこの形式を保ちつつ、ツール自体は自由に変更してください
    """A tool that does nothing yet 
    Args:
        arg1: the first argument
        arg2: the second argument
    """
    return "What magic will you build ?"

@tool
def get_current_time_in_timezone(timezone: str) -> str:
    """A tool that fetches the current local time in a specified timezone.
    Args:
        timezone: A string representing a valid timezone (e.g., 'America/New_York').
    """
    try:
        # タイムゾーンオブジェクトを作成する
        tz = pytz.timezone(timezone)
        # そのタイムゾーンの現在時刻を取得する
        local_time = datetime.datetime.now(tz).strftime("%Y-%m-%d %H:%M:%S")
        return f"The current local time in {timezone} is: {local_time}"
    except Exception as e:
        return f"Error fetching time for timezone '{timezone}': {str(e)}"

ツールは、このセクションで皆さんに構築してもらいたいものです！2つの例を示します。

  1. 変更して有用なものにできる、動作しないダミーツール。
  2. 世界のどこかの現在時刻を取得する、実際に動作するツール。

ツールを定義する際は、次が重要です。

  1. get_current_time_in_timezone(timezone: str) -> str: のように、関数の入力と出力の型を提供すること
  2. 適切に整形された docstring。smolagents は、すべての引数が docstring 内にテキストによる説明 を持つことを期待しています。

エージェント

LLM エンジンとして Qwen/Qwen2.5-Coder-32B-Instruct を使います。これは非常に有能なモデルで、サーバーレス API 経由でアクセスします。

final_answer = FinalAnswerTool()
model = InferenceClientModel(
    max_tokens=2096,
    temperature=0.5,
    model_id='Qwen/Qwen2.5-Coder-32B-Instruct',
    custom_role_conversions=None,
)

with open("prompts.yaml", 'r') as stream:
    prompt_templates = yaml.safe_load(stream)

# CodeAgent を作成します
agent = CodeAgent(
    model=model,
    tools=[final_answer], # ここにツールを追加してください（final_answer は削除しないでください）
    max_steps=6,
    verbosity_level=1,
    grammar=None,
    planning_interval=None,
    name=None,
    description=None,
    prompt_templates=prompt_templates
)

GradioUI(agent).launch()

このエージェントは、前のセクションで見た InferenceClient を、InferenceClientModel クラスの背後で今も使っています！

フレームワークを紹介するユニット2では、より詳細な例を示します。今のところは、エージェントの tools パラメータを使って ツールのリストに新しいツールを追加する ことに集中してください。

たとえば、コードの1行目でインポートされた DuckDuckGoSearchTool を使ったり、コードの後半で Hub から読み込まれる image_generation_tool を調べたりできます。

ツールを追加すると、エージェントに新しい能力が与えられます。ここでは創造的になってみてください！

システムプロンプト

エージェントのシステムプロンプトは、別の prompts.yaml ファイルに保存されています。このファイルには、エージェントの振る舞いを導く事前定義された指示が含まれています。

プロンプトを YAML ファイルに保存すると、異なるエージェントやユースケース間で簡単にカスタマイズや再利用ができます。

Space のファイル構造 を確認すると、prompts.yaml ファイルの場所と、プロジェクト内での構成が分かります。

完全な "app.py" は次のとおりです。

from smolagents import CodeAgent, DuckDuckGoSearchTool, InferenceClientModel, load_tool, tool
import datetime
import requests
import pytz
import yaml
from tools.final_answer import FinalAnswerTool

from Gradio_UI import GradioUI

# 以下は、何もしないツールの例です。あなたの創造性で私たちを驚かせてください！
@tool
def my_custom_tool(arg1:str, arg2:int)-> str: # 戻り値の型を指定することが重要です
    # ツールの説明/引数の説明にはこの形式を保ちつつ、ツール自体は自由に変更してください
    """A tool that does nothing yet 
    Args:
        arg1: the first argument
        arg2: the second argument
    """
    return "What magic will you build ?"

@tool
def get_current_time_in_timezone(timezone: str) -> str:
    """A tool that fetches the current local time in a specified timezone.
    Args:
        timezone: A string representing a valid timezone (e.g., 'America/New_York').
    """
    try:
        # タイムゾーンオブジェクトを作成する
        tz = pytz.timezone(timezone)
        # そのタイムゾーンの現在時刻を取得する
        local_time = datetime.datetime.now(tz).strftime("%Y-%m-%d %H:%M:%S")
        return f"The current local time in {timezone} is: {local_time}"
    except Exception as e:
        return f"Error fetching time for timezone '{timezone}': {str(e)}"


final_answer = FinalAnswerTool()
model = InferenceClientModel(
    max_tokens=2096,
    temperature=0.5,
    model_id='Qwen/Qwen2.5-Coder-32B-Instruct',
    custom_role_conversions=None,
)


# Hub からツールをインポートする
image_generation_tool = load_tool("agents-course/text-to-image", trust_remote_code=True)

# prompt.yaml ファイルからシステムプロンプトを読み込む
with open("prompts.yaml", 'r') as stream:
    prompt_templates = yaml.safe_load(stream)

agent = CodeAgent(
    model=model,
    tools=[final_answer], # ここにツールを追加してください（final_answer は削除しないでください）
    max_steps=6,
    verbosity_level=1,
    grammar=None,
    planning_interval=None,
    name=None,
