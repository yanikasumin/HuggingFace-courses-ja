このセクションでは、ファインチューニングを終えたばかりの Transformer モデルで予測を生成しようとしたときに起こりうる、よくあるエラーを見ていきます。これは、学習フェーズ自体のデバッグ方法を探るセクション4への準備になります。

このセクション用にテンプレートのモデルリポジトリを用意しました。この章のコードを実行したい場合は、まずモデルを Hugging Face Hub 上の自分のアカウントにコピーする必要があります。そのためには、まず Jupyter ノートブックで次を実行するか、

from huggingface_hub import notebook_login

notebook_login()

お好みのターミナルで次を実行してログインします。

huggingface-cli login

するとユーザー名とパスワードの入力を求められ、トークンが ~/.cache/huggingface/ の下に保存されます。ログインしたら、次の関数でテンプレートリポジトリをコピーできます。

from distutils.dir_util import copy_tree
from huggingface_hub import Repository, snapshot_download, create_repo, get_full_repo_name


def copy_repository_template():
    # リポジトリをクローンし、ローカルパスを取り出す
    template_repo_id = "lewtun/distilbert-base-uncased-finetuned-squad-d5716d28"
    commit_hash = "be3eaffc28669d7932492681cd5f3e8905e358b4"
    template_repo_dir = snapshot_download(template_repo_id, revision=commit_hash)
    # Hub 上に空のリポジトリを作成する
    model_name = template_repo_id.split("/")[1]
    create_repo(model_name, exist_ok=True)
    # 空のリポジトリをクローンする
    new_repo_id = get_full_repo_name(model_name)
    new_repo_dir = model_name
    repo = Repository(local_dir=new_repo_dir, clone_from=new_repo_id)
    # ファイルをコピーする
    copy_tree(template_repo_dir, new_repo_dir)
    # Hub にプッシュする
    repo.push_to_hub()

これで、copy_repository_template() を呼び出すと、テンプレートリポジトリのコピーが自分のアカウントの下に作成されます。

やりました、うまくいきました。ここで学んだことをまとめましょう。

- Python のエラーメッセージは_トレースバック_と呼ばれ、下から上へ読みます。エラーメッセージの最後の行には通常、問題の発生源を特定するのに必要な情報が含まれています。
- 最後の行に十分な情報がない場合は、トレースバックを上にたどって、ソースコードのどこでエラーが起きているか特定できないか見てみましょう。
- どのエラーメッセージも問題のデバッグに役立たない場合は、似た問題への解決策をオンラインで探してみましょう。
- `huggingface_hub` ライブラリには、Hub 上のリポジトリを操作したりデバッグしたりするために使えるツールが一式そろっています。
