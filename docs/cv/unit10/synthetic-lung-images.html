Synthetic Data Generation Using DCGAN

Unit 5 で学んだように、GAN は、生成器（Generator）と識別器（Discriminator）という2つのニューラルネットワークが絶えず対決する機械学習のフレームワークです。生成器は合成画像を作り、識別器は実画像と偽画像を区別しようとします。両者はこの敵対的なプロセスを通じて改善を続け、生成器はリアルな画像を作るのが上手くなり、識別器は偽物と本物の区別が上手くなります。

ここでは、GAN を使って医療画像を生成する方法を見ていきます。医療は、小規模なデータセット、プライバシーの懸念、限られた量のアノテーション付きサンプルといった課題を抱える領域です。研究者らは GAN を使って、肺の X 線画像、網膜画像、脳スキャン、肝臓画像などの合成画像を生成してきました。GAN-based synthetic brain PET image generation では、著者らがアルツハイマー病の3つの異なる段階について脳の PET 画像を作成しました。GAN-based Synthetic Medical Image Augmentation for increased CNN Performance in Liver Lesion Classification は合成肝臓画像を生成しました。BrainGAN: Brain MRI Image Generation and Classification Framework Using GAN Architectures and CNN Models は、複数の GAN アーキテクチャを使って脳 MRI 画像を生成するフレームワークを開発し、A Novel COVID-19 Detection Model Based on DCGAN and Deep Transfer Learning は、COVID-19 の検出を支援するために DCGAN を使って合成肺 X 線画像を生成しました。

DCGAN (Deep Convolutional Generative Adversarial Network)

DCGAN は、Radford らによって Unsupervised Representation Learning With Deep Convolutional Generative Adversarial Networks で提案されたもので、多くの研究者が合成医療画像の生成に使ってきたモデルです。これを使って合成肺画像を生成していきます。DCGAN を使ってモデルを訓練する前に、そのアーキテクチャを簡単に復習しましょう。生成器ネットワークはランダムノイズを入力として受け取り、合成肺画像を生成します。一方、識別器ネットワークは実画像と合成画像を区別しようとします。生成器と識別器の両方に畳み込み層を使い、空間的な特徴を効果的に捉えます。また DCGAN は、最大プーリングをストライド付き畳み込みに置き換え、空間次元をダウンサンプリングします。

生成器は次のモデルアーキテクチャを持ちます。

  • 入力は100個のランダムな数からなるベクトルで、出力はサイズ 1281283 の画像です。
  • モデルは4つの畳み込み層を持ちます。
  • Conv2D 層
  • Batch Normalization 層
  • ReLU 活性化
  • Tanh 活性化を伴う Conv2D 層。

識別器は次のモデルアーキテクチャを持ちます。

  • 入力は画像で、出力は画像が偽物か本物かを示す確率です。
  • モデルは1つの畳み込み層を持ちます。
  • Conv2D 層
  • Leaky ReLU 活性化
  • 以下を伴う3つの畳み込み層:
  • Conv2D 層
  • Batch Normalization 層
  • Leaky ReLU 活性化
  • Sigmoid を伴う Conv2D 層。

Data Collection

まず、実際の肺画像のデータセットを取得する必要があります。Hugging Face Hub から Chest X-Ray Images (Pneumonia) データセットをダウンロードします。

このデータセットに関する情報は次のとおりです。

* [Identifying Medical Diagnoses and Treatable Diseases by Image-Based Deep Learning](https://www.cell.com/cell/fulltext/S0092-8674(18)30154-5?_returnURL=https%3A%2F%2Flinkinghub.elsevier.com%2Fretrieve%2Fpii%2FS0092867418301545%3Fshowall%3Dtrue) より:

* このデータセットは3つのフォルダ（train、test、val）に整理されており、各画像カテゴリ（Pneumonia/Normal）のサブフォルダを含みます。5,863枚の X 線画像（JPEG）と2つのカテゴリ（Pneumonia/Normal）があります。

* 胸部 X 線画像（前後方向）は、広州婦女児童医療センター（Guangzhou Women and Children’s Medical Center, Guangzhou）の1歳から5歳の小児患者の後ろ向きコホートから選択されました。すべての胸部 X 線撮影は、患者の通常の臨床ケアの一環として行われました。

* 胸部 X 線画像の分析では、すべての胸部レントゲン写真は最初に品質管理のためにスクリーニングされ、低品質または判読不能なスキャンはすべて除去されました。画像の診断はその後、AI システムの訓練用に承認される前に、2人の専門医によって等級付けされました。等級付けの誤りを考慮するため、評価セットも3人目の専門家によってチェックされました。

まず、Hugging Face Hub にログインすることから始めます。

from huggingface_hub import notebook_login

notebook_login()

次に、データセットを読み込みます。

from datasets import load_dataset

dataset = load_dataset("hf-vision/chest-xray-pneumonia")

肺画像をリサイズし、ピクセル値を正規化して前処理します。

import torchvision.transforms as transforms
from torchvision.transforms import CenterCrop, Compose, Normalize, Resize, ToTensor

transform = Compose(
    [
        transforms.Resize(image_size),
        transforms.CenterCrop(image_size),
        transforms.ToTensor(),
    ]
)

訓練中、生成器は実画像と区別できない合成肺画像を生成することを目指し、識別器は画像を実物か合成か正しく分類することを学習します。生成器をランダムノイズで初期化することから始め、100エポック訓練します。

How did we do?

「良い」合成画像64枚がこちらです。識別器から70%の確率で「本物」というラベルを受けたものと定義します。

合成肺画像の中には良く見えるものもあれば、かすんでいるものもあることが分かります。言及すべき重要な点がいくつかあります。第一に、合成医療画像を生成する研究者は通常、「人間の介在（human in the middle）」、この場合は専門の放射線科医を用いて合成画像を評価します。その後、専門家を欺いた画像だけが、実データとともにモデルの訓練に含まれます。第二に、（少なくとも素人には）問題なさそうに見える生成画像は、互いに非常によく似ています。これは GAN のもう一つの既知の問題で、「モード崩壊（mode collapse）」を起こすことがあります。本質的には、生成器が同じ種類の出力を生成し始めることで起こります。チョコレートチップクッキーを作って多くの称賛を受けた人が、そのためクッキーを作るのが_本当に、本当に_上手くなるけれど、他の種類のクッキーは作れなくなるようなものだと考えてください。

高品質な医療画像の訓練に GAN を使うことに伴う既知の課題を踏まえ、一部の研究者は肺画像の生成に拡散モデルの使用を検討してきました。医療画像用の条件付き潜在 DDPM である Medfusion は、Diffusion Probabilistic Models Beat GAN On Medical 2D Images で提案されました。Synthetically Enhanced: Unveiling Synthetic Data's Potential In Medical Imaging Research において、Khosravi らは、拡散プロセスで生成された合成肺画像と実画像を混ぜて使うことで、モデルの性能が向上したことを見出しました。
