# まとめ

Unit 2 の `LangGraph` モジュールを修了しました。おめでとうございます！ 🥳

LangGraph を使って構造化されたワークフローを構築するための基礎を身につけました。これで、作成したワークフローを本番環境に導入することもできるようになります。

LangGraph の学習は、このモジュールで終わりではありません。さらに高度な内容を学びたい方には、次の取り組みをおすすめします。

- [LangGraph の公式ドキュメント](https://github.com/langchain-ai/langgraph) を読む
- LangChain Academy の総合コース [Introduction to LangGraph](https://academy.langchain.com/courses/intro-to-langgraph) を受講する
- 自分で何かを作ってみる！

次のユニットでは、実際のユースケースを詳しく見ていきます。理論の学習から離れて、いよいよ実践に進みましょう！
