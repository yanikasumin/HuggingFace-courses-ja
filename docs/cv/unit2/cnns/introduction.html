畳み込みニューラルネットワーク入門

前のユニットでは、視覚、画像、コンピュータビジョンの基礎を学びました。また、コンピュータで画像を解析するうえで重要な要素である視覚的特徴についても見てきました。

これまで扱った手法は、現在では「古典的な」コンピュータビジョンと呼ばれることがよくあります。小規模で制約の多いデータセットや環境ではうまく機能しますが、実世界の大きなデータセットを相手にすると限界が見えてきます。

このユニットでは、コンピュータビジョンの規模と性能を大きく前進させた畳み込みニューラルネットワーク（Convolutional Neural Networks）について学びます。

畳み込み： 基本的な考え方

畳み込み（convolution）は、データから特徴を抽出するために使われる演算です。データは1次元、2次元、3次元のいずれでも構いません。具体例で演算の仕組みを説明します。今のところ必要な知識は、この演算が数値の行列をデータの上で移動させ、データとその行列の積の和を取る、ということだけです。この行列はカーネル（kernel）またはフィルタ（filter）と呼ばれます。「特徴抽出と何の関係があるのか、どうやって適用すればいいのか」と思うかもしれません。 慌てなくて大丈夫です。これから説明します。

直感をつかむために、例を見てみましょう。1次元のデータがあり、それを可視化したものがこちらです。可視化すると、畳み込み演算の効果が分かりやすくなります。

カーネルは [-1, 1] です。まず一番左の要素にカーネルを置き、重なった数値同士を掛けて合計します。カーネルには中心があり、それは要素の1つです。ここでは右側の要素である 1 を中心とします。左側には想像上のゼロがあると仮定します。これはパッド（pad）と呼ばれるもので、後ほど改めて出てきます。カーネルの中心はすべての要素に触れなければいけないので、便宜上、要素の左側にゼロを置きます。パディングをしなければ、-1 は一番左の要素と掛けられますが、1 が一番左の要素に触れなくなってしまうため、パディングを適用するのです。どのような様子か見てみましょう。

一番左の要素（現在はパッドです）に -1 を掛け、最初の要素（ゼロ）に 1 を掛けて合計すると 0 になり、それを記録します。次に、カーネルを1つ分ずらして同じことを行い、再び記録します。この移動はストライド（striding）と呼ばれ、通常はカーネルを1ピクセルずつ動かします。より多くのピクセル分を動かすこともできます。現在の結果（畳み込まれたデータ）は [0, 0] という配列です。

畳み込まれたデータ（畳み込みの結果）は特徴マップ（feature map）と呼ばれます。抽出できる特徴、つまりデータに関する特性や変化率を示しているので、この名前は理にかなっています。

畳み込みニューラルネットワーク

なるほど、ではこれは深層学習とどう関係するのでしょうか。特徴を抽出するためにフィルタを力任せに探す方法は、すべての画像に対してうまくいくわけではありません。重要な情報を抽出したり、画像中の物体を検出したりするための最適なフィルタを何らかの方法で見つけられたらどうでしょうか。そこで登場するのが畳み込みニューラルネットワークです。画像をさまざまなフィルタで畳み込み、特徴マップのピクセルがやがて最適化すべきパラメータとなり、最終的にその問題に最適なフィルタが見つかります。

考え方は、フィルタを使って情報を抽出するというものです。複数のフィルタをランダムに初期化し、特徴マップを作り、それを分類器に入力して、バックプロパゲーションを行います。その前に、「プーリング」と呼ばれるものを紹介します。

上の例で分かるように、特徴マップには変化を示すピクセルが数多くあります。エッジがあることを知るには、変化（エッジや角など何でも）が存在することだけが分かれば十分です。

上の例では、2つのうち1つだけが得られれば十分でした。そうすれば、特徴を保ったまま保持するパラメータを減らせます。特徴マップの中で最も重要な要素を取り出すこの操作がプーリングです。プーリングを行うと、エッジがどこにあるかという正確なピクセルの位置は失われますが、保持するパラメータは少なくなります。またこの方法により、特徴抽出の仕組みが小さな変化に対して堅牢になります。たとえば、画像に顔があることを知るには、2つの目、鼻、口があることが分かればよく、それらの要素間の距離や大きさは顔ごとに変わる傾向がありますが、プーリングによってモデルはそうした変化に対して堅牢になります。プーリングのもう1つの利点は、さまざまな入力サイズに対応しやすくなることです。以下は最大プーリング（max pooling）の演算で、4ピクセルごとに最大のピクセルを取得します。プーリングには平均プーリング、重み付きプーリング、L2 プーリングなど、さまざまな種類があります。

簡単な CNN アーキテクチャを構築してみましょう。説明のために Keras の例を使い、何が起きているかを順に追っていきます。以下がモデルです（繰り返しますが、慌てなくて大丈夫です。順に説明します）。

Keras の Sequential API が何をするか分からない場合のために説明すると、レゴブロックのように層を積み重ねて接続します。各層にはそれぞれハイパーパラメータがあります。Conv2D 層は畳み込みフィルタの数、カーネルサイズ、活性化関数を取り、MaxPooling2D はプーリングサイズを、Dense 層は出力ユニットの数を取ります（これも慌てなくて大丈夫です）。

ほとんどの ConvNet の実装では、画像処理のようにカーネルをすべてのピクセルに触れさせるためのパディングは行いません。ゼロでパディングをすると、境界にも特徴があるかもしれないという前提が入り、計算の複雑さも増します。そのため、最初の入力サイズが (26,26) になり、境界沿いの情報が失われます。

model = keras.Sequential(
    [
        keras.Input(shape=input_shape),
        layers.Conv2D(32, kernel_size=(3, 3), activation="relu"),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Conv2D(64, kernel_size=(3, 3), activation="relu"),
        layers.MaxPooling2D(pool_size=(2, 2)),
        layers.Flatten(),
        layers.Dropout(0.5),
        layers.Dense(num_classes, activation="softmax"),
    ]
)
model.summary()

畳み込みニューラルネットワークは、入力層と畳み込み層から始まります。Keras の Conv2D 層は、カーネルの数とカーネルのサイズをパラメータとして取ります。起きていることは以下の図のとおりです。ここでは画像を32個のカーネルで畳み込み、画像と同じ大きさの特徴マップが32個得られます。

畳み込み層の後には、上述のとおり、保持するパラメータの数を減らし、モデルを変化に対して堅牢にするために最大プーリング層を置きます。これにより、計算されるパラメータの数が減ります。

その後、これらの特徴マップは連結（concatenate）され、平坦化（flatten）されます。

続いて、過学習を避けるためにパラメータの一部を落とすドロップアウトを使います。最後に、重みの最終形が Dense 層を通って分類され、バックプロパゲーションが行われます。

畳み込みニューラルネットワークにおけるバックプロパゲーションの理論

ここではバックプロパゲーションはどのように機能するのでしょうか。最適化したいのは最適なカーネルの値であり、それが重みとなります。最終的には、分類器がピクセル値、カーネル、クラスの間の関係を見つけ出すことが期待されます。つまり、初期の重み（カーネルの要素）で畳み込まれたピクセルをプーリングし活性化したものの集合である、非常に長い平坦な配列が存在します。これらの重みを、「猫と犬の写真を区別するために、どのカーネルを適用すべきか」という問いに答えられるよう更新します。CNN の訓練の要点は最適なカーネルを見つけることであり、それはバックプロパゲーションを使って見つけられます。CNN 以前は、特徴を抽出するために人々が自ら画像にたくさんのフィルタを試していましたが、汎用的なフィルタ（上で見た Prewitt や Sobel など）は、画像が同じデータセット内でも大きく異なり得るため、すべての画像に必ずしも有効とは限りません。だからこそ CNN は従来の画像処理技術を上回る性能を発揮します。

畳み込みニューラルネットワークを使うと、ストレージの面でもいくつかの利点があります。

パラメータ共有

畳み込みニューラルネットワークでは、すべてのピクセル、すべてのチャンネル、すべての画像に対して同じフィルタで畳み込みを行います。これによりパラメータの保持の面で利点があり、全結合ニューラルネットワークで画像を処理するよりもはるかに効率的です。これは「重みの共有（weight tying）」と呼ばれ、その重みは「tied weights」と呼ばれます。これはオートエンコーダでも見られる仕組みです。

疎な相互作用

全結合ニューラルネットワークでは、データ全体を一度に入力します。画像には数百から数千のピクセルがあるため、これは非常に負担が大きくなります。一方、ConvNet では、特徴を抽出するために使うカーネルが小さいです。これは疎な相互作用（sparse interaction）と呼ばれ、使用するメモリを減らす助けになります。
