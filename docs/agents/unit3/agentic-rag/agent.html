ガラ用エージェントの作成

Alfredに必要なコンポーネントをすべて構築しました。ここでは、それらをすべてまとめ、豪華なガラの開催を手伝う完全なエージェントに仕上げます。

このセクションでは、ゲスト情報の検索、Web検索、天気情報、Hub統計のツールを、1つの強力なエージェントに統合します。

Alfredの組み立て： 完成形のエージェント

前のセクションで作成したツールをすべて再実装する代わりに、それぞれのモジュールからインポートします。モジュールは tools.py と retriever.py ファイルに保存しました。

💡 ヒント

まだツールを実装していない場合は、ツール と リトリーバー のセクションに戻って実装し、tools.py と retriever.py ファイルに追加してください。

前のセクションから、必要なライブラリとツールをインポートしましょう。

smolagents

# 必要なライブラリをインポートする
import random
from smolagents import CodeAgent, InferenceClientModel

# モジュールからカスタムツールをインポートする
from tools import DuckDuckGoSearchTool, WeatherInfoTool, HubStatsTool
from retriever import load_guest_dataset
では、すべてのツールを1つのエージェントにまとめましょう。 
# Hugging Faceモデルを初期化する
model = InferenceClientModel()

# Web検索ツールを初期化する
search_tool = DuckDuckGoSearchTool()

# 天気ツールを初期化する
weather_info_tool = WeatherInfoTool()

# Hub統計ツールを初期化する
hub_stats_tool = HubStatsTool()

# ゲストのデータセットを読み込み、ゲスト情報ツールを初期化する
guest_info_tool = load_guest_dataset()

# すべてのツールを持ったAlfredを作成する
alfred = CodeAgent(
    tools=[guest_info_tool, weather_info_tool, hub_stats_tool, search_tool],
    model=model,
    add_base_tools=True,  # 追加の基本ツールがあれば加える
    planning_interval=3   # 3ステップごとに計画を有効化する
)

langgraph

from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

from tools import DuckDuckGoSearchRun, weather_info_tool, hub_stats_tool
from retriever import guest_info_tool
では、すべてのツールを1つのエージェントにまとめましょう。 
# Web検索ツールを初期化する
search_tool = DuckDuckGoSearchRun()

# ツールを含むチャットインターフェースを生成する
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

# AgentStateとエージェントのグラフを生成する
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## グラフ
builder = StateGraph(AgentState)

# ノードを定義する: 実際の処理を行う
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# エッジを定義する: 制御フローの動きを決める
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # 最新のメッセージがツールを必要とする場合は、ツールへルーティングする
    # それ以外の場合は、直接応答する
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

これでエージェントが使えるようになりました！

高度な機能： 会話メモリ

ガラの最中にAlfredをさらに役立つ存在にするため、会話メモリを有効にして、以前のやり取りを覚えさせられます。

smolagents

# 会話メモリを持つAlfredを作成する
alfred_with_memory = CodeAgent(
    tools=[guest_info_tool, weather_info_tool, hub_stats_tool, search_tool],
    model=model,
    add_base_tools=True,
    planning_interval=3
)

# 1回目のやり取り
response1 = alfred_with_memory.run("Tell me about Lady Ada Lovelace.")
print("🎩 Alfredの最初の応答：")
print(response1)

# 2回目のやり取り（1回目を参照）
response2 = alfred_with_memory.run("What projects is she currently working on?", reset=False)
print("🎩 Alfredの2番目の応答：")
print(response2)

llama-index

from llama_index.core.workflow import Context

alfred = AgentWorkflow.from_tools_or_functions(
    [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool],
    llm=llm
)

# 状態を記憶する
ctx = Context(alfred)

# 1回目のやり取り
response1 = await alfred.run("Tell me about Lady Ada Lovelace.", ctx=ctx)
print("🎩 Alfredの最初の応答：")
print(response1)

# 2回目のやり取り（1回目を参照）
response2 = await alfred.run("What projects is she currently working on?", ctx=ctx)
print("🎩 Alfredの2番目の応答：")
print(response2)

これら3つのエージェントアプローチのいずれも、メモリをエージェントに直接結びつけていないことに注目してください。この設計選択には、何か具体的な理由があるのでしょうか 🧐？ * smolagents: メモリは実行をまたいで保持されません。reset=False を使って明示的に指定する必要があります。 * LlamaIndex: 実行内でのメモリ管理には、コンテキストオブジェクトを明示的に追加する必要があります。 * LangGraph: 以前のメッセージを取得する選択肢や、専用の MemorySaver コンポーネントを利用する選択肢があります。

まとめ

おめでとうございます！ 今世紀で最も豪華なガラの開催を手伝う、複数のツールを備えた洗練されたエージェント、Alfredの構築に成功しました。Alfredは次のことができるようになりました。

  1. ゲストに関する詳細情報を取得する
  2. 屋外アクティビティの計画のために天気を確認する
  3. 影響力のあるAIビルダーとそのモデルに関する知見を提供する
  4. 最新情報を求めてWebを検索する
  5. メモリで会話のコンテキストを維持する

これらの能力により、Alfredは、パーソナライズされた心配りと最新の情報でゲストを感心させ、あなたのガラを大成功に導く準備が整いました。
