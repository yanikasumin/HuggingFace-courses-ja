Gradio は Hugging Face Hub 及び Hugging Face Spaces と直接連携しています。Hub や Spaces のデモは、*わずか1行のコード* で読み込めます。

### Hugging Face Hub からモデルを読み込む[[loading-models-from-the-hugging-face-hub]]
まず、[Chapter 4](/course/chapter4/2) で説明したように、Hugging Face が Hub を通じて提供する何千ものモデルから1つを選びます。

`Interface.load()` メソッドを使う場合は、`"model/"`（又は等価な `"huggingface/"`）の後にモデル名を続けます。例えば、大規模言語モデル [GPT-J](https://huggingface.co/EleutherAI/gpt-j-6B) のデモを作り、入力例をいくつか加えるコードは次の通りです。

```py
import gradio as gr

title = "GPT-J-6B"
description = "Gradio Demo for GPT-J 6B, a transformer model trained using Ben Wang's Mesh Transformer JAX. 'GPT-J' refers to the class of model, while '6B' represents the number of trainable parameters. To use it, simply add your text, or click one of the examples to load them. Read more at the links below."
article = "<p style='text-align: center'><a href='https://github.com/kingoflolz/mesh-transformer-jax' target='_blank'>GPT-J-6B: A 6 Billion Parameter Autoregressive Language Model</a></p>"

gr.Interface.load(
    "huggingface/EleutherAI/gpt-j-6B",
    inputs=gr.Textbox(lines=5, label="Input Text"),
    title=title,
    description=description,
    article=article,
).launch()
```
    
（説明文の訳：GPT-J 6B の Gradio デモです。Ben Wang の Mesh Transformer JAX を使って訓練された Transformer モデルです。「GPT-J」はモデルのクラスを指し、「6B」は訓練可能なパラメータの数を表します。使うには、テキストを入力するか、例の1つをクリックして読み込むだけです。詳しくは下のリンクをご覧ください／記事リンクの訳：GPT-J-6B：60億パラメータの自己回帰言語モデル）

上のコードを実行すると、下のインターフェースが生成されます:

### Hugging Face Spaces から読み込む[[loading-from-hugging-face-spaces]]
Hugging Face Hub 上の任意の Space を読み込んでローカルで再現するには、`Interface.load()` に `spaces/` と Space 名を組み合わせた文字列を渡します。

セクション1で見た画像の背景を除去するデモは、Hugging Face Spaces から読み込めます。

```py
gr.Interface.load("spaces/abidlabs/remove-bg").launch()
```

Hub や Spaces から読み込んだデモは、パラメータを上書きしてカスタマイズ出来ます。これが便利な点の1つです。ここではタイトルを追加し、Web カメラで動作する様に変更します。

```py
gr.Interface.load(
    "spaces/abidlabs/remove-bg", inputs="webcam", title="Remove your webcam background!"
).launch()
```

（タイトルの訳：Web カメラの背景を除去しよう！）
