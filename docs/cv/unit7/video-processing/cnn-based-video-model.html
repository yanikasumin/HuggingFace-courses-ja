CNN ベースのビデオモデル

全体的な傾向:

深層学習、とりわけ ImageNet のような大規模データセットで訓練された CNN の成功は、画像認識に革命をもたらしました。この傾向はビデオ処理でも続いています。ただし、ビデオデータは静止画像と比べて、時間というもう1つの次元を持ちます。この単純な変化が、静止画像で訓練された CNN が対処できるようには作られていなかった、新たな課題をもたらしました。

ビデオ処理における過去の SOTA モデル

Two-Stream Network（2014）

この論文は、深層畳み込みネットワーク（ConvNets）を拡張し、ビデオデータで行動認識を行えるようにしました。

提案されたアーキテクチャは Two-Stream Network と呼ばれます。ニューラルネットワーク内に2つの独立した経路を使います。

  • 空間ストリーム（Spatial Stream）: 標準的な2D CNN で、個々のフレームを処理して外見の情報を捉えます。
  • 時間ストリーム（Temporal Stream）: 2D CNN、あるいは別のネットワークで、複数のフレーム列（オプティカルフロー）を処理して動きの情報を捉えます。
  • 融合（Fusion）: 両ストリームの出力を組み合わせ、外見と動きの両方の手がかりを、行動認識のようなタスクに活かします。

3D ResNets（2017）

標準的な3D CNN は、3Dカーネル（2Dの空間情報＋時間情報）を使って、空間情報と時間情報を同時に捉えるよう概念を拡張したものです。このモデルの欠点は、パラメータ数が多いため、訓練の計算負荷が高く、2D版よりも遅いことです。そのため、3D版の ConvNets は通常、2D CNN の深いアーキテクチャよりも層数が少なくなります。

この論文では、著者らが ResNet アーキテクチャを3D CNN に適用しました。このアプローチにより、3D CNN でより深いモデルが可能になり、より高い精度を達成しました。

実験では、3D ResNets（特に ResNet-34 のような深いもの）が、特に大規模データセットにおいて、C3D のようなモデルを上回ることが示されました。Sports-1M C3D のような事前学習済みモデルは、小規模データセットでの過学習を緩和するのに役立ちます。全体として、3D ResNets はより深いアーキテクチャを効果的に活かし、ビデオデータの複雑な時空間パターンを捉えます。

(2+1)D ResNets（2017）

(2+1)D ResNets は3D ResNets に着想を得たものです。ただし、主な違いは層の構成方法にあります。このアーキテクチャは、2D畳み込みと1D畳み込みの組み合わせを導入します。

  • 2D畳み込みは、フレーム内の空間的特徴を捉えます。
  • 1D畳み込みは、連続するフレーム間の動きの情報を捉えます。

このモデルは、ビデオデータから直接時空間特徴を学習でき、行動認識のようなビデオ分析タスクでより良い性能につながる可能性があります。

  • 利点:
    • 2つの演算の間に非線形な整流（ReLU）が追加されることで、同じパラメータ数でも、完全な3D畳み込みを使うネットワークと比べて非線形性の数が2倍になり、より複雑な関数を表現できるようになります。
    • 分解によって最適化が容易になり、実際に訓練損失とテスト損失が低くなります。

現在の研究

現在、研究者たちはより深い3D CNN アーキテクチャを探求しています。もう1つの有望なアプローチは、3D CNN を注意機構のような他の技術と組み合わせることです。それと並行して、Kinetics のような、より大規模なビデオデータセットの開発も進められています。 Kinetics データセットは、人間の行動認識の研究でよく使われる、大規模で高品質なビデオデータセットです。幅広い人間の活動をカバーする数十万本のビデオクリップを含んでいます。

現在の研究

自己教師あり学習: MoCo（Momentum Contrast）

概要

MoCo は、自己教師あり学習の分野で著名なモデルで、対照学習のアプローチを使って、ラベルのないビデオクリップから特徴を抽出します。モーメンタムベースのキューを利用することで、大規模なビデオデータセットから効果的に学習し、行動認識やイベント検出といったタスクに最適です。

主な特徴

  • モーメンタムエンコーダ（Momentum Encoder）: モーメンタムで更新されるエンコーダを使い、表現空間の一貫性を保ち、訓練の安定性を高めます。
  • 動的辞書（Dynamic Dictionary）: キューベースの辞書を用い、対照学習のために大きく一貫した負例の集合を提供します。
  • 対照損失関数（Contrastive Loss Function）: 対照損失を活用し、正例と負例のペアを比較することで、不変な特徴を学習します。

効率的なビデオモデル: X3D（Expanded 3D Networks）

概要

X3D は、ビデオ認識タスク向けに設計された軽量な3D ConvNet モデルです。3D CNN の概念を基盤としながら、高い性能を維持しつつ、パラメータ数を減らし計算コストを下げるよう最適化されています。そのため、リアルタイムのビデオ分析や、モバイルデバイス・エッジデバイスへのデプロイに適しています。

主な特徴

  • 効率性: パラメータ数を大幅に減らし、計算コストを抑えながら、高い精度を達成します。
  • 段階的な拡張（Progressive Expansion）: ネットワークの次元（深さ、幅など）を体系的に拡張するアプローチを用い、最適な性能を引き出します。
  • デプロイしやすさ: 計算リソースが限られたデバイスにも簡単にデプロイできるよう設計されています。

リアルタイムビデオ処理: ST-GCN（Spatial-Temporal Graph Convolutional Networks）

概要

ST-GCN は、リアルタイムの行動認識に特化したモデルで、特にビデオシーケンスにおける人間の動作の分析に使われます。時空間データをグラフ構造でモデル化し、人間の関節の位置と動きを効果的に捉えます。このモデルは、監視やスポーツ分析におけるリアルタイムの行動検出などに広く使われています。

これらの最先端モデルは、ビデオ分類、行動認識、リアルタイム処理といった分野で優れた性能を発揮し、ビデオ処理の発展に重要な役割を果たしています。

主な特徴

  • グラフベースのモデリング（Graph-Based Modeling）: 人間の骨格データをグラフとして表現し、関節の接続を自然にモデル化できます。
  • 時空間畳み込み（Spatio-Temporal Convolutions）: 空間方向と時間方向のグラフ畳み込みを統合し、動的な動きのパターンを捉えます。
  • リアルタイム性能（Real-Time Performance）: 高速な計算に最適化されており、リアルタイムのアプリケーションに適しています。

まとめ

ビデオ分析モデルの進化は目を見張るものがあります。これらのモデルは、他の SOTA モデルの影響を強く受けています。たとえば、Two-Stream Nets は ConvNets に触発され、(2+1)D ResNets は3D ResNets に着想を得ました。研究が進むにつれて、今後さらに高度なアーキテクチャや技術が登場することが期待されます。
