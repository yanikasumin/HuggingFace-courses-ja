モデル最適化のツールとフレームワーク

TensorFlow Model Optimization Toolkit（TMO）

概要

TensorFlow Model Optimization Toolkit は、機械学習モデルをデプロイ向けに最適化するためのツール群です。 TensorFlow Lite の訓練後量子化ツールを使うと、重みを8ビット精度に変換でき、訓練済みモデルのサイズを約4分の1に削減できます。 このツールには、訓練後量子化が不十分な場合のために、訓練中のプルーニングと量子化のための API も含まれています。 これらは、レイテンシと推論コストの削減、リソースが制限されたエッジデバイスへのモデルのデプロイ、既存のハードウェアや新しい専用アクセラレータ向けの最適化された実行を支援します。

セットアップガイド

TensorFlow Model Optimization Toolkit は pip パッケージ tensorflow-model-optimization として利用できます。パッケージをインストールするには、次のコマンドを実行します。

pip install -U tensorflow-model-optimization

ハンズオンガイド

TensorFlow Model Optimization Toolkit の使い方についてのハンズオンガイドは、このノートブックを参照してください。

PyTorch の量子化

概要

モデルの最適化について、PyTorch は通常の FP32 モデルと比べて INT8 量子化をサポートしており、モデルサイズを4分の1に、メモリ帯域幅の要件を4分の1に削減できます。 PyTorch は、深層学習モデルを量子化するための複数のアプローチをサポートしています。それらは次のとおりです。 1. モデルを FP32 で訓練し、その後モデルを INT8 に変換します。 2. 量子化を意識した訓練（quantization aware training）では、フェイク量子化（fake-quantization）モジュールを使って、順伝播と逆伝播の両方でモデルの量子化誤差を扱います。 3. 量子化されたテンソルを表現し、それを使って演算を行います。これらは、計算の全部または一部を低い精度で実行するモデルを直接構築するのに使えます。

PyTorch の量子化の詳細については、こちらをご覧ください。

セットアップガイド

PyTorch の量子化は、PyTorch パッケージ内の API として利用できます。使うには、PyTorch をインストールし、次のように量子化 API をインポートするだけです。

pip install torch
import torch.quantization

ハンズオンガイド

ONNX Runtime

概要

ONNX Runtime は、クロスプラットフォームの機械学習モデルアクセラレータで、ハードウェア固有のライブラリと統合するための柔軟なインターフェースを備えています。 ONNX Runtime は、PyTorch、TensorFlow/Keras、TFLite、scikit-learn、その他のフレームワークのモデルで使うことができます。 推論に ONNX Runtime を使う利点は次のとおりです。 - さまざまな ML モデルの推論性能を改善します。 - さまざまなハードウェアやオペレーティングシステムで実行できます。 - Python で訓練し、C#/C++/Java アプリにデプロイできます。 - 異なるフレームワークで作られたモデルで訓練と推論を行えます。

ONNX Runtime の詳細については、こちらをご覧ください。

セットアップガイド

ONNX Runtime には2つの Python パッケージがあり、1つの環境にはそのうち1つだけをインストールすべきです。 GPU サポート付きで ONNX Runtime を使いたい場合は、GPU パッケージを使ってください。 ONNX Runtime の Python パッケージは pip パッケージとして利用できます。パッケージをインストールするには、次のコマンドを実行します。

pip install onnxruntime

GPU 版については、次のコマンドを実行します。

pip install onnxruntime-gpu

ハンズオンガイド

ONNX Runtime の使い方についてのハンズオンガイドは、このノートブックを参照してください。

TensorRT

概要

NVIDIA® TensorRT™ は、高性能な推論を可能にするために、訓練済みの深層学習モデルを最適化するための SDK です。 TensorRT には、訓練済みの深層学習モデルのための深層学習推論オプティマイザと、実行のためのランタイムが含まれています。 選択したフレームワークで深層学習モデルを訓練した後、TensorRT を使うと、より高いスループットと低いレイテンシで実行できます。

セットアップガイド

TensorRT は pip パッケージ tensorrt として利用できます。パッケージをインストールするには、次のコマンドを実行します。

pip install tensorrt

その他のインストール方法については、こちらをご覧ください。

ハンズオンガイド

TensorRT の使い方についてのハンズオンガイドは、このノートブックを参照してください。

OpenVINO

概要

OpenVINO™ ツールキットを使うと、ほぼあらゆるフレームワークの深層学習モデルを最適化し、さまざまな Intel® プロセッサやその他のハードウェアプラットフォームで最高クラスの性能でデプロイできます。 OpenVINO を使う利点には次のものがあります。 - OpenVINO Runtime と直接リンクしてローカルで推論を実行するか、OpenVINO Model Server を使って別のサーバーから、あるいは Kubernetes 環境内でモデルの推論をサービングします - アプリケーションを一度書けば、好みのデバイス、言語、OS のどこにでもデプロイできます - 外部依存関係が最小限です - まず CPU を使って初回推論のレイテンシを削減し、モデルがコンパイルされメモリに読み込まれたら別のデバイスに切り替えます

セットアップガイド

OpenVINO は pip パッケージ openvino として利用できます。パッケージをインストールするには、次のコマンドを実行します。

pip install openvino

その他のインストール方法については、こちらをご覧ください。

ハンズオンガイド

OpenVINO の使い方についてのハンズオンガイドは、このノートブックを参照してください。

Optimum

概要

Optimum は Transformers の拡張として機能し、特定のハードウェアでモデルを訓練・実行する際の性能を最適化し、最大の効率を確保するためのツール群を提供します。急速に進化する AI の状況の中で、専用ハードウェアと独自の最適化が定期的に登場し続けています。 Optimum により、開発者は Transformers 本来の使いやすさを保ちながら、これらの多様なプラットフォームをシームレスに活用できます。 現在 Optimum がサポートしているプラットフォームは次のとおりです。 1. Habana 2. Intel 3. Nvidia 4. AWS Trainium and Inferentia 5. AMD 8. FuriosaAI 9. ONNX Runtime 10. BetterTransformer

セットアップガイド

Optimum は pip パッケージ optimum として利用できます。パッケージをインストールするには、次のコマンドを実行します。

pip install optimum

アクセラレータ固有の機能のインストールについては、こちらをご覧ください。

ハンズオンガイド

量子化のための Optimum の使い方についてのハンズオンガイドは、このノートブックを参照してください。

EdgeTPU

概要

Edge TPU は、エッジで AI を実行するために設計された Google の専用 ASIC です。小さな物理的フットプリントと電力フットプリントで高い性能を発揮し、エッジでの高精度な AI のデプロイを可能にします。 EdgeTPU を使う利点には次のものがあります。 - Cloud TPU や Google Cloud サービスを補完し、AI ベースのソリューションデプロイのための、クラウドからエッジまでの一貫したハードウェア＋ソフトウェアのインフラを提供します - 小さな物理的フットプリントと電力フットプリントで高い性能を発揮します - カスタムハードウェア、オープンなソフトウェア、最先端の AI アルゴリズムを組み合わせ、エッジ向けの高品質でデプロイしやすい AI ソリューションを提供します

EdgeTPU の詳細については、こちらをご覧ください。

EdgeTPU のセットアップと使い方のガイドについては、このノートブックを参照してください。
